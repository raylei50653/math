## 完整分量 forcing 與兩條短鏈

只讀原未加可選原弦零值的 307,197 欄 family，其 SHA256 為
`542ee11de93a846bfbc321b098214b153c5b600318ba2e0bc5621a73ad2a55ad`。
每份實際 D 著色的完整 Kempe orbit 都在這個必要 family；不同著色的
partitions 不會被拼成一份實際分量。以下每一步都先取當前實際完整著色，
再取其實際完整分量，攜帶所有原私有頂點一起換色。

A 的 03|12 half-row `12302027` 僅有原欄 306985。全部 boundary components 是

```
03: {a}, {q,v};
12: {n,u4,u3,u2,u1,L,w,t}, {c,s}.
```

交換完整 `K03(q)` 得 44050；交換完整 `K12(c)` 則得 44520。
兩者各是由指定原頂點確定的 involution，故完整 fibres 分別注入相應終點。

44050 的 01|23 half-row `6709686` 的**全部** incident columns 是

```
39614,39615,39624,39625,47233,47239,65506,65510,67455,67457.
```

十型中 23-components 在 `{s,v,t}` 上恰為 `{s,v,t}`，或 `{s,v},{t}`。
因此在當前實際著色上交換 `K23(s) ∪ K23(t)`，重合分量只交換一次，
其 boundary contacts 必恰為 `{s,v,t}`。這個同一 D 上的 involution 得
44071，並保持 u2、u4 的原色 2。故

\[
Z_A\le Z_{44050}\le Z_{44071}.
\]

B 的 03|12 half-row `12302051` 僅有原欄 306993。全部 components 是

```
03: {a}, {q,w};
12: {n,u4,u3,u2,u1,L,t}, {c,s,v}.
```

先交換 `K03(q)` 得 44046；再交換完整 `K12(c)` 得 44107。
兩個 palettes 互不相交，兩作用的分量頂點集不受另一作用改變，合成亦為
involution。故 `ZB ≤ Z44107`。

由三個終點的原邊同色，即得：

| 假設實際原邊 | A 的完整來源鏈 | B 的完整來源鏈 |
| --- | --- | --- |
| u4v | `ZA ≤ Z44050 ≤ Z44071 = 0`，u4=v=2 | `ZB ≤ Z44107 = 0`，u4=v=2 |
| u3s | `ZA ≤ Z44520 = 0`，u3=s=1 | `ZB ≤ Z44107 = 0`，u3=s=1 |
| u2v | `ZA ≤ Z44050 ≤ Z44071 = 0`，u2=v=2 | `ZB ≤ Z44107 = 0`，u2=v=2 |

每列都與 `ZA+ZB>0` 矛盾。其他同時存在的原弦仍屬原 D；完整 Kempe
交換自然保持其合法性。若強迫終點在某原邊同色，就表示假設的完整來源
著色不存在，不能藉選不同外側著色規避。

## u2w：B 的短鏈與 A 的三層完整零 DAG

44046 的 01|23 half-row `6709662` 的全部 incident columns 是

```
39581,39582,39599,39600,47213,47224,65493,65500,67449,67452.
```

十型中 23-components 在 `{s,w,t}` 上恰為 `{s,w,t}`，或 `{s},{w,t}`。
交換實際 `K23(s) ∪ K23(t)` 得 44064，其中 u2=w=2。因此

\[
Z_B\le Z_{44046}\le Z_{44064}=0.
\]

A 的排除使用以下同源全稱零規則，而非假設某個單一共同 component：

1. 若某字面 state 在原邊 u2w 同色，它的完整 D fibre 為空。
2. 對 state s 選一份 half-row h。若 h 的**全部**原 incident columns
   各含一份已證空的完整 fibre，則每欄的非負重數 X 都為零，由原完整
   同源方程 `2 Zs = Σ(j incident to h) Xj` 得 `Zs=0`。

第二條亦可直接對實際 orbit 證：假如存在完整 s 著色，其當前完整 orbit
必為 incident family 中的一欄；對該實際欄獨立翻轉實際分量可到達欄內
已證空的 fibre，矛盾。所有私有分量都留在同一 D 和原 X 重數內。

[精確證書](certificate.json) 的 u2w 分支按此規則拓樸排序：67 個原邊
直接零、17 個深度一零、4 個深度二零、1 個深度三零，共 89 個具名字面
states；兩 target 的零深度分別為 A=3、B=2。每個非葉節點逐一保存：
原 state、完整 literal tuple、所用 half-row、**全部** incident column IDs，
以及各欄中的已零 state 與其原 half-row。沒有省略任一 incident 型。

A 最後一層使用 half-row `10067529`，共有 32 個 incident columns：

```
144309,144310,144312,144313,144314,
146294,146295,146297,146298,146299,146301,146302,146303,146304,
146741,146742,146744,146745,146746,
166569,167386,167542,225180,225181,225800,225801,225802,
225925,225926,231383,231580,231611.
```

它們分別被已零集合
`{4551,4992,5082,5098,7179,43598,43901,43917,44358,44448,44464,46545,64041}`
覆蓋；逐欄對應與這十三個節點的全部先行證明見證書。這是有限完整的
歸納證明，不是「目標在截斷探索中未出現」。因此 A=B=0，原 u2w 亦不可能。

## 2. 從原 D 混色接點降到同一原 E，不漏 strip 的接合

L 型的原 A 如上，六個原 P 點的完整外鄰列表全已固定。對 palette01，
P 中只有 n、u3、u1 色1；它們彼此不相鄰，各自與 E 的01交集恰為：

```
n–a，u3–z2，u1–z4。
```

這三個 P 點是各自接在單一原 E 點上的葉子。u4、u2、L 色2，不在此
palette；Y1 也不接任何 P 色1點。因此 strip 不能把兩個原本不同的 E01
分量接成一塊。原 D 與原 E 對 E 頂點的01連通關係**完全相同**；D 的
完整 K01(Y) 碰 n／u3／u1，分別恰當 E 的同一分量碰 a／z2／z4。

這裡沒有重新選 E：每個點仍是同一份完整著色的原點，所有 E 邊／附件保留。
所以若完整 mixed 必要證書已迫

```
F：K01^E(Y) 包含同一份著色的 {a,z4,Y,c}，
```

則可直接使用同一個實際 E01 分量，而非四份各自可行的 endpoint 路。
本項不自行證 F；下文分別標明哪些命題只需 Y連c、哪些需要 Y連z4。
F 已由[父完整原E支持閉包](../FULL_E_PROOF.md)證得；本幾何證明明確引用
該必要閉包，不把較弱單palette存活型或探索結果升格為來源。

## 3. 一條原03 crosscut 分隔完整原12兩塊，01必在色0交會

令 z0=v（target44459）或 z0=w（target44466），兩者色均為0。
原完整 E 的03 boundary contacts 是

```
K03(a)：{a,z1,z2,z3,z4,z5}；  K03(q)：{q,z0}。
```

全部原 boundary-free03分量仍保留。取**同一份實際著色**中任一條
`Q:q→z0` 的簡單03原路。因為 K03(q) 的 E boundary contacts 恰兩點，
Q 的內部不遇 E boundary，故是原 E disk 的 proper crosscut。
它將 E 分成兩側：

- c側的原 boundary arc 為 `q,c,s,…,z0`；
- 另一側的原 boundary arc 含 `Y,t,a,z1,…,z5`。

原完整 E12 塊為：44459 的 `{Y,t,w}` 與 `{c,s}`；44466 的 `{Y,t}` 與
`{c,s,v}`。12與 Q 的03原點完全不交，所以**整個** K12(Y) 都在另一側，
**整個** K12(c) 都在 c側。不能只說它們各有一條可行路；這是兩個完整
實際分量被同一條原 Q 分隔。其他私有12分量可能落在任一側，不刪除。

若同一原 E01 分量連 Y與c（F 的一部分），任一條實際01原路 `P:Y→c`
都須穿過這條 Q。兩 palette 交集只有色0，故

```
K01^E(Y) ∩ K03^E(q) 含至少一個色0的原點。
```

同理，F 給的 a→c 路也須穿 Q。以上同時使用**同一張 E、同一份著色**；
Q和P可從這一份圖中選取，沒有在不同模型間拼交點。交點不屬任何12分量，
不能把這個結論寫成兩個原12塊已相接。

**是否必有私有交點。** 若 K01(Y) 不含 z0，Q的兩端 q3、z0=0 都不在 P
上，故交點必為原 E 私有內點。由 proper crosscut 的兩側分離，可在 P、Q
的交點中選一個 X，使兩條01支與兩條03支在 X 的原 rotation 中交錯；
四條原鄰邊的對端色依次為 `1,3,1,3`。原 d(X)≥5；若恰五度，剩餘第五
原鄰點必色2，因它插在一對相鄰的1、3之間，須與兩者都異色。

若 K01(Y) 含 z0，交會可能只經原 rim 點 z0；本項不冒稱必私有。v,w 是
原01邊，所以同一01塊包含其中一點便包含兩點。這個分案對兩 target相同。
上述交錯本身尚未迫兩個12 boundary塊合併，也沒有迫一個0點同屬12分量。

## 4. Y到z4的原01短路：距離至少3；等於3時只有兩個完整star

本節只需 F 中的同一 E 連通 `Y↔z4`。端點色分別為1、0，任何01路
長度為奇數。原 S induced 且 Y、z4不相鄰，所以不可能一邊，最短路≥3。

若存在三邊原路，寫作

```
Y1–U0–V1–z4(0)。
```

U、V 必是 S外原點。U若在S，原Y−U邊與Y的僅有兩個S鄰點z5=3、q=3
矛盾；V的色1而原 S∩D 只有Y這一個色1點，V≠Y，故亦不在S。
開原路Y–U–V–z4全部在S外，不能穿越原S邊。

原簡單C5

```
Q5=(Y,U,V,z4,z5)
```

的另一側沿用兩條原S邊z4–z5–Y。原S內八點全部在Q5同一側；若它們在
Q5有界側，違反原C5 pocket最多一內點。因此Q5的有界側在S外。
Q5不是原外框B，原C5 pocket定理給恰下列二型。

**型 I：Q5有界側空。** 完整三角化須有兩條對角。所有候選中，Y−V與
U−z4由同色禁止，Y−z4由原induced S禁止；唯一可用是

```
z5–U、z5–V，兩條原邊都必存在。
```

外側三個原面給 z5 的完整外 link 弧 `Y,U,V,z4`；原 S內側已有全部原面，
其另一 link 弧是 `Y,L,u1,z4`。兩弧共同封滿原 z5 cyclic link，無空隙
可插未知鄰點，故精確得到

```
d_G(z5)=6，N_G(z5)=(L,u1,z4,V,U,Y)，允許整體反向。
```

**型 II：Q5有界側恰一個原五度中心K。** 原 pocket 給完整五輪，故

```
φ(K)=2，d_G(K)=5，N_G(K)=(Y,U,V,z4,z5)。
```

色2由它接Q5全部0、1、3色迫出。外側 link 弧現在是 `Y,K,z4`；與同一
原內側弧 `Y,L,u1,z4` 拼合，封滿 z5 的完整 link，故

```
d_G(z5)=5，N_G(z5)=(L,u1,z4,K,Y)。
```

這是兩個相鄰的原五度點 z5、K，並非新加中心。原 C3 空內部還迫
`z5–U、z5–V` 在型II皆為原非邊：它們是K完整五輪上非相鄰rim點，若
有邊即產生含另一原鄰點的非面三角形。兩型的原邊／非邊精確相反。

因此：若原來源沒有這兩個原星型，原 E 中 Y與z4的最短01路必至少五邊。
本項未證兩型違反來源；不能以「看見原W5」便套用別的來源的排除，也
不能刪除K或搬動U/V的更外側附件。型I／II中的其餘所有原點均留在E。

## 5. Y到原c的二邊路另迫原q鄰點

若原 K01(Y) 有二邊路 `Y1–U0–c1`，則原簡單C4

```
(Y,U,c,q)
```

由原 C4 pocket 有界側空。三角化須有一條原對角；Y−c同色，故原邊
`U−q` 必存在。於是 U∈K03(q)，與第3節的色0接觸相容。

U必是原D私有點：原rim色0候選只有a、z0；Y−a因原S induced而不存在，
c−z0因profile0無rim弦而不存在。原q已有互異鄰點
`{L,Y,p,h,b,c}`，再加U，得到 `d_G(q)≥7`。這是這條短路的精確原度數
義務，尚不矛盾於原q無度數上界的完整來源。

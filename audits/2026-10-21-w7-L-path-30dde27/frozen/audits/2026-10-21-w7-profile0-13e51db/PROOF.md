原 G、C5 色框、941、全域最小性、所有原附件、所有完整 fibres 及 cap lifts

## 1. 任意原外點的接觸與唯一原第三面點

固定原 induced 圈

```
C=(n,h,L,u1,u2,u3,u4), int_G(C)={R}。
```

令 `W=N_G(V(C)) \ (V(C)∪{R})`。每個 W 點都是閉 W7 外的原點。
[既有原外側接觸引理](frozen/audits/2026-10-21-w7-structural-30f2d19/geometry/PROOF.md)
給每個 w 的非空接觸集合 `A(w)=N_G(w)∩V(C)`：或一點，或原 C 上的一條邊。

若 `A(w)={i,j}` 且 ij 是 C 的原邊，則三角形 ijw 的有界側為空，故是原
三角面。w 在 C 外，因而 w 必是 ij 唯一的**外側**第三面點。這也證明
不同 C 邊的外側第三點互不相同。不是只依靠當前著色排除第二個接點。

將每個 C 點的完整外側 link 弧寫為：前一邊第三點、所有其餘外側鄰點、
後一邊第三點。上述唯一性證明：每個「其餘外側鄰點」恰有一個 C 接點；
這些列表兩兩不交，也不碰任何第三面點。個別完整 link 本身不重訪原點。
因此七條外側 link 弧依次接合，得到遍歷 W 恰一次的原簡單圈 S。

## 2. 原外邊的兩端必共用 C 接點

**引理。** 若 x,y∈W 且 xy 是原邊，則 `A(x)∩A(y)≠∅`。

反設兩接觸集合不交。先假設可選 i∈A(x)、j∈A(y)，且 i,j 在 C 上不相鄰。
原圈

```
Q=(R,i,x,y,j)
```

是五個不同原點構成的簡單 C5，且不可能是原外框 B。原路 i–x–y–j 的
內部全在 C 外；原路 i–R–j 在閉 W7 內。兩條開 i–j 的 C 弧分居 Q 的
兩側，這與原外側接觸引理的 Jordan 論證相同，只把外路的一點改為兩點。
因 i,j 不相鄰，兩條開弧均至少含一個原 C 點。

若 Q 有界側所含的開 C 弧至少有兩個點，直接違反原 C5 pocket 定理。
若恰有一個 k，該定理迫 k 為 Q 唯一內點及完整五度中心。因此 k 接 Q 的
全部五點，特別同時接 x,y，得到 `k∈A(x)∩A(y)`，仍矛盾。未知外側附件
只可能增加 Q 內點，不能消除這兩種矛盾。

剩下的情形是：每對 i∈A(x)、j∈A(y) 都相鄰。兩集合各為單點或相鄰
點對，且不交；C 長七，沒有一個點同時鄰接一條 C 邊的兩端。因此唯一
可能是 `A(x)={i}`、`A(y)={j}`，其中 i,j 相鄰。

此時取原 C4 `Q'=(i,x,y,j)`。設 z 為 ij 的外側第三面點。R 與 z 是 ij
兩側原三角面 ijR、ijz 的第三點，且均不在 Q' 上：z 若等於 x 或 y，
便與單接觸假設矛盾。兩個三角面的內部不遇 Q'，故 R、z 分居 Q' 兩側。
無論哪側有界，都至少有一個原點，違反原 C4 有界側空。引理得證。

## 3. S 的全部原弦都排除

任一原 S 弦 xy，由第 2 節共用某原 C 中心 i。三角形 ixy 在原 G 中。
若 x,y 在 i 的完整 cyclic link 中不相鄰，該 link 的兩條開 x–y 弧都含
原鄰點，分居 ixy 的兩側；其有界側非空，違反原 C3 定理。因此 x,y
在完整 link 相鄰。

x,y 均為 i 的外側鄰點；i 的另一段 link 含原 C 鄰點與 R，不能提供
x,y 的相鄰間隙。故它們在 i 的外側 link 弧相鄰，恰是一條 S 邊。
這與「S 弦」矛盾。因此 `G[W]` 恰為 induced 原圈 S。

這段論證覆蓋同一 H 列表內的弦、不同 H 列表之間的邊、H 到其他第三
面點的邊、以及不共用原 C 中心的第三面點之間的邊。沒有按點對分別換圖。

## 4. Profile 0／1 的字面完整界面

沿用既有符號 `P=(n,u4,u3,u2,u1,L)`、五個路邊外側原第三點 z1,…,z5，
以及原完整 link 列表 H_n,H1,…,H4,H_L。其餘兩個 C 邊第三點是 p,q。
由既有完整 n link `(a,p,h,R,u4,z1,H_n)`，外路由 a 前往 z1 時須反向
經 H_n。因此原 S 的有序字面形式為

```
(p,a,reverse(H_n),z1,H1,z2,H2,z3,H3,z4,H4,z5,H_L,q)。
```

原 h 五度給 qp 原邊，原 n link 給 pa 原邊。每個 H 點恰有一個 C 接點，
全部 H 點與 z1,…,z5 均為 D 私有點；a 是原外框點，p、q 保留原身份。

令 `K=|H_n|+|H1|+|H2|+|H3|+|H4|+|H_L|`，則

```
|S|=8+K,   int_G(S)=V(C)∪{R},   |int_G(S)|=8。
```

第二個等式保留任意大小外側附件。理由是七個 W7 原三角面與 C 每個點的
全部外側 link 原三角面，沿原邊接成一個實際閉 disk，邊界正是第 1 節的
簡單圈 S。外側七條弧沒有重複點，亦沒有分支或另一邊界分量。這個 disk
完全由原面覆蓋，內點恰 C 與 R；不能再在其中插入未列原點。a 位於原外框，
整個面 disk 在原 G 的有界 disk 內，所以此側確為 S 的有界側。

因此 S 是一個**完整有序接合界面**：上述八內點 patch 的全部向外附件
都經 S，任意更外側原點仍留在同一固定外側 E 中。這只是定位完整界面；
本項沒有構造八內點以下、完整 S 支援相等的合法替代 H'。

**Profile 1。** 同一論證適用，但原 n 完整五度及原面 a–n–u4 迫 z1=a，
不另有 H_n。其界面與精確長度是

```
S=(p,a=z1,H1,z2,H2,z3,H3,z4,H4,z5,H_L,q),
K=|H1|+|H2|+|H3|+|H4|+|H_L|,
|S|=7+K,  int_G(S)=V(C)∪{R}。
```

此處 a 已作為 n–u4 的第三面點計一次，不能再次加一個原私有 z1。
兩型 S 均只在 a 接觸原外框 B；原 p、q 為不同原內點，其他 S 點均為
既有來源的原私有點。原 b 留在外側 E，原面 abp、bpq 也留在 E 側。

## 5. 完整界面的七個列表與全部 lifts

令 H 為 S 及其有界側八點所成的原 patch，固定任意字面色列
`σ:S→{0,1,2,3}`。若 σ 不 proper 於 induced 原圈 S，完整 fibre 即空。
若 σ proper，對每個原 C 點 t 定義

```
L_t={0,1,2,3} \ {σ(s):s∈N_G(t)∩S}。
```

這使用 t 在 S 的**全部**原鄰點，包含完整 H 列表；沒有只留端點、刪掉
顏色重複的原點身份，或忽略外側附件。H 的完整 σ-lifts 恰與以下集合雙射：

```
{(r,(c_t)_(t∈C)) : r∈{0,1,2,3},
  c_t∈L_t\{r} 對每個 t，且 c_t≠c_t' 對每條原 C 邊 tt'}。
```

雙射只是同一份完整著色的限制／拼接：r 是原 R 色，c_t 是原 C 各點色。
H 的邊恰為 S 邊、七條 C 邊、七條 R spokes 及已完全列出的 C–S 接觸，
故沒有漏掉其他相容條件。無解時給空 fibre，有解時保留每一份 lift。
尚未加入 S 列表限制的內部候選總數恰為

```
4 · χ(C7;3) = 4 · (2^7−2) = 504。
```

因此任意長原 H 列表都可直接套用這個固定七點列表關係，無需枚舉任意
大小的新來源圖。這不是完整來源實現，也未證某個更小 H' 與此關係相等。
要與同一外側 E 接合，仍須使用 E 與 H 的同一份完整 σ；不能只比各 L_t
的獨立非空性，因相鄰 c_t 不等與共同 r 是一份 lift 的聯合條件。


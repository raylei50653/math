# 兩份既有低 p 完整 fibres 迫兩個原接受扇區皆非空

本頁從已證的兩份完整 deletion-graph fibres，逐份接回**同一原 G**。
這補入前輪 941 計數控制沒有要求的原來源存在性條件。
原度數、全部附件及字面映射見 [SOURCE_CONTRACT.md](SOURCE_CONTRACT.md)。

令 `A_a=|F_01232(G)∩{h=a}|`、`A_b=|F_01232(G)∩{h=b}|`，計算固定
原字面框 `(x,y,a,b,c)=01232` 的全部完整著色。

**命題。** 在本輪完整 r6、原 p,h=ell 五度位置的來源契約下，

```
A_a>0 and A_b>0.
```

這包括原支持 941。兩個存在量詞分別由兩份完整著色見證，不宣稱同一份
著色同時滿足 h=a 和 h=b，也不把其 Kempe 分量或私有色值拼接。

## 1. 同一 deletion graph 的兩份已證非空 fibres

把原 a,c 識別為 z，刪原 b，得同一原 T0；再刪原 x,y,p，得

```
D_old=T0-{x,y,p}=R-p.
```

原 n 是兩篇舊 proof 中的 m。D_old 保留原 h,q,n,r,s,t，以及全部其他
未刪點的私有顏色及全部邊。已證的兩份完整非空 fibres 為

| 舊權威 | `(z,s,r,t,q,h,n)` | p 的全部 lifts | xy 的全部 lifts |
| --- | --- | --- | --- |
| cofacial low-p §3 | `(A,B,A,B,C,B,C)` | `{D}` | `{(C,D),(D,C)}` |
| low-p §4 | `(A,B,A,B,C,A,B)` | `{D}` | `{(C,D),(D,C)}` |

A,B,C,D 為互異顏色。第一列的非空性及全部接回見
[cofacial proof:93–118](../../2026-10-14-cofacial-fibres-676b102/pq/PROOF.md)；
第二列的非空性及全部接回見
[low-p proof:86–145](../../2026-10-14-lowpq-source-676b102/pq/PROOF.md)。
兩個存在性均由原全域最小性對實際較小共面商圖取得；不是用普通相同
支持代表取代 D_old，也不是由單獨的邊界指派可行性推斷延拓。

第一份舊證明的非空性明列「七點互異」。這個前提在本輪已核實：z 是
原 a,c 的商點，與全部原內點不同；q,r,s,t 是互異 apex；h 不等於 r,s,t
由原度數，且 h!=q 由完整 p link；n 不等於 q,h 亦由該 link，n!=r,s
由 pn 為邊而 pr,ps 為非邊；n!=t 由 `n=t iff a=4` 與 a>=6。故沒有
把條件式舊存在定理套用到未核對的 alias 支路。

## 2. 逐份恢復原 G，而非只恢復 T0

任取第一列的一份完整 D_old 著色。恢復 p=D，恢復 `(x,y)=(C,D)`；
這給一份完整 T0 著色，且全部未刪點保留原私有顏色。
沿原已知商映射拉回，將原 a,c 都賦色 A。每條原 G 中不 incident b 的
邊，要麼是原 T0 的一條邊，要麼與它有相同不等約束；所以全部正確。
最後原 b 的完整鄰集恰為 `{a,c,p,q}`，其色集是 `{A,D,C}`，故原 b 的
唯一合法色是 B。不存在其他 b 附件待核對。

得到原完整著色

```
(x,y,a,b,c)=(C,D,A,B,A), h=B=b.
```

同一全域置換 `C→0,D→1,A→2,B→3` 把完整著色送到固定字面 `01232`，
並保留 h=b，因此 `A_b>0`。

第二列逐份作完全相同的實際接回，原 b 仍唯一為 B，但現在原 h=A=a、
n=B=b。因此原完整著色為

```
(x,y,a,b,c)=(C,D,A,B,A), h=A=a, n=B=b.
```

同一類全域色置換給固定字面 `01232` 且 h=a，所以 `A_a>0`。
若選舊表的另一份 xy lift `(D,C)`，也各給完整原著色；本證明只需各
存在一份，沒有以兩份不同 witnesses 重複計數得到更強不當界。

更精確地，固定 `(A,B,C,D)=(0,1,2,3)`，令 d_a,d_b 是上表兩份**固定
字面** D_old fibres 的完整著色數。對每一份完整著色使用兩個 xy lifts，
並分別作全域正規化：第一份用 `C→0,D→1,A→2,B→3`，第二份用
`D→0,C→1,A→2,B→3`。兩個像分別有原 q=0、q=1，因此不重疊。由原
完整 G 著色可依 q 的字面值逆置換、刪原 b,x,y,p、合併原 a,c，恢復
全部原 D_old 私有顏色。故兩個映射各自單射，且

```
A_a>=2*d_a>0,  A_b>=2*d_b>0.
```

這裡上表第二列對應 d_a，第一列對應 d_b；兩者沒有被假定相等。

這個接回只恢復原 G，沒有提出新較小圖，故本頁不另宣稱嚴格縮減。

## 3. 原固定候選的直接後果及前輪控制

第一份著色有 `h=b`，刪 p,h 後，原 h 的全部鄰點 q,L,R,n 都與 b 異色；
故新增 bn,bL,bR 的三條 fan 邊全部 proper。同一份完整著色限制到固定 G_B，
仍為原 `01232`。因此本輪來源的 **G_B 必接受 01232**。

第二份著色有 `h=a,n=b`。原接受覆蓋在同一份著色上給 `R=q or L=b`，
所以 **固定 Q1,Q2 中至少一張接受 01232**。這是同一來源兩個不同位置的
候選接受事實，不是已得到其中任何一張的拒絕條件。

同一完整著色的限制還給出計數界

```
N_01232(G_B)>=A_b>0,
N_01232(Q1)+N_01232(Q2)>=A_a>0.
```

第一個限制可逆：fan 像中原 h=b，原 p 是原 a,b,q 三色的唯一缺色。
第二個對每份原 h=a 著色固定選 Q1（若 R=q），否則選 Q2；原已證覆蓋
保證後者可用，且原 p,h 也是唯一原接受 lift。故保留每份完整私有著色，
這些界沒有把局部投影數量誤當完整 fibres。

前輪三份 [941 共同計數控制](../../2026-10-18-smaller-bad-counts-e1617a2/A/PROOF.md)
的候選支持為 `(932,932,249)`、`(932,932,249)`、`(249,249,932)`。
249 不含 `01232`。所以前兩份違反本頁的 `A_b>0` 後果；第三份違反
`A_a>0` 後果。它們仍是舊必要條件的有效控制，但不是完整來源控制，
更不是來源實現。不能以此三份控制再阻斷加入本頁存在性條件的新方法。

這只排除這三份具名控制。要淘汰三候選四列合同，仍須在新完整條件下
證明每張滿足合同的候選都迫某一原非空 fibre 為空；不能從「三份舊控制
被排除」直接推出所有來源或所有新控制都被排除。

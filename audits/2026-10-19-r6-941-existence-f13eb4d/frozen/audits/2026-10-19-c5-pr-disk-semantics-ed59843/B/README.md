# B：從字面圖層編譯 P/R 的獨立核對

本目錄只讀取父層 `BASE.json` 指向的凍結輸入；不匯入來源的矩陣轉移函數。
編譯器逐份列舉實際局部圖的全部指派，完成後才和附件矩陣逐格比較。
以下是明確重建並驗證的操作，不宣稱重播缺件的原生成器。任意大小 disk 上的接合／完整 fibre
雙射理由由獨立 A 證明提供；此 B 證書提供局部窮舉證據。

對有序目前外框 `(b0,b1,b2,b3,b4)`：

- **P**：保留全部舊頂點與舊邊；加新點 `x` 及三條邊 `xb4,xb0,xb1`。
  新外框為 `(x,b1,b2,b3,b4)`；舊 `b0` 成為內點。
- **R**：圖不變，外框改列為 `(b4,b0,b1,b2,b3)`。

P 的局部圖含舊五邊形的五條邊及上述三條邊，共六點八邊；R 含原五點五邊。
邊界頂點身份、順序、所有附著與保留舊邊都直接出現在 `P_SPEC`／`R_SPEC` 中。
操作採「輸出列、輸入欄」矩陣 convention。

## 完整字面核對

`check_local_operators.py` 的 `compile_patch` 依次執行：

1. P 檢查全部 `4^6=4096` 份六點指派；R 檢查全部 `4^5=1024` 份五點指派。
   所有邊均作不同色檢查，分別留下 312／240 份 proper 局部指派。
2. 分別保留全部 240 份 proper 目標字面外框，每份又保留十個來源類的完整 fibre，包含空槽。
   P 的 2400 槽中 2088 槽為空；R 的 2400 槽中 2160 槽為空。
3. 每份 proper 外框至少使用三色，因此 restricted-growth 正規化唯一決定完整四色置換，
   包括可能未用的第四色。證書逐 witness 記錄六點／五點原指派及其
   `source_to_canonical`，並逐目標記錄 `target_to_canonical`。
   置換作用於整張圖的所有頂點；逆置換重建同一份完整著色，沒有重選內部 witness。
4. 每份 proper 目標的十維**整數計數向量**都等於其 canonical 目標列。
   每個 canonical 類的完整 `S4` 軌道恰含 24 份字面外框。
5. 編譯出的 200 個整數矩陣格和附件相同，再核對全部 1024 個形式 masks 的
   2048 次支援轉移及來源的 264 條轉移。

矩陣的非零來源列如下；`+` 表示整數加法。所有未列來源格的係數均為零。

| 01021 | 01201 + 01231 | 01201 |
| 01023 | 01203 | 01231 |

## 污染控制與重播

同一比較器拒絕四項控制：R 改旋轉兩格、P 漏掉 `xb0` 附著、略去 canonical 色置換、
反轉矩陣行列 convention。證書保存各項首個不一致的完整格座標和係數。

從 repository 根目錄重播：

```bash
python3 -B audits/2026-10-19-c5-pr-disk-semantics-ed59843/B/check_local_operators.py --check
```

`--check` 僅讀取、重新計算及逐位元組比較證書，不寫入檔案。
初次生成使用 `--write`；以 exclusive-create 寫入且已存在時拒絕，目的地限制在本 B 目錄內。
輸出固定排序，證書含編譯器自身、父層 BASE 及全部凍結輸入的 SHA-256。

這份有限局部證書沒有枚舉任意大小 disk，也沒有證明任意一般 disk 屬於 F/C 的 P/R 文法；
沒有新增 Lean theorem。其作用是把明確圖操作的完整字面轉移與附件矩陣接起來，
供 A 的任意 disk fibre 雙射與 C 的獨立全圖重播交叉核對。

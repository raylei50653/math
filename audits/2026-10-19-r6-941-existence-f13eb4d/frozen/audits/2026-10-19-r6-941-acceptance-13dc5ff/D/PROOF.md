## 1. 實際新十圈與完整七點 cap

假設原 c=5。原 c 的已知依序鄰點 b,q,s,x 之間，恰有一個剩餘點 u，
且原有序 link 路徑完整為 `(b,q,u,s,x)`，這不是封閉 link。理由是原三角面 bqc、xsc
及原框弧 b-c-x 已固定這兩側；原 c 的所有其他鄰點位於 q 至 s 的內側弧。
前輪完整刪邊表給 c 在 D10 的度數恰三。induced C10 保證第三個鄰點
u 不是原十圈的其他框點，因此 u 是 D10 的真正私有內點。

從 D10 刪 c 只刪下原兩個三角面 qcu、cus；同一實際 disk

```
F'=G-{b,p,h,c,x,y,r}
```

的外框為 `(a,n,R,L,q,u,s,v,w,t)`，十點互異，內面仍皆三角。
保留其全部私有點、原邊及實際嵌入，不要求新十圈 induced。
原 G 的七點 cap 是舊左右 cap 加回 c。固定一份完整 F' 著色 f，對 c 的
四個可能色逐一取：

```
c outside {q,u,s};
Left_c={(b,p,h): b outside {a,c,q,p},
                    p outside {a,q,n,h}, h outside {q,R,L,n}};
Right_c={(x,y,r): r outside {s,v,w,t,x,y},
                     x outside {c,s,y}, y outside {a,t}}.
```

原完整 lifts 恰為不交聯集 `⊔_c ({c}×Left_c×Right_c)`。
不能把不同 c 的左右 lifts 相乘；所有集合固定同一份完整 f，包括全部
私有顏色。完整原星保證沒有其他 incident 邊。
[cap-lifts.json](cap-lifts.json) 對全部2461個 proper 十圈色軌道保存每個
c 色的完整左右集合，空集合亦保留；它不是2461份來源實現。

## 2. c=5,q=6 的實際新弦

若另有原 q=6，則 q 已知的六個不同鄰點恰為
`b,p,h,L,u,c`。由原 p、h、c 的完整 facial links，q 的原 link 必依序為

```
(b,p,h,L,u,c).
```

因此原 Lu 是實際邊，新框上 L-q-u 的另一側為原三角面 Lqu。
這個邊不是根據著色假設增加的；q=6 的來源星已迫其存在。
所以每份新核心有 `f(L)=f(u)` 的完整 fibre 全空。

對同一 F' 使用前輪已證完整三角化分量交換 family：10798 columns，
包括所有可能的真實互補色對分量邊界分割及所有交換重數。每份完整著色

實際交換落入已證空 fibre。逐輪只引用前一輪的零格，故無循環推理。
原三拒絕的完整 cap 係數非負，故任一可接回原拒絕列的核心格亦全空。

## 3. 明確換框圖 H 及全部132個最小性比較

仍只假設 c=5。刪原框點 c，實際外框變為 `(x,y,a,b,q,u,s)`；沿暴露的外弧
`b-q-u-s-x` 在外面加 bu、ux，令

```
H=(G-c)+bu+ux,   B_H=(x,y,a,b,u).
```

兩弧在刪 c 所露出的同一外面內不交叉，且每一條在原 G 中都不是邊：若 bu
存在，原 triangle bcu 會不是 c 的四個指定原面之一；ux 同理。這裡沒有 bx
邊，不能把這條五點 link 路徑誤稱封閉五洞。兩弧把原 b-c-x 外弧
換成 b-u-x，留下三角面 bqu、usx。原 u 從內點升為外框點；所有未刪原邊
和私有點仍保留。H 是合法簡單 plane C5 disk。
原 G 有 k+5 點，H 有 k+4 點且仍是五框，所以完成內點數恰 **k−1**。
沒有新點，沒有漏算 u 的升框成本。這張圖明確改用 B_H，不能把它的字面
列當成原 `(x,y,a,b,c)` 列。

固定同一份完整 F' 著色，H 的全部 cap lifts 恰是上節左右公式把 c 換為
u；也就是額外檢查新邊 bu、ux，而原 c 不再有色值。由此得到 H 十個
固定字面列的完整矩陣 N。原 G 的完整矩陣記作 C；兩者共用同一核心
計數向量 Z，完整計數分別為 CZ、NZ。

checker 從每個 canonical 核心列的完整 lifts 建矩陣；若核心只用了 m 個
顏色，canonical 原框列的 lifts 先除以 `(4−m)!`，轉成一個固定字面框列
的係數。因所有 proper C5 列至少用三色，剩餘色置換在這些 lifts 上自由
作用，故每個商都是整數。沒有把色軌道總數當成一份固定字面 fibre。

全域最小性給完整 `Σ(H)∈K132`。對每個 M∈K132，若假定 `Σ(H)=M`，
則每個不在 M 的 H 列都空；非負 N 因而迫相應核心格空。加上原三拒絕
的零格，逐份進行同一完整交換閉包。132份比較全部由 checker 重建：

* 除1022、1023以外的130份，每份最後原01232係數全零，與941矛盾。
* 1022、1023的必要模型仍容原支持941；不宣稱來源可實現。

所以任意這種真來源的 H 必滿足 **Σ(H)∈{1022,1023}**，亦即 H 的後九個
字面列完整 fibres 皆非空。這是條件於 c=5 的任意大小定理；沒有把計數
控制當實圖。1022及1023都屬K132，故此比較沒有完成嚴格較小bad。

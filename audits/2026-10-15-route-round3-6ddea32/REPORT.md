## 2. 保 XOR 的連通性已閉合，正偶補尚未閉合

對兩份反方向匹配 M,N，指定邊 e,f 在對稱差中必同屬一個交替環，
或分屬兩個頂點不交的交替環。同環則翻一環；異環則同步翻兩環。
其餘交替環避開 e,f，可逐一翻轉。這給任意兩份 XOR 匹配之間的路徑，
無需假設偶補終點存在。

批次交換以同一補2-factor的全部切口、路徑奇偶及重接邊計算新奇環數。
兩交換環雖頂點不交，仍可能切到同一舊補環，不能逕將獨翻的變化相加。
舊補環支援不交時可相加；每個舊補環恰切一次時另有逐交換環的
精確下降公式。合法來源是否必供應這些充分前提，仍是未解義務。

原46點控制的全部37個 XOR 單環鄰居都不降低舊量；加入雙環後有
38個新鄰居，其中2個直接到偶補。這兩份交換共享舊補環，正式證據
使用聯合手術。同36點圖另有滿足 zxy 原面、zb 原邊、bx/by 原非邊、
d(z)=8與所有小割條件的標記，但完整最小來源、原小圈與空 fibres
仍未實現。這些控制都不是來源排除。

已有偶補時，原兩方向的完整 Tait 色雙射還可只交換包含 e/f 的一環
或兩環，不必全圖改色。它保存加權計數相等，但兩邊仍可能同為零。
固定 Petersen 控制的普通 XOR 交換圖已連通，偶補計數仍為零，僅用於
一般 cubic 域的反控制。所有操作不改原圖大小，沒有完成來源的嚴格下降。

## 3. 六接點的合法 J 變成三條具名邊的返回義務

保留 `J=U/(s=t)`，寫 `m=[s=t]`。J 有原三角面 `(m,v,w)`、`(z,p,q)`
及原邊 mz；所有原私有點與完整染色仍保留。以 Klein-four 的非零原邊
色差記 `e=vw`、`f=pq`、`g=mz`，則

    E：{p,q}∩{v,w}=∅  ⇔  d(e)=d(f)≠d(g)。

這不是僅改寫符號：在同一完整 J 染色及其嵌入對偶中，三標記的
交替環位置決定是否能一步返回 E。對初始 E-free 染色：

- 三邊同色時，每個涉及該色的雙色子圖中，g 必與 e 或 f 同環。
- e、f 異色且 g 與其中一邊同色時，該同色邊必在 e/f 雙色子圖中
  與另外兩邊至少一邊同環。
- 三邊全異色時，e、f 必在它們的雙色子圖中同環。

任一條件失敗即有一個完整交替環交換到 E；整個同色對 cube 能到 E
時，一個環已足夠。主 agent 另從零核對432份六點 proper 賦色與
165份標記環分割，見 [獨立局部證書](marked-patterns.json)。
這些是來源所有完整染色都必滿足的條件，未證來源無法滿足。

新的12點球面控制具有兩個具名三角面、mz、四條 cross nonedges、
最小度五及無非面三角形；其240份完整染色中24份滿足 E，但其餘
216份對所有上述交換封閉。主 agent 另以普通頂點 Kempe 交換直接
重枚全部1296次單分量操作，亦全部封閉，見
[獨立普通 Kempe 證書](vertex-kempe-independent.json)。其 split-U 的
`(d(z),d(s),d(t))=(6,4,2)` 違反來源要求，故它否決的是僅靠這些
較弱幾何條件的任意起點返回規則。另一翻邊控制保存96個可返回的
state/pair案例；三個控制均完整保留 J/U fibres 與全部 r lifts。

## 4. 720模型的共同原邊實現已被否定

此處的實現要求：在同一原圖上，為每個既定 abstract state 選一份
完整染色；選擇須與既定 S4 全域改色及指定 component switches 相容，
並實現指定 terminal partitions。它不要求原圖只有七個 pins，亦不設
隱藏頂點數上限。

只取模型的 Layer0，即432狀態／18個 S4 軌道。任一原頂點在全部狀態
的色值是一個 S4 相容色函數。僅要求每次指定交換使其保持原色或交換
該兩色，所有可能函數恰25個。原邊兩端必在全部狀態異色，故任一
共同原圖都映到這25個函數的最大允許圖，其邊數恰41。

在狀態0 `ABABCBC` 的 CD 分量中，模型要求 t 與 q 相連；最大允許圖
中 t 的可達函數恰 `{15,19,24}`，不含 q 的函數18。任何真正的 t–q
原路徑都會映成該圖的 CD walk，因此不可能存在。相同函數的多份
原頂點也無法補出缺失路徑。這已排除任意有限階的上述精確實現。

主 agent 使用不同搜尋：只從 canonical source states 產生約束、固定
變數順序前向過濾，429個搜尋節點得到同25個函數，再核對所有432個
literal states的102000項交換條件。首個斷開證據一致；詳見
[獨立實作](check_common_graph_independent.py)及
[獨立證書](common-graph-independent.json)。

這不否定原22列可來自別的 partition／switch 選擇，也不否定每個
abstract state 對應多份隱藏完整染色的 cover。第二輪抽象交換公理的
一致性仍成立；本輪證明其指定720模型不能直接當作共同原圖。

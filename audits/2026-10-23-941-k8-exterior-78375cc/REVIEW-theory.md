# K8 同一外側：連通包絡的必要性審查

2026-10-23；BASE `78375cc0e995c868c221605c24835d7e622f0091`。
本頁只證有限必要包絡的來源涵蓋，不聲稱包絡存活即有實際外側。

## 1. 固定外側，全部 lifts 共用同一連通分割

固定一張實際外側 `E`、一份完整外側著色 `e`、原有序 C5 的字面
`01232` 及有序 K8 的字面 tuple `t`。C5 與 K8 是不相交的兩圈；
K8 cap 的七內點全部在 E 之外。對每個 palette `ab`，令
`pi_ab(e)` 為所有著色在 `{a,b}` 中的 C5 與 K8 接點按 E 的完整
`ab` 分量所得的分割。兩圈的 `ab` 原邊都必併入分割。

對每份 cap 完整 lift `l`，cap 內的 `ab` 連通關係與同一
`pi_ab(e)` 取 join，恰給出完整圖中所有碰接點的 `ab` 分量。
每個 join block 可獨立交換；任意多個 blocks 同時交換也合法。
不碰任何接點的完整分量不改兩圈 tuple，可省略於這個必要觀測。

因此正確量詞為「存在一份外側分割，使每個 cap lift、每個完整分量
子集交換都通過必要條件」。不能替每份 cap lift 另挑分割。若交換後
C5 屬 `01021/01202/01212` 的同時全局 S4 軌道，就得到原來源的
拒絕列 witness，矛盾。若 C5 仍屬 `01232` 軌道，K8 tuple 必仍在
前輪殘餘，否則同一候選縮減已排來源。

一次交換未必碰到 `01021`：從字面 `01232`，直接單 palette 交換
能迫出的拒絕列是 `01202` 或 `01212`；`01021` 可成為後續義務。
例如完整 `03` 分量必連原 C5 的位置 0、3，完整 `13` 分量必連
位置 1、3；這兩項連通是 cap 與外側 join 的要求，不可直接改寫
成 E 單獨必連。

## 2. 相對 palette 不可消失

固定 C5 字面 `01232` 時，K8 不能獨立作 S4 規範化。每個前輪
canonical residual word 都須展開為其全部不同的字面 S4 變體。
因 C5 使用四個色，固定此 C5 已完全固定全局 palette；這些 K8
變體表示不同的相對配色，不能互相當成同一狀態。

交換後如需將 C5 改寫為 canonical `01232`，必將這個由 C5 決定
的唯一全局置換同時作用於 K8，再判斷後繼狀態。單獨 canonicalize
K8 可以用來查詢 S4 不變的前輪殘餘集合，不能用來合併固定 C5 的
狀態，亦不能作固定點傳送的狀態鍵。

## 3. 兩個互補 palettes 的平面必要條件

對 `01|23`、`02|13`、`03|12` 各一對，兩份外側分割的所有 blocks
由互不相交的實際分量承擔。因此可將它們合成兩圈全部 13 接點的
一份分割，並加以下必要條件。

**每圈的非交錯。** 固定其中一圈，將另一個洞填上，所得是 disk。
原不相交分量在這個 disk 中仍不相交，所以不同 blocks 不能在此圈
交錯出現 `A B A B`。對兩圈分別檢查都合法。這個論證不假設
annulus 可直接攤成單一有序 disk。

**跨圈 blocks 的次序。** 稱同時碰兩圈的 block 為 through block。
從兩圈 cyclic words 各刪去其餘 blocks，再壓縮相鄰相同標記（首尾
亦相鄰）。若有至少兩個 through blocks，所得每個標記只能出現
一次，而且兩個循環次序必一致；若兩圈的實際相對方向尚未核定，
可放寬允許反向。證明是從每個 through block 取一條簡單跨圈路，
這些路兩兩不相交；沿任一條路切開 annulus 得 disk，其他路的
端點次序必匹配。某 block 的其他接點若夾住另一個 through block，
其連通子圖會隔斷該 through block 至另一圈的路。

**一圈內的封閉口袋。** 對任一 block B，若它在某圈至少有兩個
接點，所有其他 through blocks 在該圈的接點必落在 B 的同一個
cyclic gap 中。取 B 連通子圖的細正則鄰域；其碰本圈所切出的
口袋中至多一個能碰另一圈。其餘口袋中的接點不能由與 B 不相交
的路走到另一圈。這也包括 B 本身不跨圈的情況。例如一圈的
`X,A,X,B`，其中 X 只碰本圈而 A、B 都跨圈，雖通過一般兩-block
非交錯，仍不能是實際 annulus 分割。

上述均只作必要條件；本頁不主張這些條件的聯合已足以構造
annulus 分割，更不主張三組互補 palette 分別通過即可由同一張
有色原圖實現。重疊 palettes 共享實點，其共同來源仍是額外義務。

## 4. 固定點刪除的權限

若在某候選狀態，任何真實 E 都必提供的分割已全部被上述條件
及完整 lifts／完整分量子集傳送排空，則該狀態確實不能是來源
witness。將已排狀態再當作所有後繼必須避開的狀態，可歸納迭代。
實際來源的全部 `01232` 著色所給狀態集合在每一步都被保留。

反過來，有限必要包絡的固定點非空只給未排狀態。不同狀態的
分割選擇可能不能出自同一 E，不同 palettes 的分割也可能不相容；
沒有實際圖、完整四列 fibre 關係或相容來源證書時，不得報成
「同一外側可以實現」。

## 5. 可嚴格加強為七個 C5 rows 的共同固定點

四個色的 proper C5 恰有十個全局 S4 軌道。刪去三個拒絕列後，
其 canonical rows 為
`01012,01023,01201,01203,01213,01231,01232`。
取狀態 `(q,t)`；q 固定為其中一個 canonical row，t 仍保相對 q
的全部字面 K8 配色。初始域在 q=`01232` 使用殘餘 D，其餘六列
使用完整 cap 關係 R（不假設這六列在來源非空）。

對每個狀態仍用同一外側分割、每個 cap 完整 lift、每個完整分量
子集。此時交換後任一非拒絕 row 的後繼都必留在目前狀態域，
而非只檢查返回 `01232` 的交換。C5 至少使用三色，故它的
canonicalization 對四個色有唯一延拓：若只見三色，唯一未見色
必映到 3。把此同一置換作用 K8 可得唯一後繼鍵。

這個加強仍有直接來源歸納：假設來源存在，取同一來源的全部完整
著色，把每份著色同時規範化於原 C5。所得狀態集包含至少一個
`01232` 狀態，最初位於上述域內；全部合法完整分量交換、cap
完整重新 lifts 都還是同一圖的完整著色，因此此狀態集永遠不能
被必要固定點刪去。若七-row 固定點沒有任何 `01232` 狀態，就
排除這個 cap 的原最小來源。其餘六列是否在固定點留下狀態不影響
這個結論；那些狀態本來不要求實際正性。

七-row 固定點非空且保留 `01232` 仍只是必要條件存活；它沒有
將各狀態及各 palettes 的分割實現為同一有限平面外側。

## 6. 隔一弧 cap 的一個完整 K8 軌道確實排除

本節限有序分配 `(1,0,1,0,0,0)`，K8 接點依序記 `v0,…,v7`，
C5 接點依字面 `01232` 記 `o0,…,o4`。令
`X={v0,v1,v2,v6}`、`Y={v3,v4,v5,v7}`。
前輪殘餘 canonical word `01023213` 的 **24 個相對字面變體**
分為下列三組，每組各八個；這是逐字面有限審核的分類，並未把
固定 C5 下的不同相對 palette 當成來源對稱。

| 使用的互補 palettes | 完整八個字面 K8 tuples |
| --- | --- |
| `01|23` | `01023213,01032312,10123203,10132302,23201031,23210130,32301021,32310120` |
| `02|13` | `02013123,02031321,13102032,13120230,20213103,20231301,31302012,31320210` |
| `03|12` | `03012132,03021231,12103023,12130320,21203013,21230310,30312102,30321201` |

對這 24 份，固定一份外側著色，枚舉其每個 palette 的全部接點
分割；每份分割都須通過全部 cap lifts、全部完整分量子集交換。
仍用前輪完整殘餘作交換後 `01232` 的必要域。所得完整清單存於
[EXCLUDED-24.json](EXCLUDED-24.json)；其中下列 **2／7 列** 強迫
是有限部分，後面的交叉／口袋矛盾是紙面平面部分。

第一組中 `01` 與 `23` 各恰兩份合法分割。它們分別使 X 與 Y
各自位於一個 E 分量；該分量可與其唯一 C5 block 接合或分離。
X、Y 在 K8 的 `v0,v3,v6,v7` 呈 `X,Y,X,Y`，而兩 palettes
互補，其分量必互不相交。填上另一洞後得到 disk 中兩條相交路
矛盾。因此第一組八份都排除。

第二組的 `13` 恰有兩份分割：它將 X 或 Y（記作 B）連成一個
E 分量，且可選是否併入 C5 block `{o1,o3}`。另一側 `02` 恰
有七份。設其四個 K8 點為 A 加 d；A 是 `{v0,v1,v2}` 或
`{v3,v4,v5}`，d 相應為 `v6` 或 `v7`。其中五份已把 A、d
連成同一分量，因此與 B 在 K8 交錯，立即排除。剩下兩份恰是

`(A∪{o0,o4}) | ({d,o2})`，或
`(A∪{o2}) | ({d,o0,o4})`。

故 A、d 所屬兩個分量都必跨圈。然而 A、d 位於 B 的不同 cyclic
gaps，撞第 3 節口袋必要條件。B 是否接 C5 不影響此矛盾。
例如 `02013123` 有 B=Y、A=`{v0,v1,v2}`、d=`v6`；兩個
`02` 選擇乘兩個 `13` 選擇正好給出四份較弱審核的存活控制，
四份均被同一口袋論證排除。

第三組同樣是兩份完整 B 分割對七份另一側分割。這次完整 B
屬 `03`，其 C5 block 是 `{o0,o3}`；另一側屬 `12`，兩個
root blocks 是 `{o1,o2}` 與 `{o4}`。五份合併 A、d 的情況
由 K8 交錯排除，另兩份迫 A、d 各接一個 root block，再由 B
的兩個不同 cyclic gaps 排除。X、Y 何者為 B 仍依各字面 tuple
逐份保留。故第三組八份亦排除。

這個 24 份排除 **不需要跨圈 blocks 的整體次序檢查**；兩圈
非交錯加口袋條件已足夠。固定同一 E 的一份著色後，互補 palettes
確實在同一圖中由互不相交分量承擔，全部 cap lifts 也確實與
同一 E 接合，所以排除的是實際接受 witnesses，沒有將各列
或各 lifts 的不同外側拼在一起。

因此本有序 cap 的前輪 116 個 canonical 殘餘接受 fibres 中，
`01023213` 的全部 24 相對變體均不可能，必要殘餘縮至 115。
這不表示其餘 115 個 fibres 可同時由同一實際外側實現，也未
排除該 cap 整支。

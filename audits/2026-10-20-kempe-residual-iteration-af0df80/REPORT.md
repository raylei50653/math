# 由同步觀測改成殘餘候選迭代

2026-10-20。可以把上一輪結果抽象為一個可正確反覆執行的規則：
**先傳輸真正留下的候選，再用這次共同觀測篩選；保留篩選結果，
不補滿成所有同摘要染色。** 互補色對的連續操作可另用分量翻轉
奇偶壓縮，但中途觀測造成的淘汰必須一起保留。
這進一步給出**試探→篩選→反向還原**的主動循環：實際染色回到

每輪至多4次實際交換，末端只留真正的那份入口染色。

這是本專案從有歧義摘要轉向精確歷史語義的迭代方式，不主張
候選集合更新本身是全新的數學理論。主規則有任意有限歷史的紙面
正確性；固定cell95的完整閉包已重播，384條舊假路徑全部拒絕，

## 1. 迭代的狀態與公式

固定原圖G、原五點有序框、完整proper染色集合X。
`J(c)`是三台共同觀測，`T_a`是具名rooted Kempe交換的partial bijection。
讀取初始共同觀測`j_0`後，令

```
R_0 = {c in X : J(c)=j_0}.
R_(t+1) = {T_a(c) : c in R_t, a合法於c, J(T_a(c))=j_(t+1)}.
```

`R_t`是經過整段實際歷史後仍可能的**當前完整染色**。
同一action可以有多種可能觀測；給定action及實際觀測後，
更新結果才是確定的。空集拒絕該歷史；非法action另外明記，
不當作原狀態的有效自迴圈。

```text
當前候選 R
    ↓ 每份候選各自交換其實際完整分量
傳輸後候選 T_a(R)
    ↓ 與本次三台共同觀測相符
下一輪候選 R'
```

**正確性。** 歸納於歷史長度：R_0恰是初始觀測的完整fibres；
若R_t恰是所有相容軌跡的當前染色，逐一實際傳輸再要求新觀測，
正好得到全部可延長的軌跡，沒有新增或漏掉見證。因此
`R_t≠∅`當且僅當這整段有限歷史有一條共同完整軌跡。
完整證明、非法輸入及來源對應見[理論](theory/REPORT.md)。

每個rooted交換在合法域為對合，故傳輸為單射；
篩選只會刪除，得到`|R_(t+1)|≤|R_t|`。
這是候選數不增，不是原圖變小，也不保證每步嚴格下降。

## 2. 為何不能只保留三台當前摘要

上一輪的錯誤步驟相當於

```
精確 R'  →  只留 J(R')  →  補回所有具有這份J的染色。
```

補回的染色可能沒有沿原歷史抵達，下一步便可以冒用它。
新規則只保留精確R'，因此「每條邊分別有見證」不能再被誤認為
「整條路徑有共同見證」。兩份不同歷史若得到完全相同的當前R，
則未來更新完全相同，可安全共用一個殘餘狀態；不用保存整段歷史。
若交付還須回溯原始來源身份，則另存原始／當前見證對應或原操作紀錄；
未來狀態共用不表示兩條歷史的原始來源也相同。

以稀疏矩陣記號，令`P_a`為完整染色的partial permutation transport，
`D_j`為共同觀測j的對角篩選，row incidence向量滿足

```
r_next = r P_a D_j.
```

多步只是依序合成`P_a D_j`。中間完整染色索引保留為同一個索引，
不在投影後重新獨立選見證。這也提供分層實作：
實際圖負責傳輸，三台負責共同篩選，剩餘集合負責歷史相容性。

## 3. 可以批次合併的部分

同一phase只用一組互補色對，例如`01｜23`。
這時兩份induced二色圖不變；對每份入口候選，可固定其實際
完整components，將重複翻轉按奇偶合併。各分量翻轉可交換次序，
同一分量翻兩次取消。跨phase才重建所需實際分量。

但一個phase必須保留兩項：

1. **存活入口候選集合S**：滿足phase中所有已提供觀測的原候選。
2. **淨傳輸F**：這個phase的分量翻轉奇偶所決定的終點映射。

然後`R_out=F(S)`。只在所有中途觀測已篩選完成後，才可收攏
操作紀錄；若仍需逐步重播歷史，另保存原觀測紀錄。
分量資料依每份完整候選建立，共同接框block名稱不等於
共同私有頂點集合。完整J的中途觀測仍可能需要重算混合色對；
本輪沒有證明整體運算時間改善。

**不能消掉篩選的反例。** 初始候選
`c=01012132、d=01012233`，令`a=(12,root1)`。
執行a，觀測到c這支的中間J，便只剩c對應的中間染色；
再執行a，回到原染色c。此phase的淨傳輸是identity，
但最終候選是`{c}`，不是`{c,d}`。

若取消`a;a`時也丟掉中途觀測，就會重新放入d；
第三步再用a並要求d那支的觀測時，錯誤批次法接受，精確法拒絕。
因此在合法域，

```
P_a D_j P_a = 一個對入口候選的篩選，
```

通常不是identity；全域上`P_a²`也只是合法域投影。
此負控制與全部phase檢查保存在[phase.json](phase.json)。

72個doubleton。從這些初始集合出發，枚舉所有action／共同觀測
所能抵達的精確殘餘集合，直到閉包穩定：

| 淨傳輸identity但篩選有資訊的觀測phase | 192 |

主實驗使用凍結轉移表，[獨立複核](review/REVIEW.md)從原邊、
全`4^8`字面指派及BFS分量重新建立系統後比較。

省略的action／觀測格都明定為空，非法另有診斷。
主checker另對含空狀態的337×30×192格全部核對。

「最多2」來自此圖完整J的入口fibre大小及單射傳輸；
如果只讀框色、改用其他圖或J1來源，不能直接沿用。
在線只需更新當前一兩份完整候選，但離線仍保留原圖、完整染色／
轉移資料。本實驗沒有證明總儲存更小；336種不確定候選集合
和264種實際單染色狀態也具有不同語義，不能混作同一種壓縮比。

此外，此圖任意兩份完整染色的未來J行為都可區分，
故任何保J與全部action的確定性單染色商至少要264類。
殘餘迭代改善的是歷史正確性與按需追蹤，不繞過這個辨識下界。

## 5. 主動迭代：試探、篩選，再還原

當候選中仍有c、d，而某個action word w能讓它們的共同J觀測不同，
可以執行w並逐步觀測，留下相容候選，再把實際已執行的actions
按反序各做一次。每步都是對合，故真正染色回到入口，
但被觀測淘汰的入口候選不會回來。

```text
入口候選 R → 執行區分試探 → 篩選 → 反序還原 → 較小的入口候選 S。
```

一般版本在第一次真的淘汰候選時就停止試探並還原。
若目前候選的未來J行為兩兩可區分，每輪至少刪除一個候選，
因此從m個候選至多m−1輪到singleton。這需要能執行實際交換並
讀取完整J，合法性由J決定；不是保證任意選的試探都有效。
若候選行為不可區分，此辨識義務本身就不能成立。
詳證及來源界線見[理論](theory/REPORT.md)。

固定95圖的72個doubleton都可用長度至多2的word區分。
[probe.json](probe.json)保存逐對最短試探及兩種真實起點的完整往返：

| 雙候選初始狀態 | 最短試探長度 | 本方案加反序還原的交換數 |
| --- | ---: | ---: |
| 48個 | 1 | 2 |
| 24個 | 2 | 4 |

144個實際起點分支全部回到原字面完整染色，末端候選恰為該染色的
singleton。120個原本singleton的J狀態不需要試探。
試探長度由paired-state BFS核對最短；2／4是這個往返方案的成本，
不宣稱所有可能還原策略中的最優總成本。
此處嚴格下降的是**同一入口的候選數**，原圖及實際染色都還原，
因此仍不提供研究主命題的較小bad。

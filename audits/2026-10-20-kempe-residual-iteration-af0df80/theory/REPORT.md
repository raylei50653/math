# 同見證殘餘迭代：精確歷史、部分置換與觀測遮罩

本輪把前輪的「保留真正抵達中間摘要的完整候選」寫成可直接迭代的
合同：**先搬運原有候選，再用共同新觀測過濾；絕不補回整個摘要 fibre。**
這是標準集合／belief 更新在本專案的具體化，不主張歷史上的新理論。
BASE 為 `af0df8081e79b51f8b24e17e01b2bd5572e46a0a`；前輪未提交成果
以[凍結 bytes](../INPUTS.json)為準，並非宣稱包含在 Git BASE。

以下沿用[凍結來源合同](../frozen/audits/2026-10-20-multi-kempe-machines-af0df80/SOURCE_CONTRACT.md)
及[前輪結果](../frozen/audits/2026-10-20-multi-kempe-machines-af0df80/REPORT.md)。
紙面命題適用於明列的固定有限圖；264、192、336等數字只屬 cell95。

## 1. 狀態、觀測與非法動作

固定同一完整圖 G、有序具名框 B、全部私有頂點及字面色名。
`X=Col_4(G)` 是全部 proper 完整染色；`J:X→Q` 是同一染色產生的
框色與六份接框分割，也就是前輪三台共同觀測。

對 action `a=(ij,r)`，其中 `r∈B`，令

```
D_a = {c∈X : c(r)∈{i,j}},
T_a(c) = 交換含 r 的完整實際 ij component，僅在 D_a 定義。
```

交換不改 ij induced graph，所以 `T_a(D_a)=D_a` 且
`T_a(T_a(c))=c`。每個 T_a 是其合法域上的雙射；沒有把非法 action
當成有效自迴圈，也沒有使用 hidden component swaps。

一份**殘餘狀態**是確切集合 `R⊆X`。已知初始觀測 o_0 及完整初始
來源集合 A 時，

```
R_0 = A ∩ J^(-1)(o_0).
δ(R,a,o) = T_a(R∩D_a) ∩ J^(-1)(o).
```

未另限制來源時 A=X；若來源 fibre 本來是空的，R_0 仍明列為空。
非空 R 在每次收到完整 J 後，都包含於單一 J-fibre。J 含框色，
所以給定 R 和 a，合法性是全員相同的；不會在同一 R 中一半合法。

`δ` 是以 **(action, 實際收到的觀測)** 為輸入的確定更新。
只有 action 而沒有新觀測時，應列出所有非空 `δ(R,a,o)` 分支，
不能任選一份新觀測。這與宣稱「由 J 和 action 決定唯一新 J」不同。

若 a 在 R 上非法，程式回報 `ILLEGAL`，不產生合法 Kempe 邊。
若某條記錄卻聲稱它成功執行並得到 o，則 δ=∅，該記錄不可實現。
若應用另要保存「嘗試後被拒絕」事件，須另定事件 `reject(a)`：
它只保留 `R∖D_a`，不表示一次成功交換。這項事件不納入本輪合法
action grammar。空集合可作不可行記錄的 sink，但不是完整染色。

## 2. 任意有限歷史的可靠性、完整性與原始見證

固定觀測歷史

```
h_t = o_0, a_1, o_1, …, a_t, o_t.
```

只計每個 a_k 都合法執行的歷史。令 `F_k=T_(a_k)…T_(a_1)`，
並將「所有前綴合法」納入其定義域。定義原始候選

```
A_t = {x∈A : J(x)=o_0,
       每個 F_k(x) 定義且 J(F_k(x))=o_k，1≤k≤t}.
```

**命題。** 逐步套用 δ 得到的 R_t 恰為 `F_t(A_t)`。因此：

1. R_t 中每一份染色都有一條從 A 出發、符合全部已記觀測的完整軌跡；
2. 任何這種完整軌跡的當前染色都在 R_t；
3. `R_t=∅` 當且僅當該有限歷史在指定 A、G、grammar 下不可實現。

**證明。** t=0 是定義。若結論對 t 成立，δ 恰先從每條已存軌跡的
末端執行合法 T_(a_(t+1))，再保留觀測為 o_(t+1) 的末端。
沒有新加入其他末端，亦未刪除任何符合新觀測的末端，故得到且只得到
延長後完整軌跡的末端。歸納完成。□

這是任意有限長度的命題，不需另測到某個固定深度才成立。
它也沒有假設 J 本身可確定更新。

因 T_a 在合法域單射，觀測只會刪候選：

```
|R_(t+1)| ≤ |R_t|，   A_(t+1)⊆A_t，   |A_t|=|R_t|.
```

當前 R_t 通常不是 R_(t−1) 的子集，因染色已被搬運；真正嵌套的是
原始來源候選 A_t。每一步可保存配對 `(原始x,當前F_t(x))`，或保存
action／觀測歷史並反序執行對合以重建原始 x。

兩段歷史若有**完全相同的當前集合 R**，其所有未來可行性相同，
可共用未來狀態與轉移快取；它們的原始見證身份及歷史仍可能不同。
若交付要求回溯到原始來源，應另保留這項 provenance，不能把共用
R 誤解為兩條歷史的原始候選也相同。

候選數不增加不等於嚴格下降。可無限循環而完全不刪候選，因此
本命題沒有給 `bad→success∨smaller bad` 或研究路線的終止證明。

## 3. 稀疏部分置換與共同觀測遮罩

用 X 的不可變完整染色 ID 作座標。令 row vector r 是 R 的0/1
incidence，`P_a[c,d]=1` 當且僅當 `c∈D_a` 且 `d=T_a(c)`；
其餘為0。令 D_o 是對角矩陣，在 `J(c)=o` 處為1。則

```
r_next = r P_a D_o.
r_t = r_0 P_(a_1)D_(o_1) … P_(a_t)D_(o_t).
```

可使用 Boolean 運算；此處各 transport 為部分單射，普通整數運算
亦始終得到0/1 incidence，不會把不同候選合成重複計數。
乘法可依結合律分批快取，但不能在中途把支援集合擴成完整 J-fibre。
多台的共同 D_o 必須在同一份染色列上測試；不能各台獨立換 witness。

部分性需要明記：

```
P_a² = D_(D_a)，
P_a D_o P_a = D_{c∈D_a : J(T_a(c))=o}.
```

第一式在合法域上是 identity，在非法域是0。第二式證明：
**做 a、觀測、再做 a，可能是一個非平凡的候選篩選器。**
完整染色雖回原點，知識狀態未必回原來的集合。

凍結反例給具體數字：

```
R_0={01012132,01012233}, a=(12,root1).
a(01012132)=02012231，a(01012233)=02012233.
```

觀測第一份結果的 J 時，只留下 `02012231`；再做 a 回到
`{01012132}`。若因 `a²=id` 刪掉中間動作及觀測，會錯誤補回
`01012233`。若之後第三次 a 又聲稱觀測到第二份結果的 J，
精確殘餘更新立即得∅；只按端點 parity 化簡會誤收這條記錄。

## 4. 互補色對 phase：可批次端點，不能丟觀測

將 action word 分成三種 alphabet 的連續 phases：
`{01,23}×B`、`{02,13}×B`、`{03,12}×B`。
固定一份 phase 起點染色 c。在 phase 內，兩份 induced graphs
及全部實際 components 不變；各有效動作是在其中一份固定 component
上翻轉，這些翻轉可交換。

令 K(c) 為該染色兩個色對的全部實際 components；對 word w，
`ε_K(w,c)` 為其 action roots 指向 K 的次數 modulo 2。只要各動作
合法，phase 端點就是在所有 ε_K=1 的 K 上翻轉。合法性亦可在 phase
起點判定，因 root 是否屬於其中一個色集不隨該 phase 改變。

**可用的快取。** 對每一份候選 c，在 phase 起點建立自己的 K(c)，
之後累積每個 prefix 的 parity，無須每一步重新搜尋該兩個色對的
components。不同候選即使具有相同接框 block，其全部私有頂點集合
仍可能不同：上述兩候選的 `(12,1)` 分量分別是 `{1,5,7}` 與 `{1}`。
因此不能拿某份代表的全頂點 component 套在另一份候選上。
同框 block 名稱可作對齊索引，實際頂點 membership 仍逐候選保存。

若每一步讀三台共同 J，就必須在每個已要求的 prefix 檢查觀測。
自己的兩份分割不變，其他四份 mixed-pair 分割仍可能提供資訊。
上節 aa 已是單一 phase、端點 parity 全0，卻可篩掉一個候選。
所以「只在切換 channel 時觀測」是另一個較粗的實驗合同。

精確 phase 摘要應包含：

```
P_w：逐候選的 phase 端點部分置換；
S：phase 起點中，全部合法性及中間共同觀測都通過的候選；
r_end = r_start D_S P_w.
```

S 是以 phase 起點為 anchor 的 survivor mask。它由所有 prefix
條件交集而成；完成這個交集後才可用端點 transport 一次搬運。
其正確性直接由第2節歸納或逐候選展開得到。端點 parity、survivor
mask 與來源染色 ID 缺一不可；無證明時不得把 D_S 刪掉或移錯位置。
換到另一種 alphabet 時，應按每份真正當前染色重建所需 components。

## 5. 按需局部分支的操作演算法

不必先把全部 J 類細分成全未來最小機器。從實際 R 出發，只在遇到
不同共同後繼觀測時建立分支：

```text
step(R, a, observed_o):
    if R is empty: return INFEASIBLE
    if a is illegal at the common boundary of R: return ILLEGAL
    buckets = empty map from joint observation to exact target set
    for c in R:
        d = T_a(c)                       # 使用 c 的實際完整分量
        buckets[J(d)].add(d)             # 三台均讀同一個 d
    return canonical_exact_set(buckets.get(observed_o, empty_set))
```

若尚未取得觀測，回傳全部非空 buckets 作待選的可行輸出。
此處 `ILLEGAL` 是操作請求的拒絕結果；若驗證的是已聲稱成功執行
的歷史記錄，則其精確殘餘為∅，與第1節的 δ 一致。
`canonical_exact_set` 只排序／去除相同完整染色 ID；hash 後仍核對
集合相等。不以同 J、同邊際、相同數量或未證明可用的換色商合併。

一個 action 的自身 channel 可由接框 block 更新；需要按需處理的是
其他兩台的 mixed-pair 資訊。若目前 R 的結果確實分岔，就保存這個
`(R,a)` 的實際分組，可在同樣 R 再訪時重用。沒有分岔也必須搬運
完整 R；唯一後繼 bucket 不等於它所在的整個 J-fibre。

這種按需分支可以避免預先掃描所有未來分支；它沒有免除真正後繼
計算，也不是只在「phase 切換」才更新。觀測歧義能在同一 phase
的第一步出現，正如 aa 例子。更小 surgery descriptor 若要取代
完整候選，仍須證其搬運與更新精確。

## 6. cell95 的壓縮下界與集合狀態數

凍結[完整實驗證書](../frozen/audits/2026-10-20-multi-kempe-machines-af0df80/experiment/certificate.json)
給出 `|X|=264`、J 有192類，其中120類為singleton、72類為doubleton；
全未來 refinement 為 `192→240→264`。

**單份真實染色的確定 quotient 下界。** 若編碼 `h:X→Z` 決定 J，
且保留每個 action 的合法性及確定後繼，即
`h(T_a(c))=δ_a(h(c))`，那麼相同 h 必給全部未來字串相同 J 輸出。
凍結深度二細分已區分所有264份染色，故 h 必為單射，`|h(X)|≥264`。
這只禁止合併這些不同的行為狀態，不禁止較省 bits 的編碼。
限制 alphabet、減少觀測或改變圖族後，不能直接沿用此下界。

**精確殘餘機器是不同物件。** 它把不確定的候選集合當成狀態，
可能比真實染色狀態更多。從任一完整初始 J-fibre 出發，每條實際
歷史都維持 `|R|≤2`；但不同歷史可能抵達許多不同 singleton／pair。
所有非空殘餘集合的上界為

```
120·(2¹−1) + 72·(2²−1) = 336.
```

若允許所有192個 J-fibres 作初始狀態，這個上界實際可達：
所有完整 fibres 一開始已在。對任何 doubleton `{c,d}`，
未來可辨識性給一段共同可執行、觀測最後首次分歧的 word。
兩份染色在首次分歧前 J 相同，故合法性亦相同；選擇 c 的觀測
即可留下 singleton `{w(c)}`。再按反序做各對合，精確搬回 `{c}`；
d 同理。因而全部264個 singletons 和72個原 doubletons 可達，
恰336個非空集合。若另計∅拒絕 sink，才是337個。

這項推導依賴凍結證書的 fibre 大小及可辨識性；本輪有限閉包重播
另行核對它，不能以公式代替實測。從某個指定單一初始 fibre 出發
的可達集合數可較少；`|R|≤2` 亦不是任意圖的統一界。

## 7. 主動探測、過濾、反序還原

殘餘更新亦給出一種保留原完整染色的辨識迭代：

```
選兩份當前候選 → 選能區分它們的 action word
→ 逐步執行並讀共同 J，首次確實刪候選時停止
→ 反序執行已走 actions，還原原完整染色
→ 對留下的原始候選重複。
```

**一般有限命題。** 假設固定有限 X 中不同完整染色可由未來共同 J
行為區分，初始非空 R 位於同一 J-fibre，且目前真實染色確實在 R。
若 `|R|>1`，上述一輪能保持真實染色，還原它至本輪起點，並嚴格
縮小以本輪起點為 anchor 的候選集合。

**證明。** 選 `c≠d∈R`，取第一次 J 分歧以前的區分 word。
該前綴在 c,d 上都合法：首次 J 分歧以前框色相同，根是否合法亦
相同，故不會先以單方面非法區分它們。
現場執行時，只要尚未刪任何候選，c,d 都仍在當前集合；共同 J
又使所有候選對下一 action 合法性相同，所以可安全繼續該 word。
最遲在 c,d 的預定分歧處，實際觀測必排除至少其中一份；若實際
觀測更早偏離它們的共同預測，就更早發生過濾，此時立即停止。
由第2節，真實染色不被刪除。將已走 action prefix 反序執行，
各對合把每份存活候選送回本輪起點，真實染色亦完全還原。
已排除的候選不因還原而補回，故原始候選嚴格減少。□

因此最多 `|R_initial|−1` 個這種 probe／restore 回合便能留下singleton。
這是回合數界，不是一般 action 長度界；區分 word 的成本仍依固定
圖及候選而定。每輪都在同一原圖上，還原後的實際完整染色相同；
下降的是不確定候選數，沒有縮小圖、構造較小 bad 或排除來源 fibre。

**cell95 的可檢驗方案。** 初始192個 J-fibres 中已有120個singleton，
其餘72個doubleton。由凍結細分 `192→240→264`，其中48對的最短
區分 word 長度為1，另24對為2。對每個doubleton選一份區分 word，
途中保存全部共同觀測，再反序還原，兩種真實起點都會回原染色，
而殘餘集合已成為該染色的singleton。故有以下方案上界：

| 初始 fibre | 數量 | 此探測／還原方案的交換數 |
| --- | ---: | ---: |
| singleton | 120 | 0 |
| 最短一動作可區分的 doubleton | 48 | 2 |
| 最短二動作可區分的 doubleton | 24 | 4 |

這給72個doubleton各自至多4次交換的保原染色辨識方案；
本輪逐對操作證書及獨立審查另行核對。`2×最短探測長度` 是本方案
的上界，未證全體可能的「辨識且還原」策略之最優成本。

此程序需要實際執行能力與每步共同觀測；不能從只列必要分割的表
憑空取得觀測。若把合法 grammar 限在某個固定目標 fibre 內，
區分 word 可能不再可用，必須在該受限系統重新證可辨識性。
本輪的全圖 rooted grammar 不因終點可還原，就自動成為 J1 的
固定框修復或一般來源排除。

## 8. 結果邊界

新迭代保證任意有限歷史的**完整來源一致性**，排除前輪那種中途
換同摘要 witness 的假路徑；它的代價是保存真正候選、transport 及
必要的 anchor／觀測遮罩。互補 phase 允許端點批次及 component
快取，沒有自動消除 mixed-pair 資訊成本。

這些一般紙面命題不等於已枚舉任意圖，亦沒有將有限 cell95 換成
原 r6／941／J1 來源。完整來源前提仍 `not triggered`；一般有界
狀態表示、來源 fibre 非空性／排除、嚴格下降與新 Lean 均未完成。

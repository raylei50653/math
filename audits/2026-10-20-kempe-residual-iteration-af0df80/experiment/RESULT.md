# 保留共同完整見證的殘餘迭代

本實驗已將上一輪的聯合監測器改成可精確迭代的有限 observer。
每步保存「仍與整段已見歷史相容的完整染色集合」，交換後再按新的
聯合觀測篩選。固定 cell95 上得到 336 個非空殘餘集合，另加一個
空集合拒絕狀態；此前 384 條假的二步觀測路徑全部拒絕，
45,888 條實際二步觀測路徑全部接受。

證據：[check.py](check.py)、[certificate.json](certificate.json)。
以下只處理固定 cell95、同一有序原框與根動作；J1 `not triggered`，
一般小摘要閉包保持 OPEN。

## 迭代規則

令 `J(c)` 為同一份完整染色的三監測器聯合值。
初次觀測 `j0` 後初始化：

```
R0 = {c : J(c)=j0}.
```

在原動作 `a` 與下一個實際觀測 `j_next` 下，更新：

```
R_next = { T_a(c) : c in R,
                     T_a(c) 有定義,
                     J(T_a(c)) = j_next }.
```

`R_next=∅` 表示這段動作／觀測歷史沒有共同完整見證，立即拒絕。
下一步直接使用此 `R_next`，不重新換成全部 `J^{-1}(j_next)`。
這個差別排除了在中途換掉完整 lift 的假路徑。

同一 J 值包含字面框色，故同一非空 R 內的動作合法性一致。
非法動作在表中標記 `action_status="illegal"`，沒有圖後繼，
也不設 self-loop；若聲稱該非法動作產生某個合法 J 觀測，則拒絕。
此標記與合法動作後觀測不相容、以及已進入空集合拒絕狀態分開。

## 完整有限閉包

以全部 192 個 J fibres 初始化，對每個新殘餘集合施全部 30 個動作、
按全部可能 J 輸出分組，直到沒有新集合：

```
192 → 288 → 336 非空殘餘集合，下一輪不再增加。
```

| 項目 | 數量 |
| --- | ---: |
| 原完整染色狀態 | 264 |
| 初始 J 觀測類別 | 192 |
| 初始單元素／雙元素 fibres | 120／72 |
| 閉包後單元素／雙元素殘餘集合 | 264／72 |
| 非空殘餘集合 | 336 |
| 加入空拒絕集合的總狀態數 | 337 |
| 非空殘餘集合的最大大小 | 2 |
| 非空目標的 `(R,a,j_next)` 轉移 | 5,136 |
| 合法／非法非空狀態動作列 | 5,040／5,040 |

證書保存全部殘餘集合、全部 337×30 動作列及所有非空目標。
每個動作列的 192 個觀測標籤都定義；未列出的標籤一律指向
空拒絕狀態 0。這是完整有限轉移表的稀疏編碼。
程式逐項重建核對了 `337×30×192=1,941,120` 個標籤。

337 大於原完整狀態的 264：本輪結果不是離線狀態機壓縮。
有用的較小量是單條在線歷史當下保存的候選數，上限為 2。
此數值上限來自這張圖每個初始 J fibre 至多有兩份完整染色，
不作一般圖上的固定上限。

## 原見證錨點

可另外用初始完整染色作鍵，保存「原見證 ID → 當前完整染色」。
每步將當前染色施同一原動作，再刪去不符合觀測的鍵。
因合法 Kempe 動作是 involution，對保留候選是單射：

```
原見證鍵集合 A_next ⊆ A_current ⊆ A0。
```

因此候選不會復活、也不會憑空增加。本圖 `|A0|≤2`。
程式對全部 46,272 條二步商觀測路徑重建此原見證映射，
核對其鍵集合只減少、其像恰等於殘餘集合。
每個局部合法更新的單射性也由完整轉移表核對。

一般長度的正確性由對更新式作歸納得到：R 恰為存在同一初始完整
染色、依序執行整段動作並符合每一已見觀測的當前染色集合。
有限枚舉用來驗證實作及本圖數值；此歸納命題不依賴只測二步。
反之，候選大小可以長期維持 2；精確迭代不等於任何實際觀測序列
終究都能辨認唯一染色。

## 二步路徑與實際反例

從上一輪完整凍結表重建商轉移，再枚舉全部存在商轉移的二步路徑：

| 路徑集合 | 數量 | 新迭代結果 |
| --- | ---: | --- |
| 同一完整染色可實現 | 45,888 | 全部接受 |
| 只有逐邊存在的商見證 | 384 | 全部拒絕 |
| 合計 | 46,272 | 逐條與原圖轉移核對 |

證書列出全部 384 條拒絕路徑，並保存完整接受／拒絕列表的
SHA256；`--check` 每次完整重建這兩份列表。上一輪保存的具體反例
也獨立定位、重播並拒絕。

例如頂點順序為 `0..7`，初始觀測包含：

```
R0 = {01012132, 01012233}.
```

施 `a=(1,2,root=1)` 並觀測反例的中間 J 值後：

```
R1 = {02012231}.
```

該中間 J fibre 還有 `02012133`，但它沒有符合這段歷史的原見證，
所以不允許把它放回 R1。第二次施相同 a，真正後繼只能回到
`01012132`；如果觀測聲稱屬於 `01012133` 的 J 類，R2 就是空集合。
舊商路徑正是先換入 `02012133`，才得到假的 `01012133` 終點。

# 同時三台 Kempe 狀態機：辨識增益、跨台干涉與假路徑

2026-10-20。**多台同步觀測能增加當前辨識力，並把跨台更新缺口、
動作次序及跨步換見證的錯誤分開量化。** 在既有八點 cell95 真 disk，
單台160類、任兩台176類、三台192類；三台仍不能自行確定更新。
進一步找到 **384條沒有同一完整染色軌跡的兩步摘要路徑**，
即使這張圖的靜態同框組合和單步後繼乘積都沒有額外假組合。

本輪是使用既有圖的完整有限試驗及明列契約下的紙面命題，不是擴大
圖枚舉。BASE `af0df8081e79b51f8b24e17e01b2bd5572e46a0a`；
[凍結來源](INPUTS.json)、[原工作樹界線](BASE.json)及
[完整合同](SOURCE_CONTRACT.md)保留。未取得一般有界壓縮、
J1來源排除、較小bad或新Lean。

## 1. 實際做了什麼

同一張圖、同一份完整字面染色，三台分別讀取

```
A = (框色, π01, π23)
B = (框色, π02, π13)
C = (框色, π03, π12).
```

π為實際 maximal 二色分量與原五點框的非空交集分割。
所有私有點及邊都參與連通判定；不同台不能換染色見證。
每次操作是選色對與原框root，交換其完整實際分量。
根不在所選色對時記為非法，不當成自迴圈。

完整核對264份proper字面染色、30個action labels、3,960個合法轉移；
十個canonical框色fibres全部保存，包括4個空fibre、共11份固定字面lifts。
全字面框另有240種proper指派，其中144個非空、96個空。
原disk幾何沿用上一輪有理數座標證書，本輪唯讀重播。

三台的組合恰是前輪六分割摘要；新增的是分台的資訊分析及跨步
相容性試驗，不是聲稱換個排列就產生更強的摘要。
詳見[主實驗](experiment/RESULT.md)及[紙面命題](theory/REPORT.md)。

## 2. 多台帶來多少辨識資訊

| 同時觀察 | 當前類數 | 全alphabet下有歧義的「類／動作」 | 全未來分支逐輪細分 |
| --- | ---: | ---: | --- |
| 只看框色 | 144 | 見證書 | 144 → 192 → 240 → 264 |
| 任一台 | 160 | 288 | 160 → 224 → 264 |
| 任兩台 | 176 | 240 | 176 → 240 → 264 |
| 三台 | 192 | 96 | 192 → 240 → 264 |

每一種單台／雙台選擇均逐一核對，不只依色對稱推算。
三台比單台多32類，增加20%的當前辨識類數；這不是熵或機率提升。
三台的歧義「類／動作」組數為單台的三分之一，但分組基準不同，
不能解讀成錯誤率下降三分之二。

所有含至少一台的觀測，在此圖經兩輪**全分支未來細分**都到264類，
逐份區分完整染色。多台改善早期辨識，但這個試驗沒有降低最壞
細分深度，最後也沒有壓縮完整染色。此數字不是一般disk深度界。

## 3. 各台哪些部分能真的自行更新

一台只執行自己的兩個互補色對時，兩份induced二色圖完全不變；
新框色由含root的接框block直接交換。因此每台對自己的10個labels
是確定狀態機，160類已穩定；這個受限閉合命題適用於任意固定有限圖。
其可見分量翻轉互相可交換，k個接框blocks給`2^k`的受限動作軌道。
完整證明與hidden swaps界線見[理論§2](theory/REPORT.md#2-每台對自己的-alphabet-確實是確定狀態機)。

跨台操作會改變其他台的混合色對。固定圖上，每個色對有660個合法
「完整染色／root」轉移：

| 交換色對 | A原有接點間連通關係改變 | B改變 | C改變 |
| --- | ---: | ---: | ---: |
| 01或23（各自） | 0 | 140 | 140 |
| 02或13（各自） | 140 | 0 | 140 |
| 03或12（各自） | 140 | 140 | 0 |

此表只比較交換前後仍屬於同一色對的接點，排除了單純加入／移出
色對的效果。若直接比較整份分割，非自身台全部660次都改變，
其中包含接點色對歸屬改變，不能全部當成連通結構變化。
這給出可具體追查的跨台更新位置。

動作順序也有差別。在同一完整染色上，兩種次序皆合法的無序label對：
同色對3,600例、互補色對4,320例全部可交換；共一色的6,240例中，
5,664例完整結果不同，5,520例連框色都不同。
因此「同步觀察三台」與「無序同時執行跨台動作」必須區分。
原邊重算與具體反例保存在[coupling-v2.json](coupling-v2.json)。

## 4. 真正新增的時間資訊：384條假路徑

先把每個實際轉移投影到三台共同摘要，保留全部可能後繼。
對每個初始摘要、第一label、中間摘要、第二label、終點摘要，
比較兩種路徑集合：

| 兩步路徑語義 | 不同觀測路徑數 |
| --- | ---: |
| 只要求每條摘要邊各自有完整見證 | 46,272 |
| 要求整條路徑來自同一完整染色軌跡 | 45,888 |
| 差集：跨步拼接出的假路徑 | **384** |

以下是最簡單的已保存見證，頂點順序為0至7：

```
初始摘要的完整候選：01012132、01012233。
動作 a = (12, root 1)。

01012132 --a--> 02012231 --a--> 01012132。
```

選定中間觀測後，真正能到達它的中間染色只有`02012231`。
但同一中間摘要還容納另一份`02012133`，它不是上述初始候選
經第一步抵達這個觀測的結果。若忘記來路，摘要圖可改用它：

```
02012133 --a--> 01012133。
```

於是兩條分別有見證的邊被拼成不存在的整條路徑；
甚至違反真實交換必有的 **`a;a = identity`**。
主計算與獨立BFS/set-composition重建均得到384條差集。

這指出下一版至少要保存「這個中間摘要實際由哪些完整候選抵達」，
或證明可取代它的充分資訊。只要求每一步三台有共同染色還不夠，
也不能把摘要圖上的可達性直接當成原圖可達性。
對合、可交換性等真實動作恆等式可作必要診斷；單獨加入它們
是否足以排掉所有更長假路徑，本輪未證。

## 5. 兩個需要保留的限制與零結果

**本圖沒有靜態同框相容性缺口。** 逐一固定字面框色後，
三台邊際的Cartesian product、三份兩兩關係的join、實際共同關係
三者總大小均為192。給定當前三台摘要及action，單步後繼乘積也無
額外假tuple。這是固定圖上的零結果，不是一般相容性定理，
更不排除上一節的時間見證缺口。

**多記實際歷史不等於未來細分。** 對初始兩候選
`01012132、01012233`反覆執行`(01,root0)`，三台的共同觀測在
每一步都仍相同；兩步又回到原完整染色。無論重複多久，
候選數都維持2。表中的兩輪細分是比較所有未來分支，
並非任意實際走兩步就能認出全部染色。

可實作的精確歷史更新為

```
E_next = {a(c) : c in E_current, a合法, J(a(c)) = 新共同觀測}.
```

它保留同一軌跡的候選身份，會排除上述假路徑；但候選集合可能很大。
有界或較小的等價表示、一般跨台閉合及指定J1來源幾何仍OPEN。
本圖支持為95，完整r6／941／J1前提`not triggered`。

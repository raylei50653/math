# 原 C9 三接點的互斥與封閉耳點

2026-10-23。來源合同見 [SOURCE_CONTRACT](../SOURCE_CONTRACT.md)。本證明不使用
四色定理、數值計數錐、來源圖枚舉或內側大小上界。T2 原完整同源有限計數及
小 cap 定理作繼承前提，不由本輪的幾何控制替代。

**新結論是原第二層的同時幾何限制。現行共同 `k≥23` 保持不變。**
以下局部引理另給 `m≥10`、三接點時 `m≥11`，數值上已被共同界包含。

## 1. 合同內的原圖與已知 contact 分類

固定同一 H、原有序 induced C9 `C=(c0,...,c8)`，索引 mod 9。
`I=V(H)\C`，`m=|I|=k-9`。H 的有界面皆三角形，

\[
 d_H(c_i)\ge4,\qquad d_H(x)\ge5\quad(x\in I).
\]

原 C3 cap 空；每條原 C 邊的內側面第三點 `t_i` 位於 I，九個 t 互異。
任一 I 點的不同 C contacts 的圓周距離皆為一或四。已知這迫 contacts
至多三個，全部三接點型恰為

\[
 A_i=\{c_i,c_{i+1},c_{i+5}\}. \tag{1}
\]

上述分類及九個 t 的互異均已由 T2 得到，本輪不重新宣稱為新定理。
需要新增的是：九個形式上各自合法的 (1)，能否在同一原 disk 共存。

## 2. 三接點必是原面第三點；兩個不同三接點不能共存

**原面辨識。** 若 `x∈I` 有 contacts `A_i`，原邊 `c_i c_(i+1)` 和
原邊 `c_i x,c_(i+1)x` 形成一個簡單原 C3。其不含其餘 C 的有界側
完全位於原 C 內。原 C3 cap 空，而原嵌入已三角化，所以這個三角形
正是原邊 `c_i c_(i+1)` 的內側面。因此

\[
 x=t_i. \tag{2}
\]

沒有新增面，沒有把「共同鄰點」直接當成原面點，也沒有忽略三角形的側別。
九個 t 既已互異，不同 i 的三接點有不同原中心。

**四點交錯。** 對任意不同 i、j，可在 `A_i` 中選兩點 a、b，在 `A_j`
中選兩點 u、v，使四點互異且在原 C 上交錯出現。這是固定九圈的有限
位置引理：`certificate.json` 對全部 36 個無序 pair 分別保存兩對端點及
原環序，獨立 checker 從頭核對。它不是用有限圖來替代拓撲定理。

若 `t_i` 和 `t_j` 都有三接點，兩條原路

\[
 a-t_i-b,\qquad u-t_j-v
\]

除端點外嚴格位於 C 內；它們各為簡單弧，內部頂點互異，所選四個
端點也互異。第一弧與一段 C 弧構成 Jordan 曲線，u、v 在兩側，故第二弧
必穿過第一弧。這違反原平面嵌入。即使兩個完整 stars 另外共享某個未選取
C contact，所選兩條路仍無共同點，因為只使用各自選取的兩條原 spoke。

由 (2) 得任意內側大小的原圖結論

\[
 \boxed{|\{x\in I:|N_H(x)\cap C|=3\}|\le1.} \tag{3}
\]

等價地，九個原 t 的可選相反 contacts `t_i c_(i+5)` 至多出現一條。
所以 512 個形式子集在共同平面嵌入下，只保留空集及九個 singleton，
即十個必要模板。它們不代表十種完整來源或可行計數解。

## 3. 唯一三接點形成兩個 induced C6 原 cell

假設原 `t_i` 有 contacts `A_i`。它的三條原 spokes 將 C 內 disk 分成：

1. 已辨識的空原三角面 `(c_i,c_(i+1),t_i)`；
2. 原六圈 `D⁺=(t_i,c_(i+1),c_(i+2),c_(i+3),c_(i+4),c_(i+5))`；
3. 原六圈 `D⁻=(t_i,c_(i+5),c_(i+6),c_(i+7),c_(i+8),c_i)`。

這三個閉 cell 只沿所述原 spokes 或端點相交，兩個六圈的嚴格內部互斥。
每個六圈 induced：原 C 無弦，且 t_i 的 C contacts 已精確等於 (1)，
所以不接該六圈短弧上的其他三個 C 點。沒有 t_i／c 或兩個 C 點的 alias。

`D⁺` 的四條原 C 邊分別有原面第三點
`t_(i+1),...,t_(i+4)`。這些 t 與 t_i 不同，皆嚴格位於 `D⁺` 的有界側。
理由是沿各原 C 邊，其 H 內側三角面的開部在此 cell；第三點不能在該 cell
邊界上，否則是別的 C 點或 t_i，分別違反 C 無弦或 t 的互異。同理
`D⁻` 嚴格包含 `t_(i+5),...,t_(i+8)`。

以下將證明兩個 cell 各不只包含這四點。

## 4. 沒有三接點時 m=9 不可能：原內九圈被封閉

反設 m=9 且無三接點。因九個 t 已互異，I 恰為九個 t。每個 t 的 C
contacts 精確為它原邊的兩端；其他 contact 若存在就形成 (1)，與假設矛盾。
因此每個 c_i 的內側鄰點精確為 `t_(i-1),t_i`。

這兩點在 c_i 的原完整內側 rotation 中相鄰；原面皆三角形，故必有原面

\[
 (c_i,t_i,t_{i-1}) \tag{4}
\]

及原邊 `t_(i-1)t_i`。原 C 邊面與 (4) 接成一個沒有重疊的 annulus，
其內邊界是簡單原九圈 `T=(t0,...,t8)`。九個 t 全部在這個內框上；
因 m=9，T 內沒有額外頂點。其內部因原三角化而是一個九邊形三角剖分。

一個至少四邊的多邊形三角剖分有至少兩個耳點。可由三角面 dual 為樹、
取兩個 leaves 得到；耳點在整個三角剖分圖中只有兩個鄰點。取 T 的任一耳點
t_j。它不可能有穿過 annulus 的額外 I 邊，因原面 (4) 已封閉所有外側扇區；
它也沒有其他 C contact。故它在整份原 H 的完整 degree 恰為

\[
 2\text{（原 C contacts）}+2\text{（T 中鄰點）}=4,
\]

違反 I 點完整 degree 至少五。這是原完整 star 的矛盾，不是只計補片內 degree。
所以無三接點時 m≥10。

## 5. 三接點時每個 C6 cell 至少五個嚴格內點

只證 `D⁺`；另一側照原環序同證。反設 `D⁺` 恰有前述四個 t，沒有其他嚴格
內點。由 (3)，這四個 t 各只有其原 C 邊的兩端 contacts。原三角化與每個
`D⁺` 上 c 的完整 cell 內 rotation 迫出原五圈

\[
 P=(t_i,t_{i+1},t_{i+2},t_{i+3},t_{i+4}), \tag{5}
\]

並封閉它與 `D⁺` 間的原三角面帶。例如 c_(i+1) 的 cell 內鄰點只有
t_i、t_(i+1)，所以原邊 `t_i t_(i+1)` 必存在；其後依次相同，末端
c_(i+5) 迫邊 `t_(i+4)t_i`。五個 P 點互異，(5) 是簡單原圈。

P 內沒有頂點，因這四個 t 已是 cell 的所有嚴格內點。所以 P 的有界側為
五邊形三角剖分。至少兩個耳點中，至多一個是 t_i；故可選耳點
`t_j`、`j≠i`。它嚴格位於 `D⁺` 內，不能有原邊越出此 cell 而不碰其邊界。
它的 C contacts 恰為兩個；原面帶封閉 P 外側；cell 中沒有其他 I 點。
因此其完整原 H-degree 仍恰為四，違反五度下界。

故兩個原 C6 cell 各至少五個嚴格內點。它們嚴格內點集合互斥，又都不含
t_i，且原三角面無內點，因此

\[
 \boxed{\text{三接點存在}\ \Longrightarrow\ m\ge1+5+5=11.} \tag{6}
\]

結合無三接點情形，得到獨立的局部推論

\[
 \boxed{m\ge10,\quad k\ge19;\qquad
          \text{三接點存在}\Longrightarrow k\ge20.} \tag{7}
\]

現行共同 k≥23 更強；本輪不宣稱提高它，也不增加 n5 或排除任一具名 query。

## 6. 有限證據、控制及停止點

producer 枚舉固定 contacts／polygon triangulations；獨立 checker 不 import
producer，另從全體互不交叉對角線集合重建九邊形的 429 份及五邊形的 5 份

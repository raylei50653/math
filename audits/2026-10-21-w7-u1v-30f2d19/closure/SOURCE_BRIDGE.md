# 同一原 u1v 的完整 fibre 反證與八型覆蓋

本頁使用 [BASE](../BASE.json) 凍結的原來源契約及證據：同一任意大小原 G、
原有序外框 `(x,y,a,b,c)`、941、全域最小性、原 stars／旋轉／全部附件與私有點。
只處理同一完整 F 著色的 J1 type III 實際五邊路
`n–u4–u3–u2–u1–L` 所圍 C7 內部恰 R 的嚴格原 W7。

本輪另有**原邊 u1v**。核心仍是原誘導刪點圖

```
D=G−{b,p,h,R,x,y,r}，
rim(D)=(a,n,u4,u3,u2,u1,L,q,c,s,v,w,t)。
```

u1、v 均未被刪掉或識別，所以 u1v 是同一實際 D 保留的邊。對 D 每個固定
字面框 σ，`Z(σ)` 計數全部私有點的完整著色；空 fibre 計零。即使某份 D
著色不能接回原 R／G，它仍在這份全 Z 的量詞內。

## 1. 原未加強 family 已給出的同源支配式

以下三個 canonical IDs 對應固定原有序 rim，沒有交換原點身份：

| 名稱 | ID | 字面 tuple |
| --- | ---: | --- |
| A | 44459 | `(0,1,2,1,2,1,2,3,1,2,0,1,2)` |
| M | 44111 | `(0,1,2,1,2,1,2,0,2,1,3,1,2)` |
| F | 44127 | `(0,1,2,1,2,1,2,0,2,3,1,3,2)` |

原未加入 u1v／u3v 零值的完整307,197欄 family，有下列**完整** incidence：

| 原完整 state 的 half-row | 全部 incident 原欄 |
| --- | --- |
| A，12302027 | `{306985}` |
| M，12301211 | `{306972,306983,306985,307044,307049}` |
| M，10064313 | `J={147448,147449,167802,226130,231666}` |
| F，10064365 | 同一 J，恰好全部五欄 |

每個 half-row 的同源完整計數式是 `2Z_i=Σ_{j含該row}X_j`，所有 X 非負，
私有分量重數已在原 X 內。因此第一列的欄集合包含於第二列，第三、四列
完全相同，直接得到

```
0 ≤ ZA ≤ ZM = ZF。
```

這個來源律只依賴原941／J1／嚴格W7的完整零 fibres 與 orbit coverage，
**沒有使用新增原邊 u3v 或 u1v**。不是把已加入 u3v 零值後的 family
搬來證明另一個 graph，也不是假設 u1 與 u3 在原嵌入中可以互換。

從完整實際 components 看，同一來源律亦由原兩步作用給出：在 A 交換整個
`K03(q)`（boundary contacts恰 `{q,v}`）及整個 `K12(c)`（恰 `{c,s}`），
得到 M；在這份**當前** M 交換整個 `K13(v)`（恰 `{s,v,w}`），得到 F。
六欄的全 component 覆蓋及所有原私有點均沿用
[原完整作用證明](../../2026-10-21-w7-u3v-30f2d19/transport/PROOF.md)。
這些 component 分類本身亦在加入 u3v 零值前的原 family 上成立；本輪
[獨立checker](source_bridge.py)重新掃描上述四個 half-rows 的全部 incidence，
不讀取任何 u3v support-closure transcript。

作用與數值式都以整張同一 D 的完整著色為作用域。它們不要求原某一份
`(b,p,h,R,x,y,r)` cap assignment 維持合法；對每份當前 D 著色仍按原 cap
合同重新量化全部 lifts。也不要求中途保持 selected path／type III 的
歷史成員資格。原選定著色只提供初始正量，不替代整個 D 的 complete fibres。

## 2. u1v 的原同色零值給直接矛盾

在 F 的固定原字面框上，`u1=u3=v=1`。只用本輪實際保留的原邊 u1v，即有

```
Col_D(F)=∅，ZF=0，故 ZA=0。
```

等價地，在任何假設存在的 M 完整著色中，原 u1v 因 u1=1、v=3，已迫 u1
屬於 `K13(v)`；但完整分類迫其 boundary contacts 恰 `{s,v,w}`，不含 u1。
這已是原同圖矛盾，不需完成一份實際 improper 著色。

另一 target B=44466 是
`(0,1,2,1,2,1,2,3,1,2,1,0,2)`；它的 u1=v=1，故其**全部完整 D fibre**
也直接被原邊 u1v 禁止。A 本身 u1=1、v=0，不能被錯當成初始同色零格。
原 selected witness 給 `ZA+ZB>0`，而上述同源證明給 `ZA=ZB=0`，矛盾。

原欄48617、67755均含 A 的 half-row6712710；完整非負方程又立即推出
`X48617=X67755=0`。全程不使用兩個欄各自的獨立來源，也不需要求解LP、
構造 smaller bad 或建立原圖對稱。

## 3. 八份完整 profiles 與剩餘24型

前輪40份必要 source profiles 中，原 u1v 恰發生在

```
68,69,78,79,88,89,92,93。
```

[證書](source-bridge-certificate.json)逐份保留其完整四點接觸、全部原弦與
原編號，並核對各型的 target 支援恰剩48617、67755。證明只用它們共同的
原邊 u1v；其餘額外原弦及全部附件均可原樣保留。沒有宣稱這八份必要型
各自有 source 實現。

合已排除且互不重疊的原 u3v 八型，本輪具名覆蓋是

```
40 − u3v的8型 = 32，32 − u1v的8型 = 24。
```

剩餘24型的前輪必要支援表分成12份 joined二欄型與12份完整15欄型；
其字面 target 覆蓋為 A仍12型、B仍24型。這些只是剩餘必要型，沒有來源
存在或共同計數可行性宣稱。一般嚴格W7、C7多內點、其他J1/J2拒絕、
smaller bad及主命題均未因本頁關閉，亦無新Lean。

## 4. 驗證與傳播範圍

[source_bridge.py](source_bridge.py)逐項核對已消費輸入的BASE bytes／SHA，
從原 caps 及未加強完整 family 重新驗證四個 IDs、四份全部 incidence、
兩個原 X欄及八份完整 profiles。漏incident欄、換成u3v或誤升一般W7排除
的證書均被拒絕；normal／seed17／seed17 `-O`見
[verification](source-bridge-verification.json)。

本頁可向直接父文件採納為**嚴格原 W7 中 u1v 不存在**的具名分支定理，
更新剩餘32→24。它不把原 full-family／必要錐的其他 OPEN 邊界改成完成；
也不改寫已凍結的 u3v 或前輪40型證據。

# 共面分離、三角化與重接的獨立審查

本檔只審查本次固定來源路線，並提供兩個小圖負控制。圖的五個邊界點永遠是
`(0,1,2,3,4)`，顏色框架不換名；`5=a, 6=b` 是內點。未修改共用文件或既有證書。

## 1. 三角化論證審查：通過

已讀 `docs/c5_count_cone_bridge.md`：該文件 §2–3 已證保留一份關鍵完整染色的
near-triangulation 反例保持，但可能加 hub，允許 parallel edges，且沒有保完整 Σ。
故本次不能把「反例可三角化」本身稱為新結論。

此次較強的論證使用最小內點來源及目錄的兩兩聯集封閉性。以下論證通過独立檢查。

1. 若有目錄外 disk 圖，先選內點數最小，再選邊數最大的一張 `G`。圖是簡單圖，
   固定頂點數下邊數有最大值。保留含 C5 的唯一 2-connected block 不變更完整 Σ：
   原圖已有染色，接回每個枝塊時可排列色名以符合 cut vertex 的指定色。
   若有多餘私有頂點便違反內點最小性。故 `G` 2-connected，每個面邊界是 simple cycle。
2. 若共面非鄰 `x,y` 至少一端是內點，則沿該面識別得到合法 disk 圖 `G/xy`，
   內點數較少，故其完整關係在目錄。沿同面加邊也合法，且
   `Σ(G) = Σ(G/xy) ∪ Σ(G+xy)`。若兩個右側關係均在目錄，聯集封閉性使左側也在，
   矛盾。因此 `G+xy` 仍在目錄外，違反最大邊數。
   所以任何共面、至少一端內點的不同點，均已相鄰。
3. 假設有長度至少四的 bounded face `F`，且 `F` 含內點 `x`。在 `F` 選不連續點 `y`，
   則既有邊 `xy` 位於 `F` 外。在 `F` 的兩條開 `x–y` 弧各選 `u,v`。
   若至少一端是內點，既有邊 `uv` 也位於 `F` 外；若兩端都是邊界點，
   在原 C5 的外側加 apex，用 `u–apex–v` 連接。無論哪種情況，
   `xy` 與此 `u–v` 路徑頂點不交，卻在 `F` 的 simple boundary 上端點交替。
   在球面去除 `F` 後的閉圓盤中這不可能。
4. 目錄外來源由既有 screen 全收 T4，故 C5 無 chord。完全由邊界點構成的面若長度
   至少四，只能是 C5 本身；若它是 bounded face，disk 內便沒有地方放私有頂點。
   目錄外圖不可能有零內點。因此全部 bounded faces 都是三角形。

第三步需明說在球面補面內應用交錯端點分離，不能直接把 `F` 外口語當成原 disk。
外加 apex 只用於此拓撲反證，沒有變更研究對象或界定另一份 Σ。

此論證不需先挑 `01232`，也不需 `min |Σ|`。它保證同樣最小內點數存在一張
simple near-triangulation 的目錄外來源；沒有保證從每一張原 `G` 得到同 Σ 的三角化。
如果另加 `min |Σ|` tie-break，逐次加邊且仍目錄外時才可進一步推出完整 Σ 不變。

因此可把既有文件引用的「near-triangulation 內點 ≤12 無反例」接到任意 disk 圖的
目錄外最小來源上。文獻結果、一般圖論橋接、目錄有限聯集檢查仍是三種獨立證據。
本檔沒有重新核實外部文獻，也沒有把這項界升格成任意大小的排除。

## 2. 一份完整 p* 見證不足以保重接後的完整 Σ

具名控制 `CUS-REWIRE-2I-567` 是 induced-C5 simple near-triangulation。
除 C5 邊外，它的邊為

```
a0, a1, a2, b0, b2, b3, b4, ab.
```

其所有 bounded faces，使用與邊界相同的面定向，是

```
(0,1,a), (1,2,a), (2,b,a), (2,3,b), (3,4,b), (4,0,b), (0,a,b).
```

在 `p*=01232` 下恰有一份完整染色：`(0,1,2,3,2,3,1)`。
因原圖已三角化，「每個面內的不同點異色」在它的每份染色中都成立，
所以這個局部幾何性質本身不足以保障以下操作保持完整 Σ。

### 2.1 刪邊再 flip，連 induced-C5 都保留，仍同時失去及新增列

刪 `b0`，使原兩個面合成 `(4,0,a,b)`；再加 `a4`。得到 `F`。
原 `p*` 完整染色仍 proper，且所有邊界點與色名相同。
但 `Σ(G)=567`、`Σ(F)=854`：失去 `01012, 01203`，新增 `01212, 01231`。
所以即使同一份 `p*` 全圖見證直接保留下來，不能推出完整 Σ 保留。

### 2.2 刪邊再把內點併入共面邊界點，仍可同時失去及新增列

刪 `b2`，使原兩個面合成 `(2,3,b,a)`；將 `a` 與 `3` 識別並刪去平行邊，得到 `Q`。
原 `p*` 見證滿足 `c(a)=c(3)=3`，所以直接下降到 `Q` 的染色。
但 `Σ(Q)=774`：失去 `01012, 01202, 01203`，新增 `01231`。
此例的 `Q` 出現合法 boundary chords；全部十列都以同一固定邊界與色框比較。

完整十列延伸數如下；所有完整 lifts，包括空 fibres，均保存在 JSON。

| 邊界列 | G | G−b0 | F=(G−b0)+a4 | G−b2 | Q=(G−b2)/(a=3) |
|---|---:|---:|---:|---:|---:|
| 01012 | 1 | 1 | 0 | 1 | 0 |
| 01021 | 1 | 1 | 1 | 1 | 1 |
| 01023 | 2 | 2 | 1 | 2 | 1 |
| 01201 | 0 | 0 | 0 | 1 | 0 |

兩個控制都不全收 T4，也不實現 933／941，因此只反駁「一列見證＋局部三角化即可
保整份 Σ」的廣義主張，沒有反駁固定目標來源上的更強重接候選。

## 3. 刪邊後必須追蹤的完整共同關係

設 `e=st` 兩側三角形的 opposite vertices 是 `u,v`，`D=G−e`。
在同一份 `D` 完整染色中記錄兩個布林值

```
A := c(s) != c(t),   B := c(u) != c(v).
```

逐一固定原十列 `p`，保留四個 `(A,B)` fibres，則

```
p ∈ Σ(G)           iff D 的 p-fibre 有 A=1;
p ∈ Σ(D+uv)        iff D 的 p-fibre 有 B=1;
p ∈ Σ(D/(u=v))     iff D 的 p-fibre 有 B=0.
```

因此 flip 所需的是每一列上 `exists A=1 iff exists B=1`；識別所需的是
`exists A=1 iff exists B=0`。一列上的直接見證只證一個方向的一個實例。
尤其一般公式 `Σ(D)=Σ(D+uv)∪Σ(D/(u=v))` 的左端是刪邊後的 `D`，
不能直接換回 `G`。原邊 `st` 的恢復條件必須留在同一全圖 fibre 中。

### 3.1 固定最小目錄外來源上的新窄條件：同色 opposite 迫原邊必要

設 `G` 在所有目錄外來源中內點最少，並已在整圖同一 D5 對齊下有
`Σ(G)=R∈{933,941}`。令 `p*=01232`。使用已核對的有限事實：
沒有任何 `S∈K132` 同時滿足 `p*∈S⊆R`。

考慮有兩個三角面 `stu, stv` 的非邊界邊 `e=st`，其中 `u,v` 不同、
至少一端是內點。假設某份原 `p*` 完整染色滿足 `c(u)=c(v)`。
則 `u,v` 非鄰，刪去 `e` 後共面，令

```
D = G−e,     Q = D/(u=v).
```

識別合法且少一內點，因此 `Σ(Q)∈K132`。原 `p*` 染色下降到 `Q`，故 `p*∈Σ(Q)`。
若 `Σ(Q)⊆R` 便違反上面的有限事實。因此存在一個完整邊界列

```
p ∈ Σ(Q) \ R.
```

取 `Q` 的該列完整染色並拉回同一原頂點集合的 `D`，得到

```
c(u)=c(v),     c(s)=c(t).
```

第二個等式是必要的：若 `c(s)≠c(t)`，便可恢復原邊 `e` 得 `G` 的 `p` 延伸，
與 `p∉R` 矛盾。四條三角面側邊仍在，因此兩個等色對用不同顏色，
原四邊形在這份新增列的見證中是二色的。

所以得到比「刪邊新增某列」稍強的同源結論：

> **若原 `p*` 延伸在一個可識別 opposite pair 上同色，則刪去其間原邊必新增一列；
> 且可在同一份新增列完整染色中，讓舊邊兩端與 opposite pair 各自同色。**

這不是一般圖上的全稱重接定理；它使用最小目錄外來源、固定 `R` 與有限 subcone 事實。
也未證不同原邊的新增列見證能相容或共享。

下一步的精確共同介面可寫成四個 full-lift fibres

```
J_e(p;A,B) = { f : V(G) -> {0,1,2,3} |
              f proper on D, f|C5=p,
              [f(s)!=f(t)]=A, [f(u)!=f(v)]=B }.
```

必須保存全部十列及四格（包括空格），並保存同一頂點集、原四邊形環序與完整 lifts。
上述引理給 `J_e(p*;1,0)` 非空時，有某個 `p∉R` 的 `J_e(p;0,0)` 非空；
此 `p` 的 `J_e(p;1,0)` 與 `J_e(p;1,1)` 均空。尚不能只凭這個存在式推出全列 flip
等價，或把不同邊的四格表獨立拼成同一來源。

## 4. 重播與精確邊界

```
python3 audits/2026-10-12-cofacial-uniform-separation-eb6b2303/review/rewire_controls.py
```

腳本只重播以上五張 literal 小圖，沒有圖枚舉。它驗證 directed face incidence、
每個頂點的一個 cyclic rotation、連通及 Euler 特徵，並列出每列全部完整染色。
旋轉、literal edges、oriented faces 和完整 lifts 存於同目錄 `rewire_controls.json`。
預設或 `--check` 都只讀取既有證書，缺檔便失敗；明確 `--write` 才以 `open('x')`
建立新檔，既有檔案會被拒絕。尚未 Lean 化。

`rewire_verification.json` 保存 normal／seed17 相同 stdout 與證書 SHA-256、
刪掉 `G` 的 `01232` 完整 lift 後確實拒絕的負控制、缺檔讀取不建立檔案，
以及試圖 `--write` 既有證書時拒絕的結果。原證書在所有檢查前後位元一致。

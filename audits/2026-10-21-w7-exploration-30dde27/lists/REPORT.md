# W7 七列表：特殊規則、完整 lifts 與三種空 fibre 形狀

2026-10-21；exclusive BASE `30dde27293b5d3ad63c75fae73cda5be96db705b`。
本項承接同一 BASE 的 [profile 0／1 完整八點界面證明](frozen/PROOF.md)，
只研究已證的原 W7 七列表關係。來源文件、原 checker 與原 certificate 的
固定 bytes/SHA 見 [BASE.json](BASE.json)。沒有重新枚舉大圖。

**得到的結構是：固定 hub 後，空 fibre 只有「初始空列表」、「單點強迫
沿圈傳播衝突」、「全圈同一個二色列表的奇偶障礙」三種。**
這是七列表關係的精確判準；它沒有排除剩餘 W7 原來源。

## 1. 三層宇宙與完整共同見證

原內圈順序固定為 `C=(n,h,L,u1,u2,u3,u4)`，hub 是原 `R`。
對同一份 proper 邊界色列 `σ:S→{0,1,2,3}`，完整外鄰域給七個列表
`L_t=四個顏色 \ σ(N(t)∩S)`。每個外側完整 link 弧含一條 S 邊，
所以 proper σ 迫每個 `|L_t|≤2`。這對任意 H 長度成立。
固定 `R=r` 後，令 `D_t=L_t\{r}`。完整 fibre 是沿 C7 proper 的
`c_t∈D_t` 的**全部**選擇；四個 r 的完整 fibres 取不交聯集。
先不加列表限制的八內點候選共 `4(2^7−2)=504` 份。

實驗明確分成：

1. **形式列表。** 固定 hub=3，枚舉另外三色的非空大小 1／2 列表：
   六種 domain 的七次方，共 279,936 列。未主張這些列有合法 σ。
2. **合法局部 σ。** profile 0／1、H 總長 K≤1，共 13 個符號 collar；
   各自 proper σ 按全域色置換取 canonical 代表，共 6,655 列。
   每列的 lift 數仍保留固定字面 σ 下四個有標籤顏色的全部 lifts，
   並未把八內點 lifts 再除以色置換。
3. **原 941 來源。** 本實驗沒有原圖來源實現；第二層的局部 collar
   只是校準。不把 K=0、K=1 或任意形式列表當成原來源。

既有原 target 的 a／q 完整 03 分量分離已迫 **K≥1**；因此本項 K=0
明確不符合該原來源必要條件，只校準同一完整八點列表關係。K=1 也只是
通過這一項必要條件，沒有成為原 941 來源。`6^7` 的形式列表全集則完全
不是合法 S 色列或原來源枚舉。

[certificate.json](certificate.json) 保存 504 份完整內輪候選、形式列逐列
完整計數、合法局部 σ 逐列完整計數、四個固定 hub 計數、各規則計數，
包含全部空 fibres。不能把七個邊際列表各自非空替代為一份共同 lift。

## 2. 固定 hub 的精確空 fibre 判準

對每個 `|D_t|≤2` 的圈列表，依次進行：

1. 有空列表，則空 fibre。
2. 某點只剩色 x，便從它的兩個鄰點列表刪除 x；反覆傳播。
   若產生空列表，則空 fibre。
3. 傳播停止而全部七個列表都是同一個二色集合，則因 C7 為奇圈而空 fibre。
4. 其餘情況必有完整 proper 著色。

第 4 步有直接證明。若仍有 singleton，先固定所有 singleton；剩下每個
分量是一條路，其相鄰 singleton 的色已從端點列表刪去，而其餘點都有
兩個顏色，可沿路貪婪著色。若沒有 singleton，全部列表大小為 2。
只要它們不全相同，就有一對相鄰不同列表；在前點選後點列表沒有的色，
沿相反方向貪婪著完整條路，最後一點自動與起點不同。唯一殘餘便是
全圈同一二色列表的奇圈。

這個判準對任意長度 collar 所產生的七列表成立，不依賴 K≤1 控制。
實驗逐列以完整 126 份固定 hub 內圈候選核對全部 279,936 個非空形式列：

| 固定 hub 後的分類 | 形式列數 | 完整 fibre |
|---|---:|---|
| singleton 傳播衝突 | 162,375 | 全空 |
| 全圈同一二色列表 | 3 | 全空 |
| 其餘 | 117,558 | 全部非空 |

若連初始空列表也列入，另有 `7^7−6^7=543,607` 列，每列計數都是零。
這是形式 domain 宇宙，不是原來源數量。

## 3. 兩型 K≤1：完整計數與邊際誤判

每一列 σ 都以獨立的原局部圖完整回溯，核對 504 候選的七列表公式；
6,655 列全部相等，包括零值。下表的 lifts 是各 canonical σ 的完整
lift 數相加，不是原圖數。

| 局部 collar | proper σ 代表 | 完整 lifts 總數 | 空 fibres | 空 fibre 但某共同 r 使七列表各非空 |
|---|---:|---:|---:|---:|
| profile 0，K=0 | 274 | 254 | 114 | 114 |
| profile 0，K=1，六個插入位置 | 4,920 | 3,090 | 2,809 | 2,627 |
| profile 1，K=0 | 91 | 112 | 7 | 7 |
| profile 1，K=1，五個插入位置 | 1,370 | 1,270 | 570 | 570 |
| 合計 | 6,655 | 4,726 | 3,500 | 3,318 |

把每列的四個 r 分開，共 26,620 個固定 hub fibres：7,368 個初始空，
15,491 個傳播衝突，12 個同一二色奇圈，3,749 個非空。

**K=1 的實例。** profile 0，只有 `|H_n|=1`；固定

```text
S=(p,a,Hn_0,z1,z2,z3,z4,z5,q)
σ=(0,1,0,1,0,1,2,3,2)
L=(23,13,01,01,03,23,23)      # 順序 n,h,L,u1,u2,u3,u4
```

每個 L 都非空，而且每個 r 都使七個 `L_t\{r}` 非空；完整 lift 卻是零。
例如 r=0 迫相鄰 L、u1 同為 1。這是合法局部 proper σ，沒有原 941
來源保證；其作用是精確反駁「共同 r 加獨立列表非空便足夠」。

另一列 `σ=(0,1,0,1,0,2,1,3,2)` 的完整 hub 計數是 `(1,0,0,0)`。
固定 r=1 時

```text
D=(23,3,0,02,03,3,23)
```

每條原 C 邊的兩端各自都能選成不同色；但 h=3 迫 n=2，u3=3 迫
u4=2，原邊 n–u4 衝突。因此連逐邊可行也不能替代同一圈的共同見證。

## 4. 特殊規則：哪些恰好等價，哪些真的損失 lifts

**固定 hub／禁止 rim 色／強制 rim 色出現。** 任一完整 W7 著色的 C7
不能只用兩色，而 hub 色不能出現在 rim；因此 rim 恰用其餘三色。
對每個同一 σ、每個色 x，都有集合恆等式

```text
{完整 lifts：rim 不出現 x} = {完整 lifts：R=x}
{完整 lifts：rim 至少出現一次 x} = {完整 lifts：R≠x}。
```

這不是只比個數的巧合。checker 逐份核對集合相等，certificate 也記錄
四個色的完整計數。因此「限制 rim 只能用三色」若明確刪去某一色 x，
就是選定 hub=x；若限制 rim 只能用兩色，所有完整 lifts 都被刪光。

任意固定 hub 可能損失全部 lifts。例如上一節第二個 σ 的唯一 hub 是0，
另一列 `σ=(0,1,0,1,0,1,2,1,2)` 的完整 hub 計數為 `(0,1,0,0)`，
強行 hub=0 便把唯一 lift 刪去。在全部 3,155 個非空局部 σ fibres 中，
固定 canonical 色0為 hub 會把 1,645 個 fibres 完全刪空。這個統計以
canonical σ 的 p=0 為準，沒有把色0解讀成原 target 的 a 色。

**固定／禁止單一 rim 點的顏色。** certificate 對每列保存 7×4 個
`c_t=x` 完整計數；禁止 `c_t=x` 的完整數就是原數減此數。
這是同一 σ 的子關係，不能自行換成另一份邊界色列。

**單一列表縮／擴一色。** 對每列的每個點、每個色，若原本包含該色便
刪除，否則加入，共 28 次形式變化。所有 186,340 次完整計數均保存；
縮小的 lifts 集合必為原集合子集，擴大的必為超集，checker 逐份核對。

| 形式變化 | 變化數 | 嚴格改變完整 lift 數 | 把非空刪空／把空救活 |
|---|---:|---:|---:|
| 單列表刪一色 | 85,697 | 25,204 | 18,966 次刪空 |
| 單列表加一色 | 100,643 | 40,475 | 16,954 次救活 |

此表按「σ、位置、顏色」計次，同一 σ 可出現多次。
例如 profile 0、`|H_n|=1`、`σ=(0,1,0,1,0,1,0,1,2)` 有兩份 lifts，
只從 n 的列表 23 刪除色2，完整計數便由2降為0。
上節第一個零 fibre 的 L 列，只把原 L 點列表 01 加入色2，完整計數由0
升為3。

**這些列表縮／擴是形式敏感度測試。** 固定同一 σ 與原附件後，七個列表
已被完整外鄰域唯一決定；任改一個列表未必有合法 σ／原圖操作可以實現。
因此不能把「加一色救活」當成同一原圖的 Kempe 修復，也不能把「刪一色
刪空」當成原來源排除。下一步若採用某種特殊規則，必須先給出同一原圖、
同一 σ 下實際允許它的原幾何或分量理由。

## 5. 負控制、重播與目前邊界

兩個明確負控均保留全部空 fibre：

* 七個列表全為 `{0,1}`：共同 hub 可以是2或3，每條邊都分別可行，
  完整 C7 lifts 仍為0，這是二色奇圈。
* 列表 `({0},{0,1},{0,1},{0},{0,1},{0,1},{0,1})`：全部列表非空、
  每條邊各自可行，固定 hub=3 仍無完整 lift，這是強迫鏈衝突。

正控是完全無列表限制的八點輪，完整 lifts 恰504。

```sh
python audits/2026-10-21-w7-exploration-30dde27/lists/check.py
PYTHONHASHSEED=17 python audits/2026-10-21-w7-exploration-30dde27/lists/check.py
```

[normal 輸出](check.stdout) 與 [seed17 輸出](check.seed17.stdout) 逐 bytes
相等；兩次均重算並逐物件對照既有 certificate，不以摘要相等代替重播。
checker 不依賴第三方套件。

這項工作把「可能無法共同 lift」整理成很少的可定位形狀，並量出各規則
刪去／增加哪些完整解。任意原圖外附件、完整原 fibres、原 target 的同源
實現、原 Kempe 分量與合法較小替代均未由此取得。profile 0／1、一般
W7、J1／J2、strict smaller bad 與主命題仍 OPEN；沒有新 Lean、沒有 LP、
沒有 commit／push。

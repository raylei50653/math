## 觀察到的主結構

每個 H 點都只有一個 C 接點 t，故其顏色只能是03，或 t 的相反12色。
稱後者為 barrier。相鄰兩個同一 H 列表的點不能同為 barrier，因兩者將同色。
不同 H 列表由 z 點隔開，沒有跨列表的 barrier 鄰接限制。

在本局部 D 圖中，barrier 恰把 ordered a–q 路切斷，因此

```
a/q 在局部03不同分量 ⇔ 至少一個 barrier。
```

這只是一項原來源的必要條件。外側 E 可以再把局部不同分量連起；沒有證明任何
一份局部色列能在同一完整 E 中保持原要求的 `{a}`、`{q,v}`／`{q,w}` contacts。

**局部03分離沒有排除任何一個 H 位置。** 任意長度分配中，每個具體 H 位置
都能單獨作為唯一 barrier，且恰有一份局部色列。profile 0 的候選中心是
`n,u4,u3,u2,u1,L`；profile 1 是 `u4,u3,u2,u1,L`。K=1 已實現全部相應位置。
所以只憑這個必要條件，不能把反色障礙強迫到某一個中心。

所有 barrier 都以原邊連到 P，故在這份局部著色中已屬於同一個12分量。
單獨交換其中一點的12色會撞到其中心。原外側還可加入其他點到該分量；本項沒有
把它當成完整原 D 的全部12分量。

## 任意 K 公式與逐份 literal 核對

對固定 `k_i=|H_i|`，令

```
I_k(x)=Σ_j binom(k+1−j,j)x^j,
F(x)=Π_i I_(k_i)(x)。
```

固定 b≥1 個合法 barrier 位置後，03部分有 b+1 段；首尾段由 a=0、q=3 固定，
其餘 b−1 段各有兩種03相位。因此

```
恰b個barrier的完整局部色列數 = 2^(b−1)[x^b]F(x)，
局部03分離色列總數 = (Π_i I_(k_i)(2)−1)/2，
I_k(2)=(2^(k+2)+(−1)^(k+1))/3。
```

[check.py](check.py) 的枚舉按 ordered path 遞迴逐色生成；另一段獨立係數計算
逐 shape、逐 b 核對以上公式，714 個分配全部一致。
例如 K=2 集中到同一 H 列表，兩 barrier 將相鄰，故只有2份分離色列；
分散到兩個 H 列表則有2份單 barrier、2份雙 barrier，共4份。
這區分了「額外點總數相同」與「完整 link 中的位置相同」。

若沒有 barrier，整條路必03交替，profile 0／1 的路長分別為 `6+K`／`5+K`。
端點0、3迫路長奇數，所以 profile 0 只在 K 奇數時有唯一全03色列；
profile 1 只在 K 偶數時有唯一全03色列。它們一律違反原 a/q 分量分離。
一旦有 barrier，沒有額外的全局 b 奇偶限制；限制轉為各03段的相位。

## 特殊規則變化

以下是額外加入的探索規則，不能當作原來源必然滿足的新引理。
完整逐 K、逐 shape 計數在 [certificate.json](certificate.json) 及壓縮色列檔中。

| 加入的規則 | 看到的結構 |
| --- | --- |
| 恰一個 barrier | 任意 H 位置都可；每位置恰一列，無中心排除。 |
| 所有 barrier 都在同一中心 | 同一 H 路上的獨立集控制；集中加長不能等同分散加點。 |
| 至少兩個 barrier 中心 | K=2 首次出現；兩個不同 H 的單點已足夠，兩個同 H 鄰點不夠。 |
| 每個非空 H 都有 barrier | 這是更強的聯合篩選；K=5時兩型分別4542、2321列。 |
| z1,…,z5 全部同色 | profile 0 首次 K=5；profile 1 首次 K=4。 |
| z1,…,z5 依序03交替 | profile 0、K=1時，只能把唯一 barrier 放在 H_n 或 H_L；profile 1 的五個中心皆可。 |
| 不要求局部03分離 | 精確留下上述奇偶控制的全03色列；它們不能提升為原 target。 |
| 單獨交換一個 barrier | 立刻與原中心同色而失敗；交換整個局部12分量則仍 proper，但改變 P target。 |

全 z 同色的最小長度分配也很集中。profile 0 恰為
`(H_n,H1,H2,H3,H4,H_L)=(0,1,1,1,1,1)` 或 `(1,1,1,1,1,0)`，
各有31份局部分離色列。profile 1 恰為 `(H1,H2,H3,H4,H_L)=(1,1,1,1,0)`，
有15份。這些門檻直接來自相鄰 z 同色時不能用空 H 連邊；
profile 0 還需在 a／q 至少一端容納額外 H。這是可在任意 K 延伸的局部規則。

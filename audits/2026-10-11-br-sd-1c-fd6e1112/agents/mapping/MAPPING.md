## 2. 一份 W 的精確原圖含義

記 `C0` 為具名三環、原 uv 及兩條原外臂的 skeleton，這只是同一原 C 的邊子圖，
**不是一份已完整 degree4 的來源再被任意加邊**。

候選原 C 的額外旁支 W 是有限非空原 block subtree，`W−x` 非空連通，
`V(W)∩V(C0)={x}`，`x∈J1∪J2`；其唯一向 skeleton 的附件為 x。
W 的所有 vertices、edges、B attachments 及 block incidences 都必為候選原來源自己的資料。
沒有新增 s/r contacts；s 的原有序內鄰仍恰 p/q。W 若接 J1 私有點便屬原 L，
若接 J2 私有點便屬原 S；它沒有成為第三份 mixed 或獨立原 unary U。

保留其他原形狀：`J1∩J2={r}`；J3 與兩者互斥；原 uv 為 J2 到 J3 的唯一
環間 bridge，`u≠r`；p/q 外臂錨點是原 a1/a3，零長時 p=a1／q=a3。
允許 a3=v，不從「私有」一詞假定 H_M 二連通。

W−x 沒有 s-contact，故 x 是 H_M 的割點。r 仍是 C 的割點，但 s 的原 p/q
接線把 L/S 在 H_M 中接回，因此 r 不由此成為 H_M 割點。
本輪不使用 SD-A 的二連通前提；有一份真正 W 時，該前提實際不成立。

## 3. 全 degree 預算與第一個 W-block

對每個原 `z∈C`，寫 `t(z)=1_{sz∈E(M)}`、`k(z)=|N_B^M(z)|`。
完整原度數恆為

`4=d_M(z)=d_C(z)+k(z)+t(z)`。

對接點 x，m 是 W 在 x 貢獻的實際 C 邊數。下表 d0 只算 skeleton 的 C0 邊，
因此候選來源必給 `k(x)=4−d0(x)−m−t(x)`。這個必要預算不授權刪任何原附件，
也不從預算反推一份 disk embedding。

| 原接點 x | skeleton d0 | t | 原 B 附件必要數 | 可容第一個 W-block |
| --- | ---: | ---: | ---: | --- |
| r | 4 | 0 | −m | **任何 m≥1 都違反完整 degree4；結構排除** |
| a1，p 外臂零長 | 2 | 1 | 1−m | m=1；只能 bridge |
| a1，p 外臂正長 | 3 | 0 | 1−m | m=1；只能 bridge |
| J1 的其他私有點 | 2 | 0 | 2−m | m=1 bridge，或 m=2 odd-cycle／triangle |
| u∈J2 | 3 | 0 | 1−m | m=1；只能 bridge |
| J2−{r,u} | 2 | 0 | 2−m | m=1 bridge，或 m=2 odd-cycle／triangle |

拒絕 degree lists 的外部刻畫迫 C 及 W 的 blocks 為 Gallai blocks；上表用的是這個
必要結論，不把任意裸 block 稱為 Gallai block。第一個 W-block 的 clique K4 在 x
貢獻三邊，表中全部合法接點都沒有該預算。
內部其他 W 點也須逐點核 `d_C+k=4`，因為 W 沒有 s-contact；第一 block 可行的
degree 預算本身不證明後面的 block tree、actual B attachments 或 disk 都可行。

G 與 M 的唯一 degree 差是原 r 的唯一 B-spoke：`d_G(r)=5`、`d_M(r)=4`，
`k_G(r)=1`、`k_M(r)=0`。s 在两圖的三條原 B-spokes 與 p/q 均全留，完整 degree5。
其他有效內點包括整份 W 的原點在 G/M 都是完整 degree4。

## 4. 原 witnesses 保存與兩個精確例外

原 J1/J2 的合格候選集合改為

`W1=V(J1)−{r,a1,x}`（x 不在 J1 時不扣 x），
`W2=V(J2)−{r,u,x}`（x 不在 J2 時不扣 x）。

集合中的每個點只屬其本環 block，非 C 割點，非 s-contact，且原 list 包含 D。
其原 C 鄰居仍恰本環兩個原環鄰點，其餘原 M 鄰居恰兩個 B 附件。

| W 接線 | 兩個合格 witnesses 是否必存在 |
| --- | --- |
| x=a1 或 x=u | 扣除集合沒有增加第三個不同點；兩份任意奇環均存在 witness |
| x 為 J1 其他私有點、`|J1|≥5` | J1 至多扣三點，至少剩兩點；J2 原 witness 保留 |
| x 為 J2 其他私有點、`|J2|≥5` | J2 至多扣三點，至少剩兩點；J1 原 witness 保留 |
| **J1 triangle `(r,a1,x)`，x 與 r/a1 不同** | J1 選點集合空；J2 witness 保留 |
| **J2 triangle `(r,u,x)`，x 與 r/u 不同** | J2 選點集合空；J1 witness 保留 |

在最後兩列，x 是新割點，不能將 `D∈L^D(x)` 改寫成 `D∈S_J1` 或 `D∈S_J2`。
外部刻畫只給 `L^D(x)=S_Ji∪S_K`（K 是第一個 W-block），且兩 palette 互斥；
D 可以僅位於 `S_K`。這是舊選點推廣的第一個明確失敗步驟。

degree 預算本身沒有排除這兩份 triangle：m=1 或2都有非負 k。
**不宣稱那些裸 block 接線有 actual disk source，也不宣稱一般 D-routing 成立。**
下節的原 S 局部矛盾會在完整本輪來源合同中排除它們，使用不同且更窄的必要前提。

## 5. 逐原點 lists 與原 S pair 的新增 proof-use

原 M 的 lists 是

`L^D(z)=Col−(β(N_B^M(z))∪({D} if sz is an original edge else ∅))`。

完整原 degree4 直接给 `|L^D(z)|≥d_C(z)`。s=D 不撞任何原 s−B 边，因為 β 未用 D。
若存在 C 的完整 L^D-coloring，沿全部 B−B、B−C、s−B、s−C、C−C 原邊，
與同一 β、s=D 接成 M 的完整 coloring；若合同保留孤立自由原內點，另保留其原自由因子
並任意填色。這違反 M 自己拒絕 β。因此 C 不可著色。
外部 Dvořák 刻畫給每個原 block K palette S_K，奇環大小2、bridge大小1，
每個原頂點 list 等於 incident palettes 的互斥聯集。

新增 proof-use 是對**整份原 S 的 raw actual support**精確套用：

`N_B^M(S)=N_B^G(S)={b_i,b_{i+1}}`。

M 只刪 r-spoke，不改任何 S−B 邊。原 q 外臂、J3、v 都在 `H_G−{r,s}` 的同一
原 S，故每一原點 z∈J3／q 外臂都有 `N_B^M(z)⊆{b_i,b_{i+1}}`。
若 W 接 J2，整份 W 也必遵守這個 raw support 限制；不能借 boundary 同色重命名
或另外添一個框點。W 接 J1 時，S 本身及 J3／q 外臂仍沒有改動。

在同一 β 下，真框邊 endpoints 顏色不同；命名為 A/B，第三個 β 色為 T，未用色為 D。
這是同一 literal 色框中的符號名，不是對各 block 各自的色置換。

1. 選 `w3∈V(J3)−{v,a3}`。奇環至少三點，至多排除兩個不同點，故任意環長都存在。
   W 不接 J3；w3 非割點、非 s-contact，d_C=2，完整 degree4 強迫 k=2。
   raw pair support 強迫它的兩個實際 B 鄰居恰為 b_i/b_{i+1}，因此
   `L^D(w3)={T,D}=S_J3`。
2. q 外臂零長：`q=a3` 有原邊 sq，故 `D∉L^D(q)`；但 q 屬 J3，所以
   `D∈S_J3⊆L^D(q)`。矛盾。此步含 a3=v，不要求 q 非割點。
3. q 外臂長1：原 first edge E=a3q 是 bridge。q 是端點，d_C(q)=1、t(q)=1，
   完整 degree4 给 k(q)=2，兩個原 B 鄰居恰 pair，故 `L^D(q)={T}`。
   q 只屬 E，故 `S_E={T}`；在 a3，E 與 J3 palettes 必互斥，卻相交於 T。
4. q 外臂長≥2：記 z 為 a3 的第一個原 off-cycle 鄰點。z 不是 q，沒有 s-contact，
   只屬外臂兩個 bridge blocks，d_C(z)=2，k(z)=2，所以 `L^D(z)={T,D}`。
   原 first edge E=a3z 的非空 singleton palette 滿足 `S_E⊆{T,D}`，
   但在 a3 必與 `S_J3={T,D}` 互斥。矛盾。

所有接點與 lists 都在同一原 M；沒有把割點 D-presence 平均分配給各 palette。
長臂情形只需一條原 first edge 的 palette 包含於其另一端點的完整 list，
因此不需要推一條未證的通用 D 傳遞引理。

這份局部反證在候選原來源内涵蓋一份 W 接 J1/J2 的全部 degree 合法位置、
兩個 triangle 例外，以及任意原三環／外臂／W 大小。
它只因本輪保留 terminal J3 與未改動 q 外臂而適用；若旁支改接 J3／q 外臂，
讓 w3 變割點、添 q-arm 附件、增加 s-contacts，或不再有 raw true edge-pair support，
這個對照不能繼續使用。

# 六接點迫色：原共同鄰點公式與商圖障礙

2026-10-15。BASE `6ddea32a81349821ad3724ae1652bddb9c6a7b04`。
本輪只寫獨占目錄；原圖、命名及色框保持不變，未 commit／push。

**新任意大小推論是原 U 的三個精確共同鄰點公式；它們進一步證明，
用指定三點商圖迫出六接點禁止事件的路線必出現 loop 或非平面。**
完整證明與每個原環的有界側理由見 [PROOF.md](PROOF.md)。

固定原最小來源 `d_G(x)=d_G(y)=d_G(b)=4`、`d_G(r)=6`，令
`a0=d_G(a)`、`c0=d_G(c)`。在同一個 `U=R-r` 中：

| 新公式 | 精確條件 |
| --- | --- |
| `N_U(s)∩N_U(t)={z}` | 本固定 r6 來源 |
| `N_U(s)∩N_U(p)={z}∪({q} if c0=4)` | 本固定 r6 來源 |
| `N_U(t)∩N_U(p)={z}∪({j_a} if a0=5)` | `tp` 不存在，即 `a0≥5`；j_a 是原 a-fan 唯一中點 |

原小 C5 `(x,s,j,t,y)` 的有界側含 r，故排除額外 st 共同鄰點；
`(s,c,b,p,j)` 的有界側含 q，會迫 `q=5,c0=4`，違反已採納低 q 界；
原空 C4 `(t,a,p,j)` 則迫原完整 a-fan 為 `(y,t,j,p,b)`。
整圖反射給 q 側對應式。這些是來源必要幾何推論，不是從有限表宣稱實現。

合法第一步 `J=U/(s=t)` 因此恰有 `k−1` 點、`3k−9` 邊，是球面三角化圖。
既有薄 C5 cap 的成本 `k−3<k` 供應一份完整 `s=t` 染色；未指定其 pq。

六點事件 `E: s=t 且 {p,q}∩{v,w}=∅` 精確分為兩個 whole-graph 義務：

`H_p=U/(s=t=p)+qv+qw`，`H_q=U/(s=t=q)+pv+pw`。

其完整染色與原 U 的兩個互斥事件 fibres 逐份雙射。單有 `s=t=p/q`
尚不等於 E；上列額外不等式不可省略。若再按 `z=v/w` 分四支，各支
是 `K_{d,e}=U/({s,t,d},{z,e})+opposite(d)opposite(e)`，仍保全部私有點。

令 `δ_p=[a0=5]+[c0=4]`。`tp` 存在時 p 支產生原邊 loop；否則
`h=a0+c0−8≥3` 給 `δ_p≤1`。三點識別精確抑制 `2+δ_p` 條重邊，故
`I_p=U/(s=t=p)` 的邊數超過平面上界 `2−δ_p≥1`。
q 側反射同理。H 的超額至少3；四個 K 的超額至少4。
這是任意嵌入均非平面的密度證明，不只是某組面內弧會交叉。

直接 `U/(s=t)+pv+pw+qv+qw` 更固定含 K₃,₃，兩側為
`{z,v,w}` 與 `{[s=t],p,q}`。上述來源推論另封住了將它拆成較小商圖的做法。
數值上的薄 cap 成本雖較小，但非平面商圖無法套原最小性；拆回全部識別
並恢復原 G 的完成成本仍為 `k+5`，沒有保壞嚴格下降。

有限 checker 並未重跑原26列。它直接核對事件的96份具名局部賦色、全部
r lifts，以及帶私有點 h 的三份 whole-graph controls。其完整染色數為
2880／1920／1920，事件 fibres 為192／96／96；完整 pin fibres 與空格均保留。
這些控制不是原最小來源。[驗證](VERIFICATION.md)包括正常、seed17、
刪除完整 lift／刪空 fibre／損壞密度資料三種拒絕，以及 exclusive-create 拒絕。

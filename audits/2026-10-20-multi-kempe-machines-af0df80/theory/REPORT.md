# 三個互補色對狀態機：可閉合的部分、同步的限制與新增分析

固定 BASE `af0df8081e79b51f8b24e17e01b2bd5572e46a0a`；本頁只讀
[凍結契約](../frozen/audits/2026-10-20-joint-kempe-state-1148ce0/SOURCE_CONTRACT.md)、
[前輪理論](../frozen/audits/2026-10-20-joint-kempe-state-1148ce0/theory/REPORT.md)
及 cell95 的完整原邊。結論是：**每一台對自己的互補色對動作都能精確
更新；三台一起讀同一染色，能分析跨台相容性與資訊增加，但仍不能只靠
三份當前摘要決定任意下一步。** 以下一般命題只需固定有限圖，不用平面性。
有限控制及明列反例則限於八點 cell95；沒有一般 J1 結論。

## 1. 同一個實際系統，三份同步觀測

固定完整圖 G、有序具名接點 B、字面色名 0,1,2,3，以及同一完整 proper
染色 c。`π_ab(c)` 由全圖實際 maximal ab components 的非空 B 交集組成。
三個 channel 為

```
O_A(c) = (c|B, π_01(c), π_23(c)),   Σ_A = {01,23} × B;
O_B(c) = (c|B, π_02(c), π_13(c)),   Σ_B = {02,13} × B;
O_C(c) = (c|B, π_03(c), π_12(c)),   Σ_C = {03,12} × B.
```

標籤 `(ab,r)` 在 `c(r)∈{a,b}` 時，交換含原 r 的完整實際 ab component；
否則非法，輸出明記 `⊥`。`Σ=Σ_A∪Σ_B∪Σ_C`。所有 root 限於原 B，
沒有新增私有點 root，也沒有把 hidden components 合為空 block。

本頁「同步」是每執行一個實際 action，三台都讀取同一份結果染色。
原圖與接點身份固定；每一步的完整私有染色及字面色框由三台共用。
沒有讓三台各選一份 witness，也沒有把不同時間的觀測拼成一份當前狀態。

## 2. 每台對自己的 alphabet 確實是確定狀態機

**命題。** 若 `O_A(c)=O_A(d)`，則對每個 `α∈Σ_A`，c,d 的合法性相同；
合法時 `O_A(αc)=O_A(αd)`。B、C 兩台亦同。

**證明。** 以 `α=(01,r)` 為例。交換0/1不改變頂點是否屬於色集
`{0,1}`，也不改變是否屬於 `{2,3}`；G 的邊沒有改變，故兩份 induced
graphs、全部實際 components 及兩份接框分割完全不變。合法性由
`c(r)` 決定；新框色只在 `π_01` 中含 r 的 block 逐點交換0/1。
這些資料全在 O_A 內。23 動作及其他台同理。□

因此可直接寫出 transition：

```
(f, π_ab, π_de) --(ab,r)--> (swap_ab on block_r(f), π_ab, π_de).
```

同一台的一切有效 visible component toggles 互相交換次序而結果不變：
相同 pair 的 components 互不相交，互補 pair 的頂點集亦不相交；
上述 component 集合在整段自己的 alphabet word 中固定。
若當前兩份分割共有 k 個非空接框 blocks，則從一份 c 出發的這種
rooted-action orbit 恰有 `2^k` 份完整染色，亦有 `2^k` 份不同 O：
每個 block 可由其中任一 root 獨立翻轉；不同子集在至少一個框點異色。
各 root action 名字可能指同一 component，故不能把 root 數誤當 k。

若額外允許自己的 hidden component swaps，它們在該台是自迴圈，但
完整染色 orbit 會擴大；這些操作對其他台未必是自迴圈。因此上面的
`2^k` 完整染色數只適用於明列的 rooted grammar。

O_A 亦恰等價於「框色加全部長度至多一的 Σ_A 框色觀測」：正向由
transition 公式；反向逐 root 比較動作前後哪些框點異色，恢復它的
component block。因自身已閉合，更長的**純 Σ_A** 字串不會再拆細
O_A 的等價類。新增辨識力必須來自混合 alphabets 或額外觀測。

## 3. 跨台動作與同步乘積仍缺什麼

01 動作保留 A 的兩份分割，但 B、C 的四份分割全部是 mixed pairs。
例如新02圖必須先刪實際 component S 內的舊0頂點，再加入 S 內的
舊1頂點及它們對舊2頂點的原邊；舊 component 可能分裂，新 stars
又可能把 residual components 接起來。僅有接框分割看不到這些資料。
其他色對對稱。因此一台可作自己 alphabet 的自主機器；對外來動作，
它仍需實際圖染色、足夠的 surgery 資料，或觀測到的真正新狀態。

同步三元組

```
J(c) = (O_A(c), O_B(c), O_C(c))
```

除三份重複框色外，恰是前輪「框色＋六分割」；不是更細的摘要。
前輪同圖反例直接保留：

```
c = 01012132,  d = 01012233,  J(c)=J(d).
α = (12,1):
αc = 02012231, αd = 02012233.
```

α 屬 C 的 alphabet，故兩個結果的 O_C 相同；O_A 不同：

| 觀測 | αc | αd |
| --- | --- | --- |
| π_01 | {0,2,3} | {0} / {2,3} |
| π_23 | {1} / {4} | {1,4} |

這是**自己這台精確更新，其他台卻需要隱藏資訊**的同一步例子。
因此三台即使共同限制到真正同 witness 的 tuples，也未成為 Σ 上的
確定 quotient。把非確定後繼畫成多條邊，可精確記錄一步可能性；
若跨步自由串接，仍可能每一步換了一份 witness，產生假可達路徑。

本圖已實際出現這種拼接錯誤，甚至只需重複同一個 α。初始 joint
fibre 恰為上面的 `{c,d}`。執行 α 並觀測 `J(02012231)` 後，
真正的當前候選只剩 `02012231`；但這個 joint 類另含
`02012133`，它不在原 fibre 的一步像中。若忘記歷史，允許在中途
偷換到這份染色，再執行 α，就會誤報結果 `01012133` 的另一個
joint 類可達。真正連做 α、α 是對合，必回到原完整染色。
[兩步計數證書](../coupling-v2.json) 記錄46,272條抽象觀測路徑、
45,888條實際可實現路徑，相差384條；`theory/check.py` 獨立核對
這個具體 witness，不重算總數；完整計數與交叉核對由父 audit 保存。

跨台操作也不能一般視為無次序的同時交換。在同一 c 上令
`α=(01,0)`、`β=(12,4)`，兩種次序均合法，但

```
先 α 後 β：20201031;
先 β 後 α：10120032.
```

同步觀測有明確意思，跨台同時執行仍須另定排程及衝突規則。
這個負控制及上面舊碰撞由 [獨立 BFS checker](check.py) 按原邊重算。

## 4. 三台一起能新增哪些可分析資訊

固定同一字面框 f，先由完整染色形成真正 relation

```
R_f = {(O_A(c),O_B(c),O_C(c)) : c|B=f},
Ω_f(x,y,z) = {c : c|B=f, O_A(c)=x, O_B(c)=y, O_C(c)=z}.
```

每個實際 triple 留完整 Ω；比較用的候選格即使 Ω 空，也應顯式記錄。
以下量均能由完整固定圖 fibres 分析：

| 分析 | 可回答的問題 | 必守界線 |
| --- | --- | --- |
| 同框相容性 | 各台各自可行，哪些組合沒有共同染色？ | 比較 R_f 與同 f 的邊際乘積，不能先混不同 f。 |
| 三台相關性 | 加第二、第三台後，哪個 witness fibre 被再分開？ | pairwise 相容不自動推出三方共同相容。 |
| 條件資訊量 | 給定一台後，另一台剩多少候選、多少完整 lifts？ | 熵或機率需明定抽樣分布；類數不等於機率。 |
| 跨台更新依賴 | 哪個外來 action 使某台的同觀測 sources 分岔？ | 同步 successor triple 必須來自同一 c，不能獨立挑後繼。 |
| 混合字串辨識 | 哪串跨台 actions 能分開當前三台仍相同的兩份染色？ | 這是額外未來測試能力，不是重排當前欄位。 |
| 操作次序與不變量 | 哪些 moves 可交換、哪些分割在受限 word 中保持？ | 自身 alphabet 的交換性不能延伸到所有 alphabets。 |

其中真正新的結構訊息是「誰與誰能共同出現」、「哪一步把歧義傳到
哪個 channel」及「需要什麼混合測試才看得出私有差異」。
多台的存在本身不增加 J 的資訊；不同投影、同步限制及實際歷史
才提供可量化的分析。

這張圖的實測須與一般可分析項目分開：
[實驗證書](../experiment/certificate.json) 在144個實現的字面框中，
真正 joint tuples、同框邊際乘積及 pairwise join 都合計192個；
**沒有**找出靜態「各自可行卻不能共同出現」的空格。
固定當前 joint/action 後，
[後繼檢查](../coupling-v2.json) 的邊際乘積也沒有額外假 tuples。
所以本輪不能宣稱觀察到非平凡的靜態相容排除；已觀察到的是增加
channel 的分辨率、跨台更新歧義，以及上節的**跨時間 witness
拼接**。一步集合無假 tuples，不等於多步路徑無假拼接。

## 5. 未來細分與已走歷史是兩件不同的事

**未來行為細分。** 設 `P_0(c)=J(c)`，遞迴

```
P_(t+1)(c) = (P_t(c), (P_t(αc) or ⊥)_(α∈Σ)).
```

P_t 比較**所有**長度至多 t 的未來 action words 的 J 輸出。
它會保留從未真的執行的分支；不是在現場多記 t 次實際觀測。
前輪凍結 cell95 的 `192→240→264` 是這種 refinement，
當前三台 J 的192類與舊摘要完全一致。有限終止來自此圖有限染色數，
不給任意 disk 的統一類數、深度或有界內部描述。

**線上歷史信念。** 若現場知道初始觀測 j_0，精確候選集合為
`E_0={c:J(c)=j_0}`。真正執行 action α_t 並觀測 j_(t+1) 後更新

```
E_(t+1) = {α_t c : c∈E_t, α_t legal at c,
                        J(α_t c)=j_(t+1)}.
```

這是當前完整染色候選集合；只保存三台當前摘要不足以重建它。
每個 rooted swap 在其合法域上為對合，所以此精確更新不增加候選數；
觀測可以剔除候選。然而一條實際歷史可能一直沒走到能區分候選的
動作，不能從「所有未來分支可區分」推論「任意長歷史都能識別」。
本圖亦有明確負控制：從上面的二元 fibre `{c,d}` 重複
`(01,0)`，兩份候選始終給相同三台觀測，兩步後又回原 fibre。
故任意長度的這種實際歷史都保留兩個候選；checker 獨立重播此循環。

若一段 word 能分開兩份候選，該 word 後接反序 action word 可回到
原完整染色（每步皆為同一 root 的對合）。這給主動試探及還原的
方法；若要聲稱最短識別成本，還須指定可讀哪些 channel、可選哪些
actions、是否容許重置，以及最壞或平均成本。本輪未證此類界。

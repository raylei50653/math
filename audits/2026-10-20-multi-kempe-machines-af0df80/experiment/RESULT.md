# 同時三個 Kempe 監測器：固定 cell95 的完整有限實驗

BASE：`af0df8081e79b51f8b24e17e01b2bd5572e46a0a`。
證據：[check.py](check.py)、[certificate.json](certificate.json)。
只在本實驗目錄產生檔案；不修改凍結輸入，不 commit 或 push。

結論：加入第二、第三個監測器，增加能直接區分的狀態，減少不能確定
後繼的「類別／動作」組合。每個監測器對自己的兩個互補色對操作已封閉；
容許全部六色對輪流作用時，三個監測器一起仍然不封閉。這個有限實驗中，
所有非空監測器組合均需兩輪 Moore 細化，最後都區分全部 264 份染色。

## 固定來源及完整狀態

使用凍結 catalogue 的 `cells["95"]`，補上有序原框
`B=(0,1,2,3,4)` 的五條邊。圖有 8 個具名頂點及 16 條邊。
所有色名為字面 `0,1,2,3`，不作全域換色商、不混合圖。
catalogue SHA256：
`04650cea947a5086360e895c1a7350690f53da745314379a3328b97ee02d81b8`。

獨立枚舉全部 `4^8` 字面染色，按原圖邊篩出 264 份 proper 染色。
用 adjacency DFS 求全圖 maximal bichromatic components，
不匯入舊 audit 的 DSU 或 refinement 程式。
全部染色、圖邊、30 個動作、264×30 的完整轉移表均保存於證書。

動作 `(a,b,r)` 的 `r` 固定屬於原框 B；只交換全圖中含 r 的完整
maximal ab component。當 `c(r)` 不屬於該色對時，後繼為 `-1`。
每份染色恰有 15 個合法動作，共 3,960 個合法有向轉移；
每個合法動作都已核對同標籤作用兩次返回原染色。

三個監測器為：

| 監測器 | 保存的資訊 |
| --- | --- |
| M1 | 字面框色及 `pi_01, pi_23` |
| M2 | 字面框色及 `pi_02, pi_13` |
| M3 | 字面框色及 `pi_03, pi_12` |

`pi_ab` 是全圖 ab components 與 B 的非空交集所成分割。
任何聯合列的全部座標必須出自同一份完整染色。

## 多監測器增加的可區分資訊

以下「歧義類別／動作」指同一觀測類別內，某一固定標籤得到兩個
不同觀測後繼（或合法性不一致）。目前的合法性已由字面框色決定，
所以實際衝突均來自不同的後繼觀測。

| 觀測 | 初始類別數 | 有歧義的類別數 | 歧義類別／動作數 | 共同 30 動作的 Moore 類別數序列 |
| --- | ---: | ---: | ---: | --- |
| 只有框色 | 144 | 見證書 | 見證書 | 144 → 192 → 240 → 264 |
| 任一個監測器 | 160 | 32 | 288 | 160 → 224 → 264 |
| 任兩個監測器 | 176 | 48 | 240 | 176 → 240 → 264 |
| 三個監測器 | 192 | 48 | 96 | 192 → 240 → 264 |

三種單監測器、三種雙監測器均逐一重建，數值各自相同。
每加一個監測器，初始類別增加 16；三個相對一個增加 32。
這是觀測等價類數目的增加，不是聲稱有 32 個獨立 bits。
歧義類別數本身會隨類別細分而增加，故不能單獨當作改善指標；
歧義類別／動作數由 288 降至 96，而完全封閉仍未達成。

各輪歧義類別／動作數依次為：

- 單監測器：`288 → 192 → 0`。
- 雙監測器：`240 → 96 → 0`。
- 三監測器：`96 → 96 → 0`。

限制每個監測器只能接受其自己兩色對的 10 個根動作時，
M1、M2、M3 各自都是 160 類、零歧義，無須再細化。
因此本例直接分辨了「各自操作封閉」與「在共同操作下聯合封閉」：
前者成立，後者不成立。

## 同來源的明確反例與深度

下面染色字串的頂點順序一律是 `0,1,2,3,4,5,6,7`。

初始反例：

```
c = 01012132
d = 01012233
```

兩份染色的三個監測器全部相同。動作 `(1,2,root=1)` 後：

```
c' = 02012231
d' = 02012233
```

目標的字面框色相同，但 M1 分開：
`pi_01(c')={{0,2,3}}`，
`pi_01(d')={{0},{2,3}}`；
`pi_23(c')={{1},{4}}`，
`pi_23(d')={{1,4}}`。
這是一個共同圖、共同框色、共同原動作的聯合狀態更新反例。

另有一對染色需兩步才被聯合觀測區分：

```
01023213 --(1,2,1)--> 02023213 --(1,3,4)--> 02021233
01023312 --(1,2,1)--> 02023311 --(1,3,4)--> 02021133
```

起點及第一步的三個監測器全部相同，第二步 M1 不同。
所有單步動作都不能區分這一對；程式以同時走兩份染色的 BFS
驗證最短區分長度為 2。再施 `(0,1,0)`，兩條路徑的框色才變為
`12020` 與 `12120`；框色觀測的最短區分長度是 3。
全部中間染色與觀測分割都在證書內。

## 靜態相容性與轉移相容性：本例都是零偽組合

對每個固定字面框色 beta，從同一圖的全部完整 lifts 求三個 marginal
集合，再比較：

1. 三個 marginal 的 Cartesian product；
2. 三份真正二元投影的 pairwise natural join；
3. 同一完整染色產生的真正三元關係。

144 個非空字面框色合計，三者都是 192 列；偽 Cartesian 列與偽
pairwise-join 列均為 0。本例每個字面框色下，至多只有一個監測器
有多種可能值，因此沒有產生同框靜態拼接衝突。
這個零值只描述本圖，不證明一般圖的三個 marginal 可自由組合。

另外固定完整三監測器來源類別、同一動作、同一目標字面框色，
比較各目標座標的可能集合與真正目標三元關係，也未產生額外
Cartesian 或 pairwise-join 偽列。雖然沒有這類偽列，同一觀測類別
仍可能有多個真正後繼，故這個零值不表示聯合觀測已是確定狀態機。

更長路徑的共同見證由另行計算的
[coupling-v2.json](../coupling-v2.json) 檢查：若只保存三監測器商狀態，
再把各條存在的商轉移自由接起來，長度 2 的觀測路徑有
46,272 條，但同一份完整染色可實現的只有 45,888 條，差 384 條。
即使連續兩次施同一個 involution 動作，也可能由中途換掉完整 lift
而產生假的終點。這是跨時間共用來源失敗；與上面同一時刻的零偽列
是不同問題。此項證據由整合／獨立 review 程式提供，
不列作本目錄 `check.py` 的重建結果。

## 重播、次序控制及負控制

以下皆成功；命令在 repo root 執行：

```
python3 -B audits/2026-10-20-multi-kempe-machines-af0df80/experiment/check.py --check
python3 -B audits/2026-10-20-multi-kempe-machines-af0df80/experiment/check.py --check --seed 17
python3 -B audits/2026-10-20-multi-kempe-machines-af0df80/experiment/check.py --negative-controls
```

seed 17 先打亂 `4^8` 候選枚舉次序，再重建 canonical 輸出，
逐 byte 與既有證書一致。此控制針對枚舉次序，不作隨機圖外推。

負控制均在獨立臨時副本上執行，四項均拒絕：
錯誤染色總數、刪去空 fibre、把不同字面框色的 marginal 座標拼接、
把非法動作改成 self-loop。負控制屬證書污染拒絕測試；
有限數值另由完整重建及獨立 review 核對。

## 證據邊界

本例提供有限資訊增益、操作相依性、最短可觀測深度，以及完整
相容關係的可重播數值。沒有完整 J1 來源觸發：
`j1_source_status = not triggered`。一般多監測器閉包與一般
retained-pin 界保持 OPEN；264 類封閉只指這張固定圖與原框根動作。

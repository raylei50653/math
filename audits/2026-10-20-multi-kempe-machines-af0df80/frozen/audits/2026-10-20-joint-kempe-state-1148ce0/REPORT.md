# 同染色聯合 Kempe 狀態初驗：八點反例與觀察深度

2026-10-20。**第一版「框色＋六對接框分割」不能自行更新：同一張
八點 C5 disk、相同字面框色、相同六份分割，經同一 rooted Kempe
action 得到不同的下一份摘要。** 這否定這一版摘要的一般逐步充分性；
同染色 joint 的方法仍可用於分層、診斷及增加必要資訊。

新紙面定位是：對所有以接點為根的單分量交換，這六份分割恰等價於
**深度一的字面框色觀測**。它不是完整未來行為碼。

BASE、凍結來源及原有未提交工作界線見 [BASE](BASE.json)、
[輸入雜湊](INPUTS.json)、[完整契約](SOURCE_CONTRACT.md)。
本輪有紙面命題、固定真圖有限證書及獨立核對；沒有新 Lean、
941 來源實現、最後拒絕排除或較小 bad，也沒有 commit／push。

## 1. 精確候選與動作

固定同一圖 G、有序接點 B、同一份完整 proper 四色染色 c。
`pi_ab(c)` 是全圖實際 maximal ab components 與 B 的非空交集分割。

```
S_B(c) = (c|B, pi_01(c), pi_02(c), pi_03(c),
               pi_12(c), pi_13(c), pi_23(c)).
```

六個色對全部由同一 c 求得，私有點參與連通判定，沒有逐色對另選見證。
同一 action `(a,b,r)` 交換含原接點 r 的完整 ab component；當 r 的色
不在 ab 時，action 不合法。根在 B 的 grammar 不含 hidden component
swaps；完整 Kempe 可達性若需要那些操作，必須另保留。

這一版只保留接點分割，未保存每個分量的全部私有頂點身份。
若保留所有頂點在六個色對系統中的身份，僅從一頂點屬於哪三個色對
已能恢復其顏色，實際回到完整染色資訊；不是本輪測試的壓縮摘要。

## 2. 同圖、同色框、同動作的真 disk 反例

取凍結 catalogue 的 `95` 代表，頂點 `0,...,7`，原框
`B=(0,1,2,3,4)`。除五條框邊以外，全部邊為

```
05 06 07 17 25 26 27 36 46 56 57.
```

比較兩份完整字面染色：

```
c = 01012132
d = 01012233
```

它們的原框都是 `01012`，六個接框分割也逐項相同：

| 色對 | c 與 d 的共同接框分割 |
| --- | --- |
| 01 | {0,1,2,3} |
| 02 | {0,2,4} |
| 03 | {0,2} |
| 12 | {1} / {3,4} |
| 13 | {1} / {3} |
| 23 | {4} |

同一 rooted action `((1,2),1)` 在 c 中交換 `{1,5,7}`，在 d 中交換
`{1}`。兩者都取當時的實際完整分量；不是把一份染色的頂點集合
直接套到另一份染色。結果：

| 來源 | 完整目標 | 新框色 | 新01分割 | 新23分割 |
| --- | --- | --- | --- | --- |
| c | `02012231` | `02012` | {0,2,3} | {1} / {4} |
| d | `02012233` | `02012` | {0} / {2,3} | {1,4} |

再共同執行 `((0,1),0)`，分別交換 `{0,2,3,7}` 與 `{0}`，完整目標
為 `12102230` 與 `12012233`；框色已分成 **`12102` 與 `12012`**。
所以相同初始 joint 摘要連兩步後的框色都不能決定。

[主證書](experiment/certificate.json) 保存全圖、十個完整字面 fibres、
反例前後全部六組完整 components 及實際動作。
[獨立幾何與染色核對](review/check_collision.py) 使用精確有理數座標：
外框 `(0,0),(4,0),(6,3),(3,6),(0,4)`，內點為

```
5=(206,127)/71, 6=(169,210)/71, 7=(229,85)/71.
```

逐邊、逐面與面積驗證這是真正以原 C5 為外框的 disk。
此圖完整支持是95，**完整 r6／941／J1 來源前提 not triggered**；
反例不排除那些更窄來源上的額外結構。
也沒有宣稱八點是所有 disk 反例的最小大小。

## 3. 有限域初驗與增加接點

主實驗只重播132份已保存代表，沒有重新枚舉 disk 圖宇宙。
十個 canonical 框色逐一保留完整字面 fibres；目標不獨立換色正規化。
狀態數在各圖內分別計數後加總。

| 有限核對項目 | 結果 |
| --- | ---: |
| 固定圖／完整框色 fibres | 132／1,320 |
| 空 fibres／完整字面 lifts | 405／1,810 |
| 聯合摘要 | 1,280 |
| 由聯合摘要進一步分開的框色 fibres | 310 |
| 已執行 rooted actions | 27,150 |
| 有摘要相同而後繼不同的圖 | 90 |
| 有歧義的摘要／動作組合 | 1,229 |

以上顯示 joint 確有增加可觀察資訊，但不足以給確定的摘要更新。
沒有碰撞的其餘42份代表，只在本有限域通過，不是一般充分性定理。
詳細逐圖結果及四種污染拒絕見 [實驗說明](experiment/RESULT.md)。

另以獨立的 `4^8` 全字面枚舉與 union-find 在95圖上做
[保留接點與逐步細分](refine.py)，保存 [證書](refinement.json)。
全圖恰264份 proper 字面染色，3,960個合法 rooted actions；
**所有測試的動作根都仍限於原五個框點**。

| 觀測／保留接點 | 摘要類數 | 是否可在此圖更新 |
| --- | ---: | --- |
| 原六分割 | 192 | 否 |
| 再保留內點5的顏色及其六分割位置 | 264 | 是 |
| 再保留內點6 | 192 | 否 |
| 再保留內點7的顏色及其六分割位置 | 264 | 是 |

本固定圖的最小新增接點數為1，選5或7都可以。但264類已逐份區分
全部完整染色，這個修正沒有壓縮染色狀態，也不給一般一接點上界。
新增觀測接點沒有新增 action roots；不可對這個變體直接套下一節
「所有觀測接點皆可作根」的等價式。

固定95圖的完整 action graph 上，逐輪按全部標籤後繼細分：

```
只觀察框色：144 → 192 → 240 → 264（穩定）
六分割摘要：     192 → 240 → 264（穩定）
```

因此在此圖、此 grammar，完整框色未來行為區分所有264份染色。
這個深度三／深度二是固定有限圖的結果，不是任意 disk 的統一深度界。

## 4. 紙面定位與下一版候選

對所有 `(ab,r), r in B` 的 rooted actions，若保存原框色與每個合法
一步後的框色，就能由「哪些位置改色」重建含 r 的分量接框 block。
對全部 r、ab 重做，恰得到六份分割。反向則由分割直接計算新框色。
所以

```
S_B(c)=S_B(d)
  iff 所有長度至多一的 rooted action 字串給相同字面框色觀測。
```

非法動作也作明確觀測。完整證明、hidden actions 界線見
[理論 §2](theory/REPORT.md#2-action-grammar-與六分割確定的部分)。

反例的缺失資訊是交換所涉及的私有區域，以及混合色對在刪除／加入
頂點後的連通變化。下一版宜針對指定 action 保留：

1. 先刪被換走的該色頂點後，剩餘的實際 components；
2. 新加入色頂點對這些 components 的實際接線；
3. 具名接點在所得 quotient 上的位置。

既有 [connectivity surgery](../../docs/c5_kempe_connectivity.md#1-一次交換的六個色對)
精確給出這種單步更新；該引理已有普通 Lean，本輪只是重用。
四個混合色對的 quotient 仍須由同一染色、同一分量建立。
這是**指定一步的充分描述**；它能否在交換後繼續更新、能否保持
有界大小，仍為 OPEN。

## 5. J1 的接續接口與停止點

在同一原核心 F 的兩個剩餘字面 fibres 中，將既有 `01|23` 的
S／M兩層，與 `03|12` 的I／II／III三型一起記錄，可定義六格
**實際共同染色子fibres**。每格允許為空，尚未供應六格的共同來源。
其餘兩個色對仍保存，沒有以兩份投影取代完整 joint。

固定在這兩個字面 fibres 內的可見單次交換，只能是S層的01
`{v,w}` 分量交換；這是既有總體分層雙射。它可能改變I／II／III型，
不能宣稱逐格配對。Hidden component swaps 也可能改變分層，不能
因框色不變就刪去。完整合同與逐格必要條件見
[理論 §4–5](theory/REPORT.md#4-固定-j1-來源的必要-joint-類型)。

本輪停止於：

* 一般六分割逐步充分性：已由真disk反例否定。
* 六分割的深度一觀察等價：紙面證明。
* 固定95圖的加接點與有限細分：完整有限證書。
* J1：條件式接口整理；來源 not triggered，兩個目標 fibres 仍未排除。
* 一般增強狀態閉合、成功／較小bad下降及新Lean：OPEN。

接續應在具名 J1 操作上，對同一完整染色建立四個 mixed-pair
surgery quotients，檢查哪個 residual 分裂或附件可由原來源幾何控制；
有限存活或抽象六格都不替代這項來源義務。
目前入口由 [State 導覽](../../docs/c5_state_guide.md) 維護。

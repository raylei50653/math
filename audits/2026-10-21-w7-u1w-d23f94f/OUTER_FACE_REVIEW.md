# 五個原外側第三面點的獨立 link 審查

2026-10-21；只讀審查。這不是 u1w 證書的額外前提。
依據為原 SOURCE_CONTRACT 的同一實際 W7／rotation、原 C3 有界側空，
及原結構證明的外側點至多接兩個相鄰 W7 框點。

沿 `n,u4,u3,u2,u1,L` 五條原邊，令其 W7 外側第三面點依序為
`z1,z2,z3,z4,z5`。既有外側接觸引理保證五點互異，均不在 W7 圈上，
且均異於 n–h、h–L 的外側第三點 p、q。對無弦 profile 0，五點皆為
同一 D 的私有點；profile 1 只有弦 au4，第一點為 `z1=a`，不能仍稱
五點全私有。其餘點仍為 D 的私有點。

## 四個 ui 的完整 link

在某個 ui，令 P、Q 是原五邊路上的前後鄰點，並令 z、z′ 是相鄰兩條
路邊的外側第三面點。原 W7 面與外側原面固定了 link 的兩段：

```
P — R — Q,
Q — z′ — (零個或多個額外原鄰點) — z — P.
```

所以 ui 至少有五個不同原鄰點 `P,R,Q,z,z′`。若 `dG(ui)=5`，外側
link 的額外鄰點數為零，原三角化迫原邊 zz′。

反向不能僅由「存在 zz′」宣稱它們在 link 相鄰。必須先看原簡單三角
`ui–z–z′–ui`。原 C3 有界側空使它成為原有界三角面，因此其在 ui
的某一個 link 角沒有其他鄰點。link 的另一弧已含不同的原點 P、R、Q，
所以原面只能占 z 到 z′ 的外側弧。這迫該外側弧沒有任何額外原鄰點，
故 ui 的全部原鄰點恰為五個，`dG(ui)=5`。

因此對 ui=u4,u3,u2,u1，均有完整等價：

```
z1z2 ∈ E(G) iff dG(u4)=5,
z2z3 ∈ E(G) iff dG(u3)=5,
z3z4 ∈ E(G) iff dG(u2)=5,
z4z5 ∈ E(G) iff dG(u1)=5.
```

這不允許在未知 degree 下補上任何一條 zi z(i+1) 邊。

## 左右端的完整 link

L 的已知 link 是
`h–R–u1–z5–(額外原鄰點)–q–h`。
所以 L 至少五度，若恰五度，外側 link 直接迫原邊 z5q。

profile 0 的 n 已知 link 是
`a–p–h–R–u4–z1–(額外原鄰點)–a`，六個鄰點全部不同。
所以 n 至少六度，六度直接迫 az1。
反向若 az1 原有邊，原三角 n–a–z1 由原 C3 定理為真原面；
另一段 link 已含 p,h,R,u4，故外側 z1 到 a 的 link 弧必空，迫 n 恰六度。
因此 profile 0 上 `az1 ∈ E(G) iff dG(n)=6`。

## 03 色框與來源缺口

在原選定的實際 witness 上，五條路邊端點均為 1、2，所以每個 zi
均為 0 或 3。這個事實**本身不表示**五點已相鄰，或已在同一個實際
03-component 中。

原 type III 的那一份完整 F 著色已給 03 邊界分量
`{a}`、`{R}`、`{q,z0}`，所以 a 與 q 在同一份著色中分離。
刪 R 得到 D 亦不會連接原來分離的兩點。完整原 family 對 A、B targets
的唯一 03 欄另給同樣 a／q 分離，可作獨立核對。

profile 1 若四個 ui 與 L 均五度，上述完整 link 迫
`a=z1–z2–z3–z4–z5–q`，整條原路均為 03 色，撞 a／q 分離。
故這五個原點至少一個有額外原鄰點，即 degree 至少六。

profile 0 若 n 六度、四個 ui 與 L 均五度，則同理得到原 03 路
`a–z1–z2–z3–z4–z5–q`，同樣矛盾。因此 n 至少七度，或上述五點
至少一個 degree 至少六。這裡六邊 03 路的偶數長度亦與 a=0、q=3
的固定色值不合。

這些是具名來源的 degree 障礙，沒有排除帶額外外側鄰點的 profile 0／1。
沒有把五個第三面點的存在或原最小性，直接當成已證的縮減、可接回保壞
或全部來源不可能。

## 1. 同一實際 core 與完整回填

刪原 E 中的 x,y,r，留下同一實際 disk F，其有序外框為

```
C=(a,n,R,L,q,c,s,v,w,t)。
```

其相異性及 simple disk 證明由 B 提供，使用原完整 x,y 星、r 六度
旋轉及 h-v、h-w 非邊。F 保留每條未刪原邊及全部私有頂點。
令 Z(u) 為同一完整 F 對一份固定字面 proper C10 指派 u 的全部延拓數。
全域色置換給完整著色雙射，故可用 2461 個 S4 正規化列記錄 Z；
每格仍是一份**固定字面代表**的計數，不是整個軌道的總數。

固定原 E 字面列 e=(a,n,R,L,q,c,x,y)。它的完整 cap 回填是全部
(s,v,w,t,r)，滿足 C10 邊以及

```
x != s,r; y != t,r; r notin {s,v,w,t}。
```

原 E 其餘需要的邊 cx、xy、ya 已在 e 的 properness 中；新增的完整
邊為 xs,xr,yr,yt,rs,rv,rw,rt。沒有其他 r 附件。於是

```
N_E(e)= sum over all these complete cap lifts of Z(canonical(C))。       (1)
```

這是逐份完整著色的雙射：限制到 F 並記錄五個刪除於介面的色值；
反向逐點回填同一份完整 F 著色。空 lift 集也保留。T 是 (1) 的
274×2461 非負整數矩陣，有 2549 個非零格。

原 G、Q1、Q2、G_B 的十列固定字面計數接著分別是 M_G T Z、
M_Q1 T Z、M_Q2 T Z、M_GB T Z。M_G 保留所有 (b,p,h) lifts；
Q1 的條件是 n=b,R=q；Q2 是 n=L=b；G_B 是 b∉{n,L,R}。
全部共有的 b 邊仍給 b∉{a,q,c}。checker 直接重建全部固定外框指派、
四個介面點色值及全部 16 個 p,h 指派，沒有只使用非空投影。

另一個同源查詢是 U=R-r：原 a,c 識別為 z，刪原 x,y,b,r。
對 U 的固定外框 (z,s,v,w,t) 指派，令原 a=c=z，逐份枚舉 n,R,L,q，

```

```

本節只分解原來源，沒有另計一張縮減圖。

## 2. C10 計數向量的兩種必要條件

平面線性空間的紙證與前輪 C 的 inclusion-exclusion 相同，但現在在
**實際 F** 的 C10 上使用。展開全部非框邊的 properness 指示函數，
每個選邊子圖的邊界連通分割皆 noncrossing。故

```
Z = A10 c，c 為有號整數向量。
```

2461 個 proper C10 列上非零的 noncrossing 等色欄共有 603 個。
checker 完整重建 603 欄；沒有以浮點 rank 代替等式重建，亦沒有要求 c
非負。每個保存的控制都逐格等於同一組有號整數欄係數的重建。

第二條件保留完整分量交換的字面重數。固定互補色對 {0,1}|{2,3}，
令 H 為保持此分拆的八元群；59052 個 proper 字面 C10 列分為 7382 個
H 軌道。對軌道 j，h_j 是其大小，i(j) 是 S4 列 id。

一份完整 F 著色有 b 個接框分量及 z 個不接框分量；同時交換各個
實際分量是自由作用，每個字面邊界結果出現 2^z 次。三角剖分的分界
arcs 證明仍給

```
b = 邊界 side 轉換次數 / 2 + 1。
```

因此存在同一組非負整數權重 w，使全部 7382 個等式

```
h_j Z_i(j) = sum_o v_o(j) w_o。                                    (2)
```

v_o 逐份記錄交換軌道落入 H 軌道的**重數**。它不只記錄支持。
允許的邊界分量分割必須 noncrossing、每塊屬於一個 side、同 side 的
相鄰框點在同塊，且滿足上述塊數等式。這些是所有真正 F 的必要條件；
不宣稱通過者都可由同一實際圖實現。內部分量沒有省去，它們只影響
共同權重 w 的 2^z 因子。

完整發現錐有 10798 個不同 orbit columns。重播只需保存證書實際使用
的正 columns：每欄保存原字面起點、完整分量分割及整數權重，checker
直接檢查所有合法性條件，再枚舉全部 2^b 份交換結果，精確核對全部
7382 個等式。它不依賴 LP 套件或已保存的稀疏矩陣。

## 3. 原最小性迫出的兩份正 fibres 確實加入同一 Z

[B/FORCED_SECTORS.md](../B/FORCED_SECTORS.md) 從同一 D_old=R-p 的兩份
完整非空 fibres，逐份恢復同一原 G，證 h=a 與 h=b 原接受扇區皆非空。
本節使用其更精確的**原 D_old 子 fibres**，不僅要求候選接受。

固定 (A,B,C,D)=(0,1,2,3)。兩份原字面 D_old 查詢為

```
(z,s,r,t,q,h,n)=(0,1,0,1,2,0,1)，p=3；
(z,s,r,t,q,h,n)=(0,1,0,1,2,1,2)，p=3。
```

每份都有 xy=(2,3),(3,2) 的完整原接回，原 b 唯一為 1。
限制到同一 F 後，其完整固定字面計數分別恰為

```
d_a = Z1561+Z1568+Z1743+Z1750+Z2290+Z2297 > 0；
d_b = Z507+Z514+Z871+Z878 > 0。                                      (3)
```

這些 id 依字典序的 proper C10 正規化列排序。前者的 (R,L) 恰為
(2,1),(2,3),(3,1)；後者恰為 (0,3),(3,0)；兩者的 (v,w) 都恰為
(2,3),(3,2)。各列包括全部局部 lifts，沒有只選一個分支。checker 從
完整原邊約束重新推出這 6／4 格，不把 id 常數當成證明。

原 accepted 扇區是完整原 G 的另一組總計數；(3) 是已具名 D_old
子 fibre 的固定指派計數，不能把其數值與整個原接受扇區數混為一談。
各份 D_old 著色的兩個 xy lifts 給原 q=0、q=1 的不交像，故 B 的
A_a>=2d_a、A_b>=2d_b 與 (3) 相容。

| 控制 | 原 G | U | Q1 | Q2 | G_B | d_a | d_b |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| Q2_source_positive | 941 | 319 | 1021 | 941 | 1021 | 4 | 4 |
| allK_source_positive | 941 | 319 | 1023 | 1023 | 1023 | 10 | 16 |

第一份的**同一張 Q2**接受 01232，並拒絕 01021、01202、01212；
因此本頁新必要模型本身不能證明 Q2 的四列合同不可能。
第二份同時讓三候選支持落在 K132，故本頁新必要模型本身亦不能迫出
至少一張候選在 K132 外。這兩份向量不能拼成一份來源，也沒有給真正
來源的 planar graph 實現。特別是第一份一旦有真實來源實現，Q2 的
嚴格較小及目錄外會立即違反原全域最小性；目前沒有這份實現。

[certificate.json](certificate.json) 另保存前輪三份具名控制的 C10
共同正 lift，E 計數恰是前輪數值的四倍。這三份雖有 U 支持 319，
仍各漏掉 (3) 的其中一個正條件：Q1／Q2 控制 d_b=0，G_B 控制 d_a=0。
所以它們只保留作新來源正條件的負控制，不再稱為完整來源控制。
同檔的 allK 是上表第二份相同向量，方便逐層比較。

發現階段對前輪另一份 maximal count vector 的 LP 未找到 C10 共同

上述兩份有效整數控制已足以給本頁方法的精確停止點。

## 5. 重播、獨立性及最後缺口

唯讀標準庫 checker 直接重建完整介面、所有固定外框 rows、全部局部
p,h 與 r cap lifts、所有被使用的分量交換及完整的 planar span。
它沒有網路、沒有寫檔、沒有浮點數或 LP 相依。

```bash
python3 -B audits/2026-10-19-r6-941-leakage-b89c591/A/check.py
PYTHONHASHSEED=17 python3 -B audits/2026-10-19-r6-941-leakage-b89c591/A/check.py
python3 -B audits/2026-10-19-r6-941-leakage-b89c591/A/check.py --negative-controls
```

負控制分別拒絕：用另一份 core 向量配原快取 fibres、少算完整交換重數、
截斷 signed-span、漏掉 U 的正 fibre、跨候選拼接負列，以及漏掉原最小性
迫出的正 D_old fibre。全圖分量作用與 inclusion-exclusion 是上述紙證；
Python 是精確有限等式重播，沒有聲稱 Lean 形式化。

本頁未構造較小 bad，也未淘汰 Q1／Q2 的真正來源路線。保留的量化缺口為：
對每一個符合完整契約的真正原 G，是否存在 i∈{1,2}，使固定 Q_i 的
01232 完整 fibre 非空，而其 01021、01202、01212 全部 fibres 為空；
或是否存在 H∈{Q1,Q2,G_B} 的其他完整支持證書，證 H 不在 K132？本頁模型已保留兩個真實 D_old
正 fibres；尚缺能排除其整數控制的**真實來源結構或完整著色映射**。

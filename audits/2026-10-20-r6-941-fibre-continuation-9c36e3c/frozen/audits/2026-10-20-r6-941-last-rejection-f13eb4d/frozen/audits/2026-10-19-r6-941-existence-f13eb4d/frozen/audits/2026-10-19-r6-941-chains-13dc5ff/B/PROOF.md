始終是同一原圖

```
D=G-{b,p,h,x,y,r},  outer(D)=(a,n,R,L,q,c,s,v,w,t),
```

## 1. 原 cap 的短圈給五個新增禁 pair

左右 cap 的原三角面由完整 stars 逐一給出：

```
left:  bap,bpq,bqc,pan,pnh,phq,hnR,hRL,hLq;
right: ayt,yrt,yxr,xrs,xsc,rtw,rwv,rvs.
```

這兩個實際填片分別以原框路 `a-n-R-L-q-c` 與 `c-s-v-w-t-a` 接在
D 的外面；外框仍是原 `(x,y,a,b,c)`。任意 z 位於 D 的內部。若 z
同時接下表的兩個端點，所列原簡單短圈的有界側必含表內互異原點：

| 私有 z 的接觸 pair | 原短圈 | 必在有界側的具名原點 |
| --- | --- | --- |
| a,q | z-a-b-q-z | p,h,n,R,L |
| a,s | z-a-y-x-s-z | r,t,w,v |
| n,c | z-n-p-b-c-z | h,q,L,R |
| q,t | z-q-b-a-t-z | p,h,n,R,L |
| c,t | z-c-x-y-t-z | r,s,v,w |

表中定位沿原 cap 的实际三角面与 z 的两条原 spoke 得到。例如第一圈
以原外弧 a-b 及 b-q 在左 cap 封住 a 至 q 的内框弧；该弧的 n,R,L
及原 cap 点 p,h 全在圈内。第三圈沿 n-p-b-c 封住 n 至 c 的内框弧，
其 R,L,q 与 cap 点 h 在圈内。右侧两圈同理封住原 r 的完整扇形。
所有点均互异且不在所列圈上，绝不把 deleted cap 当成 D 的内点。

第一圈违反原 C4 有界侧为空。其余四圈都含至少四个原内点，违反原
C5 为空或恰一原五度 W5 中心的完整二分。这里保留 W5 例外；这些圈
也都不同于原 B。因此每个私有 z 的完整 S 都不能含上述任一 pair。

checker 将原左右 cap 面与一个纯定位用的 z-C10 轮拼成参考嵌入，
从原外面在删去短圈边的 dual 中 flood，逐一重建表内的具名内点。
参考轮的其他 spokes 只是在实际两条 spoke 之间补的拓扑弧，**不是**
断言任何未给原边存在，也不枚举来源图。其他私有点可以在这些区域中
任意出现，只会增加短圈内点数，不能消除具名内点。

## 2. 完整接触 envelope 从 60 格缩为 46 格

把这五个禁 pair 与前轮全部 C4/C5、原 a-c 禁 pair 及 B/D 排除共同
施于同一个 z 的完整 S。全部 `2^10` 个子集，包括空集合，按大小剩余

```
|S|       0   1   2   3   4
必要容许  1  10  19  14   2
```

故每个私有点仍最多四接触，但四接触仅剩

```
A={n,R,s,v},  B={R,L,v,w}.
```

这仍是必要 envelope；未证 46 格或这两型分别有真来源实现。所有规则
针对同一个原 G、同一个完整邻集 S，不能把不同图的局部可能性拼接。

## 3. 整张 D 至多一个四接触私有点

任取私有 z，它的实际 spokes 将 D 分成与 S 中相邻接触点对应的
扇区。另一私有点 u 必位于其中一个开扇区。原平面性迫 u 的**全部**
C10 邻点落在该扇区的闭框弧内；否则原 u-rim 边必须跨过 z-spoke。
允许 u-z 边，不影响其余 spoke 对区域的分隔。

A 的四条闭弧为

```
[n,R], [R,L,q,c,s], [s,v], [v,w,t,a,n]；
```

B 的四条闭弧为

```
[R,L], [L,q,c,s,v], [v,w], [w,t,a,n,R]。
```

A、B 的任一完整四接触集合，都不包含于这八条中相应第一点的任何
一条闭弧。于是 A/A、A/B、B/A、B/B 四种有序配对全部不可能。
checker 保存每种配对的全部四个扇区及各自落在弧外的接触点，未只查
同型。由此得到**整张实际 D 的四接触私有点至多一个**。

## 4. 原图距离与完整私有诱导图

上述五 pair 中，a,q 在原 G 中确实有共同邻点 b,p，不能声称其原图
距离至少三。其余四 pair 则得到

```
dist_G(a,s), dist_G(c,n), dist_G(q,t), dist_G(c,t) >= 3.
```

它们都不是原 rim 边；induced C10 也排除 rim 共同邻点。全部私有
共同邻点已由 §1 排除。对每一 pair，再逐个核对被删六点的**完整**
stars：a 的 cap 邻点恰 b,p,y；s 的恰 x,r；c 的恰 b,x；n 的恰 p,h；
q 的恰 b,p,h；t 的恰 y,r。每对两端的这两个集合不交，因此无 cap
alias。checker 保存每对每个 cap 点的相邻情况。

令 H 是 D 全部私有点诱导的图；不得删去其中任何私有边。H 连通：
由于 rim induced，每个 D 内面至少有一个私有点，每条非框边至少有
一个私有端点；三角化 disk 的内面 dual 连通，相邻内面因此共享一个
私有端点，所以所有私有点处于同一 H 分量。

每个私有 z 在 G 与 D 中度数相同，至少五。其完整 facial link 内，
两个连续的 rim 接触若不是原 rim 相邻点，中间必有私有邻点；否则
它们会由原 link 边相接，违反 induced C10。各个非边 gap 需要不同
私有邻点。两种四接触型的 gap 长度都是 `(1,4,1,4)`，故至少两个
私有邻点，原度数至少六。其余 |S|<=3 时，原五度下界同样给至少
两个私有邻点。因此 **H 连通且最小度至少二；四接触点原度至少六**。

若 H 有 m 点、e 条边、总 rim 接触数 T，则 D 的 Euler 恒等式给
`T=3m+7-e`。由 §3，`T<=3m+1`，故 `e>=6`。这是结构限制，未提供
超越既有原 r6 `k>=25` 的新内点数界，也未构造较小 bad。

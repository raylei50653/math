## 1. J2：十二項的完整聯集配對

只在 `a2=0` 分支，沿用前輪十二個固定字面完整 fibres。
令 `e=(e0,e1)` 為 `(0,1)` 或 `(1,0)`，`d∈{2,3}`，定義

```
I(d,e)   = #F(0,1,3,1,3,1,d,e0,e1,d),
II(d,e)  = #F(0,1,2,1,3,1,d,e0,e1,d),
III(d,e) = #F(0,1,2,3,0,1,d,e0,e1,d).
```

在每份完整 F 著色中，取含 s 或 t 的所有實際23分量之聯集，將它們
各交換一次。若 s、t 同分量，該分量只交換一次。
23誘導圖不變，故同一操作自身為逆。

全部允許接框分割都保證 q 不在這個聯集內。對第一、二族，交換
可能改變 R 的色，故應配對**兩族的聯集**；不能逐族宣稱 d 計數相等。
第三族的 R、L 亦在該聯集外，故自行配對。完整固定字面計數因此滿足

```
I(2,e)+II(2,e) = I(3,e)+II(3,e),
III(2,e)      = III(3,e),

N01021(J2) = 2 Σ_e [ I(2,e)+II(2,e)+III(2,e) ].
```

原 J2 cap 以固定 `(b,x,y)=(2,0,1)` 及唯一 `r=5−d` 接回，
所以這是完整著色雙射，沒有遺漏重數或更換原五框。
六項非負，故最後拒絕為零**等價於這六個 d=2 fibres 同時為零**；
同時得到固定字面拒絕計數為偶數。本輪沒有證明其中任何一項為零，
也沒有把「六項」宣稱為完整來源幾何下的最小可能數目。

詳細映射、全部分割與獨立核對見 [transport](transport/PROOF.md)、
[checker](transport/check.py) 及 [review](review/REVIEW.md)。

## 2. J1：兩個目標之間只有分層雙射

前輪定義 `Z(q,d,e)=#F(0,1,3,2,q,1,d,e0,e1,d)`，
J1 最後拒絕零值仍等價於

```
B01=Z(3,2,(0,1))=0,   B10=Z(3,2,(1,0))=0.
```

在每個 Z fibre 中，a、n、c 在同一01分量，v、w 在同一01分量。
恰有兩種必要接框型：

* 這兩個01分量分開，且 s、t 在同一23分量。
* 這兩個01分量相同，且 s、t 在不同23分量。

第一層可交換含 v 的整個01分量，精確交換 e 的次序，得到兩個
完整子fibres之間的雙射。第二層的同一操作還會改 a、n、c，
故不給所要求的固定框雙射。前輪 q 單射也不能未經證明就當作保此分層。

因此，若另證其中一個 B 為零，另一方向所有可能殘留必屬第二層：
a、c、v、w 同一01分量，而 s、t 的23分量分離。
既有必要分量零閉包在任一單邊 B 設零後仍留另一方向四個 Z fibres；
這是該方法未能再縮成單一目標的界線，不是來源實現或來源反例。

## 3. 同一著色的幾何與新填片界線

[幾何證明](geometry/PROOF.md)將 J1 的未覆蓋部分 `q~z0` 精確分成：

* `R~q` 於03：每條這種路至少四邊。
* `n~L` 於12：路長至少五邊，或三邊路迫出以原 R 為唯一內點的 W5。

第二項的例外給 `d_G(R)=5` 及完整原 star，連同 p、h 暴露七圈
`(a,b,q,L,u1,u2,n)`，內部恰 p、h、R。這是一個具名原圖子支，
尚未構造較小 bad。若另有 `s~t` 於23，其路長亦至少四邊，且與
原01的 a—c 路、03的 q—z0 路同時給出有序交會。
以上都量化同一完整著色，沒有提供長路上界或來源矛盾；
原五圈的單 W5 例外不能略去。

另檢查原 r 六角洞的全部14份零內點三角化，各與 J1、J2 左操作
共同實施，得28張合法較小圖，完成成本分別 k−4、k−3。
68908份完整 cap 記錄含57364個空集合，共18592份 lifts。
前輪兩份必要整數控制在這28張新圖仍全落在 K132；
這個明確有限擴充尚未排除控制，且控制仍沒有原圖實現。

# 完整分量傳送續篇：J2 十二項縮為六項，J1 的方向交換障礙

固定 [本輪 BASE](../BASE.md) `9c36e3c4789dfec07d60ec4e042f0bafe17451d1`，
承接 [完整來源契約](../frozen/audits/2026-10-20-r6-941-last-rejection-f13eb4d/SOURCE_CONTRACT.md)
及全部上游假設。以下始終量化同一實際
`F=G-{b,p,h,x,y,r}`，有序 rim 為 `(a,n,R,L,q,c,s,v,w,t)`。
所有完整 fibres 包含全部私有點與空值；所有交換作用於完整實際分量。
原框 `(x,y,a,b,c)` 不變，且交換後按前輪唯一 cap 接回同一候選。
不使用四色定理、matching 假設或來源實現猜測。

## 1. J2：同一個 involution 配對兩族的聯集

只在原 `a2=N01232(Q2)=0` 分支工作。由凍結的
[J2 完整十二項定理](../frozen/audits/2026-10-20-r6-941-last-rejection-f13eb4d/J2/PROOF.md)，
令 `e=(e0,e1)` 為 `(0,1)` 或 `(1,0)`，`d∈{2,3}`，定義同一 F 的固定字面完整計數

```
I_(d,e)   = #F(0,1,3,1,3,1,d,e0,e1,d),
II_(d,e)  = #F(0,1,2,1,3,1,d,e0,e1,d),
III_(d,e) = #F(0,1,2,3,0,1,d,e0,e1,d).
```

每份 F 著色以唯一 `b=2,x=0,y=1,r=5-d` 接回 J2。
因此 `N01021(J2)` 是上述十二項的和，每項係數為一。

對任一份完整著色 `φ`，令 `C_s(φ),C_t(φ)` 是它實際 `{2,3}` 誘導圖中
包含 s、t 的分量。定義 `Tφ`：交換集合 `C_s(φ) ∪ C_t(φ)` 中的 2、3。
**若兩分量相同，只交換一次。** 不交換其他分量，私有點完整隨分量交換。
這是合法完整著色；其 23 誘導圖完全不變，故同一兩個根分量亦不變，
從而 `T²φ=φ`。

前輪對族 I、II 各型的全部七個 `01|23` 允許分割都給

```
q 不在 C_s 或 C_t 中。
```

所以 T 固定字面值 a=0、n=1、L=1、q=3、c=1
與 e 全部不變，s=t=d 變成 `5-d`。R 的色可能固定或交換，
仍是 2 或 3。因此 T 是以下兩個**不交聯集**之間的完整著色雙射：

```
F(I,2,e) ⊔ F(II,2,e)  ↔  F(I,3,e) ⊔ F(II,3,e)。
```

這不是各族分別 d 配對的主張。當 R 屬於根分量聯集時，T 會交換族 I、II；
不能把七個必要分割的個數當成七份等重實際著色。直接得到

```
I_(2,e)+II_(2,e) = I_(3,e)+II_(3,e)。
```

族 III 的全部兩個 `01|23` 分割則給 R、L 都不在根分量聯集中；
同一 T 固定左型 `(R,L,q)=(2,3,0)`，因此也有
`III_(2,e)=III_(3,e)`。綜合得新的任意大小同源恆等式

```
N01021(J2)
  = 2 Σ_e [ I_(2,e)+II_(2,e)+III_(2,e) ]。
```

所以固定字面計數是偶數，且 J2 最後拒絕為零，當且僅當以下六個完整 fibres 同時為零：

```
F(0,1,3,1,3,1,2,0,1,2), F(0,1,3,1,3,1,2,1,0,2),
F(0,1,2,1,3,1,2,0,1,2), F(0,1,2,1,3,1,2,1,0,2),
F(0,1,2,3,0,1,2,0,1,2), F(0,1,2,3,0,1,2,1,0,2)。
```

六項沒有任何一項在本輪被證為零。前輪 J2 支持恰943，故假定真來源中
這六項至少一項正；此處只是更精確的剩餘排除義務。

## 2. J1：e 方向交換只在精確分層上成立

只在 `a1=0` 分支工作，沿用前輪
`Z(q,d,e)=#F(0,1,3,2,q,1,d,e0,e1,d)`，`q∈{0,3}`。
任一實際完整著色的 `01|23` 分割只有兩型：

* 分離型：v、w 的共同01分量不含 a；其接框交集恰 `{v,w}`，且 `s~t` 於23。
* 相連型：a、n、c、v、w 同屬01分量，且 s、t 在不同23分量。

q=0 時 q 也屬含 a、n、c 的01分量。上述是對每份實際著色的同時結論，
不是任選其他色對的分割拼接。

令 `S(q,d,e)` 與 `D(q,d,e)` 分別為兩層的完整計數，則
`Z=S+D`。交換完整 `K01(v)` 在分離層恰只改 rim 的 v、w，
保持同一01誘導圖且自身為逆。因此

```
S(q,d,(0,1)) = S(q,d,(1,0))。
```

在相連層，同一交換亦改 a、n、c，故不給固定字面的 e 對換。
這只否定此特定通用交換公式，沒有否定所有可能的來源論證。
例如 `B_e=Z(3,2,e)` 的差完全由相連層承擔：

```
B_(0,1)-B_(1,0) = D(3,2,(0,1))-D(3,2,(1,0))。
```

若 `B_(0,1)=0`，前輪 q 單射及 d 雙射亦給同方向四項全零。
另一方向若仍有任何 A/B 著色，它的分離層經此雙射必落到零 fibre，
故只能是相連型；反向完全對稱。這新增條件式的分量鎖定，
沒有證明另一方向也為零。

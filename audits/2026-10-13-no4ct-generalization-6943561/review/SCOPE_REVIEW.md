# 去 4CT 技巧的一般適用範圍：獨立反向審查

本輪只讀 frozen 輸入，不改寫舊證書。以下紙面論證不假設四色定理。
相對可染性的 k 均指 frozen 新契約中，全域內點最小的目錄外 C5 來源大小；
不能換成任意一張圖的大小。來源存在是反證中的假設。

## 1. 可合法一般化的是有大小界的平面增廣

前序下降引理給：不可四色的 N 點 loopless planar graph 會產生至多 N−6
內點的 932 disk。因此每張 N≤k+5 的 loopless planar graph 都可四色。

令 H 是 n 點具名平面圖。指定若干界面同色 blocks，以實際無交叉外側樹
識別；假設 blocks 皆為 independent sets，收縮共減少 d 點。再加入 a 個
私人點及任意指定邊。若所得圖確實 loopless planar 且

\[
n-d+a\le k+5,
\]

則得到一份同時滿足全部這些指定等式／不等式的 H 完整染色。證明只需對
這一張增廣圖用相對可染性，再限制／拉回。指定不等式是實際加上的邊；
不同 blocks 可同色，除非另有邊約束。不等式必須一同可平面實現，不能
因為每條弦單獨可畫就把相交弦全部加入。同理，兩份分別可染的增廣不能
合成同一份完整 lift。

因此 C8 內部 H 的 n=k 情形，無收縮時有 a≤5 的私人點預算；收縮 d 點後
可有 a≤5+d。這是平面性／looplessness／總大小均已驗證後的充分定理，
不是所有具五個私人點 gadget 都可套用。相對可染性給存在量詞；一般
`Σ(H)=Σ(H')` 的每列雙向保存，仍須另外證明。

## 2. 三角形預著色可接回，四環指定列未必可接回

若一張圖已有一份四色染色，其指定三角形任何 proper 三色列都能延伸：
三角形上三個互異色值，可由一次 S4 置換對齊。整張圖只作這一次共同換色。
同一理由适用於單點、邊，以及任何已有染色且允許列恰為一個 S4 軌道的介面。
若其他點有固定 lists 或固定色值，這次置換未必保留它們，不能直接套用。

四環不同。輪圖 W4 的 canonical proper C4 rows 與 hub 的完整 fibres 為

| C4 literal row | hub 可用色 | fibre 大小 |
| --- | --- | ---: |
| 0101 | 2,3 | 2 |
| 0102 | 3 | 1 |
| 0121 | 3 | 1 |
| 0123 | 無 | 0 |

W4 本身有四色染色，固定列 0123 卻不能延伸。這是對「相對可染 ⇒ 每個
proper 預著色都能延伸」及相應 singleton-list 說法的實際反例，與未知
目錄外來源無關。完整關係不能由單一存在見證取代。

K4 palette 也不是無條件的預著色轉換。若增廣圖真的符合 §1，則可把其
K4 四色用 S4 正規化，取得相對 palette 的指定色；但把四個 palette 點
都置於同一外面，已不可能：四點 outerplanar graph 最多 2·4−3=5 邊，
K4 有六邊。任意 terminal-to-palette 的接線因此須逐張驗證實際平面性。

## 3. 長邊界的實際反例：不存在與邊界長度無關的常數內點代表界

**定理。** 對每個整數 t≥2，存在一張具有 4t 個具名邊界點、t 個內點的
plane disk G_t，使任意保持其完整四色邊界關係的圖 R（甚至不要求平面）
若有 m 個內點，必有

\[
4^m\ge2^t,\qquad m\ge\lceil t/2\rceil.
\]

這裡代表保留全部 4t 個互異邊界 labels 及同一 literal 色框，可以任意
改變其他邊和內點。結論不限於保留原圖幾何的代表。

**來源。** 依序取 C_{4t} 邊界
`(a0,b0,c0,d0,a1,b1,c1,d1,...,a(t−1),b(t−1),c(t−1),d(t−1))`。
每組加邊 a_i d_i，在該四邊形內放 h_i，接 a_i,b_i,c_i,d_i。四邊形耳朵
互不交疊，故這是實際平面 disk；每個耳朵就是 W4。

每組獨立選擇

\[
P=(0,2,0,1),\qquad Q=(0,1,3,1).
\]

全部 2^t 列均在 Σ(G_t)：連接不同組的邊一律為 `1–0`，P 組的 hub
取 3，Q 組取 2。這些選定列各有恰一份 hub lift。

**代表的邊界邊。** 令 L 為全部 a_i,c_i，Rside 為全部 b_i,d_i。
全 P 列把 L 全染 0，故任何同完整關係代表不能在 L 內有邊。全 Q 列
把 Rside 全染 1，故 Rside 內也不能有邊。因此代表所有邊界至邊界邊均
跨越 L／Rside。若每個 a_i=0、d_i=1，b_i∈{1,2}、c_i∈{0,3}，
則所有這些邊一律 proper，連任意新增弦也不例外。

**內點 assignment 不可共用。** 對上述每個接受列，在代表選一份完整
延伸。若兩個不同列共用完全相同的 m 個內點色值，在某個差異組 i，
取 P 的 b_i=2、Q 的 c_i=3，其餘色值取第一列。每個變動界面點的新色
在第二列也曾配合同一內點 assignment，故所有界面至內點邊仍 proper。
內點邊不變；邊界邊則由前段的 disjoint palettes 保證 proper。如此得到
代表的一份完整染色，其第 i 組是 `(0,2,3,1)`，卻用盡四色，不能延伸
到來源 h_i，矛盾。因此 2^t 個接受列須用不同內點 assignment，而 m 個
內點總共至多有 4^m 種 assignment。證畢。

例如 t=11 的 C44 來源，任何完整關係代表至少需要六個內點；故 C5 的
五內點界不能原封不動推成所有 C_b 的統一五內點界。此處 C44 僅是
44 邊形的名稱，與工作樹既有研究代號無關。

此定理**不否定**每個固定 b 有某個有限界 f(b)：固定 b 只有有限個四色
邊界關係；對每個實際可實現關係各選一份有限 witness，最大大小便給
非構造性的 f(b)。它也不反駁任意固定 C8 的小代表猜想，只排除與 b
無關的統一常數界。上述低度耳朵族不是原最小目錄外來源，不用來排除
933／941／932；其角色是檢验錯誤的一般化。

## 4. 固定寬度與完整關係是另外兩項義務

平面性不保證任意指定剝層的 separator 寬度固定。r×r grid 的 r 條橫向
路徑彼此頂點不交，任何分隔左端與右端的頂點集合至少有 r 點；這只需
每條路徑都須被截斷的初等理由。把任意大的 grid 畫在 C8 內並以一條橋
接入，仍為固定 C8 的合法 disk。因此「平面且外框 C8」本身不給每個
內部切割八點界。此例並不符合當前最小來源的 degree／連通性條件，亦
不否定它可能另有更小的完整關係代表；要證目標來源的固定寬度，仍須
使用那些額外來源條件給新的結構證明。

## 5. 有限控制與外側 cap 的獨立覆核

`scope_controls.py` 用標準庫核對 W4 的全部四個 canonical fibres，以及
t=2,3,4 的全部 2^t 選定列、每列全部 hub lifts、所有能容納選定列的
邊界邊、154 對列的 forbidden coordinate hybrids。任意 t 的定理來自
§3 紙面證明，不把有限控制當成無界枚舉。

`independent_caps.py` 不 import producer。它以基邊所在面的唯一分解
遞迴，獨立得到 C8 的 903 個 polygon dissections；再遍歷全部非三角
面 hub 選擇，對每張具名圖核對完整 directed darts／Euler、以圖邊 DFS
重算全部 274 rows 的完整 hub tuples，包括空 fibres 與空 tuple。
詳細結果保存於 `independent_caps_result.json`。

正常及 `PYTHONHASHSEED=17` 的兩份 checker `--check` 重播均 PASS。
2274 份 cap 共 623,076 fibres，其中 470,831 為空、完整 hub lifts 共
169,446。`--write` 只允許 exclusive 建新檔，`--check` 不改證據；最初
scope checker 的 JSON tuple/list 比較錯誤及修復另記於 `VERIFICATION.json`。

量詞控制：每張 cap 分別與每個殘留必要支援 U 有非空交集，但是全部
cap 關係的共同交集為空。前者既不給一個同時通過所有 cap 的 row，也
不給實際來源 H。真正的必要條件是每張 cap 有某份同一來源 H 的適合
染色；不同 cap 可以用不同完整 H lifts。不能交錯這兩個量詞。

紙面結果層：§1 相對增廣原理、§2 預著色界線、§3 任意長邊界下界、
§4 初等切割反控制。有限控制層：W4、t=2/3/4、2274 cap 圖族。
未證一般主命題、任意大小三支排除、固定 C8 完整代表界或新 Lean theorem。

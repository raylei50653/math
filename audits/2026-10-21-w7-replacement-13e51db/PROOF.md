# W7 保界面縮減：單中心不可能與 52 個具名 cap 控制

2026-10-21；exclusive BASE `13e51db3ec3d8d7ec7eeef60167afdc19ad956c4`。
[BASE.json](BASE.json) 固定六份原 authority 的 bytes／SHA256，逐份與 BASE
Git bytes 相等。[checker](check.py) 每次先核對 custody。本頁的原來源仍承接
J1 五邊路 strict only-R 契約，原 profile 0／1、完整有序界面與全部原附件不變。

**本頁沒有排除 profile 0／1。** 已證的是單獨 W7、同七框且嚴格減內點的
完整支援替換不可能；另精確核對 52 個明確 cap 候選的必要支持測試，全部未通過。
有限必要色列不是原共同來源的實現，也不能從未通過測試反推來源存在。

## 1. 單獨 W7 不能用同七框的零內點 patch 替換

令 H 為固定有序七圈 S 上、唯一內點 R 接七個圈點的原 W7。
其完整字面支援恰為

\[
\mathcal R_S(H)=\{\sigma:\sigma\text{ proper on }C_7,
\quad |\sigma(S)|\le3\}.
\]

因為七圈奇長，這裡每份色列恰用三色；缺少的第四色正是 R 的唯一可用色。
固定 S 的七個不同原點以及所有外部附件，若 H' 具有更少內點，就必須沒有內點。
H' 是七邊形的非交叉弦子圖。把缺少的弦加到任一三角剖分 T；這只為構造
H' 的合法著色，不把補邊當成原圖邊。

T 有三色著色：由三角剖分的耳逐個刪到一個三角形，再反向恢復每個耳點，
取其兩個已相鄰鄰點以外的第三色。T 的任一三角形迫三色全用。
七個點分成三個非空色類，至少一類有三個點。把該類的一個點改成第四色，
所有邊仍 proper，三個原色也都仍存在。因此得到一份 T、從而 H' 的合法
**四色全出現**的 S 色列。該色列不在 R_S(H) 中。

所以對每個這類 H'，都有

\[
\mathcal R_S(H')\not\subseteq\mathcal R_S(H).
\]

這已否決完整支援相等，也否決由「每個較小 patch 的支援均包含於 H，
再由多個候選覆蓋接受」構成的單中心替換族。沒有使用四色定理。
本定理不限制包含更多原頂點的較大 patch，也不否決利用固定原外側 E 的
額外完整關係來排除 H' 的四色色列；後者需另證原 E 的共同來源條件。

有限核對有 91 個 normalized proper C7 色列，W7 支援其中 21 個。
全部 42 個三角剖分各保存一份四色反見證；有限核對校準上面任意 H' 的紙證。

## 2. 原 p／h／R cap 的 52 個具名候選

固定原九圈 `(a,b,q,L,u1,u2,u3,u4,n)` 及其全部外側，包括原有序 C13 核心 D、
原右 cap `(x,y,r)`、原外 C5 `(x,y,a,b,c)`。左 cap 的原內點為 p,h,R。
每次僅刪一個完整 star 中心，再在它露出的原 link 多邊形內作三角剖分：

| 刪除原點 | 原完整 cyclic link | 剖分數 |
| --- | --- | ---: |
| p | `(a,b,q,h,n)` | 5 |
| h | `(p,q,L,R,n)` | 5 |
| R | `(n,h,L,u1,u2,u3,u4)` | 42 |

所有非刪除原點、原框、原外側附件及原 b–c 邊保留，每個候選少一個內點。
新增弦位於原 star 所在的閉 disk 內，原 star 完整性及原 induced C7／九框弦
分類保證沒有遺漏外側接觸；這是具名局部候選，不是新原圖枚舉。

對每份固定字面 C13 色列 σ，逐份枚舉每個候選兩個內點及原框 b 的所有色，
再與原右 cap 的全部 `(x,y,r)` lifts 以同一 σ 配對。得到

\[
A_j(\sigma)\subseteq\{\text{原十份 normalized C5 rows}\}.
\]

原 G 的 A(σ) 同樣由完整原 p,h,R stars 直接重算，61,308 個原必要色列
均與 frozen `caps.json.gz` 的原 G 支援相同。這裡只比較完整支援，不要求著色數相等。

若某個候選同時對全部已知可能 σ 滿足

\[
A(\sigma)\subseteq A_j(\sigma),\qquad A_j(\sigma)\subseteq941,
\]

則同一原 E 的每份接受見證都保留，三個拒絕 row 也都保留，從而得到更小
941 來源。若只想用多候選覆蓋接受，第二項仍須對各候選成立。這是充分條件；
不是宣稱每個較小 bad 都必須逐色列滿足它。

## 3. 完整原必要支持的核對結果

使用 published `independent-results.json.gz` 的完整 `profile:0`、`profile:1`
固定點，分別有 61,308、38,647 個必要色列。profile 1 不只用原 a≠u4 種子，
而是用其全部原 orbit 零傳播固定點。

52 個候選都存在必要色列使 A_j(σ) 含原拒絕 row，且都存在必要色列使
A(σ) 中某 row 在 A_j(σ) 遺失：

| 原 profile | 每候選拒絕洩漏色列數範圍 | 每候選遺失原支援色列數範圍 |
| ---: | ---: | ---: |
| 0 | 328–1,676 | 4,132–5,640 |
| 1 | 160–1,226 | 2,660–3,940 |

兩型的最少洩漏候選都是刪 p、加 `b−n,n−q`。profile 1 的一份具體控制為

```
state 22337:
(a,n,u4,u3,u2,u1,L,q,c,s,v,w,t)
 = (0,1,2,0,1,0,1,2,0,1,2,3,1).
原 G 完整 cap 支援：{01232}；
刪 p、加 b−n,n−q 的完整 cap 支援：{01202,01212}。
```

此 σ 在原必要固定點內，但**未證其在同一實際 D 中有完整著色**。
故這是必要模型上特定充分條件未成立的證據，不能說每個實際來源的候選都
確定洩漏，也不能證明這 52 個候選絕不可能配合更強同源約束完成縮減。

這些結果只封住兩種目前直接使用最小性的路線：單中心同七框的無條件
支援替換，以及 52 個刪點補面候選在現有必要支持上直接繼承拒絕的證法。
profile 0／1 來源排除、較大 patch 縮減、一般 W7、J1／J2、strict smaller bad
及主命題均 **OPEN**。沒有大型 LP、來源圖枚舉或新 Lean。

# J1 實際五邊路：induced C7 與 only-R 的完整 W7 子型

固定 BASE `417732fc5ef0a012829fd6712333b1c906128d3a`，承接
[凍結來源契約](../frozen/audits/2026-10-20-r6-941-fibre-continuation-9c36e3c/SOURCE_CONTRACT.md)
與其全部上游。原 G、原有序 C5 框 `(x,y,a,b,c)`、原支持941、全域
最小內點數再最大邊數、p/h 完整五度、r 完整六度、原旋轉、非邊、全部
私有點和附件、原 C3/C4/C5 pocket 定理均保留。只在原 Q1 接受零值
的 J1 分支工作；不加 matching 前提，不引用四色定理。

固定**同一份原核心完整著色** f，原核心及殘餘色列為

```
F=G−{b,p,h,x,y,r},  rim(F)=(a,n,R,L,q,c,s,v,w,t),
(a,n,R,L,q,c,s,v,w,t)=(0,1,3,2,3,1,2,e0,e1,2),
(e0,e1)=(0,1) 或 (1,0)。
```

其 03|12 分量為 type III。本文另固定這份 f 中的一條**原實際**簡單
12 五邊路

```
P=n–u4–u3–u2–u1–L,
f(n,u4,u3,u2,u1,L)=(1,2,1,2,1,2)。
```

四個 ui 首先只是這條路上的不同原點；不先假設其舊框身份。前輪
[三邊路整支排除](../frozen/audits/2026-10-20-r6-941-j1-c11-1148ce0/REPORT.md)
保證這份 f 中沒有任何 12 的 n–L 三邊路。

## 1. 任意實際五邊路都給 induced 原 C7

原簡單圈

```
C=(n,h,L,u1,u2,u3,u4)
```

的 h 側為原固定扇形 n–R–L；原 h 的另一側接 p 及原外框 b，故
此扇形位於 C 的有界側。R 色為3，不在 P 上，並位於 C 嚴格內部。
這正是前輪三邊路的原有界側論證，圈長改成七；不把 C7 當作 C5。

C 的十四條可能弦全部不存在，理由逐項完整：

* P 上距離二或四的六對端點等色，故不是原邊。
* P 上距離三的三條候選弦 `n-u2,u4-u1,u3-L`，任一存在都會給同一
  完整著色的12三邊 n–L 路，違反前輪已證排除。
* P 兩端的 `n-L` 是舊 induced C10 的原非邊。
* 剩餘四條 `h-ui` 違反原完整 `N_G(h)={p,q,n,R,L}`；ui 屬 F，
  不可能是 p/h，且12色排除 q/R。

所以 C 是 **induced 原 C7**。這個結論不要求四個 ui 先是舊 F 私有點，
也不要求 C 只有一個內點。一般 C7 pocket 的內點數仍無上界；原短圈
定理沒有「C7 只有 R」或「R 五度」的結論。

## 2. 明確增加的嚴格子型：C 內部恰 R

從本節起，另加原圖子型前提：**C 的有界側唯一原點是 R**。這是
原來源的完整幾何條件，不是從必要計數存活格挑一張圖，也沒有宣稱
一般五邊路已被此型覆蓋。

由 §1 的 induced C7 及原內三角化，每個 C 的邊界邊都須與 R 成一個
原三角面：若沒有 R，該三角形需要 C 的一條弦，而弦已全部排除。
因此這個 pocket 恰為 W7，七個原面及完整旋轉為

```
Rnh,RhL,RLu1,Ru1u2,Ru2u3,Ru3u4,Ru4n,
N_G(R)=(n,h,L,u1,u2,u3,u4),    d_G(R)=7。
```

允許整體反轉旋轉。R 是 C 的嚴格內點，故不可能還有跨過 C 的其他
原鄰點；列出的 star 是完整原 star。特別不能沿用三邊路子支的 R 五度。

這同時**推得**四個 ui 均為舊 F 私有點：它們都接原 R，而舊 induced
C10 中 R 的框鄰點恰 n,L；其餘舊框點不可能被識別為 ui。這一步保留
ui 的原點身份，沒有創建新點或搬用其他著色的附件。

原 p/h 的八面與 W7 共用兩面 hRn、hLR，合併得到原實際九框 disk

```
rim=(a,b,q,L,u1,u2,u3,u4,n),   interior=(p,h,R),
faces=abp,bpq,pqh,phn,pna,hqL,hLR,hRn,
      Rnu4,Ru4u3,Ru3u2,Ru2u1,Ru1L。
```

十三面滿足 `2·3+9−2=13`。所有其他原附件均在這個閉 disk 外。

## 3. 九框的二十七條原外弦：唯一可能 a-u4

內路 P 接回該邊；沿十三面 dual 刪去 P 所穿的 dual 邊，**不接原外框
邊 ab** 的那一側必在原閉圈的有界側。因此圈內至少含表列原點，其他
原附件只會增加內點數。這固定了原有界側，並未自由改換嵌入。

| 原外弦 | 原內路 | 圈長 | 圈內至少含 | 結論 |
| --- | --- | ---: | --- | --- |

| a-L | a-p-h-L | 4 | R,n,全部 ui | 禁止 |
| a-ui, i=1,2,3 | a-p-h-R-ui | 5 | n 與 u(i+1),…,u4 | 至少二點，禁止 |

分離面與全部已強迫原內點。由原 C3/C4 空內部及 C5 至多一個五度
中心，只有 a-u4 未被排。

若 a-u4 存在，其原 C5 圈內已有 n，原 pocket 定理迫

```
d_G(n)=5,  N_G(n)=(a,p,h,R,u4)。
```

反之若原 n 五度，它已經有這五個不同鄰點；完整 facial link 的末對
u4,a 必相鄰。故得到精確二分

```
a-u4 存在  <=>  d_G(n)=5；
d_G(n)≥6  <=>  九框 induced。
```

這沒有排除其中任何一型，也沒有完成較小 bad。

## 4. 同一四點的完整舊框接觸：720 組縮為112組

時保留全部私有點及空接觸型；不把各點的邊際可能性當作共同來源。

W7 完整 star 給 u1 接 R,L；u2/u3 接 R；u4 接 n,R。§3 排除九框
外弦，原 `dist_G(t,R)≥3` 排除所有 ui 接 t，原 `dist_G(L,s)≥3`
另排除 u1 接 s。施於每一完整 S，恰得

```
S(u1) ∈ {RL, RLv, RLw, RLvw}；
S(u2),S(u3) ∈ {R, Rs, Rv, Rsv, Rw, Rvw}；
S(u4) ∈ {nR, anR, nRs, nRv, nRsv}。
```

每個記號均是集合，未列接觸不存在。共 `4·6·6·5=720` 份完整四點

## 5. 同源 C13 介面與完整 lifts

在 only-R 子型，刪除原點得到同一實際圖

```
F13=G−{b,p,h,R,x,y,r},
rim(F13)=(a,n,u4,u3,u2,u1,L,q,c,s,v,w,t)。
```

原完整 R star 露出五個原三角面 Rnu4 至 Ru1L，故 F13 是實際簡單
三角化 disk。n、ui 及其所有其他鄰點、所有私有附件均保留；圖大小
沒有上界。原九框 induced 也不保證 C13 induced。全部可能 C13 原弦
僅為

```
a-u4, s-u4, v-u4,
s-u3, v-u3, w-u3,
s-u2, v-u2, w-u2,
v-u1, w-u1。
```

§4 的112個共同 profile 保留它們的相容性。帶弦的實際 C13 仍可用
三角化 disk 的完整互補色對 orbit 計數；不得藉「induced」偷刪這些邊。

選定原 f 限制後給一份實際正完整 fibre，其 rim 必為兩者之一：

```
(0,1,2,1,2,1,2,3,1,2,0,1,2)，
(0,1,2,1,2,1,2,3,1,2,1,0,2)。
```

令 Z 為同一 F13 各字面 rim 的**全部完整著色數**，則上述兩項和正。
這是原實際著色給的正性，不是必要支援格的未刪即正。

固定一份完整 F13 著色後，原 G 左 cap 變數為 b,p,h,R；Q1/J1 左 cap
變數為 b,R。R 必對**全部六個**原 rim 鄰點 `n,u4,u3,u2,u1,L`
檢查異色；G 還保留原 hR 邊。R 在選定 f 中是3，但對其他 fibres
**必重新枚舉全部四色**。原完整 stars 保證左右 cap 無未列互接及
私有接觸；限制與逐份接回互逆。原右 cap `(x,y,r)` 亦逐份完整保留。
因此 G、Q1、J1 的每個固定原 C5 字面 fibre 都是同一 Z 的非負整數
cap 投影，包括空 fibres。將112個接觸型作細分時，也必固定同一份
原附件、用它的同一 Z；不能把各型的存活格拼成一張來源。

計數分支的結果由 [counting](../counting/) 自己的證書與 checker 承擔；
本頁只證明它在 only-R 子型的原來源語義，沒有藉有限必要系統存活
宣稱來源存在，也沒有自行宣稱其已導出矛盾。

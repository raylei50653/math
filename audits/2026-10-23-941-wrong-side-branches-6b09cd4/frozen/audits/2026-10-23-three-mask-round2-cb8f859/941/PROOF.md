# 941：完整分量樹的原路徑瓶頸與01／12橋點

2026-10-23；BASE `cb8f8593e273a7426ecadd59797a6e643cc4768e`。
本紙證只承接普通短型I、初始02型13／36的同一原F。所有原附件、完整star、
rotation、有序B14、原色框、全部空fibres與full lifts均保留。K不是一個點；
所有不碰框的02／13分量也保留，沒有私有點數或原度數上界。

## 1. 固定原圖中的完整02／13分量鄰接樹

F是凍結authority所給的三角化closed disk。把實際完整02分量和實際完整13
分量各當一個節點；原F跨palette邊存在時，將兩個節點相接，稱此圖為T。
這裡包括所有沒有boundary contact的私有分量。

**輔助事實：T是一棵樹。** 在每個原02頂點放值+1、每個原13頂點放值−1，
在每個原三角面內線性延拓。proper四色保證每個三角面恰有兩個跨palette邊；
零集在其中是單一線段。零集不經原頂點，於是整份零集是互不相交的簡單閉曲線
及端點在原disk boundary的proper arcs，沒有分岔。

零集補集的每個區域恰對應一個完整誘導palette分量：逐三角面收縮到其同號
原頂點／原同號邊即可看出連通性相同。每條零曲線／arc在disk中分隔兩側。
互不相交的這些界面之區域對偶是樹；每條界面給一條對偶邊。跨palette原邊
的兩端就在同一條界面的兩側，故此完整區域對偶正是T。不能刪掉被閉曲線
包住的rootless分量，也不能把只有boundary contacts的商圖充作T。

此處僅用於這份已知三角化F的原分量拓撲。沒有三角面覆蓋時，該推論為假：
未三角化四圈 `U0–V1–L0–H3–U0` 的完整分量鄰接圖就是四圈，03路
`U–H–L` 的最後出口也不是V所屬分量。checker保留這個精確缺前提控制。

現在固定

```text
K = K02(U)，完整boundary contacts = {U}；
B = K13(V) = K13(Y)，完整contacts = {V,Y,q,c}；
L = K02(z4)，L ≠ K。
```

原boundary邊 `U–V`、`V–z4` 迫T含 `K–B–L`。三個節點不同，因此這
正是T中K到L的唯一簡單路。原H13(z1)、H13(z3)及任意私有分枝仍留在T中。
本項的新應用使用完整分量的鄰接與原路的投影；不是只重述碰框partition的
六個block數，也不是從六個boundary block猜全部私有分量。

## 2. 03型4的最後出口必落在完整B13

另假設初始03型4，固定同一份實際F中一條最短03路P：U→z4。令x是P上
最後一個K0點，X是其後的色3點；原證已給X私有且X後的尾路完全避開K0。
本節重新導出並加強這點。

P投影到T得到從K到L的walk。X的完整13分量H鄰接K；從X到z4的尾路
在投影中不再回K，因為03路上的K頂點只能是原色0。
若H不是B，樹T中H所在的K分枝到L的唯一路必返回K，與該尾路矛盾。因此

```text
X ∈ 完整 B13(V,Y,q,c)。
```

初始03型4的P所在完整03塊之boundary contacts為
`{a,z1,z2,z3,z4,U}`。其中色3為z1、z3；兩者都不在B中。B的唯一色3
boundary contact q又不在這個03塊，所以X必為F私有點。這同時保留前輪
完整K與H13(z1)、H13(z3)的無邊限制。

新增的實際連接義務是：**同一個私有X在同一完整13分量中連到V、Y、q、c；
X的每個原色1鄰點亦屬這個B。** 這些路線須由原私有13邊給出，不能每個
端點換一份獨立見證，也不能讓一個rootless13分量代替這個最後出口。

這沒有說X後的原色0點立即屬L。實際投影walk可以在B及其他分枝間往返，
用不同原頂點而保持P簡單；只排掉需要再次回K的分枝。兩個五度第五色2
鄰點的K-membership side及原度數至少六分支仍全部保留。

交換完整K後，X色3不動，尾路原色0點全在K外，故同一原尾路仍接z4及
原a弧。這是在實際delete/insert後的連通義務；沒有重新選第二個partition。

## 3. 原01與唯一後繼12迫一個K外原色0橋點

令ψ為同一完整K的02交換。原01四型逐型都給U、c在同一完整01分量。
凍結的唯一03|12後繼卻給ψ下

```text
C = 完整K12ψ(U)，包含V、Y、t（44459另有w）；c、s不在C。
```

固定一條最短的**實際原01路**Q：U→c。在Q的色1頂點序列中，第一個
色1點因鄰接U，必在C；最後的c不在C。取序列第一次從C變到C外的相鄰
兩點r1、s1，它們之間恰有一個原色0點T。於是

```text
r1 ∈ C，s1 ∉ C；原邊 r–T–s；T ∉ K。
```

若T∈K，交換後T變2，兩條原邊就會在ψ的12圖中接起r、s，矛盾。
任一原F色2鄰點Z若屬K，原02邊T–Z又迫T∈K，因此所有這些Z也在K外。
這是用同一實際交換及同一條原路得到的橋點，沒有逐步換palette survivor。

### T為F私有點時的完整原link

原kernel接觸契約保證F私有點的全部原G鄰點仍在F，所以確可用完整原
cyclic link。T原色0，鄰色只有1、2、3。沿完整link的兩個方向從r到s，
各至少有一個原色3鄰點：否則該link弧全用1、2，且上述所有色2均在K外，
交換後這條原link路仍在12中接起r、s，矛盾。

因此有至少兩個不同原色1及兩個不同原色3鄰點。若原度數5，完整link
的鄰色multiset恰為

```text
{1,1,2,3,3}，唯一色2鄰點在K外。
```

第五點若再用1或3，五圈link將被1、3二染，故不可能。若缺色2，完整
link用1、3交替，原度數必為偶數；原最低內度五只給至少六，不能排除。
存在色2而度數至少六的情形也保留。

T在K外保持原色0，故所有原色3鄰點經同一T，在ψ的**同一個實際03分量**
中連通。它們不能分別接唯一後繼的a弧與q塊。此處在私有分支確為全部
原鄰點；下節boundary分支只對F內鄰點及完整F分量作此敘述。

### T碰B14時的完整分類

T必在原01含U、c的同一完整block內。四個原01型都保留，可能的boundary
原色0點精確是：

- a、z4：四型都容許；其ψ03分量是完整a弧塊。
- z2：只在含z2的大01 block那兩型容許；其ψ03分量仍為a弧塊。
- 原色0的v（44459）或w（44466）：只在含v、w的大01 block那兩型容許；
  其ψ03分量是完整q塊。

U屬K，不能作T。certificate逐列保存四型完整contacts及每型全部候選，
未把boundary分支冒充具有完整F內cyclic link的私有點。沒有證明T必私有。

## 4. 有限核對與確切停止點

checker逐份保留四份target／02完整來源列、兩種初始03選擇、四個初始01型、
唯一後繼的完整boundary blocks、同一全域inverse、全部七點共同lifts及
完整G／Q1／J1 cap records。整份上游二步證書按bytes凍結，包含全部空fibres。

七個固定三角化小disk控制逐份核完整面、完整原邊、cyclic links、完整02／13
分量樹與獨立零界面對偶，並在**同一圖上**交換完整K，記錄全部六個palette
交換前後完整分量，rootless分量的boundary contacts明列空list。它們分別保留
出口五度兩side、出口無色2六度、橋點五度色2在C／C外兩side、橋點無色2
六度，以及一個不能冒充最後出口的rootless13分枝。控制均沒有完整941
來源前提；例如不是原B14＋原z5完整star＋原caps，故來源觸發均為
`not triggered`，不是來源實現或來源排除。

新的來源紙證限制是第2、3節；第1節為所用平面拓撲。兩target各八個初始
配對仍OPEN，沒有新pair exclusion。尚缺X所在完整B的原私有13路線、Q的
實際橋點身分、其完整link與兩側、以及它們和同一K／唯一後繼的共同接合。
不能由本項控制缺少完整來源而推出原來源不存在。無新較小bad、Lean、LP、
matching或全稱941／W7／J1／J2結論。

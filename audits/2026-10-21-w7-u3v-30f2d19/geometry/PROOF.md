# 原 u3v 的來源橋接、實際分隔與完整 u3 link

固定 [BASE](../BASE.json) 及其凍結輸入，完整承接原941／J1來源契約與嚴格
only-R／W7：同一原 G、有序框 `(x,y,a,b,c)`、完整支持941、最小內點數再
最大邊數、原 p/h/r stars、全部原附件／旋轉／私有點及短圈 pocket 定理。
選定同一完整 F 著色中的實際路 `n–u4–u3–u2–u1–L`；圍成原 induced C7
內恰只有 R，因此原 R 完整七度。仍是同一實際核心

```
D=F13=G−{b,p,h,R,x,y,r}，
rim(D)=(a,n,u4,u3,u2,u1,L,q,c,s,v,w,t)。
```

本輪新增條件是**同一原邊 u3v 存在**。前輪40份必要共同 profile 中，這一
條件恰對應原編號 `10,11,12,13,14,15,43,44`。每份的全部原接觸與其他
原弦均保留，不把一條特徵邊當作完整圖。以下均不加四色定理或 matching。

## 1. 原邊迫零的是整份完整 fibre

對 D 每個固定字面框色列 σ，`Z(σ)=|Col4(D;σ)|` 計入**全部**原私有點的
完整著色，包括無法接回原 R 或原 G 的著色。若 `σ(u3)=σ(v)`，每份候選
著色都違反實際保留在 D 的原邊 u3v，故

```
σ(u3)=σ(v) ⇒ Col4(D;σ)=∅ ⇒ Z(σ)=0。
```

此結論不需選定某一 Kempe 歷史、某一可接回 cap 的子集，亦不需在每份
著色中另選 u3 或 v；二者一直是同一原點。全域 S4 換色保留相等關係，故
可直接對原 canonical C13 states 使用。額外原弦及任何大小的私有附件不會
恢復這些 fibres。

[checker](check.py)唯讀核對原66,430 states 與61,308個既有 live states；
u3v 使其中 **15,382個既有 live states** 的完整 fibre 為零。這正是最小
profile10（原可選弦只有 u3v）的額外來源零值；其他七份 profile 都有同一
原邊，可保守地只使用這一組零值。

兩個原 witness 的 `(u3,v)` 分別是

```
44459：(1,0)；44466：(1,1)。
```

所以原 `Z44466=0`。原實際完整路著色仍給 `Z44459+Z44466>0`，因此本分支
必有 `Z44459>0`。這是同一實際 D 的全 fibre 正性與零值；不是分別由不同
來源圖供應的邊際見證。

## 2. 與完整 orbit 排除的來源接合

前輪 orbit coverage 已允許原 C13 帶弦：每個實際完整互補色對 orbit 的
boundary column 都在既有完整必要家族中；原私有分量的重數仍納入非負 X。
加入 u3v 不會破壞此涵蓋，只可能令部分必要 columns 不可實現。原完整 cap
lifts、R 的全部四色量化及 inherited C10 零值均不改變。

每個原 half-row 的方程仍是 `2Z_i=Σ_{j含該row}X_j`，所有 X 非負。
若某 Z 已為零，該 row 所有 X 必為零；若某 state 有一個 half-row 的全部
columns 已為零，同一全 Z_i 也必為零。不能為不同 half-rows 改選另一份 D。

因此 [完整零值閉包](../closure/check.py) 可從§1的原邊零值出發，在原完整
家族上逐步傳遞。它負責實際有限 certificate 與每次傳遞，不由本頁另造
計數或聲稱數值求解結果。本輪最小profile10的精確證書實際再傳遞10,794個
state零值，得到 `X66582=X67755=Z44459=0`。這與§1的同源正性直接矛盾，
排除的是**嚴格原 W7 且有原邊 u3v** 的共同分支；其餘七份額外原弦完全
不必被刪掉。此處只是採納sibling證書的原來源含義，幾何本身不獨立承擔
這10,794次有限傳遞。

上述接合不要求 D induced、不限制原附件大小、不構造另一張 smaller bad。
只能向上採納為這個具名分支的排除，不能聲稱一般 W7、一般五邊路或 J1/J2
已關閉。前輪40型只因此減去這八型，餘32型（44459仍20型、44466仍24型）
另待研究；它們的交集仍保留同一原圖的量詞。

## 3. 原 u3v 將同一 D 分成 C8 與 C7

原邊 u3v 的內部位於實際 D disk 中，故把 D 分成兩個實際三角化 subdisks：

```
D8：rim=(u3,u2,u1,L,q,c,s,v)，
D7：rim=(v,w,t,a,n,u4,u3)，
D8∩D7 恰為原邊 u3v 及其端點。
```

任意其他原點及附件都落在其中一側。兩側嚴格內點之間沒有跨側原邊，否則
必穿越原分隔邊。固定**相同字面** u3,v 顏色後，兩側全部完整著色的限制與
逐點拼回互逆。因此每個固定完整框 σ 都滿足真正的同源乘積式

```
Z_D(σ)=Z_D8(σ|rim(D8)) · Z_D7(σ|rim(D7))。
```

沒有 orbit 倍率；私有點沒有被刪掉、識別或換來源。這也給完整著色的
splicing：兩份 D 完整著色若在 u3,v 同色一致，取第一份 D8側與第二份
D7側便得第三份同一 D 完整著色。只在已存在的這兩個同源 subdisks 間
拼接，不能拼接來自不同原圖的計數片段。

這是真正來源的額外乘法／矩形支援限制，但**本輪排除不依賴它**。
有限控制也顯示不能只靠兩個 target columns 做新矛盾：固定 `(u3,v)=(1,0)`，
原 column66582 與67755 的字面支援各已是 `D8的8列 × D7的4列 =32列`；
聯集亦為 `D8的12列 × D7的4列 =48列`，同切口拼接不產生新列。checker
只從兩個既有完整 columns 恢復這些列，不枚舉新原圖。

## 4. 完整原 u3 link 顯示哪些私有鄰點仍不能忽略

W7 原面固定 u3 link 的一段為 `u4–R–u2`；D 側的原接觸次序則為
`u2–[s]–v–u4`，允許整體反轉。方括號表示僅在完整 profile 含 u3s 時存在。
相鄰已知 link 點若是原非邊，就不能在完整 facial link 中直接相連，必須
有額外 u3 鄰點；不同開 link gaps 中需要不同原點。

這些額外點都是 D 的私有點：原完整舊框接觸已列完；其餘 ui／n／L 之間
由原 induced C7 排除弦；已刪 cap 點的完整 stars 也排除新的 u3 鄰接。
因此不能把 unknown gaps 以無附件的局部扇形代替。精確下界為：

| 原 profile | 已知原 u3 鄰點數 | 原非邊 link gaps | 原 d_G(u3) 下界 |
| --- | ---: | --- | ---: |
| 10,11 | 4 | u2–v、v–u4 | 6 |
| 12 | 4 | u2–v | 5 |
| 13,14 | 5 | u2–s、v–u4 | 7 |
| 15 | 5 | u2–s | 6 |
| 43,44 | 4 | v–u4 | 5 |

各式來自完整 link，沒有另外假設 degree≥5。相關原三角形
`a n u4`（11,14,44）、`u3 u4 v`（12,15）、`u3 s v`（13,14,15）、
`u3 u2 v`（43,44）由原 C3 空內部確為相應 subdisk 的原 ear face。
這只固定面與額外附件義務，沒有授權刪除 u3、把 u2/u4 識別，或把原941
support 沿某張新圖搬運。

## 5. 證據邊界

[證書](certificate.json)保留八份完整 profile、原弦、原 link gaps、degree
下界、ear面、完整同色零格清單、兩欄的32／48列控制，以及凍結輸入 bytes／SHA。
全部已消費輸入逐項核對本輪 BASE。checker 拒絕不同字面切口顏色的拼接；
normal／seed17／seed17 `-O` 的結果記於 [verification](verification.json)。

本頁提供原來源到精確計數閉包的橋接，以及額外 source-level 結構；實際
Z／X零值排除由 sibling closure 的證書負責。沒有 LP、新原圖枚舉、Lean或
smaller bad。一般 W7、一般 C7多內點、其他 J1/J2拒絕及主命題仍OPEN。

## 1. 精確四接點替換

四個互異具名接點依序為 `a₀,a₁,a₂,a₃`，下標 mod 4。固定共同色框
D={0,1,2,3}。下列邊是局部圖的**完整**接線：

| 局部圖 | 全部邊 |
| --- | --- |
| 四輪星 W | 框環 a₀a₁a₂a₃a₀；私有中心 c 接全部 aᵢ |
| 輪環 disk Q | 同一框環；新私有環 b₀b₁b₂b₃b₀；bᵢ 接 aᵢ、aᵢ₊₁；中心 c 接全部 bᵢ |

Q 有九點二十邊。環帶的八個面為 `(aᵢ,aᵢ₊₁,bᵢ)`、
`(aᵢ,bᵢ,bᵢ₋₁)`；內側四個面為 `(c,bᵢ₋₁,bᵢ)`。
它以原四環為外界，每個內面都是三角形。

**四接點等價定理。** 在固定順序 `(a₀,a₁,a₂,a₃)` 及同一 D 上，

\[
R_W=R_Q=\{\alpha:\alpha\text{ proper on }C_4,
                        \ |\alpha(C_4)|\leq3\}.
\]

W 的結論直接來自中心必須避開四個接點色。對 Q，先考慮框的四點
互異；以一個全域色置換寫為 `0123`。各 bᵢ 的可用色集依序為

```text
{2,3}, {0,3}, {0,1}, {1,2}。
```

若 b₀=2，則 b₁=0 會迫 b₂=1、b₃=2，與 b₀b₃ 邊矛盾；故 b₁=3，
接著只有 `b₀b₁b₂b₃=2301`。若 b₀=3，依次被迫得到 `3012`。
兩者皆用滿四色，中心 c 無色可用。這證明必要方向。

若框 proper 且至多三色，保持接點順序、只做全域色置換後，恰有
下列三種情形。表中直接給完整延拓，逐邊皆正常：

| a₀a₁a₂a₃ | b₀b₁b₂b₃ | c |
| --- | --- | --- |
| 0101 | 2323 | 0 |
| 0102 | 2313 | 0 |
| 0121 | 2303 | 1 |

故充分方向也成立。這是固定四個具名接點的完整關係等式，不只是
兩點投影或分別存在的延拓。checker 另從原邊窮盡 `4^4` 個接點賦色，
接受恰為三個 S₄ 軌道／60 份賦色；環帶的完整八接點關係另行保存。

**任意上下文替換。** 若某圖中的私有 c 的全部鄰點恰為四個 aᵢ，且
四條框環邊存在，刪去 c–aᵢ，加入 Q 的完整新接線，則所有位於這個
局部私有部分之外的具名 ports，其完整四色 relation 不變。因為固定
外部全部顏色後，兩個局部延拓問題由上式逐份等價。其他點間的邊、
對四接點的全部外部附件皆保留；不需平面性或外部染色定理。

中心與新環點必須密封；**不能觀察舊中心色**。以五接點順序
`(a₀,a₁,a₂,a₃,c)`，舊圖接受 `01012` 而 Q 拒絕；Q 接受 `01010`
而舊圖拒絕。此處即使沿用 c 的名字，也會重新染色。另刪去 Q 的一條
中心 spoke 後，框 `0123` 可延拓。兩個界線均有完整關係與見證控制。
相較前輪整來源奇偶公式，本輪有真正可接回任意上下文的四接點等價；
它仍不保留第五個內部觀察點。

## 2. 任意層數的兩來源族

沿用[原核心](c5_two_vertex_repair_sources.md#1-具名核心與可檢查來源條件)：

```text
U=(x,l,y,m,n,p,q,r)=(a0,a1,a2,a3,a4,b0,b2,b4)
(s,t)=(x,y) 正向；(s,t)=(y,x) 反向。
A 私有路徑：h9–h5–h7–h6–h8。
B 私有路徑：v–w。
```

在 A 選 c=h5，其環狀鄰點為 `(x,h7,y,h9)`；在 B 選 c=v，其環狀
鄰點為 `(p,r,q,w)`。兩者皆是完整 degree-4 三角面星。分別作 d_A、d_B
次 §1 替換，每次在同一中心 c 的最新四輪星操作；d_A、d_B≥0。
新點保持其來源 ownership，兩來源仍只共享 x、y。

每次增加四點十二邊，因此全圖有

\[
|V|=15+4(d_A+d_B),\qquad |E|=35+12(d_A+d_B).
\]

在每一步，原四個三角面組成的 disk 被 Q 的十二個三角面取代，其餘
面與四條邊界邊保留。這同時施工於兩份原整圖 rotation；限制到來源
仍以各自原 C₅ 為外面。中心仍 degree 4，可反覆施工任意有限次。

由四接點等價逐次接回，兩來源完整五框關係仍為 R127／R167，並且
共同色框中的自然接合 J 完全不變。全圖染色的構造從原 `core_lift`
開始，按 §1 三行表逐次更新中心與新環點；保持全部外部顏色，特別
保持 U。這不同於任意獨立換色來源後再拼接。

## 3. 舊密封補片及整來源奇偶化約無法開始

以下是不受控制圖大小限制的結構證明。

**沒有密封 clique 補片。** 原 A、B 的每個三角形都是來源 disk 的一個
面，可由完整原邊與 rotations 直接核對。輪環替換刪去中心的四個舊
三角形，新增的三角形恰為 §1 列出的十二個面；其餘三角形不變。
因此任意層數下，每個來源三角形仍都是面。

用下面的 elementary disk fact。若簡單 disk 三角剖分的外界是一個
簡單環，且每個三角形都是面，則刪去任意大小至多三的 clique S 後，
每個剩餘分量都含原框點。證明是在外面加一個新點 o，接全部框點，
成為球面三角剖分 T。T 中每點的鄰點依環序形成一個簡單 link cycle。
刪一點時，經該點的路徑可沿 link 改道；再刪一點時，第二個 link
至多少一點，仍連通。因此 T 刪任意兩點後連通。若 S 是三點 clique，
它在原 disk 是三角面；第三點的 link 中，前兩點相鄰，刪掉這兩個
連續點後仍為非空路徑。因此同樣能改道，T−S 連通。任意原私有點在
T−S 通向 o 的路徑必先經某個未刪框點，證畢。

若存在可刪的非空密封私有分量 C，其完整附件 S=N(C) 為至多三點
clique，則 C 是來源刪 S 後不含框點的分量，矛盾。這排除**所有**這種
補片刪除的第一步，不只排除某個選定核心的拆法。兩來源只共享原框點，
故也排除保留 U 的跨來源補片刪除。沒有使用「補片必可四色染色」的
外部假設。

**不是已分類的整來源路徑族。** 當 d_A>0 或 d_B>0，該側最內環上
`c,b₀,b₁` 是三個私有點的三角形；私有誘導圖不可能是 path。因此
[前輪定理 §1](c5_two_vertex_repair_strips.md#1-來源族及完整附件)的整來源
A(L,R) 或 B(K) 接線前提不成立。這只針對已證的整來源化約，不聲稱
所有可能的局部 path 操作都不適用；前輪已證那些操作不能任意帶著
固定四接點直接替換。

**也不含保持框點與 ownership 的舊核心子圖。** 原 A 有三個私有點
`h9,h5,h7` 同時接 x、y。首次擴張 h5 後，這樣的私有共鄰只剩 h9、h7：
x、y 是 rim 的相對點，每個新環點只接兩個相鄰 rim 點。後續層數
只接私有環點，不能補回第三個共鄰。因此舊 A 不可能單射嵌入。
原 B 有兩個私有點 v、w 同時接 p、q；擴張後同理只剩 w，故舊 B
亦不能單射嵌入。這連非誘導副本都排除，不只是原標號下缺邊。

每次施工時，中心度數仍四，新環點度數五，舊 rim 點的度數增加一；
因此私有最低度數始終至少四，舊 degree≤3 消去也無法開始。
當兩個 d 均正時，兩來源都已超出原補片／整來源路徑化約；新輪環
逆化約則能把它們帶回原骨架。這沒有證明新化約系統的必要性或唯一性。

## 4. 完整可用框與 repairs

原 U 誘導圖不變，候選五環仍恰為原五條。原兩個可用混合框

```text
C₁=(x,n,m,y,q)，C₂=(s,l,t,r,p)
```

的整圖 rotations 已由 §2 面替換延伸。對其餘三框的否定證書，將每條
舊 spoke `aᵢ–c` 換成 `aᵢ–bᵢ–c`；四條 spoke 的內部分別為互異新點。
這在新圖中給一份固定 U 的舊圖 subdivision。兩條交錯原路徑因此可
逐次延伸，仍不相交，仍避開被檢查框的其他點。三個不可用框繼續被
阻斷，全部可用框恰為 {C₁,C₂}。這裡沒有新增雙來源相對區域政策。

J 不變且完整可用框族相同，故 P 不變。兩方向均仍有
J/P/Δ=60/114/54 個全域 S₄ 軌道。原十一份稀疏 U 補全以 §1 表格
延拓，改動的 U 點集合完全不變；完整四點投影及兩類覆蓋等式也不變。
由[共同 repair lemma](c5_two_vertex_common_repair.md)，全部極小修復仍為

```text
A={x,l,y,m}，T={s,t,p,q}，B={s,p,q,r}
𝓔={S⊆U : |S|=4, {q,r}⊆S}∖{B}
{A,B}；{A,T,E}，E∈𝓔。
```

共有一組二份及十四組三份，A 是唯一 forced scope。原 W_A 仍通過全部
至多三點投影而不在 J；四點修復已充分，故 r*=4。
r=0,…,4 的殘留軌道仍為 `54,54,16,16,0`。

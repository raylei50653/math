## 1. 前提、葉點與兩個分支

沿用前報告 G=K−{01,04}、induced 框圈 Γ=(0,1,2,3,4)、disk、
內點 degree≤4、deg_G(0)=2。c 的框列 01021，S 是 maximal 0/1
分量且 S∩Γ={0,1,2}，c′ 是同一 S 上的交換。舊 13 有簡單
L₃:1→4，新原始 02 有簡單 L₂:1→3。
B₃ 是新 02 誘導圖刪框點 1 後包含 3 的分量。

假設 N(0)∩B₃ 非空。前報告給出唯一此類鄰點 w，舊色 1，
完整鄰色 0,2,3,3，唯一 S 鄰點是 0。w 在每條 L₃ 上、
不在任何 L₂ 上。0 的另一鄰點 b 是 S 內舊色 1 的非葉點，b∉B₃。

[原 sector](c5_degree5_sectors.md#3-剩餘問題的精確五邊形重寫) 的內點
完整 degree=4；刪除的兩條框邊不碰內點。本報告明確分開這個等號
與前幾輪採用的 degree≤4 放寬，不把框點也套入度數限制。

## 2. 切斷分支至少七內點

假設 S−{1} 分離 0、2。取 S 內簡單 0–1 路徑 P₀；它是 Γ-path。
它不能先走葉點 w，因此第一內點是 b；最後內點記 a，舊色 0。
令 p 是 L₂ 第一內點，舊色 2；u 是 L₂ 最後內點，新色 0。
令 q、r 是 L₃ 上 w 的兩個鄰點，舊色 3。

以下七個都是不同內點：

| 身份 | 舊色與區別 |
| --- | --- |
| w、b | 舊色 1；一個是 S 葉點，一個不是 |
| a | 舊色 0、在 S，故新色 1 |
| p | 舊色 2 |
| q、r | 兩個不同舊色 3；框上沒有舊色 3 |
| u | 新色 0，可能是 S 內舊色 1 或 S 外舊色 0 |

u 不等於 a（新色不同）、p、q、r（舊／新色不同）；
u∈L₂−{1}⊆B₃，故不等於 b；L₂ 與 L₃ 只交於 1，故 u≠w。
因此 **|C|≥7**。沒有假設這些路徑本來很短。

## 3. 七內點等號迫使 b 的 degree≤3

若恰七內點，它們就是上表全部頂點。簡單路徑與顏色重數遂強迫
（按 L₃ 順序命名 q、r）：

```
P₀ = 0–b–a–1，L₃ = 1–q–w–r–4，L₂ = 1–p–u–3。
```

理由：P₀ 除端點外只有一個可用舊色 0 的 S 點 a；L₃ 必經 w，
但只有兩個舊色 3 點；L₂ 只有一個內部色 2 點 p，且不能經 w、b。
w 的唯一舊色 2 鄰點也必為 p。因此還有 Γ-path **0–w–p–u–3**。
u 的身份只有「舊色 0、S 外」及「舊色 1、S 內」兩型。

逐一檢查 b 的所有潛在鄰點：

- 0、a 已是鄰點。
- 1、4、w 與 b 同舊色；u 若舊色 1 也同色，不能鄰接。
- u 若舊色 0 且在 S 外，b–u 會違反 S maximal，不能鄰接。
- 2 不能鄰接，否則 0–b–2 在 S−{1} 中連通 0、2。
- 3、p 不能鄰接：各給出 0–b–3 或 0–b–p–u–3，與 L₃
  頂點互斥、框端點交錯，違反 disk。
- 只餘 q、r；但若兩者都鄰接 b，則舊 13 路徑 **1–q–b–r–4**
  避開 w。這已違反 w 在每條 L₃ 上；也可直接與
  **0–w–p–u–3** 組成交錯互斥 Γ-paths。

故 b 只能鄰接 0、a 及 q、r 中至多一個，得到 **deg_G(b)≤3**。
這不與放寬的 degree≤4 矛盾；但與原 sector 的完整 degree=4 矛盾。
因此切斷分支在原 sector 必有 **|C|≥8**。

排除的是必要路徑配置的任何接線補全；沒有枚舉七內點候選圖。
上述每個排除理由都保留同一 c、S、頂點身份，增加其他邊不會修復。

## 4. 未切斷分支在 degree≤4 下已至少八內點

假設 S−{1} 有簡單 0–2 路徑 P。由 disk 交錯性，P 分別與
L₂、L₃ 相交於 t₂、t₃；[雙 star 引理](c5_sector_saturated_cuts.md)
給出完整鄰色 0,0,2,2 與 0,0,3,3，因此 t₂≠t₃。
w 是 S 葉點，不會是 P 的內點，故 w 與兩個 t 都不同。

L₃ 同時經過 w、t₃。沿簡單 L₃，它們可按任一順序出現；
框端點 1、4 與 w、t₃ 都是舊色 1。因此三段

```
1 → 第一個標記 → 第二個標記 → 4
```

的開區間各至少含一個舊色 3 內點，且三者互異。
P 上 t₂、t₃ 之間至少有一個舊色 0 內點 a；t₂ 的兩個舊色 2
鄰點中至少一個 p 是內點，因為框上只有頂點 3 是舊色 2。

得到八個不同內點：三個舊色 1 的 w、t₂、t₃，一個舊色 0 的 a，
一個舊色 2 的 p，以及三個舊色 3 點。因此 **|C|≥8**。
此分支不需要內點 degree=4 等號，也不預設兩種 stars 的先後次序。

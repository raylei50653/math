**新結果：132 個既有來源關係的最小投影階數為 11 個二階、101 個四階、

## 1. 固定色框下的兩種階數

令色集 Q={0,1,2,3}，S 是具名接點集，R⊆Q^S 是非空完整字面關係。
色名只作一次共同 S4 作用；不把各投影各自正規化後直接拼接。
定義

\[
\operatorname{cl}_r(R)=
\{x\in Q^S:\ \forall T\subseteq S,\ |T|=r,
\ x|_T\in\pi_T R\},\qquad
d(R)=\min\{r\ge1:\operatorname{cl}_r(R)=R\}.
\]

域是全部 Q^S，包含不 proper 的 tuple；框邊限制由投影本身恢復。
因每個較小 scope 都包含於某個 r-scope，使用全部恰 r 點投影等價於
使用全部至多 r 點投影。故 R⊆clᵣ₊₁(R)⊆clᵣ(R)，且 d(R)≤|S|。

對原八點 U 上接合關係 J，指定合法框族 𝓕 後，另定義

\[
P_{\mathcal F}(J)=\bigcap_{F\in\mathcal F}\pi_F^{-1}(\pi_FJ),
\qquad
r^*(J,P)=\min\{r:\ P\cap\operatorname{cl}_r(J)=J\}.
\]

沿用既有約定：P=J 時 r*=0。這是**無輔助變數、只合取投影條件**的模型。
d(R) 是來源本身的階數；r* 是已有 P 之後還需要的修復階數，不能混稱。
本文也不把「階數」混同最少條件數或全部 inclusion-minimal repairs。

## 2. 接合的紙面上界與代表無關性

兩個實際來源 A、B 只有指定的兩個框點共用，私有內點互斥，
整張接合圖恰為兩來源邊集聯集。共同對齊其有序框 S_A、S_B，令
U=S_A∪S_B。對**任意大小**來源，完整接合恰為

\[
J=\pi_{S_A}^{-1}(\Sigma_A)\cap
  \pi_{S_B}^{-1}(\Sigma_B).
\tag{1}
\]

理由是同一 U tuple 在共享點取同一字面色；兩個私有延拓可直接合併。
式 (1) 不需平面性，但需要確實沒有額外共用私有點或跨來源邊。
並且

\[
J=\pi_{S_A}^{-1}(\pi_{S_A}J)\cap
  \pi_{S_B}^{-1}(\pi_{S_B}J).
\tag{2}
\]

右方包含 J；反向由 π_S J⊆Σ_S 及 (1) 得到。

**上界引理。** 對任意非空 J⊆P⊆Q^U，

\[
\boxed{r^*(J,P)\le d(J)\le
       \max\{d(\Sigma_A),d(\Sigma_B)\}\le5.}
\tag{3}
\]

證明：令右端最大階數為 r。若 x 通過 J 的全部 r 點投影，則它通過
每個來源框內至多 r 點的 Σ 投影，因為 π_TJ⊆π_TΣ。來源 r-decomposability
推出 x|S_A∈Σ_A、x|S_B∈Σ_B，故 x∈J。再交上任何包含 J 的 P 不改變結果。
兩原框本身即給至多五階的另一個直接證明。
既有catalogue的兩點介面都容許異色，故其精確兩點接合非空。
若另考慮空J，任一單點投影已為空，可獨立用一階條件處理。

這提供一個**接合語義的上界**；它不聲稱至多五個來源內點、不計 repair
條件個數，也不保證操作後忘掉某些接點的投影仍有同一階數上界。
存在量化消去隱藏點可以增加所需階數：原圖全由二元邊約束組成，
§4 的三內點代表消去內點後已需五階。

**條件式代表無關性。** 若另一組來源保留同一 Σ_A、Σ_B、具名接點雙射，
且仍為上述精確接合，則原 U 上的 J 自動相同。若另外證明整圖可用的
具名框族 𝓕 相同，則 P、所有投影排除集合及全部 repairs 也相同。
不必先證兩組來源可由某份局部改寫規則互相轉換。

因此輪環、雙扇、D₁₃ 等來源族的共同角色可以分開：完整局部等價負責 Σ；
密封／ownership 負責式 (1)；面表與交錯路徑負責 𝓕。圖形正常形的完備性
是額外問題。相反，只有 repair 家族形狀相同，不能倒推出 J 相同；
[正反向 transport](c5_two_vertex_repair_transport.md)已有反例。

## 3. T4 全收時的四階引理

**引理。** R 是 S4 不變的 proper C₅ 關係，若 T4⊆R，則 d(R)≤4。
此結論完全是關係代數，不需要來源圖或 disk 性質。

取 x∉R。若 x 不 proper，某條框邊的同色端點已被二點投影拒絕。
若 x proper，因全部四色列都接受，x 必是三色列，色重數為 (2,2,1)。
刪去其唯一 singleton 點，剩下沿四點路徑交替的兩色。被刪點的兩個
框鄰點異色，故任何 proper 補回只能用另外兩色之一；兩種補回
恰在同一 S4 orbit。若這個四點 restriction 在 π_T R 內，R 的
S4 不變性便迫 x∈R，矛盾。因此四點投影一定能拒絕 x。

直接推論：兩個 T4 全收的來源精確接合時，對任何 J⊆P 均有 r*≤4。
但 T4 不是四階性的必要條件；既有 R127、R167 也都是四階。
932 加任意三色列的全部 32 個抽象 masks 已核對本引理，
**包含尚不知有無 disk 實現的 933、941**。四階性不能排除這兩個候選。

## 4. 有限初驗與具體反例

新 [checker](../scripts/c5_relation_arity_audit.py)與
[證書](../artifacts/c5_relation_arity/observations.json)從既有完整 pattern order
展開全部共同色名 tuples，對每份關係掃完整 4^5 域。

| 來源最小階數 d | 既有 class 數 | 意義 |
| ---: | ---: | --- |
| 2 | 11 | 全部二點投影足夠 |
| 3 | 0 | 本 catalogue 沒有恰三階者 |
| 4 | 101 | 三點仍不足，四點足夠 |
| 5 | 20 | 全部四點投影仍不足 |

20 類分成四個 D₅ 軌道；D₅ 只整理結果，計算仍保留固定邊界標號：

| 軌道代表 | 全部具名 class IDs |
| ---: | --- |
| 223 | 223, 351, 379, 635, 731 |
| 383 | 383, 479, 735, 763, 891 |
| 509 | 509, 703, 887, 990, 1003 |
| 511 | 511, 767, 895, 991, 1019 |

一個容易讀的反例是 **R511=Ω\{01232}**，既有代表只有三個內點。
拒絕 tuple `01232` 的全部四點 restrictions 分別都有原圖延拓：

| 省略的框點 | 一份完整圖染色，次序為 b0,…,b4,5,6,7 |
| ---: | --- |
| b4 | 01231123 |
| b3 | 01202133 |
| b2 | 01032312 |
| b1 | 03232311 |
| b0 | 31232100 |

每列固定其餘四個框色，且通過同一原圖全部十五條邊；完整 `01232` 卻不可延拓。
五個局部延拓是五份不同染色，不能拼成一份全域染色。
證書保存全部 20 個反例的原邊集、完整 Σ 重算、拒絕列及共 100 份四點延拓。
Disk 身份沿用 catalogue，這輪沒有重跑其 planarity checker。

全 1,024 個抽象十 bit masks 中，140 個不是四階可重建；這不是
140 張圖或 140 個 disk classes。上述 20 個是其中已知有 disk 代表者。

## 5. 六個原接合案例回歸

從原來源邊集重建八點 J；逐條重驗既有所有候選框的 rotation 或
交錯路徑證書，再由 J 的框投影重建 P。沒有把舊接受旗標當新判定。

| 原案例 | 來源 d 的最大值 | 相對 P 的 r* | r=0,…,5 的多餘軌道數 |
| --- | ---: | ---: | --- |
| reference、reference_reverse、shared_chord_frame_edge | 2 | 0 | 0,0,0,0,0,0 |
| free_pairs | 2 | 0 | 0,0,0,0,0,0 |
| private_interiors、private_interiors_reverse | 4 | 4 | 54,54,16,16,0,0 |

式 (3) 解釋兩個非平凡案例的四階**上界**；其三階不足、唯一最少兩份
及十五組全部極小 repairs 仍依賴各案例的下界與覆蓋證書，不能只由上界推出。

## 6. 後續實驗與驗證界線

若未來要找精確兩點接合的 r*=5，式 (3) 已保證：至少一個來源
必在上述二十類之中。這是**必要候選條件，不是存在性結論**。
可先選 R511 的既有代表及少量具名接點對，明列候選框並重驗 disk 可用性，
再計算相對完整框族 P 的 r*。若得到五階反例，保存 x∈P\J 對全部
四點 scopes 的完整原圖延拓；若全四階，僅記該域，不提升成普遍四階定理。

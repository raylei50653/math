# C：實圖與完整字面 fibres 獨立重建

本包從凍結附件的 F／F+C 文法內最小代表字串，重建完整圖、目前有序 C₅
邊界及每個有向內面，再直接枚舉固定字面邊界著色的所有全圖延拓。
圖構造與著色枚舉不讀取轉移矩陣；最後才與附件的整數矩陣及支援轉移比較。
這是新寫的獨立重建，**不是缺件的歷史原始生成器／驗證器重播**。

## 操作與實圖資料

- F：頂點 0…4 的五邊形，加弦 0–2、0–3；內面為
  (0,1,2)、(0,2,3)、(0,3,4)。C：無弦五邊形，一個五邊形內面。
- P：保留全部舊頂點與舊邊，新增 x 及 xb₄、xb₀、xb₁；目前邊界改為
  (x,b₁,b₂,b₃,b₄)，附加有向面 (b₁,b₀,x)、(b₀,b₄,x)。
- R：圖及內面不變，邊界改為 (b₄,b₀,b₁,b₂,b₃)。

每一案例的 `graph` 明列全部邊、目前邊界及全部內面。檢查器驗證圖連通、
五邊界單純性、每條邊的有向面入射、Euler 特徵 1，及每個頂點的 link：
內點為一圈，邊界點為一路徑。F 案例另檢查內面全為三角形；C 的五邊形內面
如實保留，並未視為三角剖分。

## 結果

| 核對 | 結果 |
| --- | ---: |
| 每套文法的最小代表 | 132 |
| 每代表案例 | 本身、P 後繼、R 後繼 |
| 實圖案例（兩套文法合計） | 792 |
| 固定十列的完整 fibres | 7,920 |
| 其中空 fibres | 2,278 |
| 全部字面全圖著色 | 10,642 |
| 最大頂點數／單一 fibre 大小 | 12／8 |
| 整數矩陣／支援／disk 檢查不符 | 0／0／0 |

`literal_fibres[i]` 保存每一個實際延拓在遞增 `interior_vertices` 上的字面
顏色字串；目前邊界固定為 `rows[i]`。`[]` 是空 fibre，`[""]` 是無內點時的
唯一空指派。因而從目前邊界與此字串能完整重建同一張圖上的一份著色。
並未把相同支援、不同計數或不同實圖合併。

矩陣比較使用整數計數 `new[i] = Σ_j M[i][j] old[j]`；不是 Boolean 計數。
所有代表成本也與附件的文法內最小內點數一致。這些案例核對最小代表的
實圖上界及其後繼，最小性下界仍由既有有限模型的 Bellman 核對承擔。

## 獨立枚舉與污染控制

主要枚舉器按實圖鄰接限制，以飽和度選擇下一內點，逐一列出全部字面著色。
另用無剪枝的 Cartesian product 枚舉八個字串的全部十列，共 80 個完整
fibres；逐份清單相同，包含最大 12 頂點案例。

七項控制全部檢出：刪除 P spoke 卻保留三角面、重複邊界點、單面反向、
孤立新增頂點、合法但漏 spoke 的四邊形附接、反方向 R，以及把計數壓成
Boolean 而保持相同支援。前四項由 disk 結構檢查拒絕；後三項以完整整數
fibre 計數檢出。

## 重播與界線

從項目根目錄執行（僅 Python 標準庫）：

```bash
python3 -B audits/2026-10-19-c5-pr-disk-semantics-ed59843/C/check_full_graph.py --check
```

`--check` 重算全部結果後逐位元組比較 `certificate.json`、`verification.json`，
全程唯讀。`--write` 僅以排他建立模式建立本 C 目錄的上述兩檔，已有輸出即拒絕。
凍結來源證書 SHA-256 先依
`../BASE.json` 核對；輸出及檢查均為確定性的。

本包的 7,920 是 792 個主要案例各十列。歷史來源另述 8,020 fibres，包含額外
控制案例；這裡未宣稱重播那份未附程式的完整流程，也未將 80 個獨立枚舉
交叉核對加算成主要案例。三角面插點不是 P/R 字母，本包不重做該項來源控制。
一般 disk／指定 r6 來源均具有此 F/C 文法代表的覆蓋命題仍為 OPEN。

# C 對 A／B 的交叉覆核

讀取 `../A/REVIEW.md` 與 `../B/check_local_operators.py`，並以
`python3 -B .../B/check_local_operators.py --check` 重算 B；通過 5,120 份局部指派、
200 個整數矩陣項、2,048 份形式轉移、264 條附件轉移及四項污染控制。

B 的圖 patch 由實際邊集合定義，未讀取矩陣來選取局部著色。對每一個 240
字面目標，十個來源槽包括空槽均保留；每份來源帶有作用於完整著色的調色盤
置換及逆置換。編譯出來的矩陣才與凍結附件比較。因此沒有用相互獨立的局部
邊際代替同一份相容著色，也沒有把 S₄ 軌道大小誤乘到固定字面計數。

A 的任意大小證明保留全部舊圖，沿目前外框的 b₄–b₀–b₁ 弧附接一個 disk；
限制／延拓給出以實際舊 b₀ 顏色分槽的完整 fibre 雙射。對非 proper 目標
另外保留新邊界 gate，對 proper 目標的正規化以同一全局調色盤置換完成。
這足以支撐任意 disk 的明定操作語義；本 C 的有限實圖枚舉提供另一路實例核對。

未發現實質問題。三份工作共同保持「明定操作的重建」與「附件缺件原程式的
歷史重播」的區分；一般 disk 的 F/C 文法覆蓋仍需獨立證明。

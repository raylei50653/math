# 一般 wrong-side 主稿的獨立紙證覆核

2026-10-23。審查對象為
[一般 wrong-side PROOF](../2026-10-23-941-wrong-side-general-6b09cd4/PROOF.md)，
不是以有限圖校準替代來源論證。只寫本專屬目錄，未改被審稿或其證書。

結論：所要求的四處量詞／框邊界論證均通過，未發現須修正的數學步驟。
保留下列前提與結論範圍；沒有審成一般 wrong-side 排除。

1. **固定 S、任意真交數、再變 L。** 固定同一原 P、S 後 p、n_S 都固定。
   任一 C 中簡單 r→e 路的內部不碰兩條避 C 的尾路，故確為原 Jordan 圈；
   它與同一 β 只交 p、n_S。β 的其餘 boundary 端點不可能嚴格在 F 內的
   Jordan 圈有界側；n_S=boundary Yq 中點時，β 的 F 內側臂亦進有界側。
   因而內部中心恰是同一開 β(p,n_S) 上的中心，與 L 無關。可先固定一個
   內中心及一個外中心再任意變 L，不是事後每條 L 各挑兩個不同 patch。
   共 k0／非端點 b1 的全路割點、共同01邊的全路橋量詞因此成立。

2. **恰二真交才變 S 或 B∩C 起點。** 改選同一完整 B 中的簡單 S 時，
   α、β、P、r、T 及同一對中心都不變；e、W*、h、n_S 可變。內外中心各
   奇數且總共恰二，使同一對中心對每份 S 都各佔一側，即使它們互換內外
   身份亦不影響共同點必落 Γ。原 b3 色3，不能落 P01 或 Lψ12，所以每條
   S 都含它。任意 a∈B∩C 必為原色1；以 a 為起點仍有最後 C 點，B 的
   全部原邊仍在 Ω 外，兩尾段的分離及 Γ∩β 論證保持。因此 B−b3 中含 b
   的分量避開全部 B∩C，而非僅分開原固定的一份 Y→b 路。這個變 S 的
   全路推論沒有被誤推到四次以上真交。

3. **b=c 時 q 的 F boundary 扇區排除。** boundary 原路 Y−q−c 避開任何
   私有共同 b3，故全路割點只能是 q。真的選 S₀=Y−q−c 後，P 的原01色及
   避 C 性質排 Y、q，首次交點才確為 h=c。所造 Γ 在 q 使用 F 的兩條
   boundary 邊；局部整個 F 扇區在 Γ 有界側，因 F 外側通無窮遠。即使 q
   的 F 扇區不是凸角，這個有界側判定也成立。任一以 q 為頂點的 F 實際
   三角面，其內部不穿 Γ 原邊，故與該局部扇區同側。外中心 patch 含 q
   並至少提供一個這樣的原面，於是矛盾。不需要 q 的完整 G-cyclic link、
   額外度數，或 G 在 F 外的面。

4. **h=c⇒b=c 是單向身份。** h∈P[r,b]，而同一 P 是以 c 為終點的簡單
   路；若該前綴已含 c，前綴終點 b 只能是 c。反向 b=c⇒h=c 對任意 S
   不成立；主稿只在特選 S₀ 後使用 h=c，未顛倒量詞。

引理4中 v≠q 時的無框附枝亦核對：V、Y∈B∩C 已在刪 v 後的 b 分量外，
boundary Y−q−c 避 v，故 q、c 也不在該分量；這不是整個 B rootless。
v=q 時 c 例外正確保留。共同13邊若為 boundary Yq，兩個不同 patch 的
兩個共邊面須佔原邊兩側，而 F 只有一側實際面，故該子支不成立。

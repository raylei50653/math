# W7 同源 Kempe 排除的共用證法

2026-10-21；凍結 BASE `d23f94f739468593db653ec03f903c30adfd5fb0`。
本頁整理既有 u3v／u1v 證明與本輪 u3w／u1w、其他型的共同邏輯；
各新分支的逐欄短證與檢查入口由 [REPORT](REPORT.md) 索引。

## 1. 所有分支固定的同一來源

完整承接[原來源契約](../2026-10-20-r6-941-j1-five-edge-417732f/SOURCE_CONTRACT.md)：
任意大小有限簡單 plane C5 disk G、原框 `(x,y,a,b,c)`、完整支持941、
全域最小內點數再最大邊數、原 stars／rotation／全部原附件與私有點。
只固定 Q1 接受零的 J1 type III 實際12色五邊路
`n–u4–u3–u2–u1–L`，並加原 C7 有界側恰只有 R 的嚴格 only-R 前提。
一般五邊路不自動有這個前提。

原核心始終為

```
D = G − {b,p,h,R,x,y,r},
rim(D) = (a,n,u4,u3,u2,u1,L,q,c,s,v,w,t).
```

Z_i 計同一 D 在固定字面 rim 色列的**全部完整著色**，包括空 fibres 與
不能接回 G 的完整著色。原 G／Q1／J1 的全部 cap stars 不變，每份當前
D 著色各自量化同一原 cap 的全部 lifts。X_j 是同一 D 的完整實際 Kempe
orbits 按 boundary column 合併的非負權重，保留所有不碰 rim 的私有分量。
原選定完整著色只供應 `Z44459+Z44466>0`，無需每一步維持該選路歷史標籤。
原七個正量與兩個 sector 可以由同一原圖的不同完整著色供應；這些正量
不必由同一份著色同時供應。共同來源要求的是原圖、附件及完整 Z／X 不換。

## 2. 完整支持全覆蓋零傳播引理

原[同源計數證明](../2026-10-20-r6-941-j1-five-edge-417732f/counting/PROOF.md)
給每個 normalized half-row h 的同一來源恆等式

\[
2Z_{i(h)}=\sum_{j\in I(h)} X_j,\qquad Z_i,X_j\ge0,
\]

其中 I(h) 是**原完整 family** 中所有含 h 的欄，不能抽樣、漏掉未選欄，
也不能按不相容的來源各自選 I(h)。本輪固定的原 family 有307,197欄，SHA256
`542ee11de93a846bfbc321b098214b153c5b600318ba2e0bc5621a73ad2a55ad`。

有兩條安全推理規則。

1. **原邊種子。** 假設同一原邊 e=ij 實際存在。某 state 在 i、j 同色，
   則該完整 fibre 空，Z=0。這涵蓋所有 D 完整著色，不只可接回 G 的部分。
2. **全覆蓋回推。** 為 I(h) 的每一欄 j 指定一個它包含的 half-row k_j，
   且 Z_{i(k_j)} 已證零。由 k_j 的非負恆等式得 X_j=0，再由 h 的完整
   恆等式得 Z_{i(h)}=0。各欄可使用不同的零見證；所有欄都必須被覆蓋。

有限有向無環證書只需把這些規則按順序列出。它是同一來源的紙面非負
恆等式推論，加原完整邊界分類的精確有限核對。當短鏈存在時，可再直接
描述完整實際分量的換色；一般分支證明不必硬化成一條共同字面鏈。

這也有實際染色的反證讀法：若某 fibre 有一份完整著色，其 actual orbit
必落在 I(h) 的某一欄。選該欄對應的完整分量交換，即抵達已證空 fibre，
矛盾。所有交換都攜帶同一 D 的全部原私有點；不能只翻 rim 上幾個點。

## 3. 既有 u3v／u1v：共同的兩輪字面作用

既有完整 family 對以下三份原有序 rim 色列給出同一作用：

| 名稱／state | 字面 tuple |
| --- | --- |
| A=44459 | `(0,1,2,1,2,1,2,3,1,2,0,1,2)` |
| M=44111 | `(0,1,2,1,2,1,2,0,2,1,3,1,2)` |
| F=44127 | `(0,1,2,1,2,1,2,0,2,3,1,3,2)` |

A 的03／12分割只有原欄306985。交換完整 `K03(q)`（接觸 `{q,v}`）與
完整 `K12(c)`（接觸 `{c,s}`）得到 M；兩個互補 palettes 的作用可交換次序。
M 的02／13分割完整支持為147448、147449、167802、226130、231666，
五欄都迫完整 `K13(v)` 接觸恰為 `{s,v,w}`。交換它得到 F。
故同圖完整 fibres 有

\[
Z_{44459}\le Z_{44111}\le Z_{44127}.
\]

F 同時滿足 u1=u3=v=1。若原邊 u3v 或 u1v 存在，終點即為原邊種子零。
另一個 target B=44466 在該原邊也本就同色，因此兩 target 都零，與原 witness
正量矛盾。這兩分支各自成立，不互用另一條邊的前提。

## 4. u3w／u1w 必須重新分類

B 的原字面 tuple 為 `(0,1,2,1,2,1,2,3,1,2,1,0,2)`。
它的03／12 half-row 12302051 唯一 incident 欄為306993，實際分量接觸是

```
03: {a}, {q,w};
12: {n,u4,u3,u2,u1,L,t}, {c,s,v}.
```

首輪交換完整 `K03(q)` 與 `K12(c)`，必得到

```
M'=44107=(0,1,2,1,2,1,2,0,2,1,2,3,2).
```

這裡 v 也被攜帶改色；M' 的02／13支持有14欄。因此不能把上一節的 v、w
交換名稱後當作原圖的證明。本輪兩個 w 分支改用第2節的完整覆蓋規則，
各自從原實際邊同色種子回推 B=0；A 則直接在 u3w／u1w 同色為零。
逐欄證書與原圖來源橋接見兩個分支報告。

## 5. 套用於其他型與保留邊界

每個固定原 profile 保留全部原弦，各自使用第2節，不能拼接不同 profile 的
可行片段。原40份正 witness 必要覆蓋中，舊 v 分支排16型；本輪 w 分支排
12型，另外四個單邊引理 u4v、u3s、u2v、u2w 排其餘10型。

原 profile0（無弦）與1（僅原 au4）仍有兩個 target 的必要支持。其餘原
接線已排，並不把「原非邊」轉成某個著色 fibre 零值。無弦支仍須容納
五個不同原外側私有面點，不能刪成沒有私有點的小圖。

這兩型的原面資料亦不同：profile0 的五條路邊外側第三面點全為不同
D 私有點；profile1 因原 au4 迫 `d_G(n)=5` 與原面 `(a,n,u4)`，首個
第三點必為原框點 a，僅其餘四個為私有點。對兩個 target，這些第三點
都只能用0／3色，且 profile1 的首點 a 固定為0。詳細原 rotation、完整
link 與 degree 義務另見[私有面點審核](../2026-10-21-w7-private-face-points-d23f94f/REPORT.md)。

**尚未證：** 這兩型的來源矛盾、其必要計數錐的精確可行／不可行、來源
實現、一般 W7、一般 C7 多內點、一般 J1／J2、嚴格較小 bad 與主命題。
沒有新增 Lean。完整來源覆蓋與 count 恆等式的任意大小量詞沿用原紙證；
有限程式只核對其本輪所用完整欄與有限推論，不冒稱新的形式化定理。

## 6. 可直接使用最小性的完整關係替換引理

固定原外側 E 與原 patch H，兩者的**全部**共同接合點恰為同一有序界面 S，
所有內外邊都經 S；原外框 B 保留在 E 與 S 中。設合法替代 H' 也只沿同一
S 接到 E，且對每份固定字面 S 色列，包括空列，有

\[
\mathcal R_S(H)=\mathcal R_S(H').
\]

對任一原外框字面色列 β，完整 G=E∪H 有延拓，恰當存在同一 S 色列 σ，
使 E 有相容於 β、σ 的完整著色，且 σ∈R_S(H)。把最後一項換為
σ∈R_S(H')不改變真假，因此新 G'=E∪H' 的原外框完整關係與 G 完全相等。
這個接合使用同一 σ 的共同 witness，不把獨立接點 marginals 拼起來。

若另外證明 G' 合法保持原有序外 C5、有限簡單 plane disk，並且計入全部
補完成本後原內點嚴格下降，則 Σ(G')=Σ(G)=941，仍為目錄外來源，直接違反
全域最少內點。這個**以最小性求矛盾**的合同不要求著色數相等，也不要求
新圖保留原W7或Q1／J1構造；新圖只需屬於該全域最小性比較的來源類。

若另想把本輪的同源計數方程、個別cap lifts或特定選路歷史搬到新圖，
那是更強的另一合同，需分別證明相應完整fibre傳輸。不能把這些額外要求
誤當前述完整支援替換引理的必要前提。

本輪尚未給出任何滿足這些條件的 H'。仍缺的是**具名合法替代、完整S關係
相等及嚴格大小下降**；上述條件式接合引理本身已證，不能把它報成已完成
W7縮減或已構造較小bad。

## 2. 完整原 T 星迫六份不同的原 K 面點

記原 N 六圈依序為 n0=r,n1=τ,n2=sΓ,n3=b,n4=y,n5=a。
它是 T 的完整 cyclic link，所有輪面 Tn_i n_(i+1) 都是原實際面，
任何非連續 n_i、n_j 間沒有原邊；T 與完整 K 也沒有原02邊。
六點皆是原 F 私有點，完整原度至少五，所有原鄰點恰可在此原輪或 K。

任一 k∈K 不能同鄰兩個**非連續** n_i,n_j。否則原四圈

`n_i–T–n_j–k–n_i`

的兩條對角 T–k、n_i–n_j 均是原非邊，撞原 C4 有界側為空且必三角化。
這裡用同一實際原 k，不把分開可行的原星拼成共鄰。

每條 N 六圈邊 n_i n_(i+1) 的非 T 側原面第三點記為 q_i。
它不能再是原 N 點（否則是完整 T link 的弦），亦不能是 T 或其他原
M 點，故 q_i∈K。原 C3 空側使這些是真正原面，不是虛構 face witness。
若某個 K 點同鄰連續 n_i,n_(i+1)，其原三角形必為該邊另一側的原面，
故它正是 q_i；不能在同側另放第二份三角形。

六個 q_i 兩兩不同：若兩個不同原邊共用 q，該 q 至少碰三個 N 點，
必有兩個非連續 N 點，已被前一段排除。更強地，任何
`k∈K\{q0,…,q5}` 最多只鄰一個 N 點。

## 3. 完整 N 星共同接成一個原 K6 collar

固定原 N 点 n_i。其完整 link 的輪側弧是 n_(i−1)–T–n_(i+1)，
另一側弧從 q_(i−1) 經若干 K 點走到 q_i。最低度五及 q_(i−1)≠q_i
保此弧至少含兩個 K 點。其內部不能用任何其他 q_j：那會給 q_j 額外
的 N 接觸；亦不能跨不同 n_i 的外弧重用一個其他 K 點，因該點最多
只鄰一個 N 點。各原 full link 自身亦不重複點。

因此六份外弧在**同一原 rotation** 上接成一個簡單原 K 圈；它使用六個
不同 q_i，加上至多 |K|−6≤1 個不同的額外點。圈長只能是6或7。
原 K 是 proper02分量，任何原圈皆為偶數長，故圈長恰六，沒有額外點。
所以每個 N 點原度恰五，完整外弧就是 q_(i−1)–q_i。

此論證已控制全部原 K 點對完整 N 的接觸，沒有假定 ω 的剩餘原星已封滿。
ω 可以在這個六圈上，也可以完全在其外；兩種情形的未知原 K/B stars
及所有旁觀點稍後原樣保留。O 核心的 τ 原六度立即與此全 N 五度矛盾。

六個輪面、六份 N 邊外面及六份 N–K–K 外弧面共同封成18個原三角面。
相鄰面只在同一原邊以相反方向接合，抵消後只剩該簡單 K6；這是原 T
輪 disk 的逐面外擴，保持有界側，沒有從抽象 Euler 數猜原面側。原 K6
有界 disk 的完整內點恰為 `(r,T,sΓ,τ,a,y,b)`，共七點、30邊。
完整七原星均封閉，故外部附件只經同一原六接點進出，沒有漏邊。

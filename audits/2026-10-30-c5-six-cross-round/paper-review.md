# 六附件等號及跨輪必要條件：獨立紙面核對

`docs/c5_kempe_period4_s5.md`。本檔不依賴 producer 的判定；所有一般結論均在下文給證。

## 1. 六附件等號：原誘導無弦六環

設 c,d 是同一完整 O 的 proper 四著色，在 B 及五個原面第三點 w_i 上相同。
取非空差異分量 Q，A=N_G(Q)。附件分隔引理給出原簡單環 C，
其原邊來自只刪 Q 後含 v 分量面向 Q 的面邊界 W；全部 Q 與 v 在 C 的相反開側，
V(C)⊆A，|C|≥6，而且 C 完全不使用 B 的原邊。

**等號引理。** 若 |A|=6，則 V(C)=A 且 G[A]=C。因而 G[A] 本身就是一個
在 c,d 間逐點固定的原無弦分隔六環。這裡的固定只指這兩份著色。

證明：|C|≥6 及 V(C)⊆A 先迫 |C|=6、V(C)=A。假設 G[A] 還有一條弦 e。
e 的內部落在 C 的一個開側，並把該側分成兩個由原簡單環界定的子盤。
兩子環均由 e 加一條 C 弧組成，長度至多五。

- 若 e 在 Q 側，由 Q 連通且不碰 A，全部 Q 落在同一子盤；取其子環 L。
- 若 e 在 v 側，取含 v 子盤的子環 L。

兩種情形的 L 都是 A 中的原簡單環，逐點固定，且分隔全部 Q 與 v。
長三／四與 S34 矛盾。若長五且 v 側至少兩點，固定五環剛性迫 Q 中各點不變，矛盾。
若長五且 v 側只有 v，v 的五個鄰點全部在 L 上，故 V(L)=B，L 必使用 B 邊。
但 L 含至少兩條 C 邊，而 C 完全不使用 B 邊；在由 B 的五個點構成的三角剖分中，
S34 排除 B 的弦（非相鄰 B 點的原邊與 v 構成分隔三環）。因此 L 只能是 B，矛盾。
故不存在 e。證畢。

最後一段也可直接用五度點的原星：只有 v 的五邊盤內每一相鄰鄰點必沿原 link 接邊，
故 L 的循環次序必為原 B。此證沒有補弦，也沒有把附件閉走當成簡單環。

## 2. 無弦環一側的連通性：六附件核沒有自身側的固定內島

**開側連通引理。** 有限簡單球面三角剖分中，長度至少四的原無弦簡單環 C，
其任一非空開側 S 的誘導原圖 G[S] 連通。

證明：每條 C 邊在該側的原三角面第三點必在 S；若第三點也是 C 點，便給一條弦。
在每個 a∈C 的該側原 link 中，從前一環點到後一環點之間的所有內部鄰點均屬 S，
且相鄰 link 點間都有原邊。這條非空 link 路把 a 兩側 C 邊的原第三點接起。
沿 C 一周可知所有這些原第三點，以及所有該側鄰 C 的點，同屬一個 G[S] 分量。
任一 G[S] 分量都必鄰 C：取它到 C 的原圖路，離開該側前必先碰 C。
故不可能有第二分量。證畢。

**整側推論。** 在第 1 節的六附件情形，Q 恰為 C 的不含 v 開側全部點集。
否則該側的連通原圖中必有 Q 到另一點的第一條跨邊，給出 A 中不在 C 的點。
所以這個 Q 側沒有固定內島，也沒有另一個差異分量。
其他差異分量、固定島與遠端重接仍可存在於 v 側；本推論沒有刪掉它們。
這個結論逐一適用於 D^(0)、D^(1) 的六附件分量，但沒有把兩組分量配對。

## 3. 一、二點六附件核：可以完整辨識的合法局部交換

**單點案。** 若 Q={x}，則 d_G(x)=6，C 是 x 的完整原 link，並填滿 x 側原面。
c(x)≠d(x) 迫 C 的全部點只能使用另外兩色；proper 六環因此交替使用這兩色。
x 使用兩個缺色之一，兩端恰互換。兩缺色在完整 O 中包含 x 的實際雙色分量正是 {x}，
所以一次合法 Kempe 交換便把這個核從 c 的填法改成 d 的填法，且不改其他原點。

**二點案。** 若 Q={u,z}，則 uz 是原邊。任一含 uz 的原三角形必為原面
（否則是分隔三環）；所以 u,z 恰有兩個共同鄰點 p,q，分別是 uz 兩側原面第三點。
u,z 各至少有四個外附件；其聯集六點、交集兩點，迫每點恰四附件，原度皆五。
兩個原 link 在 C 上給出

```
C=(p,a,b,q,c,d),  N(u)={z,p,a,b,q},  N(z)={u,q,c,d,p}.
```

每個核點都變色，故它的四個固定附件使用至多兩色。原長三路 p-a-b-q 迫這四點
交替兩色，且 p,q 異色；另一側 q-c-d-p 使用相同的兩色。因此全 C 交替兩色，
u,z 使用另外兩色，兩端恰互換。完整 O 的這個雙色分量正是 Q。
此 disk 的八個原三角面已填滿 C 的核側，無另藏固定島。

這兩案提供同一完整來源中的真交換，**並未迫出 B 三色**；交換的分量避開 B。
更大的六附件核沒有在此分類，也沒有證其兩種填法在固定 C 下 Kempe 連通。

## 4. 混合色態上的條件式有限逃逸引理

**當下單步準則。** 在一份完整 proper O 著色中，若 B 恰用四色，必有一個重複色及
三個 singleton 色。任兩個 singleton 色的框點若不在同一個當下實際雙色分量，
交換其中一個框點的分量便刪去該 singleton 色，使 B 恰用三色。
這只使用一份當下完整著色；所需兩點的失接不能用異時刻的路證明或否定。

選取 c,d 差異分量中任意 k 個上述一／二點六附件核。它們彼此無原邊，且每個核的
全部附件在 c,d 間固定。各自的缺色交換因而在任意混合態中仍為同一完整雙色分量。
這 k 次交換可任意次序進行，給出同一完整 Kempe 分量內的 2^k 份完整混合著色。
若其中一份混合著色滿足單步準則，至多 k+1 次合法交換即可使 B 三色。

故全封鎖假設額外要求：這 2^k 份完整混合著色中，每一對 singleton 框色都必在
當下完整雙色圖中連通。這比只核四個 H 軌道點的連通限制更強。
但尚未證六附件幾何及 H^4 閉合會迫任何一份混合態失接。

## 5. 第一次指定步失敗即給出同時刻的替代逃逸

每個指定交換前，框都是一個重複色 r 及三個 singleton 色 s,p,q。
指定色對為 {r,s}，根點是其中一個 r 框點；另一個 r 框點與 s 框點之間有 B 原邊。
這可直接逐步核原框字

```
ABACD, ABDCD, ABDCB, ACDCB, ACDAB.
```

因此，指定根分量若與 B 的交集不只根點，就必同時含另外兩個 r/s 框點。
在該分量內取根到第一次碰其他 B 點的簡單雙色路 P；P 內部避開 B。
P 的兩端與 p、q 兩個 singleton 框點沿 B 交替，無論先碰另一 r 還是 s 都成立。
刪 v 後的原嵌入是外界 B 的閉盤；Jordan 分隔迫任何 p–q 路都碰 P。
但 p/q 與 r/s 色集合互斥，同一份當下完整著色的兩條雙色路不能碰原點。
所以當下 p、q 框點必在不同完整雙色分量，交換其中一份便使 B 三色。

這給出可重播的有限逃逸：在第一次指定步失敗前保留所有成功交換，然後不做失敗的
指定交換，改做上述互補色對的一次完整分量交換。若失敗發生於第 m 個指定步，
逃逸只需 m 次真交換（含最後替代交換）；共同全域重標可藉後續色對共軛而只作記帳。
合法 n17 的第三輪第三步失敗，故自 c_2 起兩次成功指定交換加一次替代交換可逃逸。
直接從保存原 `exterior_edges` 及該步前完整色向量另作 BFS：AD 分量恰為
`{0,4}` 與 `{6,7,9,12,15,16}`；交換 `{0,4}` 後原有序 B 的字為 `DBDCB`，恰三色。
這個引理既不要求借用別時刻的路，也不需要 S5；它並沒有證真正四週期必發生失敗。
全封鎖四週期的二十步因此必全部通過指定單點交集測試。

## 6. 兩組差異的精確傳播式；不搬運分量

令 c_t=H^t(c)、c_4=c_0。定義 D^(0)=diff(c_0,c_2)、D^(1)=diff(c_1,c_3)。
在第 r 與 r+2 輪同步比較同一個子步，兩份當下完整著色記為 a,b，當步色對為 P，
從同一原框根點求得的兩個實際完整分量記為 K,L；τ 是 P 的交換。
令 J={x:a(x)∈P 且 b(x)∈P}。一步後的差異集滿足精確等式

```
diff(a',b') = diff(a,b) △ ((K △ L) ∩ J).
```

逐點證明：兩邊同換或同不換均保留相等性；只有一邊換時，若兩色都在 P 中則
相等與相異互換，若有一色不在 P 中則始終相異。共同全域正規化不改差異集。
因此完整五步把 D^(0) 變為 D^(1)，下一輪又把 D^(1) 變回 D^(0)。
這是差異集的傳播，不是 Q 的逐點搬運：K△L 可含原本固定的遠端原點，
差異分量可以分裂、合併或跨過原附件。兩組六環只分別在對應兩份著色間固定。

四輪閉合另要求全部原點、全部雙色分量及所有內／外接合在第 4 輪恢復第 0 輪；
兩輪前綴沒有此要求。端點色框相同、端點附件相同，甚至端點接口分割相同，
都不能取代完整色向量及中間二十次分量的閉合。

## 7. 完整接合與仍缺的橋

對每個固定原六環 C 及每一份當下完整著色，各色對在 C 上的有效接口點集由當下色決定。
分別計算 C 核側與 v 側的實際雙色分量，保存每個分量的全部 C 附件；
再把兩側分割及 C 的原雙色邊取 join，即得完整 O 的接口分割。
每側分割都服從原盤面的非交叉性；但 v 側分割可隨其他差異核、固定區換色及遠端重接改變。
兩輪比較中即使 C 色固定，v 側分割也未必固定。每次交換後均須重新計算。

仍缺的橋是：從全部這些實際接合、四輪精確閉合和 S34／S5，迫出某份可達完整態
的 singleton 框色失接，或迫出原固定五環剛性適用的位置矛盾。
三接口的非交叉分割本身沒有交錯四端點禁型，不能自行給所需矛盾。
沒有紙面根據把所有六附件核降為一／二點核；沒有理由預設全部差異分量均為六附件。

七附件以上、一般 P4、週期六以上、全封鎖分量存在性及原 Q5 都保持 OPEN。
逐點四輪詞、抽象接口分割或有限圖搜尋只是必要模型／有限證據；與原圖實現須分開。

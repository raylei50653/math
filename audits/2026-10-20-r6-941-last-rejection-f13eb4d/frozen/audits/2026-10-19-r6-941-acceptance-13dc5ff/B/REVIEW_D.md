# B 對 D 的獨立紙面幾何及介面審查

審查對象為 [D/PROOF](../D/PROOF.md)、[D/check.py](../D/check.py)
及其完整證書；來源仍是本輪凍結的同一完整原 G。未改寫 D 證據。

**結論：D 的原 c=5,q=6 排除、換框候選合法性及完成 k−1 成本通過。**

1. 原 c 是框點，鄰接 `(b,q,u,s,x)` 是有序 link 路徑，並非五圈。
   原完整五度 star 的四面是 bcq,cqu,cus,csx。u 是舊 D10 中 c 的第三
   鄰點；舊 induced C10 排除其他 rim 身份，原完整 b,x,y,r,p,h stars
   排除 cap 身份，故新核心私有 u 及簡單十圈成立。
2. 原 q=6 時已有六個互異鄰點 b,p,h,L,u,c，其旋轉路徑由 p,h,c 的面
   接成 `(b,p,h,L,u,c)`，所以 Lu 確是原邊，能將新 core 的 L=u
   完整 fibre 置零。沒有從假定著色另加一條圖邊。
3. 原 G−c 的實際外框是 `(x,y,a,b,q,u,s)`。沿其暴露外弧 b-q-u-s-x
   在外面加 bu、ux，兩弧內部不交叉，分別留下原三角化填片 bqu、usx，
   得新外框 `(x,y,a,b,u)`。這不需要不存在的 bx 邊。D 初稿將此寫成
   「五洞」，審查指出後已改為上述實際七框；候選圖本身沒有變。
4. bu、ux 原本皆不存在，亦直接由 b,x 完整 stars 排除。H 的所有點
   仍互異且沒有 loop；除刪 c 的 incident 邊外，其他原邊和私有點保留。
   G 的 k+5 點減一得到 k+4 點；五個新框點包含升框的原 u，所以內點
   恰 k−1。沒有接回成本或刪掉 u 後又免費補回的問題。
5. D 的原完整 cap 是逐個 c 色作不交聯集，c 不等 q,u,s，另由原左右
   集合保留 cb,cx。H 的 cap 刪 c，改以新增 bu、ux 的不等式接回。
   因此兩個完整矩陣使用同一新 core 的每份完整著色和全部 lifts。
   固定字面框已分別標為原 B 與新 B_H，沒有偷換列名。
6. 對所有132個 K masks 的枚舉只把候選拒絕列及原三拒絕置零，再使用
   任意大小真來源都受的交換必要 family。只用原 alpha 非空就排除130
   個 masks，因此不需要另拼出原其他六個正 fibre。剩下1022/1023均在
   K132，D 的結論限於同一 H 後九列正，不構成較小 bad。

B 未重新枚舉 D 的全部132份比較；這部分由 D 正常／seed17 精確重播與
本輪獨立 C 審查承擔。B 的交叉審查覆蓋指定原星、別名、實際弧、完整
接回、同一來源及成本；沒有宣稱來源可實現或一般主目標完成。

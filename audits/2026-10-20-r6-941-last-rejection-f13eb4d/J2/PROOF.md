## 1. 同一圖、同一字面 fibre 的精確分解

假設 `a2=N01232(Q2)=0`。凍結的 [J2 定理](../frozen/audits/2026-10-19-r6-941-existence-f13eb4d/C/PROOF.md)
已給同一合法較小圖

```
J2=(G-{p,h})+{aL,aR,bL},  完成 k−2,  Sigma(J2)=943。
```

令 `F=G-{b,p,h,x,y,r}`，同一實際有序 induced rim 為
`(a,n,R,L,q,c,s,v,w,t)`。每份 F 著色均含它的全部私有點；以下不換 F。
固定 J2 拒絕字面框 `01021`，即

```
x=0,y=1,a=0,b=2,c=1。
```

則其任意完整著色都必有

```
n=1,  {v,w}={0,1},  s=t=d in {2,3},  r=5−d，
```

左側恰只可能以下三族：

| 族 | (R,L,q) | d 的選擇 | (v,w) 的選擇 |
| --- | --- | --- | --- |
| I | (3,1,3) | 2、3 | (0,1)、(1,0) |
| II | (2,1,3) | 2、3 | (0,1)、(1,0) |
| III | (2,3,0) | 2、3 | (0,1)、(1,0) |

每列四型，總共十二個固定字面 F fibre；同一型的 cap `(b,x,y,r)`
唯一，沒有任何新的內點色要選。因此限制與接回互逆，給出完整著色雙射。
記 `Z_u` 為同一 F 在固定字面 `u` 上的完整延拓數，包含可能的零值，則

```
N01021(J2) = sum_{十二個 u} Z_u。
```

若以 frozen 的 restricted-growth C10 代表計數，各係數仍是1，index為
`1631,1638,1652,1659,1813,1820,1834,1841,1935,1942,1956,1963`。
色置換作用於整份著色，不把整個 S4 軌道的基數乘到 Z 上。

排除其餘型的證明是任意大小的完整分量零閉包：由原 G 三個零列、
`a2=0` 與 J2=943 的零列起始，每一輪只用上一輪已證空 fibre。
`check.py` 重建2461個 C10代表、7382個 H軌道及10798個交換 columns，
逐格重做閉包並與 frozen C 比較的 live set相同，剩1973格。
這1973格中恰十二格能接 J2 的01021，逐份完整 literal cap係數皆1。
閉包適用於全部真實 F 著色及全部私有點；沒有要求 live格實際非空。

全部十二型的原 `Left(F)` 都是空集，甚至換 b,p,h 色也不能接回原G。
I、II中 a,n,q 三色0,1,3及 c=1迫 b=2，原p被四鄰色全阻；III中
b=2或3時p被迫為另一色，而h的四個其餘鄰點又全阻。這是精確的
原 cap 障礙，不能因某個 F fibre 不延拓 G 就宣告它在 F 中為零。

## 2. 在同一完整著色中的唯一分量型

對每份上述完整著色，同時記兩個互補二色誘導圖的實際連通分量與
C10的交集。凍結的三角化分量定理保證：分割 noncrossing、同側
相鄰框點在同一塊、框上有2m次 side轉換時接框塊數恰m+1。
每個分量包含其全部私有點。交換任一組完整分量所得的全部邊界型，
必都留在已證可能的1973格中；任一落入已證空格的分割不可能實際發生。

`check.py` 直接枚舉全部 noncrossing 分割，保留上述三條，再逐份檢查
全部分量交換結果，包含重複 canonical型的重數。這不是選一條有利路徑。
對每份十二型及三個互補色對，所有未排除分割完整保存在證書。
每族每份型的三色對 `(01|23,02|13,03|12)` 分割數分別是

```
I: (7,2,2),  II: (7,3,1),  III: (2,1,3)。
```

因此族II的 `03|12`、族III的 `02|13` 分割各自唯一。令 z0、z1
分別是 v,w 中色0、色1者。下面每組大括號是同一實際分量與框的
**完整交集**，未列出的私有點仍屬該分量，不是假設只有這些點。

| 族與 d | 第一色對側 | 互補色對側 |
| --- | --- | --- |
| II,d=2，03側/12側 | `{a}`, `{q,z0}` | `{n,R,L,t}`再含與t相鄰的z1（若w=z1）；`{c,s}`再含與s相鄰的z1（若v=z1） |
| II,d=3，03側/12側 | `{a,t}`再含w（若w=z0）；`{q,s}`再含v（若v=z0） | `{n,R,L,z1}`, `{c}` |
| III,d=2，02側/13側 | `{a,t}`再含w（若w=z0）；`{R,s}`再含v（若v=z0）；`{q}` | `{n,z1}`, `{L,c}` |
| III,d=3，02側/13側 | `{a}`, `{R,z0}`, `{q}` | `{n,t}`再含w（若w=z1）；`{L,c,s}`再含v（若v=z1） |

例如族III中，**L與c必在同一個13分量**，而q所在02分量的接框交集
恰`{q}`。族II中，d=2時a所在03分量接框僅`{a}`；d=3時c所在12
分量接框僅`{c}`。這些分量可以整個交換，但不能只交換邊界接點。
表中的多條連接與分離同時屬於一份完整著色，沒有跨著色拼接。
不同互補色對的必要列表亦不宣稱能自由組合或已有共同來源實現。

## 3. 停止點與重播

上表的強制路徑沒有長度上界。原 induced C10及短圈定理給其若干
短路分支限制，但目前沒有從這些必要路徑推得矛盾；不能將原C5的
單W5例外省略，也不能將長二色路徑當成短圈。

由凍結的同一 J2支持943，`N01021(J2)>0` 在假定真來源中必成立，
故十二個完整 fibre至少有一個非空。尚需排除這十二項的聯集，才能
與同一 J2的接受正性完成嚴格縮減。這裡沒有取得該排除，也沒有
取得來源圖實現、原Q選擇存在性、一般K∞或新Lean定理。

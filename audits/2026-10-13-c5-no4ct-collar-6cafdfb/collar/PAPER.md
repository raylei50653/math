## 2. 原圖中的實際 collar

令 `t_i=d(b_i)−4≥0`，`h=Σ_i t_i`，並令 `a_i` 是框邊
`b_i b_(i+1)` 的內側三角面 apex。無 crosscut 使每個內點至多接一對相鄰框點。
若某內點同時接 `b_i,b_(i+1)` 而不是 `a_i`，三環
`b_i b_(i+1) v` 的內側包住原三角面 apex，形成分離三角形，矛盾。
因此五個 apices 互異；除 apices 外，每個接框內點只接唯一一個原框點。

按 b_i 的實際 rotation，內鄰點依序為
`a_(i−1), y_(i,1), …, y_(i,t_i), a_i`。各點互異且不同 fan 的 y 互異。
內面三角迫連續鄰點間都有原邊。五串合成具名簡單環，固定順序為

```
a0, y_(1,*), a1, y_(2,*), a2, y_(3,*), a3, y_(4,*), a4, y_(0,*).
```

每一環帶三角形都是原圖的實際面；其餘圖位於內圈內側，形成同一 C_(5+h)
disk H，允許 chords 及任意內點數。證書保存所有具名 attachments、原環帶
邊、面、内外頂點序；没有交換不同 t 的內側來源或另選接點。

## 3. 完整欄、同框 fibres 與必要 Kempe 固定點

在上面固定順序取全部 proper 內圈四色軌道 p。固定 p 的一份具名字面代表，
枚舉外框全部 240 個 proper 字面指派 b，保留滿足所有實際環帶邊的指派。

令 S 為同一實際 H 的完整關係。逐份全圖著色限制與逐頂點接回給精確等式

```

```

空欄與空 fibres 亦保留。證書的每個 joint lift 都按「五個原框點＋具名內圈」
記錄完整 annulus 著色；內側來源未被構造，因此沒有捏造 H 的内部 full lifts。
這些 annulus lifts 與同一 H 的相符内圈著色可逐點接合。

固定目標 R，設 `A0={p : C_t(p)⊆R}`，其中也含完整空欄。精確等式给 `S⊆A0`。
對各 p 的三組互補色對，枚舉全部 noncrossing 分量邊界 partitions：
同一色對的相鄰框端點必同分量；交換任意分量子集所得全部列構成一個 orbit。
若某 split 沒有任何完整 orbit 包含於目前 A，刪除 p，直到固定點 A∞。

Soundness：若 `S⊆A_r`，任取 `p∈S` 的一份 H 完整著色，其實際分量
partition 就是候選之一，所有分量交換仍是同一 H 的著色，故完整 orbit
包含於 `S⊆A_r`。p 不會被刪，歸納得 `S⊆A∞`。不同 splits 的抽象
partitions 不需被假定可同時實現；它們只給必要上界。
若存活欄聯集缺少 R 的一列，精確 transfer 立即矛盾。

## 5. C7：精確 transfer=941 的無四色定理矛盾

唯一必要殘留為 `t=(0,0,1,0,1)`，具名內圈
`(a0,a1,y_(2,1),a2,a3,y_(4,1),a4)`。這是舊 C7 證書中
`(a0,a1,y2,a2,a3,y4,a4)` 的原順序；y 的下標僅補明唯一索引，未旋轉或重標。
91 個 proper 色軌道中，必要上界 U 有 55 列，整數 mask 為
`755425272170557940120206052`。checker 重播原完整證書並逐項核對此 U。

對同一實際 H，令 `x_p` 為固定具名字面 p 的完整四色延伸數。逐邊不等
指示函數作 inclusion–exclusion，得

```
x_p = sum_{F⊆E(H)} (-1)^|F| 4^k0(F) E_{π(F)}(p).
```

其中 π(F) 是 (V(H),F) 分量在具名邊界誘導的 partition；`k0(F)` 是不接
邊界的分量數。不同分量連接交錯邊界端點會違反 disk 平面分離，故 π(F)
noncrossing。`E_π(p)=1` 當且僅當 p 在 π 的每個 block 上常值。
因此同一 H 的全部 x 座標在 429 個 noncrossing equality vectors 的共同
線性 span 內。沒有假定展開係數非負；非負的是實際延伸數 x。

凍結 checker 枚舉全部 429 個 partitions（其中 36 欄在 proper C7 列非零），
以 Fraction 推導七份恆等式，再逐一對全部 429 欄檢查零 residual。
全 rank=36、U 外列 rank=31 僅作診斷；證明使用逐欄完全相等。
`S⊆U` 使所有 RHS 的 U 外座標為零，三份身份給

```
x_6 + x_35 = 0,
x_58 - x_6 = 0,
x_89 - x_6 = 0.
```

由 x≥0，`x_6=x_35=x_58=x_89=0`。四列按固定原序為
`0101212,0120131,0121202,0123231`。完整原環帶欄核對：U 中可接到
外列 `01232` 的全部內列索引恰為 `[6,58,89]`。它們全部計數為零，
而 941 接受 `01232`，故精確 `transfer(S)=941` 不可能。
這適用任意大小 H，也適用 H 完全無著色的情形（此時本來就不能 transfer 成 941）。
整段沒有使用四色定理、外側 fan cap 或普遍來源可染性。

必須區分更強命題：**「不存在任何 C7 disk H 使 Σ(H)⊆U」**。
舊證明利用某個 fan cap 與 U 只交一列，再用 4CT 保證黏合圖可染，
迫該列接受。本包沒有採用這一步，亦沒有證明該更強命題的 no4ct 版本。
凍結 count 證書中的舊 `target_source_status` 文字表示計數的普遍條件式排除；
本輪實際目標來源仍是 `not triggered`，沒有構造任何 932／933／941 圖。

## 6. 推論與保持 OPEN 的邊界

三支目標均不可能有 h≤2，故 h≥3。既有內點最小度五與 near-triangulation
的 Euler 等式給

```
n5 = 6 + h + sum_{v interior, d(v)≥7}(d(v)−6) ≥ 9.
```

這只提升最小目錄外來源的結構必要條件。無界 932（其排除含 4CT 難度）、
無界 933／941、一般 `K∞=K≤5` 仍 OPEN。已有無4CT前提的 `K≤15=K≤5`
直接球面證明保持有效。未重證 C8 的八項來源分類，沒有推進 C8 或增加 k 下界。
紙面拓撲、有限必要運算、實際來源與 Lean 分開：本包沒有新增 Lean 定理。

## 2. 紙面核對與所有大小条件

本輪採用前輪給出的 `k≥16`、非空及 T4 全收、chordless 原 C5、二連通
近三角正規形、邊界度數至少四及內點度數至少五。不重新證明前輪的
Corollary 20、球面生成或有限 K witnesses；其信任界線沿用兩份 no4ct 報告。

對二邊 crosscut `b2–v–b4`，短側框為 `(b2,b3,b4,v)`，長側框為
`(b4,b0,b1,b2,v)`。兩側私有內點 s,t 與原內點數的正確等式是

```
k = s + t + 1,  s,t >= 0,  s < k,  t < k.
```

唯一被提升成框點的原內點是 v；不能混入四度例外中的 `+3`。
短 C4 增廣 dummy 後的內點仍是 s，因此其完整關係屬七項 L4；長 C5
直接由 t<k 進入 K。這足以替換原普遍 C4 screen，無須任意大小 C4 定理。
兩片的交集恰為切線三頂點與兩邊，原圖其他邊不能跨越切線。
完整接合必使用同一個 v 實際色值；固定 924 項接合全落 K 便給矛盾。
另一個合法佐證是代表替換後 `k'≤3+5+1=9<k`，但有限接合證明本身
不需要消費这个九內點界。

無分離三角形的証明只需原圖已可染：固定原 G 的一份完整染色，把其
內側限制作一次全域換色，便能接到任意剩餘圖的 proper 三角形指派。
刪 r≥1 個嚴格內點維持完整原框關係且有 `k'=k-r<k`。三角形嚴格
內部沒有原外框點，故刪除仍為合法原 C5 disk。932 完全符合此論證。

對原框邊的五個面 apex，相等會造成同一內點接至少三框點，因而違反
crosscut 排除；其他同接某框邊兩端的內點會包住原面 apex，違反無分離
三角形。因此每個邊界內側 link 的中間點只接該單一框點，五條 link
除了指定端點外完全不交。簡單圖的 rotation 保證單一 link 也無重複點。
這得到原圖中的簡單環，並非只得到一條可能自接觸的閉步道。

環外全部扇面都是原 G 的實際三角面；無法再容納未列頂點或邊。因此
所有剩餘圖確實在環內，完整 transfer 公式成立。若內側私有內點為 m，

```
|C| = 5 + h,  k = 5 + h + m,  m >= 0.
```

這項大小只是結構計數；不據此把任意 C6/C7 disk 分類成 K。

## 3. 完整 transfer 與 Kempe 的普遍性

對同一內側 H 的完整關係 S，每個具名內列 q 的外圈欄 C(q) 保留原支持
接邊與同一四色框；限制與黏合逐列給 `Σ(G)=⋃_(q∈S) C(q)`。
若目標是 R，必有 `S⊆{q:C(q)⊆R}`，包含空欄在內。

對真實 q 的任一完整延伸及任一互補色對，其實際邊界分量都是 checker
列舉的 noncrossing partition，且每個交換軌道都留在同一 H 的 S 內。
所以刪除無完整軌道的列永不刪掉真實 S。這個 soundness 不需來源大小界、
4CT、P 非空或普遍外側 screen，也不要求不同 splits 的抽象 partitions
能同時實現。固定點欄聯集缺 R 的任一必收列即可反證 exact transfer。

獨立重算確定：21 份 932 查詢的固定點全空；933 的 21 項及 941 的
20 項也被排除。唯一殘留仍是 941、`t=(0,0,1,0,1)` 與具名 C7 上界 U。
因此不存在把 933 某個 singleton 接受條件偷用到 932 的量詞問題。

## 4. C7 的可用結論精確到哪裡

同一 H 的 literal 邊界延伸數 x(p) 經逐邊 inclusion–exclusion 滿足

```
x(p) = sum_(F subset E(H)) (-1)^|F| 4^k0(F) E_pi(F)(p).
```

pi(F) 由同一 disk 圖的分量決定，因此 noncrossing；E 只要求同一分量
內同色，不要求不同分量異色。係數無非負性假設，真實 x(p) 才非負。
固定代表的計數不用 S4 軌道大小係數。這些細節均與凍結 COUNT_PROOF 相符。

全部 429 partitions 的精確恆等式且 U 外坐標為零，給
`x6+x35=0, x58=x6, x89=x6`。非負性令 indices `6,58,89` 都為零，
而它們恰是 U 中能透過原 collar 產生必收 `01232` 的全部內列。
故 exact transfer=941 不可能。此為無界 H 的紙面結論，沒有枚舉 H。

空關係的零向量也滿足上述等式，因此**不據此證明任意 `Σ(H)⊆U`
的 C7 disk 不存在**。舊較強敘述的 fan-cap＋4CT 不在本輪依賴中。

## 6. Euler、交付與停止點

三支 h≤2 均已排除，故 h≥3。`|E|=3k+7` 導出
`Σ_(V\B)(6-d)+Σ_B(4-d)=6`；由內點最小度五及邊界超額 h，恰得

```
n5 = 6 + h + sum_(v interior, d(v)>=7)(d(v)-6) >= 9.
```

已覆核總報告的結論與依賴表，未見越出上述契約的數學宣稱。
此輪沒有提高 `k≥16`，沒有證任意非最小來源的同一度數限制，也沒有
完成新三支的 C8 分類。舊 C8 cofacial quotient 的可染性依據、小 cap
的確切大小與 932 的 h=3 清單，都仍待逐項接入；不能沿用舊八项作完整
殘留表或引用其 `h=3⇒k≥19`。

最終接受範圍：本輪三支最小來源的 crosscut／簡單內圈／h≥3／n5≥9。
無界 932／933／941、一般主命題與新論證 Lean 形式化仍 OPEN。

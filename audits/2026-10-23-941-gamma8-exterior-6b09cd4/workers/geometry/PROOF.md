# Γ8 二內點：至少四個同源圈外私有點

沿用 `audits/2026-10-23-941-gamma8-cells-6b09cd4/PROOF.md` 的全部來源
合同、同一 Γ8、同一 φ／ψ、完整 J／H 分量及十一個必要型。這裡只加
`j=2`，不假定任何 Γ 上點五度，也不假定全局恰兩個真交。

## 圈內私有共鄰隔開圈外共鄰

若兩個非鄰接 Γ 頂點 p、q 有一個嚴格圈內原共鄰 t，則 p、q 沒有嚴格
圈外原共鄰 v。否則原四圈 p–t–q–v 的對角 p q 是原非邊，而 t v 跨越
原 Jordan 圈 Γ，亦是原非邊；這撞原 C4 有界側空且三角化。
本輪只對 t=τ 或 ζ 使用此引理，沒有改任何 rotation 或附件。

特別全部十一型都有：r、s 無圈外共鄰（共 τ）；x、d 無圈外共鄰（共 ζ）。
L 型另有 T、x 無圈外共鄰（共 τ）；R 型另有 T、d 無圈外共鄰（共 τ）。
所有其他由 τ／ζ 給出的禁共鄰對列於 `barriers.json`，只屬同一原圖的
圈外附件限制，並不排任何一型。

## 四條外側實際面的第三點

在原邊 d r、r T、T s、s x 的 Γ 外側實際三角面，依次記其第三點為

`u、a、b、c`。

r、T、s 已是 rootless 私有點；x∈K\C，且 K 的唯一框接點是 U∈C，故
x 亦私有。因此這四面及第三點都在原 F，且第三點嚴格在 Γ 外：Γ 的
完整誘導圖與內側面已固定，不存在可作外側第三點的另一本圈頂點。
由完整分量身份，

`u,c ∈ K2 ∪ N3，a,b ∈ M2 ∪ N3`。

K 的唯一框接點原色為 0，而 N、M 都 rootless，所以 u、a、b、c 全部是
F 私有點。由 r、s 無圈外共鄰，四點只可能有兩種相等：u=a 或 b=c；
這兩種相等都必是原色 3 的 N 點（M≠K）。

L 型 s 的 Γ 閉盤內鄰點恰 T、τ、x。若 b=c，完整 cyclic link 的外側
僅一點 b，則 s 的原度數為 4，故 b≠c。R 型 r 同理排 u=a。O 型兩者
皆排，因此 O 型已迫四個不同圈外私有點。

## L／R 的三點假設亦矛盾

假定 Γ 外最多只有三個私有點。

L 型必有 u=a，且圈外私有點恰 a、b、c。a 為 N3；由 T、x 無圈外共鄰，
c 不是 T 的鄰點。T 的原全星全部 rootless 私有，故 T 的外側 link 必
恰為 r–a–b–s，於是 a b 是原邊，b 為 M2。

s 的每個原鄰點亦私有：原色 3 鄰點屬 rootless N；原 02 鄰點若不在 K，
就在 J−K 的同一 rootless 支；若在 K，只有 U 可能在框上，但 s∈E 與
U∈C 不可鄰接。a 不能鄰 s（否則是 r、s 的圈外共鄰），所以 s 的外側
link 恰 T–b–c–x，迫 b c 是原邊，c 為 N3。

R 型必有 b=c∈N3。由 T、d 無圈外共鄰，u 不是 T 鄰點；T 全星私有，
故其外側 link 恰 r–a–b–s，迫 a 為 M2。

現在兩型在 x 的外側 link 都由 s 先走到 c∈N3，再朝 h∈B1 走。c 不可
直接鄰 h，因 N≠B；所以 c 後面必有另一原鄰點 w，且 w 是原色 1 或 2。
若 w 是原色 1，c w 使 w∈N，故私有；若 w 是原色 2，x w 使 w∈K2，
亦私有。這個 w 也嚴格在 Γ 外。

L 型 w 不能是 a 或 b，因二者鄰 T 而 T、x 無圈外共鄰。R 型 w 不能是 u
（u 鄰 d，而 x、d 無圈外共鄰），也不能是 a（a∈M2 而 x∈K0）。兩型
都已有 c≠w，所以 w 是第四個圈外私有點，矛盾。

**結論。** 十一個 j=2 必要型各迫至少四個不同的 Γ 外原 F 私有點；連同
τ、ζ，至少六個原私有點不在 Γ 上。r、T、s、x 亦私有，所以這份共同
骨架至少涉及十個不同原私有點。沒有把圈外 patch-k2 或指定 Z 再重複
計數，沒有提高既有全局 k≥23，也未聲稱此下界 sharp。

這仍是外側原 stars 的必要負擔，沒有接完固定 B14、初始八配對或完整
941 來源；十一型與一般 wrong-side 均未排。

## O 型一律五點：不用預定框附件

對 O 型，若 Γ 外只有四個私有點，它們必恰為上述不同的 u、a、b、c。
T、d 及 T、x 都各共圈內 τ，所以 u、c 都不能鄰 T。T 全星私有迫其外側
link 恰 r–a–b–s。s 全星私有且 r、s 無圈外共鄰，迫其外側 link 恰
T–b–c–x。因此 a b、b c 均為原邊。

若 c∈N3，x 外側 link 在 c 後的下一點 w∈N1∪K2 如前必私有；w 不能
是 u（x、d 共圈內 ζ），亦不能是 a、b（T、x 共圈內 τ），迫第五點。
所以 c∈K2，進而 b∈N3、a∈M2。四點中只有 a 可能在 M2，而原邊 r a
使 a∈C。

接著考慮 r 的外側完整 link。r 的原色 3 鄰點全在 rootless N；原 02
鄰點不是在 K，就是在 J−K 的同一 rootless 支。K 的唯一框接點是 U0，
故 r 的所有鄰點除可能的 U 外皆私有。b、c 都鄰 s，因此不能鄰 r；所以
r 的外側 link 從 u 到 a 中間，至多能再用框點 U。如果 u∈K2，u 與
a∈M2 同色非邊，而插入 U∈K0 仍不能接 a∈M2。因此 u 必在 N3。

現在在原 G 的完整 cyclic link(d)，由 r 沿 Γ 外側走到 u，再朝 e 走。
d 若是 F 私有點，原全星在 F；若 d=U，U 仍是本普通短型I合同的原 G
內點，所以仍可使用**原 G** 的 cyclic link，沒有把 F 的框 link 當 cyclic
link。u∈N3 不可直接接 e∈B1，因此 u 後面必有另一 link 點 w，其原色
為 1 或 2。原邊 u w 及 d w 分別迫 w∈N1 或 K2，兩者均私有；而 u
本來就是 F 私有點、保全部原 G star，所以這個 w 必仍在 F，沒有漏到
F 外的原附件。它嚴格位於 Γ 外側。

w 不能是 a（a∈M2 與 d∈K0 不可鄰），不能是 b（b 原色3），不能是 c
（c 鄰 x，而 x、d 共圈內 ζ，沒有圈外共鄰），亦不同於 u。這迫第五個
Γ 外私有點，矛盾。

**收緊。** 全部 O 型一律至少五個 Γ 外原 F 私有點，L／R 型至少四個。
這不需要 d／e／h／W* 有任何框身份，也不需要指定 T 或 r 五度；四點
反證過程才迫其最低 link。

## 與 M2 separator 的安全合用

`../b14/FINDINGS.md` 的 M-flip separator（已在本目錄 `REVIEW.md` 獨立
核對）給：若 d=U 或 e∈{V,Y}，完整原 E 中的 s–x–h 到 E 的框接點之
每條 ψ12 路均經 M2。若 Γ 的完整 E 本身碰框（等於 c 的框分量 D），
才可再推出 M2∩E 非空；E 可能 rootless，不能省掉此條件。j=2 時全部
M2 點均嚴格在 Γ 外。若 h=c，因 C 必碰框，對稱地必需 Γ 外的 M2∩C
非空。

上述 O 四點假設只提供一個 M2∩C 點 a，沒有 M2∩E 點，所以 d=U 或
e∈{V,Y}、且 E 碰框時，separator 也能獨立給第五點。這個條件推論被一般 O 五點
界涵蓋，但指出完整 M2 的圈外側別義務；不能把 h=c 的 C-side 義務誤作
另一個自動新增點。

所有推論只用已證必要條件；沒有宣稱下界可實現，也未排掉任何 O 型。

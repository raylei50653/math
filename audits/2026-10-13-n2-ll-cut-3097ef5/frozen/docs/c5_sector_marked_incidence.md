## 1. 單步介面與安全刪減引理

沿用前報告的一般圖前提：proper 四色染色 c，單一 maximal a/b 分量
S，以及第三色 d。對每個有序混合色對 (a,d)，從舊 c、S 建構二部圖 Q：

- retained 節點表示 H=G[(A\S)∪D] 的一個分量，只保存節點 ID 及其中
  框點的標記，不保存分量內頂點、邊或染色。
- star 節點表示一個 x∈B∩S，保存原頂點 ID 及框標記。鄰接只記它碰到
  哪些 retained 分量；同一分量的多條實際邊合為單一 incidence。

star 的原頂點 ID 在四個介面共用，不因混合色對不同而重新命名。
retained ID 只在各介面內有效，不能把不同混合色對的同號節點視為
相同頂點。四份介面都由同一份 c、S 抽取；此資料格式本身不保證
任意四份外來介面可共同實現。

稱至少帶一個框標記的節點為 terminal。定義 Q*：

1. 刪去完全沒有 terminal 的連通分量。
2. 反覆刪去沒有框標記、目前度數至多一的節點，直到無法再刪。

**引理。** Q* 與 Q 在全部框標記上的連通分割相同，因此 Q* 精確
決定此步新 a/d 框分割。連同未變的 a/b、互補色對及共同色重標，
四份 Q* 精確決定完整六色對的後繼 profile。

**證明。** 第一步刪去的分量沒有任何被查詢的框點。第二步中，
無標記的度 0 點不在任何框點路徑上；度 1 點不可能是兩 terminal
間簡單路徑的內點，也不是其端點。因此每一步保持全部 terminal
間連通性。原有框標記沒有被刪去，終止後分割仍相同。前報告已證
新混合誘導圖與 Q 的框分割相同。將四份結果以同一色置換重標即得
完整後繼。此證明不使用 planarity、degree 或 3903 假設。

這只是一次查詢的介面；Q* 不保證保存下一次交換需要的 retained
分割。不是資訊最小性、共同圖可實現性或多步充分狀態定理。

這兩條刪減規則也**不給一般大小上界**。例如一條任意長、交替 b/d
的路徑，兩端標記為框點，再加舊色 a 的點連到所有 b 點。全部 b 點
與該 a 點構成單一 maximal a/b 分量；交換後的 a/d quotient 正是
原長路徑。所有內部節點無標記但度數為二，兩條規則都不能刪。
這是一般圖引理的紙面例子，不是 3903 或 disk 控制，也未新增搜尋圖。

## 3. 不能刪光無框節點

兩種過強投影分別在 5,928 及 1,936 份混合介面上改變框分割。
計數是失敗的介面實例，兩類可能重疊，不表示互異圖數。

**刪光無框 stars 失敗。** 圖 41、c0、move 7，交換 1/2 分量 {4,6}，
考慮新 1/0。retained 框標記為 {0} 及 {1,2,3}；無框 star 6 同時
連到兩者。正確結果為 {0,1,2,3}。刪掉 star 6 後變成
{0}|{1,2,3}。安全規則保留這個度 2 star。

**刪光無框 retained 節點失敗。** 圖 41、c1、move 0，交換 0/1 分量
{0,1,2,3,6}，考慮新 1/3。無框 retained r1 同時連到帶框 stars 0、3；
另一無框 r0 只連 star 1。正確結果是 {0,3}|{1}。安全規則只刪 r0；
若連 r1 也刪，誤得 {0}|{1}|{3}。完整圖邊、染色、交換與 Q 均已保存。

這些一般圖控制仍非平面，不能當成 disk 反例。其用途是排除未附加
其他前提的過強資訊省略規則。

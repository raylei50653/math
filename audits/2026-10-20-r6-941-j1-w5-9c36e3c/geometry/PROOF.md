# 原 W5 七框：唯一可能外弦、精確度數二分與完整接觸

固定本輪 BASE 及同一來源 G，完整承接凍結的
[SOURCE_CONTRACT](../frozen/audits/2026-10-20-r6-941-fibre-continuation-9c36e3c/SOURCE_CONTRACT.md)
與其全部上游。原有序 C5 框仍是 `(x,y,a,b,c)`，原支持恰941，
全域最小內點數再最大邊數；所有原附件、完整 stars、旋轉、私有點與
原 C3/C4/C5 pocket 定理保留，不加 active-f 假設，不使用四色定理。

本頁只處理 `a1=N01232(Q1)=0` 的 J1 原 W5 三邊路子支。其原片已由
[凍結 geometry 證明](../frozen/audits/2026-10-20-r6-941-fibre-continuation-9c36e3c/geometry/PROOF.md)
確定：有序七框

```
(a,b,q,L,u1,u2,n)
```

內部恰為原 `p,h,R`，十一個原面是

```
abp,bpq,pqh,phn,pna,hqL,hLR,hRn,Rnu2,Ru2u1,Ru1L.
```

原 p,h,R 都完整五度，內部圖為路 `p-h-R`。所有剩餘私有點、附件均在
此閉 disk 之外。本頁不把殘餘 F 著色當作 G 著色，不假定它可延拓。

## 1. 七框只可能有原外弦 a-u2

原 ab 是原 C5 外框的邊。若七框兩個非相鄰點另有原邊 e，此邊必在
上述十一面原 disk 的外側。取下表原路徑 P，則 `P+e` 是原 G 的簡單
閉圈。沿十一面 disk 的面 dual，刪去 P 穿過的 dual 邊；不接原面 abp
的那一側，必在此圈的有界側。理由是另一側接原外框邊 ab，不能被
G 中的閉圈包在嚴格內部。這同時固定了有界側，沒有把任意外路或任意
嵌入當成原路。

下表「內部至少含」只列十一面原 disk 已經強迫在有界側的點；圈外
補區若還有其他原點，只會增加其內部點數。

| 假設原外弦 | 原路 P | 圈長 | 內部至少含 | 結論 |
| --- | --- | ---: | --- | --- |
| a-q | a-p-q | 3 | L,R,h,n,u1,u2 | 原 C3 非空，禁止 |
| a-L | a-p-h-L | 4 | R,n,u1,u2 | 原 C4 非空，禁止 |
| a-u1 | a-p-h-R-u1 | 5 | n,u2 | 原 C5 多於一內點，禁止 |
| a-u2 | a-p-h-R-u2 | 5 | n | 只可能是以 n 為中心的單 W5 |
| b-L | b-p-h-L | 4 | q | 原 C4 非空，禁止 |
| b-u1 | b-p-h-R-u1 | 5 | L,q | 原 C5 多於一內點，禁止 |
| b-u2 | b-p-h-R-u2 | 5 | L,q,u1 | 原 C5 多於一內點，禁止 |
| b-n | b-p-n | 3 | L,R,h,q,u1,u2 | 原 C3 非空，禁止 |
| q-u1 | q-h-R-u1 | 4 | L | 原 C4 非空，禁止 |
| q-u2 | q-h-R-u2 | 4 | L,u1 | 原 C4 非空，禁止 |
| q-n | q-p-n | 3 | L,R,h,u1,u2 | 原 C3 非空，禁止 |
| L-u2 | L-R-u2 | 3 | u1 | 原 C3 非空，禁止 |
| L-n | L-h-n | 3 | R,u1,u2 | 原 C3 非空，禁止 |
| u1-n | u1-R-n | 3 | u2 | 原 C3 非空，禁止 |

這是全部十四對非相鄰七框點，沒有遺漏新私有點 u1,u2 的識別風險。
尤其未另加 `d(n)>=6` 時，不能稱此原七框為 induced，也不能直接識別
a=u2 而宣稱商圖一定沒有原 loop。

## 2. 原圖的精確二分

若原邊 a-u2 存在，原 C5 `a-p-h-R-u2-a` 的有界側含 n。原 C5 pocket
定理迫其唯一內點恰為 n，並給完整原 star

```
d_G(n)=5,  N_G(n)=(a,p,h,R,u2)
```

（允許整體反轉旋轉）。原面 a-n-u2 因而確實存在，不另含任何原點。
合併這一個原面與原十一面得到 induced 原六框

```
(a,b,q,L,u1,u2),  內部恰 (p,h,R,n).
```

其十二面已完全列出；內部原圖的邊為 `ph,pn,hn,hR,Rn`，四個內點都
完整五度。此為一個明列的四點 diamond 原片；本頁不藉其名稱引用任何
一般可約性結論。

反過來若 `d_G(n)=5`，原 n 已有五個不同鄰點 a,p,h,R,u2，故完整 link
恰是以上次序。原圖內三角化迫 link 的最後兩點 u2,a 相鄰。因此

```
a-u2 存在  <=>  d_G(n)=5.
```

若 a-u2 不存在，原 n 的度數至少六，且 §1 已排除其餘十三條原外弦，
原七框因此 induced。原片只有這兩個幾何子型；僅用本節幾何尚未排除它們。
後續同源縮減排除n=5，見§5；單W5或四點diamond的定位本身不提供較小bad。

凍結來源另有 `n=5 => a>=7`；這與上述單 W5 相容，不能當成 n=5 的
矛盾。若取原完整 d_a 接受著色，`a=h=0,b=n=L=1,q=2,p=R=3`，則
一般 W5 只給 `{u1,u2}={0,2}`。在 n=5 子型，原邊 a-u2 再迫
`u1=0,u2=2`，所以六框字面恰為 `(0,1,2,1,0,2)`。這只針對原完整
d_a 著色；沒有把另一份殘餘 J1 著色的顏色移入其中。

## 3. 展開 C11 的完整接觸，只剩五條可能原弦

仍用原完整 F 的 induced 十框 `(a,n,R,L,q,c,s,v,w,t)`。u1,u2 是原 F
的私有點；其完整舊框接觸 S(u1),S(u2) 受凍結
[chains/B 原接觸 envelope](../frozen/audits/2026-10-20-r6-941-fibre-continuation-9c36e3c/frozen/audits/2026-10-20-r6-941-last-rejection-f13eb4d/frozen/audits/2026-10-19-r6-941-existence-f13eb4d/frozen/audits/2026-10-19-r6-941-chains-13dc5ff/B/PROOF.md)
約束。該必要 envelope 完整保留空集與所有私有點，沒有假設存活集可實現。

原完整 R star 先給 `{R,L}⊆S(u1)` 與 `{n,R}⊆S(u2)`。§1 的禁止
原弦排除 u1 接 a,n,q 以及 u2 接 q,L。凍結來源的原圖距離界
`dist_G(t,R)>=3` 迫 t 不接 u1,u2；`dist_G(L,s)>=3` 迫 s 不接 u1。
把這些**同一點的完整接觸**限制施於凍結必要 envelope，精確得到

```
S(u1) ∈ { {R,L}, {R,L,v}, {R,L,w}, {R,L,v,w} },
S(u2) ∈ { {n,R}, {a,n,R}, {n,R,s}, {n,R,v}, {n,R,s,v} }.
```

特別是 c 不能接 u1 或 u2，w 不能接 u2。故在原實際

```
F'=G-{b,p,h,R,x,y,r},
rim=(a,n,u2,u1,L,q,c,s,v,w,t)
```

這十一個框點中，除了原框邊，全部可能原邊只剩

```
a-u2, s-u2, v-u2, v-u1, w-u1.
```

不能無條件宣稱這個 C11 induced。原 C11 的既定圓周次序又排除弦
`u2-s` 與任一 `u1-v,u1-w` 共存，以及 `u2-v` 與 `u1-w` 共存。
二十個完整接觸配對因此恰剩十二個無交叉的必要配對，八個被排。
完整配對全部保存在 [certificate.json](certificate.json)。這十二個只是
必要接觸配對，沒有實際來源或共同私有圖實現聲明，也不把它們跨著色拼接。

在 n=5 子型，唯一含 a 的 u2 接觸型是 `{a,n,R}`。沒有額外上界限制
外側私有點數時，u1,u2 的原度數下界可以由更多私有鄰點滿足，不能據此
強迫剩餘四條可選外弦中的任一條存在。

## 4. 合併本輪完整介面閉包後的原圖結論

本節另用 [interface 的同源完整 fibre 定理](../interface/PROOF.md)，不屬於
本頁純 pocket／接觸 checker 的輸出。該定理逐一假設上述五條可能原弦
中之一存在，保留整張 F'、原 cap 的全部重新賦色及完整分量交換。
`s-u2,v-u2,v-u1,w-u1` 各使原 G 的一個已知正列完整為零，故這四條
原邊全部不可能存在。這是對同一實際 G 的條件式反證，不把閉包存活格
或各弦的邊際結果宣稱為不同來源的共同實現。

合併 §3 的完整 envelope，因此得到原圖的更強結論

```
S(u1)={R,L},
S(u2)={n,R}             若 n>=6，
S(u2)={a,n,R}           若 n=5。
```

若 n>=6，F' 的 C11 rim 確實 induced。若 n=5，F' 只多原弦 a-u2；
n 在 F' 的完整 star 恰為 `{a,u2}`，為原三角形 a-n-u2 的 ear。
刪去此原 n 後，同一實際

```
F''=G-{b,p,h,R,n,x,y,r}
```

有 induced 原十框 `(a,u2,u1,L,q,c,s,v,w,t)`。其外側仍保留所有其他
原附件與私有點。此處只刪原點，未完成 C5 候選；因此不把 F'' 的點數
當作完成成本，也沒有把 n 的原色從另一份著色移進來。

因原私有點的度數至少五，u1 在原 F 的完整私有鄰點至少三個，包含 u2；
u2 在 n>=6 子型至少三個，包含 u1，在 n=5 子型至少兩個，包含 u1。
這些是額外私有鄰點的存在界，仍沒有外側私有點數上界。

## 5. 重播與精確停止點

[check.py](check.py) 綁定六份凍結來源 SHA256，由原十一面重新建面 dual，
核對全部十四條外弦的原路、圈長與強迫內部原點，並重新讀取原完整接觸
envelope，重建四／五個接觸型與全部二十個共同配對。它有限核對的是
上述組合表；Jordan 有界側及原 C3/C4/C5 pocket 應用是本頁的紙面證明，
沒有宣稱機械驗證原圖來源或任意大小平面拓撲定理。
正常與 seed17 重播通過；將七框無條件改為 induced、或竄改為來源已排除
的兩份負控制均拒絕，見 [checks.json](checks.json)。§4 的較強結論由
interface 自己的證書／checker 核對，沒有在本頁重複或混合其證明權限。
證書建立使用 exclusive-create；嘗試覆寫既存證書的控制亦拒絕，原證書
bytes／SHA256 保持不變。

```
python3 -B audits/2026-10-20-r6-941-j1-w5-9c36e3c/geometry/check.py
```

本頁的幾何checker本身只給結構二分。後續
[同源六框縮減](../replacement/PROOF.md)在n=5型構造同一完成k−6的C，
接受01232且三拒絕完整fibres全空，因而排除該型。
整個原W5子支仍剩n>=6的induced七框／C11，尚未閉合；全部J1／J2亦未閉合。
沒有新Lean結果、commit或push。

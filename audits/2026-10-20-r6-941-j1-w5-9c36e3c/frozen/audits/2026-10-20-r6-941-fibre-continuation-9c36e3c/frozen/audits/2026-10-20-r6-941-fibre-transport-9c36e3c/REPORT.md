## 1. 同一完整核心上的傳送

只在 a1=0 分支固定同一實際 F，rim 次序仍為
`(a,n,R,L,q,c,s,v,w,t)`。沿用前輪已證八個完整固定字面 fibres，定義

```
Z(q,d,e) = #F(0,1,3,2,q,1,d,e0,e1,d),
q∈{0,3}, d∈{2,3}, e∈{(0,1),(1,0)}。
```

計數包含全部私有點，空 fibre 計零。每份 F 著色有唯一完整 J1 cap
接回；全部接回後才計作 J1 的 01021。以下交換在 F 上進行，接回 cap
可隨之改色，但原有序框 `(x,y,a,b,c)=(0,1,0,2,1)` 固定。

**d 配對。** 交換實際 23 分量中含 R 的整個分量，再對整份 F 著色
全域交換 2、3。前輪每一個允許的實際 01|23 分割都給同一輸出
`(q,5-d,e)`，沒有選擇有利分割。全域 (23) 保持 23 誘導圖不變，且
與該分量交換可交換，故此映射自身為逆。因此任意大小同源計數滿足

```
Z(q,2,e)=Z(q,3,e)。
```

**q 單射及精確像。** q=0 時，前輪 03|12 分割迫 q 所在的實際 03
分量與 rim 的交集恰 `{q}`。交換此完整分量，只有 rim 的 q 由0變3，
給 `Z(0,d,e)` 到 `Z(3,d,e)` 的單射。其像恰為後者中 q 的03分量
接框仍僅 `{q}` 的完整著色：同一交換為逆，且保持整個03誘導圖不變。
不能把此單射當作覆蓋整個目標 fibre 的雙射。

在 d=2 的 q=3 目標中，全部三個允許接框型的 q 塊恰為
`{q}`、`{q,z0}`、`{R,q,z0}`，其中 z0 是 v,w 中色0的點。
故未覆蓋部分恰是同一完整著色中 `q~z0` 於03的部分。
令該部分的完整計數為 E_e，並令

```
A_e=Z(0,2,e), B_e=Z(3,2,e)。
```

有逐著色不交雙射分解 `B_e=A_e+E_e`。這裡 E_e 不是另一張圖的
邊際計數，也沒有假設不同色對可任意拼接。

## 2. 最後拒絕的精確重寫

把前輪八項完整 fibre 和代入上述雙射，得到

```
N01021(J1)=2 Σ_e(A_e+B_e)=4 Σ_e A_e+2 Σ_e E_e。
```

尤其此固定字面計數必為偶數；而且

```
N01021(J1)=0  ⇔  B_(0,1)=B_(1,0)=0。
```

故 J1 的八項排除義務可以縮成以下兩個完整 fibres 的排除：

```
F(0,1,3,2,3,1,2,0,1,2),
F(0,1,3,2,3,1,2,1,0,2)。
```

這兩項仍可能含 `{q}` 或 q—z0 連通部分；本輪沒有證明任何一項為零。
若另能證 A 的兩項為零，剩餘才可全歸入 q—z0 的實際03長分量。
不能省略此條件直接宣稱每份拒絕都具該連接。

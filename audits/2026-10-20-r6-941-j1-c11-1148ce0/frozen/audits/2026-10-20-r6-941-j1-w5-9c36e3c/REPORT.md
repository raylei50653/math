## 1. 原圖結構的新來源結論

固定原七框 `(a,b,q,L,u1,u2,n)`，內部恰 p,h,R，十一個原面與三個完整
五度 stars 不變。[幾何證明](geometry/PROOF.md)排除十四條可能原外弦中的
十三條；唯一可能的 a–u2 恰當且僅當原 n 五度。此時
`N_G(n)=(a,p,h,R,u2)`，與原片合併成 induced 六框、四個五度內點。

原完整接觸定理再把
`F'=G-{b,p,h,R,x,y,r}` 的十一框可能弦縮為五條。
[完整接回與零傳播](interface/PROOF.md)逐條加實際原邊後，證明

```
s–u2、v–u2、v–u1、w–u1 全部為原非邊。
```

每條若存在，都迫**原 G 的完整01232 fibre 空**，與原支持941矛盾。
這四條是真來源排除結論；推理不靠較小圖搜尋零命中，也沒有刪掉
任何原外側附件。完整舊 C10 接觸因此精確為

```
S(u1)={R,L},
S(u2)={n,R} 或 {a,n,R}。
```

下節排除 n=5 後，實際剩餘來源必有 `S(u2)={n,R}`。

| 精確子型 | 實際核心與原有序 rim | 剩餘狀態 |
| --- | --- | --- |
| n≥6 | F'；`(a,n,u2,u1,L,q,c,s,v,w,t)` 為 induced C11 | 仍OPEN |
| n=5 | F''=F'−n；`(a,u2,u1,L,q,c,s,v,w,t)` 為 induced C10 | 由同一 k−6 候選排除 |

第二型的原 n 是 F' 的三角耳，完整 F' 鄰點只有 a,u2。其完整 G 的
接回包含 b,p,h,R,n,x,y,r，已在下面較小候選推理中逐項計算。

## 2. 全部 fibres、接回與獨立重建

對全部7381個 proper C11色軌道，保留原 G、Q1、J1的全部左 cap 集合與
原右 cap 集合，包含空集，固定同一完整核心著色逐份作 Cartesian product。
原 R 是 cap 變數，其他著色中不再固定為短路見證的3。
上游 C10 的已證零格亦經全部合法 R lifts 傳入；共同閉包留5951格。
兩個短路見證5093／5100均未排空。a–u2子型的閉包留3777格。

n=5 型另以18條左 cap 原邊、11條右 cap 原邊直接重建全部2461個 proper
C10色軌道；對 n 的每個合法完整 lift 傳入已證 C11零格。
最後留1889格，短路見證1876／1880均未排空。
這些存活格未被宣稱為正 fibres。n=5 的閉包雖不直接排掉見證，
卻足以證明下節新候選三拒絕全空；不能把「閉包未排見證」當作來源存活。
獨立逐邊接回核對及信任界線見 [review](review/REVIEW.md)。

## 3. n=5：同一候選的完整 k−6 縮減

原 n=5 的實際 induced 六角洞為 `(a,b,q,L,u1,u2)`，內部恰 p,h,R,n。
在刪掉這四點的洞內，先畫三條互不相交的 diagonals

```
a–L、b–L、a–u1，
```

它們三角化六角洞。收縮後兩條，抑制平行邊時保留原外框邊，得到

```
C=(G−{p,h,R,n})/(a=u1,b=L)；原框仍為 (x,y,a,b,c)；完成 k−6。
```

原六框 induced 保證所識別的兩對都沒有原邊，故不生loop。兩個商類各只含
一個原框點，原五框保持互異。a–L只變成原ab的平行copy；沒有新點或
未計入的重建費用：刪四個原內點，另把兩個原內點併入原框，恰減六。
全部其他原點、原邊、附件與私有點均保留。

固定同一完整 F'' 著色 f，C的全部左 lifts 恰為

```
{b : a=u1，b=L，b∉{a,c,q}}。
```

與同一 f 的完整原 Right(f) 作Cartesian product，就是 C的全部完整著色。
全部2461個核心軌道逐份重建，三拒絕列的正係數支持分別落在24、60、60格；
它們全部是已證零格，與1889個必要存活格完全不交。故**同一C**滿足

```
N01021(C)=N01202(C)=N01212(C)=0。
```

原 d_a 完整正 fibre 在 n=5 時有
`a=u1=0,b=L=n=1,q=u2=2,p=R=3,h=c=r=0`。
刪點並沿上述商映射限制這份**實際完整著色**，原所有私有顏色保留，
兩個 xy lifts 各以全域置換送到同一原字面01232，因此 `N01232(C)>0`。
沒有拿必要未刪格充當接受見證，也沒有用殘餘F著色代替原d_a。

凍結K132沒有任何支持接受01232而同時拒絕三個指定列，所以C是完成
成本嚴格下降的bad，違反原G的全域最小性，**n=5子型排除**。
完整證明、正式checker與獨立逐邊全fibre核對見
[replacement](replacement/PROOF.md)、[獨立縮減核對](review/diamond_reduction_check.py)
及 [review](review/REVIEW.md)。

## 4. 其他替換方法的有限邊界

同七框的完整原 p,h,R關係共有91種 proper色軌道，其中31種有完整 lift。
保原三拒絕的一個充分條件，是新補片的完整關係包含於原關係，並保留
原 d_a 的實際接受見證；完整接回與完成成本須同時計入。
原 d_a 對七框恰有兩種色型 `(0,1,2,1,0,2,1)`、`(0,1,2,1,2,0,1)`；
它們與殘餘 J1 著色是不同的完整著色，未混合其分量或私有顏色。

本輪的明確標記三角化替換、來源零格過濾、右 r 洞接回與六框四點型
搜尋範圍及數字見 [replacement](replacement/PROOF.md)。
七框一般型的已檢查族尚無通過候選；六框精確n=5型則得到上述C。
其他零命中只記錄已驗證有限族及充分判準的界線，
不外推任意合法較小 disk 不存在，也不把局部存活關係當作來源實現。

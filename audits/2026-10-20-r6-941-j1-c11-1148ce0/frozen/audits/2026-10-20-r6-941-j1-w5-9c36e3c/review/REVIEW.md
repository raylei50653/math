# 獨立審核：n=5 子型已以同一較小 disk 排除；整個 W5 子支仍 PARTIAL

固定本輪 exclusive BASE 與完整凍結來源契約；本目錄只新增獨立審核，未改上游證書。原 C5 有序框始終是 `(x,y,a,b,c)`，原七框始終指原圖中的 `(a,b,q,L,u1,u2,n)`，其內部原點恰為 `p,h,R`。保留全部原附件、完整 stars、私有點、旋轉、原短圈與全域最小性；不使用四色定理或 active-f matching 假設。

審核結論是 **PARTIAL**。原 `n=5` 子型有一張真正同源、同原框的完成 `k−6` 候選，接受 `01232` 且 `01021/01202/01212` 三個完整 fibres 同時為零，因此由原全域最小性排除。原 `n>=6` 子型、整個原 W5 子支與全部 J1/J2 仍未閉合。

## 同一候選的 n=5 化約

承接 geometry 的原圖 pocket 證明：原邊 `a-u2` 存在當且僅當 `d_G(n)=5`。此時原完整 star 是 `N_G(n)=(a,p,h,R,u2)`，原面 `a-n-u2` 確實存在。把這一個原面併入固定十一面原片，得到原六框

```
(a,b,q,L,u1,u2),  內部恰 (p,h,R,n).
```

這是明列的原片擴張，不是假定原七框內部其實有第四點。只在這個已證原六框內畫三條不交弧 `a-u1,b-L,a-L`；它們把原六角洞三角化。然後收縮前兩條弧，抑制多餘平行邊，保留原框邊的原 copy。`a-L` 在收縮後只給原 `ab` 的多餘 copy。因此完成圖正是

```
C=(G-{p,h,R,n})/(a=u1,b=L).
```

原 `a-u1,b-L` 均為非邊，收縮不產生 loop；兩個識別類互不相交，各只含一個原框點。原框五點仍互異，全部原框邊保留。弧是在實際同一洞中先畫再收縮，故不依賴任意商圖的共面猜測。兩個會形成二重邊的短區域是上述三角化中的原空洞三角形，不刪除任何剩餘點。所有其他原附件與私有點完整保留。

被刪的 `p,h,R,n` 都是原內點，`u1,L` 亦為原內點且各識別到原框點 `a,b`；沒有新點，完成內點數精確是 `k−4−2=k−6`。此處成本是完成 C5 圖的成本，不是暫存核心的內點數。

## 完整 C10 核心與候選所有 lifts

先用原 R 完整 star 暴露 C11，再由同源完整分量閉包排除四條可能原弦 `s-u2,v-u2,v-u1,w-u1`。在 n=5 子型，原 C11 唯一額外弦是 `a-u2`，n 在該核心的完整 star 恰為 `{a,u2}`。刪去原 n 後，同一實際

```
F''=G-{b,p,h,R,n,x,y,r},
outer(F'')=(a,u2,u1,L,q,c,s,v,w,t)
```

為 induced C10 disk。其全部其他原點與私有點仍在，並非只有十個接口點的圖。

對任一份完整 F'' 著色 f，候選左集合精確是

```
Left_C(f)={b : a=u1, b=L, b notin {a,c,q}}.
```

候選右集合是全部原 right cap assignments

```
Right(f)={(x,y,r): r notin {s,v,w,t,x,y},
                    x notin {c,s,y}, y notin {a,t}}.
```

候選的完整著色恰是遍歷同一實際 F'' 全部完整 f，再取 `Left_C(f)×Right(f)`。左、右 cap 間沒有原邊；左只剩原 b，右為原 x,y,r。原商映射的 pullback 與限制互逆，包含全部私有色及所有空 fibres。沒有分別選取可行投影，也沒有改原有序框。

`diamond_check.py` 對全部 2,461 個 proper C10 色軌道，以明列的 18 條原左邊、11 條原右邊，直接枚舉原 `(b,p,h,R,n)`、Q1/J1 的 `(b,R,n)` 與全部 `(x,y,r)`。n 在 F' 中只有 a,u2 兩個鄰點，故任一份完整 F'' 著色的每個 `n notin {a,u2}` 都給真正完整 F' 延拓；若任一延拓落入已證 C11 零 fibre，該完整 F'' fibre 就為零。繼承最終 v4 的 `a-u2` profile 後有 572 個初始零格，完整 Kempe 交換閉包留下 1,889 格，兩個殘餘見證 1876/1880 仍在。這些未刪格只是必要支援，沒有來源實現聲明。

`diamond_reduction_check.py` 不匯入其他 cap checker；它直接按上述候選左條件、全部 11 條原右邊，重建全部 2,461 格的完整十列係數，保留全部零格與完整右 lifts。對 **全部 1,889 個未排核心格**，同一張 C 的 `01021,01202,01212` 係數逐項全零。由每份實際 F'' 著色都只能在這個未排集合內，三個候選完整 fibres 同時為零，並非只排除兩個殘餘見證。

接受正性另由同一來源的原完整 d_a 著色提供。原星形條件及 a-u2 原邊迫

```
a=c=r=h=u1=0, b=n=s=t=L=1, q=u2=2, p=R=3,
{x,y}={2,3}, {v,w}={2,3}.
```

因此原完整著色限制到 C 時滿足 `a=u1,b=L`，所有剩餘原邊仍 proper。刪去的四點均有固定色，故限制不丟失任何私有色；再對所選完整著色施行同一全域色置換，就得到固定原有序框的 `01232` 著色。checker 另逐份核對四種 literal `(x,y),(v,w)` 方向的全 right lifts 與接受係數。沒有把別張候選的接受正性移到 C。

`catalog_check.py` 讀取已凍結 `artifacts/c5_cells/cells.json`，核對精確十列次序與全部 132 個 K132 masks；其中沒有任何 mask 同時滿足 bit9=1 與 bits1,4,6=0。因此這張完成內點 `k−6<k` 的合法同框 C 支持在 K132 外，直接違反原全域最小性。這只排除 n=5 原子型。

## C11 四條原弦的獨立覆核

`check_interface.py` 不匯入父層 cap 程式，按明列原邊重建全部 7,381 個 C11 軌道的原 G、Q1、J1 完整左集合與完整右集合。矩陣 SHA256 與父層 v4 完全相同；直接 cap 零格是 702，繼承原 C10 零格後為 1,194。

`chord_check.py` 使用已凍結、具有來源量詞的互補色對分量 family，獨立以 integer bitsets 實作完整 half-palette 覆蓋與逐輪刪除。它另外從凍結原 C10 證書重新計算全部 R lifts 的繼承零格；基礎、a-u2 與四條待排原弦的完整 live IDs 和每輪刪除 IDs 都逐項對上 v4：

| 額外假設原弦 | 未排格 | 原 G 的01232仍有係數 |
| --- | ---: | --- |
| 無 | 5951 | 有 |
| a-u2 | 3777 | 有 |
| s-u2 | 2997 | 無 |
| v-u2 | 2706 | 無 |
| v-u1 | 2448 | 無 |
| w-u1 | 2436 | 無 |

後四行對每份實際完整核心著色均成立，與同一原 G 的01232正性矛盾，因此四條原邊排除是來源結論。未排格的存在不被當成共同來源實現。

## 原七框完整關係及通用替換方法的界線

`check.py` 由固定十一面獨立重建邊、邊界、Euler 與 p,h,R 的完整五度 stars，並重新核對 1,147 份凍結輸入 bytes/SHA。91 個 proper C7 色軌道中，31 個有非空完整 `(p,h,R)` lifts、60 個為空；31 個非空格有29格唯一 lift、2格兩份 lifts，合計33份。證書逐格保存完整列表，包括空列表。

僅對原 patch 的 60 個空格套全部429個 noncrossing 分割、1,785份交換 columns 的必要模型，刪8格再刪2格後仍留50格。這沒有圖來源實現或一般不可約性含義。只用此原 patch 關係的通用替換搜索，與上述使用全來源且擴張為原六框的 n=5 化約，是不同量詞的問題。

替換線的固定 C7、0/1/2 個有標號內點的 flip 枚舉完整性有如下初等理由：對任一內點 v，其 degree>3 時 link 為簡單圈；star 外的既有鄰點間 chords 不交叉，故有某條 incident edge 的 opposite chord 不存在，可以 flip 降低 v 度數。到 degree3 後刪 v。degree3 點可用兩次 flips 跨相鄰三角形搬移；面 dual 連通，且 C7 至少有五個面，可將 v 停在不受下一個 flip 影響的面，模擬刪點後全部 flips。對內點數歸納，得到固定標號邊界的完整連通性。有限 zero-hit 仍只約束明列的標記 triangulation 家族，不排除任意新 disk。

## 驗證、信任邊界與停止點

正式預設重播為 `check.py`、`check_interface.py`、`chord_check.py`、`diamond_check.py`、`diamond_reduction_check.py` 與 `catalog_check.py`。正常、seed17、竄改空 fibre／cap lift／範圍旗標的負控制記錄於本目錄 receipts。證書均 exclusive-create；先前證書與探索輸出保留。

此審核重新實作完整 cap 代數與 zero-closure 演算，未機械重證原 Jordan/pocket 定理、原來源最小性或完整分量 family 的全稱適用證明；這些沿用明列凍結來源紙面定理。使用該來源定理，n=5 的真正 source exclusion 已證。n>=6 的 induced 七框與 C11 仍保留 OPEN；沒有構造適用於整個原 W5 子支的同一候選，沒有全部 J1/J2 閉合，沒有新 Lean、commit 或 push。

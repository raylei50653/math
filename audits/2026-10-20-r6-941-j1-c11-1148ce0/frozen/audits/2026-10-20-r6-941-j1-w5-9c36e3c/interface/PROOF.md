# 原 R 五輪完整接回的 C11 介面

本頁完整承接[本輪來源契約](../SOURCE_CONTRACT.md)。固定選出的原 u1,u2，
但對其他著色重新量化其全部色值，不保留殘餘見證的色值。

刪去原 F 外框上的五度 R。其 F 內完整 star 為 `(n,u2,u1,L)`，
三個原面 `Rnu2,Ru2u1,Ru1L` 恰露出原路 n–u2–u1–L；
u1,u2 是互異原私有點。因此

```
F'=G-{b,p,h,R,x,y,r},
outer(F')=(a,n,u2,u1,L,q,c,s,v,w,t)
```

是同一實際三角化 C11 disk。它不被假定 induced；所有其他原邊及私有點保留。
F' 有 k−2 個點與 k−13 個內點。此數字不是完成 C5 候選的成本。

對一份完整 F' 著色 f，寫其 rim 為上述字面十一元組。
顏色全集 K={0,1,2,3}。原左 cap 的全部 assignments 為

```
Left_G(f)={(b,p,h,R):
 b∉{a,c,q,p}, p∉{a,q,n,h},
 h∉{q,L,R,n}, R∉{n,u2,u1,L}}.

Left_Q1(f)={(b,R): b∉{a,c,q}, b=n, R=q,
 R∉{n,u2,u1,L}}.

Left_J1(f)={(b,R): b∉{a,c,q}, b=L, a≠R,
 R∉{n,u2,u1,L}}.

Right(f)={(x,y,r): r∉{s,v,w,t,x,y},
 x∉{c,s,y}, y∉{a,t}}.
```

以上左、右 cap 間沒有原邊。固定 f 後，每張完成圖的完整著色恰為其
`Left(f)×Right(f)`，並按原有序框 `(x,y,a,b,c)` 分組。
Q1 與 J1 的商圖著色依原商映射完整拉回；保留全部私有點及空集合。
R 作為 cap 變數須重新枚舉，不能一直固定為殘餘見證的3。

[checker](check.py)保留全部7381個 proper C11色軌道的完整左右集合，
並將 G、Q1 的十列係數逐項對照凍結舊 C11 R-star cap 模型。
每個 core 至少使用三色；未用色穩定子為 `(4-d)!=1`，故把全部 lifts
按 canonical C5列分組後，係數恰為固定字面 C5列的係數，沒有軌道大小因子。

以原 G 的三個拒絕零列、Q1接受零及同一J1的01202／01212零列產生初始
零格；另保留上游已證完整 C10 零格的接回約束：只要一個合法 R lift
落到已證空的 C10 fibre，對應完整 F' fibre 便為空。702個 cap 零格的聯集
因而擴成1194格，再套用凍結的三角化 disk 完整互補色對分量交換定理。
分割必 noncrossing，交換作用於各實際完整分量的全部私有點；
邊界不相遇的分量不影響 rim。逐輪覆蓋失敗僅給新的零 fibre，未刪格不宣稱非空。
全部58786個noncrossing分割、22143個半色框列、36487個完整交換columns
重新生成，最後留5951格。七個原正列均尚有未排格。

選定三邊路的兩個字面完整 F' 見證為

```
(0,1,2,1,2,3,1,2,0,1,2),
(0,1,2,1,2,3,1,2,1,0,2).
```

它們的 canonical IDs 為5093、5100，均未被此閉包排空。
在這兩列 J1 cap 的 R 只能是3，故它們確實對應原殘餘著色的限制，
沒有把另一個 R lift 當作原見證。

## 四條原弦的來源矛盾

[原圖幾何證明](../geometry/PROOF.md)及凍結完整接觸 envelope 保證原 F'
的可能弦只有 a–u2、s–u2、v–u2、v–u1、w–u1。對任一實際存在的弦 uv，
先令所有 f(u)=f(v) 的完整 F' fibres 為零，再作同一完整交換閉包。
這個步驟保留原圖的實際邊；不以不存在的邊推顏色必須相等。
完整交換軌道若違反弦的 properness，也不可能是實際原分量軌道。

| 額外假定的一條原弦 | 閉包最後未排格 | 原 G 的01232仍有未排格 |
| --- | ---: | --- |
| 無 | 5951 | 有 |
| a–u2 | 3777 | 有 |
| s–u2 | 2997 | **無** |
| v–u2 | 2706 | **無** |
| v–u1 | 2448 | **無** |
| w–u1 | 2436 | **無** |

最後四列的每個原01232 cap係數均落在已證空格。因此它們各自迫
`N01232(G)=0`，與原完整支持941矛盾，故四條原邊全部不存在。
這是完整來源前提下的任意大小條件結論，不是「零命中」式來源排除。
[certificate-v4.json.gz](certificate-v4.json.gz)逐型保留完整 live IDs、
刪除輪與原各正列狀態；另列的多弦型只作擴大必要域的交叉核對。

結合原圖幾何，精確得到

```
S(u1)={R,L},
S(u2)={n,R} 或 {a,n,R}。

n>=6：F' 的上述 C11 是 induced。
n=5：a–u2 是 F' 唯一弦，原面 a–n–u2 是三角耳；
     F''=F'−n 的框 (a,u2,u1,L,q,c,s,v,w,t) 是 induced C10。
```

原 u1 的其餘至少三個鄰點均為舊 C10 私有點；u2 在 n>=6 型也至少三個，
在 n=5 型至少兩個。原 u1u2 是其中一邊；這些下界未限制其他私有點數。

兩個幾何型未由上述 C11 方法直接排除。後續
[六框同候選縮減](../replacement/PROOF.md)利用其已證零格構造完成k−6的C，
接受01232且三拒絕全空，因而排除n=5型；n≥6的induced C11仍OPEN。
正常、seed17及竄改證書負控制另有重播記錄。前三份發現階段證書保留原
bytes；正式重播預設檢查第四版。checker未機械形式化 Jordan/pocket
論證；沒有共同原圖實現或新Lean。

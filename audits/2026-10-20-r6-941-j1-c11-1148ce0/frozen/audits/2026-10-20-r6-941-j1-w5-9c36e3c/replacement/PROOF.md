# 原 W5 七框子支：n=5 已排除，n≥6 保留完整義務

固定本輪 exclusive [BASE](../BASE.md) 與全份 frozen 來源契約。
原同一 G、原框 `(x,y,a,b,c)`、原最小完成內點數 k、原完整支持941、
`a1=N01232(Q1)=0`、所有原附件、具名點、旋轉、完整 stars、私有點與
原短圈定理全部保留。不引用四色定理或 matching。本文證明的是原 W5
七框子支之 **n=5 子情形** 不可能；n≥6 以及其他 J1/J2 仍 OPEN。

## 1. n=5 的同源實際較小圖

原七框為 `(a,b,q,L,u1,u2,n)`，內部恰 p,h,R。幾何工作線已證：唯一
可能的七框外側原弦是 a–u2；它存在當且僅當原 n 為五度，並強制完整
原 star

```
N_G(n)=(a,p,h,R,u2).
```

在此情形，把原三角形 a–n–u2 合入原十一面七框，得到同一原圖中的
六框 `(a,b,q,L,u1,u2)`，內部恰 p,h,R,n，十二個面就是原十一面加
`a n u2`。刪這四點不丟失任何六框外的原附件。

在這個實際六角洞先畫入三條互不相交的弧

```
aL=(0,3), a–u1=(0,4), bL=(1,3).
```

它們三角化六角洞。a–u1、bL 均為原非邊，兩弧互不相交；同時收縮
後，aL 僅成為原 ab 的平行 copy。抑制重邊時保留原 ab 等原框 copy。
沒有 loop；只有原框點 a、b 分別與各自的原內點 u1、L 識別，五個原
框點仍互異，所有原 C5 框邊保留。故

```
C = (G−{p,h,R,n})/(a=u1,b=L)
```

是同一原有序框 `(x,y,a,b,c)` 的合法簡單 plane C5 disk。所有外側
原邊、附件及私有點均保留。它刪四個原內點，再作兩次各減一個內點的
識別，沒有新增點，**完整完成成本恰 k−6**。不要求 C 保持原度數、
r6 或941身份。

## 2. 同一 C 的完整三拒絕公式

令實際

```
F''=G−{b,p,h,R,n,x,y,r},
rim(F'')=(a,u2,u1,L,q,c,s,v,w,t).
```

原 n 的完整 star 保證它在上一層 `F'=G−{b,p,h,R,x,y,r}` 中恰只鄰
接 a、u2；因此每份完整 F'' 著色的每個合法 n 色均可接回 F'，不是只
選其中一個 n 色。這正是 [diamond source checker](../review/diamond_check.py)
承接上層全部已證空 fibres 的依據。

固定任一字面原框列 `z=(x,y,a,b,c)`。對同一實際 F'' 的每份完整著色 φ，
候選全部左接回恰為

```
φ(u1)=φ(a), b=φ(L), b∉{φ(a),φ(c),φ(q)}.
```

右接回仍是原 x,y,r 的**完整** stars：xy、xc、xs、ya、yt 皆 proper，
r 不同於 x,y,s,v,w,t。刪去的 p,h,R,n 無色可另選，候選亦無新增點。
以原右 cap 的每份合法 r 計一次，便得到 N_z(C) 的完整非負和；限制
與接回互逆，包含全部私有點與空 fibres。這裡不使用不同核心著色的
邊際或各自可行分量拼接。

[reduction_check.py](reduction_check.py) 獨立枚舉全部2461個 proper C10
色軌道、每格全部4個 b 值與64個 x,y,r 值，保留全部十列整數係數及空
接回。三拒絕列係數非零的核心格數恰為

| 原固定字面列 | 非零係數核心格 | 在已證可能集1889格中的交集 |
|---|---:|---:|
| 01021 | 24 | 空 |
| 01202 | 60 | 空 |
| 01212 | 60 | 空 |

每個不在1889格集合中的核心 fibre 已由原來源的零值及完整分量交換／
完整 n 接回證為零。這個集合只是實際核心可能集的已證上界，未刪格
不被宣稱為來源實現。非負完整 fibre 公式直接給同一 C

```
N01021(C)=N01202(C)=N01212(C)=0.
```

這是由有限且完整的局部 cap 係數核對推出的任意大小同源定理；不是
把有界搜尋零 hits 當作不存在的定理。獨立工作線以直接 edge predicates
重建同一全部 cap，見 [獨立 checker](../review/diamond_reduction_check.py)。

## 3. 同一 C 的實際接受與最小性矛盾

凍結來源定理已有同一實際來源的 `d_a>0`，每份完整著色在原具名點上
滿足

```
a=c=h=r=0, b=n=L=s=t=1, q=2, p=R=3,
{x,y}={2,3}, {v,w}={2,3}.
```

這裡 L=1、R=3 由原 a1=0 定理取得。原 R 的完整 W5 star 與原邊
L–u1、u1–u2、u2–n 迫 `{u1,u2}={0,2}`。原 a–u2 邊又迫
`u2=2,u1=0`。故**每份實際 d_a 著色**滿足 C 的兩個識別式，限制後
即是同一 C 的完整著色。兩個實際 xy lifts 各作全域換色回固定原框
`01232`，因此 `N01232(C)>0`。正值來自原實際 d_a，並非從1889格中
選一份尚未實現的必要控制。

原最小性要求每張完整成本小於 k 的合法 C5 disk 支持在凍結 K132。
本 checker 另直接讀入凍結132個 masks，核對其中沒有任何 mask 同時
`bit9=1` 且 `bit1=bit4=bit6=0`，即接受01232而拒絕全部三列。因此
同一 C 的接受、三拒絕與成本 k−6 形成原最小性矛盾：**原 W5 子支的
n=5 情形被排除**。沒有依賴其他候選各自的某個零值。

## 4. n≥6 的兩張實際候選及精確未竟義務

此時原 a–u2 不存在，七框外弦皆不存在。仍保留 n 及其全部實際外側
附件，可在原七角洞作

```
C0=(G−{p,h,R})/(a=u1,b=L),
C1=(G−{p,h,R})/(a=u2,b=L).
```

各自先畫兩條嵌套不交弧再收縮，必要時補三角化弧；所有識別端點均為
原非邊，不合併不同原框點，完成成本各恰 **k−5**。原實際 d_a 若
`(u1,u2)=(0,2)`，C0 接受；若為 `(2,0)`，C1 接受。必須選同一份實際
見證所對應的同一候選，不能將二者的零值拼接。

[long_case.py](long_case.py) 與 [完整證書](long-case-certificate.json.gz)
對實際 F' 的有序 C11 rim `(a,n,u2,u1,L,q,c,s,v,w,t)` 逐份重建
所有原右 cap lifts。承接目前5951格已證可能集後，兩候選各仍有
`24/8/8` 個完整字面核心 fibres 分別供三拒絕列接回，所有係數恰一。
證書列出各份完整十一字；這40項在各候選內為完整非負和，**沒有一項
在此被證為正或全部證為零**。尚須在實際來源排除這些 fibres，或另作
較小 bad；不能從 n=5 的成功推論 n≥6 或全部 W5/J1/J2 閉合。

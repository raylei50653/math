## 1. 實際 C11 與一份正 fibre

固定 J1 殘餘完整著色中的原實際三邊路 `n–u2–u1–L`。原短圈定理
已給 `N_G(R)=(n,h,L,u1,u2)`，原 R 的度數恰五，以及七框
`(a,b,q,L,u1,u2,n)` 內的十一個原面。特別是原 `u1,u2` 互異且是
舊 C10 的私有點；它們是原點，沒有新建點或借用另一張圖的附件。

刪除原 `b,p,h,R,x,y,r` 後，同一實際圖

```
F' = G−{b,p,h,R,x,y,r}
```

是三角化 disk，依序外框為

```
B = (a,n,u2,u1,L,q,c,s,v,w,t).
```

這使用 R 在舊 F 中的完整 star `(n,u2,u1,L)`，露出的三個原面
`Rnu2,Ru2u1,Ru1L`。**沒有刪 n**：n 的全部其他原鄰點、它們的所有
邊與私有附件均保留在 F'。因此 `d_G(n)` 沒有上界亦不影響這個核心。
凍結幾何與介面定理在 `d_G(n)≥6` 下另給 B induced；以下計數證明
只需同一簡單三角化 disk 與這個實際圓周次序，不把非邊解讀為等色。

固定的那份殘餘完整著色限制到 F'，字面 rim 恰為兩者之一：

```
(0,1,2,1,2,3,1,2,0,1,2),
(0,1,2,1,2,3,1,2,1,0,2).
```

按凍結 checker 的 restricted-growth 次序，其 S4 正規代表 IDs 是
5093、5100。令 `Z_i` 為**同一 F'** 在第 i 個固定正規代表上的全部
完整著色數。全域色置換作用於全部私有點，故

```
Z_i ∈ Z_{\ge0},       Z_5093 + Z_5100 ≥ 1.
```

這個正值來自實際已選著色，不是從必要閉包的未刪格選取一份「見證」。
往後枚舉其他著色時，`u1,u2` 的色值重新自由量化；只有它們的原點
身份與原附件固定。

## 2. 所有 cap 方程用同一 Z

固定一份完整 F' 著色 f，依 B 寫其十一色。原 G 的左 lifts 恰是

```
{(b,p,h,R):
 b∉{a,c,q,p}, p∉{a,q,n,h},
 h∉{q,L,R,n}, R∉{n,u2,u1,L}}.
```

Q1、J1 的完整左 lifts 分別是

```
{(b,R): b∉{a,c,q}, b=n, R=q, R∉{n,u2,u1,L}},
{(b,R): b∉{a,c,q}, b=L, a≠R, R∉{n,u2,u1,L}}.
```

三者同一完整右 lift 集為

```
{(x,y,r): r∉{s,v,w,t,x,y},
          x∉{c,s,y}, y∉{a,t}}.
```

全部被刪原點的完整 stars 保證兩 cap 間沒有未列邊，亦沒有未列私有
接觸。限制與逐份接回互逆。Q1/J1 商圖依原商映射完整拉回，空 lifts
保留為空；R 是重新枚舉的變數，不能固定為選定殘餘見證中的 3。
因此原 G、Q1、J1 每個固定原 C5 字面列的完整著色數，均是同一 Z
的上述非負整數 cap 投影。

正規化不藏軌道倍數：proper 奇圈 C11 與 proper C5 每列至少用三色，
故其 S4 穩定子都是平凡群。兩端軌道大小均為 24；對正規 C11 代表
枚舉全部 cap，再按 C5 正規列分類，所得係數正是固定字面 C5 fibre
的係數。對 `h=a`、`h=b` 的原接受扇區加入相應原等式亦一樣成立；
這兩個投影分別是 `A_a,A_b`，不是更窄的具名 `d_a,d_b`。其正性由
凍結來源的 `A_a≥2d_a>0`、`A_b≥2d_b>0` 取得。

所以原支持941的三個零列、Q1 的接受零列、J1 的兩個零列全部成立；
原七個正列以及凍結定理的兩個正接受扇區也均屬同一投影系統。所用
正性可能來自同一圖的不同完整著色，這是計數方程所允許的量詞，
沒有拼接它們的私有顏色或 Kempe 路徑。

凍結 C11 `live` 的補集也確實是零 fibre：其 cap 零格由非負投影
直接得零；舊 C10 零格對每個合法完整 R lift 接回；每輪完整分量
交換只用前輪已證空格。故限制 `Z_i=0` 於這個補集不假設存活格
有來源實現。

## 3. 任意 plane disk 的 signed noncrossing span

這一節不需三角化。令 `I=V(F')\B`，固定 proper 字面邊界 t。直接對
**全部原邊**作 inclusion-exclusion：

```
Z(t) = Σ_{A⊆E(F')} (-1)^|A| 4^{k_0(A)} [t 在 π(A) 的每塊上相等].
```

其中 `π(A)` 是 spanning graph `(V(F'),A)` 的連通分量在 B 上所誘導
的分割，`k_0(A)` 是完全不接 B 的分量數。每個這種私有分量可任選
四色，故因子為 `4^{k_0(A)}`；接 B 的分量一旦 t 在其接點相等，
顏色就已完全固定。孤立私有點也算入，沒有丟掉任何內部分量。

不同 A 分量在同一 disk 內互不相交，故 `π(A)` noncrossing：如果
不同塊有圓周交錯的四個接點，取各自連通分量內的簡單路即違反
Jordan 分離。若某塊同含 B 的相鄰兩點，其等色指示在全部 proper
rim 列上恆零，可刪除此零欄。

因此，以所有 proper noncrossing 分割 π 的等色指示為欄

```
P_{i,π} = [第 i 個正規 rim 在 π 各塊上相等],
```

存在**帶符號整數**向量 `σ`，使

```
Z = P σ.
```

σ 不受非負限制。這是來源 F' 的逐邊恆等展開，並非假設每個 NC
分割或任一帶符號組合都是某張共同私有圖。允許全部實數 σ 是必要
條件的放寬，不能製造假矛盾。

## 4. 三角化給出的完整互補色對 orbit 計數

固定互補色對 `{0,1}|{2,3}`。對一份完整 F' 著色，同時取兩側誘導
圖的全部實際連通分量。接 B 的分量形成一份分割 π；每塊同側、
同側相鄰框點同塊，且 π noncrossing。

令框上 palette 轉換次數為 `2m`。在每個原三角面連接兩條跨側邊的
中點：proper 三角面的三點不可能全在同一個二色 palette，所以每面
恰有一段。內部跨側邊中點度二，邊界跨側邊中點度一，得到互不相交
的 proper arcs 與閉圈。m 條 arcs 切出 `m+1` 個接框區域，內部閉圈
不改變接框區域數；每個同側區域可逐面縮回同側誘導圖。因此接框
分量數 `b=m+1`，也就是 checker 的

```
框上 π 轉換次數 = 2(b−1).
```

這個判據沒有約束不接框私有分量的數量。它只列舉涵蓋全部真實分割
的必要 family，不聲稱 family 中每個分割有來源實現。

現在把 F' 的**全部完整著色**依固定 palette 的完整分量交換分成
orbits。一次交換在選定分量的每個點上互換 0/1 或 2/3；包含全部
私有點。交換保持頂點的 palette，因此分量本身不變，且所有交換
互相交換。若該 orbit 有 b 個接框分量及 q 個不接框分量，則其
`2^{b+q}` 份完整著色互異；每份邊界交換結果恰出現 `2^q` 次。

令 H 為保留無序 palette split 的八元色置換群，r 為其 proper
rim orbit。`hsize_r` 是 r 中的字面 rim 數，`i(r)` 是其 S4 正規
代表。全域色置換對全部私有點給出雙射，故所有完整著色落入 r 的
總數正是

```
hsize_r · Z_{i(r)}.
```

對每個許可接框分割，枚舉全部 `2^b` 次交換，按 H-row 保留重數，
便得到 checker 的一個 column `B_{r,j}`。任一真實完整 orbit 的
接框分割及該 column 都在 family 中；以 `2^q` 加入其 column
權重。合併相同 columns 後得到某個**非負整數**向量 β，且

```
A Z = B β,        A_{r,i}=hsize_r [i=i(r)].
```

因此這是精確計數方程，不只是支援覆蓋。私有分量以共同正倍數留下，
沒有把不同色對的局部路徑或不同來源的 fibres 拼接。容許任意非負
實數 β 是必要條件的放寬，同樣不能製造假矛盾。

## 5. 已完成的精確排除與原短路義務

前四節把每個原實際來源送到同一組

```
Z ≥ 0,  Z_i=0 (i 不在凍結 live),
Z=Pσ,  AZ=Bβ,  β≥0,
原 cap 零值與正值,
Z_5093+Z_5100≥1.
```

[精確整數證書](orbit-farkas-certificate.json) 已由
[標準庫 checker](../counting/check.py) 從全部7381個正規 rim、
22143個 H-rows、36487個完整 orbit columns 重建核對。它只使用
完整 orbit 計數及已證空格：對第三節 signed span 的乘數全部為零，
對原 G 七個正列與 `A_a,A_b` 的額外正權重也全部為零。唯一正權重
是選定原短路的完整 fibre 和，權重恰16。

具體地，在4290個已證零 H-rows 上取乘數8；在另132個 H-rows 上
取68個 −1 與64個 +1。乘上第四節的同一來源計數方程，逐項化簡後
得到

```
16 (Z_5093 + Z_5100) + Σ_j s_j β_j = 0,
s_j ∈ Z_{\ge0}.
```

全部5951個可能核心格的其餘係數恰零，15693個非零 orbit slack 的
完整索引與整數值均保存在證書；所有其他 orbit slack 恰零。
checker 對完整36487欄核對，並未只核對發現階段留下的列或欄。

左式第一項至少16，其餘各項非負，與零等式矛盾。因此
**任意大小、全部原附件保留的這一具名三邊路來源分支不可能存在**。
這是由實際圖的完整計數導出的整數矛盾；數值 LP 只用於尋找乘數。
沒有先把必要向量當成圖，也不需要構造較小 bad。

將此結果與凍結 n=5 排除合併，原 J1 type III 的同一實際 12
n–L 簡單路不能長三；其長度為奇數且至少三，故**每條至少五**。
一般 J1/J2 的剩餘 fibres、type I 的長路、其他原來源及主存在性
仍不由本頁閉合；沒有新增 Lean 定理。

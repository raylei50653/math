## C11 計數與平面 span 的適用性

令 `z_i` 是**同一實際 F'** 的固定字面 canonical C11 完整著色數，
含全部私有點。全域換色令同一色軌道的各字面著色數相等；`z_i>=0`。
凍結零 fibre 證明令 5951 格之外的 `z_i=0`。

固定顏色配對 `{0,1}|{2,3}`。保留該無序配對的八個全域置換形成 H。
proper C11 至少用三色，所以 H 在每份 rim 字上的作用自由；每一半色框
列含恰八個字面 rim，故該列完整著色總數為 `8 z_i`。

對同一份實際完整著色，同時枚舉兩側每個實際雙色連通分量的整份交換，
含全部私有點。凍結三角化 disk 的完整互補分量定理保證接觸框的分量
形成 noncrossing 分割，其不同分量的框巡行為一棵樹的雙向巡行。
[dual_check.py](dual_check.py) 以「每條樹邊恰巡行兩次」獨立生成所有
允許分割及完整交換軌道。沒有接觸框的分量仍被完整交換，對框計數只貢獻
非負軌道重數。因此存在一份非負共同軌道向量 q，使

```
8 z_(rowid(h)) = sum_j B[h,j] q_j。
```

這是每份完整著色的共同計數分解，不是逐顏色對任選邊際分割。

另對實際 F' 的 proper-colouring 指示函數逐邊作 inclusion-exclusion。
每個邊子集的連通分量在 disk 中的框接觸形成 noncrossing 分割 π；
未接觸框的連通分量只貢獻 4 的整數次方。該項在固定框著色 t 的條件
是同一 π block 內各點同色。若 π 把相鄰框點放在同一 block，該項在
全部 proper 框著色上恆為零；其餘正是全部 proper noncrossing 分割。
因此存在有號整數向量 s，使

```
z_i = sum_pi P[i,pi] s_pi,
P[i,pi] = [每個 pi block 在第 i 個 rim 字內同色]。
```

這證明使用有號 span 的必要性；沒有要求 s 非負，也沒有宣稱任意 span
向量都有共同平面圖實現。上式對任意大小的同一實際 F' 成立。

計數發現程式所計算的 h=a／h=b 接受扇區是完整 `A_a,A_b`，不是窄的
指定 `d_a,d_b`。其正值由凍結上游 `A_a>=2d_a>0`、`A_b>=2d_b>0`
取得；獨立重建與對偶輸出沿用此正確命名。

## 對偶重播的信任邊界

[dual_check.py](dual_check.py) 不匯入 scipy、pickle、求解器矩陣或凍結
Kempe 生成器。noncrossing 分割使用首 block 的 interval 遞迴；半色框
使用三個獨立 palette cosets；caps 則用上述逐邊完整重建。
它重新驗證 5951 個非負核心座標、36487 個非負完整軌道座標，以及
1585 個有號 span 座標的精確整數係數。數值 infeasible、time limit 或
浮點 dual ray 都不是本頁接受的證明；來源排除須以精確整數重播為準。

## 已通過的 132 列完整計數相消

**獨立整數重播已通過，來源子支排除。**
本線由不同 noncrossing 生成法重建的 36487 個 columns 與凍結 SHA
相同，逐項核對 [完整整數 ray](../geometry/orbit-farkas-certificate.json)
亦通過，見 [正常紀錄](dual-normal.log)。這不是數值 LP 狀態的採信。

最後證書的 signed-span 乘數全部為零；原七個正列及 `A_a,A_b` 的乘數
亦全零。所以上述 signed-span 審查是有效的旁支核對，**最終排除只需
完整 orbit 計數與選定短路見證正值**。

從 36487 個 columns 中，15693 個碰到已證空的核心格。對每個這樣的
column j，取其所碰半色框 h：`8 Z_i=0`，而該行是 β 的非負和，且
`B[h,j]>0`，所以 `β_j=0`。剩下正是 20794 個完整 columns。

完整 ray 在零格的 4290 個半色框行各放乘數 8；這只是把已知
`β_j=0` 回填成全 column 非負 slack 的記錄。真正使用的 live 半色框
乘數只有 132 個，64 個為 +1，68 個為 −1。記此向量為 η。精確核對是

```
每個剩餘 column j：sum_h η_h B[h,j] = 0；
每個 live 核心 i： 8 sum_{h:rowid(h)=i} η_h
                  = -16  若 i=5093 或 5100，否則為 0。
```

因此同一份完整計數系統 `AZ=Bβ` 給出

```
-16 (Z_5093 + Z_5100) = 0。
```

兩項都非負，故兩個完整核心 fibres 都空；然而原選定實際三邊路著色
給 `Z_5093+Z_5100>=1`，矛盾。全證只使用同一實際 F' 的完整著色與
實際分量，n 的所有額外原附件仍在其中。

這完成使用者指定的 `d_G(n)>=6` induced C11 殘支。與凍結 n=5
結果接合，原 J1 type III 的此種實際 n–L 三邊路不可能；其同一 12
簡單路長度必至少五。一般 J1/J2、其他長路分支及主存在性仍未因此
閉合。本線沒有新增 Lean 定理，也沒有構造或宣稱較小 bad。

[balance_check.py](balance_check.py) 另以本線獨立生成的 K，直接核對
reduction 的 132 列小證書，沒有經過 E/U 浮點矩陣；
[結果](balance-normal.log)為全部 20794 columns 精確相消，兩個指定
核心係數恰 −16，其他 5949 個 live 核心係數恰零。

完整 ray 的正常與 seed17 重播均通過；[四項控制](dual-checks.json)
及[三項指定控制](dual-requested-checks.json)全部拒絕竄改：刪活半色框、
加大正值係數、刪零半色框回填、加入未消除的 signed-span 係數、翻轉
活乘數符號、刪掉見證正項、漏掉一項 orbit slack。來源契約與證書的
適用性由本頁和 geometry 的全稱證明承擔；checker 驗證有限精確恆等式，
沒有將其包裝成新的 Lean 形式化結果。

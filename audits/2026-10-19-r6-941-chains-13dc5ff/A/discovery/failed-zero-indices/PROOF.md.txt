# A：同一 d_a 著色的完整互補分量型與最短路徑五輪

BASE `13dc5ff163045c85b5c82dde438eb5f275dab999`。逐項承接
[本來源契約](../../2026-10-19-r6-941-acceptance-13dc5ff/SOURCE_CONTRACT.md)
與它指定的全部上游附件、非邊、相異點、私有點、嵌入及全域最小性。
量詞只在原完整支持恰941的同一任意大小真來源；原框仍為 `(x,y,a,b,c)`。
以下沒有 matching 前提，也沒有把支持模型視為圖。

## 1. 同一份完整著色中的互補分量同時受限

固定原實際核心 `F=G-{b,p,h,x,y,r}`，框依序
`(a,n,R,L,q,c,s,v,w,t)`。固定前輪非空舊 `d_a` fibre 的任意一份
**完整**著色，連同全部私有點；使用前輪指定的同一完整 lift，故

```
a=c=r=h=0, b=n=s=t=1, q=x=2, p=y=3, {v,w}={2,3}.
```

前輪真來源分量定理給：`a1=0` 時 `(R,L)=(3,1)` 且 `R~q` 於實際
`F[{2,3}]`；`a2=0` 時 `(R,L)=(2,3)` 且 L 的實際 `F[{1,3}]` 分量遇
n 或 t。這裡的每個分量同時包含該份著色的全部私有點。

沿用已證的[三角化互補分量邊界定理](../../2026-10-19-r6-941-quotients-13dc5ff/A/PROOF.md#3-三角化給出的完整分量邊界分割)：
在一份完整著色中，同時記兩側二色誘導圖的所有接框分量。所得分割
noncrossing，同側相鄰框點必同塊；若 side 轉換為2m次，接框塊數恰m+1。
證明用每三角面的跨側邊中點線段，得到m條不交proper arcs；不接框的
閉圈不改變接框區域數，且同側區域逐面縮回同側誘導分量。這個論證
適用任意大小F，不限制內部分量數，也不把兩個不同著色的路徑拼接。

**新結論 A1。** `a1=0` 時，同一份著色的 `{0,1}|{2,3}` 接框分割只有
以下兩種；花括號各指完整實際分量與框的交集：

| 型 | 01側 | 23側 |
| --- | --- | --- |
| I | `{a,n,c,s,t}`, `{L}` | `{R,q}`, `{v,w}` |
| II | `{a,n,t}`, `{c,s}`, `{L}` | `{R,q,v,w}` |

因此 L 的01分量與框的交集**恰為 `{L}`**，可交換該完整分量而不動任何
其他框點；而 `a~c` 於01側，當且僅當 `{R,q}` 與 `{v,w}` 是兩個不同
23分量。它是同一份完整著色中的同時二擇一，沒有獨立選路。

理由：框side有六次轉換，共四塊；實際rim邊已把01側a,n,t接在一起、
c,s接在一起，23側v,w接在一起。R,q同塊後，noncrossing迫L單獨一塊。
四塊條件便留下表中兩型。兩種v,w顏色順序都給同一結果。

**新結論 A2。** `a2=0` 時，同一著色的 `{0,2}|{1,3}` 接框分割在每個
v,w順序下恰有七個必要型，完整表保存在
[certificate.json](certificate.json) 的 `actual_component_normal_forms`。
其中都有下列兩個較便讀的結論：

* 若 L 的13分量遇 n，R 的02分量與框的交集恰為 `{R}`。
* 若 L 的13分量不遇 n，它必遇 t，且 a,R 必在同一個02分量。

這裡框side轉換八次，總共五個接框塊；checker逐份列出所有noncrossing
分割，先保留全部實際rim邊，再施同一L分量的已證義務，得到7、7型。
這是原實際分量的必要分類；不宣稱每一型有真來源實現。

## 2. 三邊二色路徑恰迫原五度輪，不能草率升為五邊下界

**新結論 A3。** `a1=0` 的同一完整d_a著色中，如果實際23分量含三邊路
`R-U-V-q`，則 U,V 是兩個不同的原D10私有內點，色分別2、3，且

```
d_G(L)=5,   N_G(L)=(h,R,U,V,q),
```

原 `(h,R,U,V,q)` 是induced C5，L是接滿此五圈的唯一原五度中心。
三個原面為 `RLU,LUV,LVq`，加上原面 `hRL,hLq`，正好形成這個完整W5。

證明：R,q的原邊不存在；異色端點的23路長為奇數，故最短可能為三邊。
若有上述三邊路，induced C10排除U,V為其餘框點。原C5
`(R,L,q,V,U)`的有界pocket位於F內；L的全部core鄰點都困於其中。
完整原C5定理給空三角化或單一W5中心，兩種都保留。
W5使L的core度數只有3，與既有下界4矛盾。空五邊形的五種三角化中，
Rq為禁止舊弦；RV、Uq又分別同色，故唯一proper填片是兩弦LU、LV。
因此L的core度數恰4，且它只失原h一個鄰點，原度數恰5、完整link如上。
外五圈的hU、hV被原h完整star排除，Rq由induced C10排除，RV、Uq
由同份著色排除；所以該五圈induced。原C5例外正容許這個五輪。

**新結論 A4。** `a2=0` 時若同份13著色含三邊路 `L-V-U-n`，則U,V為
原私有點，色依序3、1（沿n-U-V-L），而

```
d_G(R)=5,   N_G(R)=(h,n,U,V,L),
```

外五圈induced、R是唯一五度中心。證明對原C5 `(L,R,n,U,V)`逐項重做：
LR、Rn是原rim邊，Ln是禁止弦，另一組同色弦也不能存在；唯一空填片
是R扇形，單W5因R的core下界4而排除。這是原同一圖的直接論證，沒有
把來源反射成另一張圖。L至t的三邊13路沒有這個C5分類，仍未排除。

所以23的R-q路、或13的L-n路，精確結論是「三邊且有指定原五輪，或
最短至少五邊」；**沒有證明三邊不可能**。checker保留五種空填片及W5，
不能把W5中間點core度3的結論錯用到可行的空扇形（中間點core度4）。

## 3. 完整C11介面仍容納四個短路徑邊界控制

為檢查A3/A4是否已可用原支持條件排除，按兩個完整五度star剝下L或R：

```
F_L=F-L,  rim=(a,n,R,U,V,q,c,s,v,w,t);
F_R=F-R,  rim=(a,n,U,V,L,q,c,s,v,w,t).
```

這是原實際三角化disk，保留全部其他原點、原邊及嵌入，十一點相異；
不要求新rim induced。先固定同一份完整F_L或F_R著色f，再枚舉被剝中心
z的四個色：L分支要求 `z notin {R,U,V,q}`，R分支要求
`z notin {n,U,V,L}`。每一個z固定後，原完整caps恰為

```
Left_z={(b,p,h): b notin {a,c,q,p},
                    p notin {a,q,n,h}, h notin {q,R,L,n}};
Right={(x,y,r): r notin {s,v,w,t,x,y},
                    x notin {c,s,y}, y notin {a,t}}.
```

全部原lifts是 `⊔_z ({z} × Left_z × Right)`，包括每個空集合。
Q1/Q2則固定同一z與同一右cap，分別用完整商條件
`b=n,R=q`、`b=n=L`及 `b notin {a,c,q}`。沒有把不同z、不同私有點
著色、不同候選的零列混合；不增添原星以外的邊。

[interface.py](interface.py)以標準庫整數重建全部7381個proper C11色軌道、
22143個互補色對H軌道、36487個完整分量交換columns。新rim不必induced，
三角化互補分割定理仍適用。從原完整三零列及分支 `a_i=0` 的非負完整
cap係數先證零格，再逐輪只用上一輪零格作完整交換覆蓋刪除：

| 分支 | initial live | 每輪刪除 | 最後live |
| --- | ---: | --- | ---: |
| 原L=5、a1=0 | 6289 | 843,722,333,347,206,63,6,6 | 3763 |
| 原R=5、a2=0 | 6289 | 818,566,229,147,74,13,14,2 | 4426 |

本節只算完整S4軌道的非負lift係數以判零；表中資料**不是**固定字面N。
四個A3/A4短路徑的字面d_a C11邊界（兩種v,w次序）全部未刪除，canonical
ids分別7217、7210、5030、5023，逐份列於證書。它們只是必要介面存活，
沒有內部圖、嵌入或全來源實現；沒有宣稱整個live集合有共同整數計數實現。
因此本輪完整此介面沒有排除短路徑五輪，不能借它證五邊路長下界。

本節沒有造出新較小圖，也沒有省接回成本；它是對明確原五度star分支
的任意大小必要介面核對。其他所有原來源短圈、最小性及度數仍有效，
本節未把它們從沒有內部點的邊界資料自動判為通過。

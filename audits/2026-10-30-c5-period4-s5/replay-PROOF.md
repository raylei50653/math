# 四輪獨立重播與完整外部的緩衝區

2026-10-30。此證書是有限真圖與有限歷史重播，不提供圖枚舉的完備性。
獨立程式為 [c5_period4_s5_replay.py](../../scripts/c5_period4_s5_replay.py)，
只使用 Python 標準庫，不 import 搜尋、來源、Kempe 或 buffer producer。

## 精確接合引理

固定完整原外部 O、同一份 proper 著色 c 及一個色對 P。
由原 B 的 O-距離取 A_r=O[{d≤r}]，界面 L_r={d=r}，r=1、2。
保留全部 O；界面固定依原頂點標號排序，不假設為環。
令 R_r=V(O)\V(A_r)，E_r=O[L_r∪R_r]。

在 P 誘導子圖內，把 O[R_r] 的每個實際分量 Q 換成一個輔助點，
該點接到 Q 在 A_r 的**全部原鄰點**；這些附件均在 L_r。
再接回 A_r 的全部原雙色邊。所得圖在 A_r 的分量分割，
恰為完整 O 的實際雙色分量限制到 A_r 後的分割。

紙證：任一 O 路徑按 A_r 與 R_r 的連續片段分開，每段遠端片段皆在一個 Q，
可換成通過其輔助點的兩邊路徑。反過來，通過一個輔助點的兩個附件，
可用同一 Q 中的真路徑接起；串接後得到 O 中的 walk，刪去迴圈即得路徑。
兩向均使用同一份 c；沒有從別份完整著色取路徑。

所以五步 root 分量在 A_r 的成員可以用這個增廣圖精確恢復。
交換之後必須重算 A_r 的雙色分量、所有 Q 與其附件；前一時刻的重接資料不能沿用。
只保存 A_r 著色或 L_r 著色，均不能自行恢復這個分割。

## 真四輪的必要資料

證書對一條 H 的週期四，保存同一 O 的四輪、每輪交換前及五次交換後的
共 24 份完整字面著色。每次交換以原 O 邊集重新 BFS，核對所選完整分量、
root、色對、框交集恰為指定 singleton，以及交換後全原邊仍 proper。
每輪 σ⁻¹ 作用於全部原外部頂點，不能僅正規化 B 或 buffer。
四個正規化完整著色必須兩兩不同，且第四輪後精確等於第一份。

24 份著色、全部六個色對與兩個 radius 都另重算上述接合。
因此 full-O 分量中，在 A_r 分裂而由遠端重接的每一事件均可直接核對。
H|B 回復沒有被用作任何 buffer 的回復條件。

## S5 的固定五環剛性

固定 G∈G_str 與刪除中心 v。令 C⊂O 為原 simple C5，v 所在的開側至少兩點。
若兩份完整 proper 著色 c,d 在 C 上相同，則在不含 v 的另一開側也相同。

紙證：S5 迫另一側至多一點。若為空則無事；若僅 q 一點，
原圖最小度至少五與 Jordan 分離迫 q 接到 C 的全部五點。
proper 著色迫 C 最多用三色；C 是奇環故恰用三色，q 的顏色唯一。
這裡使用的是 S5 的**原嵌入開側點數**，並使用 δ(G)≥5。
這個引理沒有證明週期四一定會產生這樣一條 C。

checker 對每條原 C5、每個四輪相位的 c 與 H²c 保存實際比較，
包括固定框、兩個原開側與對側差集；合法來源必滿足此蘊涵。

## Errera 負控制的實際結果

沿既有來源證書的原標號，刪除點為 16，B=(0,1,2,3,4)，
五個外側第三點依序為 (5,10,9,15,11)。
這五點構成原 simple C5 W。W 的兩側為
{0,1,2,3,4,16} 與 {6,7,8,12,13,14}；各六點，故違反 S5。

四輪 20 次交換全為真實完整 O 分量。完整 Kempe 分量有 100 份共同 S4 商態，
2,400 份字面著色，共核 1,000 份 quotient component actions；含三色框，故並未全封鎖。
證書保存全部商態、全部六色對的所有分量交換與一條三步的商逃逸路徑。
共同 S4 商是精確的：C5 每份 proper 著色至少用三色，所以作用自由，
每個商態恰 24 份字面 lift；任一全域色置換可由逐分量交換實現。

一層 buffer 的投影週期為二，兩層 buffer 的投影週期為四。
每一輪 H 都改變一層全部五個附件，但 H² 在一層完全回復。
H² 在第二距離層及第三距離層仍有差異；full-O 的四相位沒有因此被壓成二。
24 時刻與六色對中，一層／二層各核出 48 份真遠端重接紀錄。
這個數字按本次四輪快照計數，不是舊報告全部 100 態的重接計數。

W 在 c 與 H²c 上固定，對側差集為：相位 0/2 是 {7,12}，
相位 1/3 是 {7,8,13}。這是刪去 S5 後，固定五環仍可包住二步差異的直接負控制。
不能把它視為合法 S5 圖的局部週期四，更不是全封鎖分量反例。

## 獨立有限歷史核對

checker 不沿用歷史 producer 的展開函式，而從每步 stay/swap bit choices
重新枚舉 28 份單輪詞；核五條原邊的兩個附件詞、2,090 份完整四輪閉詞與 hash、
32 份共同 phase、可能附件重合、相容原附件邊、兩個完整 rim phase 及其無 cap 結果。
點歷史僅為實際分量歷史的必要鬆弛；不把 stay/swap bit choices 當成可獨立實現的交換。

# 五個共同原面的 S5 必要條件

2026-10-30。此文只給必要條件，既不假設有全封鎖分量，也不將逐點歷史的可行性當成實際 Kempe 可實現性。

## 同一原面與來源幾何

沿既有原 rotation 固定 `B=(b0,…,b4)`，`v` 為五度點；`w_i` 是原邊 `b_i b_{i+1}` 在 `G−v` 側**同一個原三角面**的第三點，所有下標模五。固定原嵌入，不能按時刻另選第三點或重新排列附件。

**來源引理 A（使用 δ≥5、S34）。** B 是 induced C5。每個第一距離層外點 x 的 B 附件只可能是單點，或一對相鄰 B 點。因為若 x 接兩個非相鄰框點，`v−b_i−x−b_j−v` 是原簡單 C4，兩條 B 開弧各有原點，在球面嵌入的兩側皆非空，違 S4。每個 w_i 均在 B 外，且只接指定二端；五個 w_i 兩兩不同。若相鄰邊共第三點，該點便接三個 B 點，其中有非相鄰二點；非相鄰邊共點也立即有非相鄰附件。這些是來源的拓撲限制，歷史相等並不能替代它們。

**來源引理 B（真正使用 S5 的外部三邊捷徑）。** 若存在原路

`b_i−x−y−b_{i+2}`，其中 x,y 為不同的 `V(O)\B` 原點，則

`C=(v,b_i,x,y,b_{i+2})`

是原簡單 C5。由原 v 星的輪轉，`b_{i+1}` 與 `b_{i+3},b_{i+4}` 位於其相反開側。因此 S5 迫含 `b_{i+1}` 的開側恰有該一點。這點不能向另一側接邊，δ≥5 迫它接 C 的全部五點，故

`x=w_i, y=w_{i+1}, d_G(b_{i+1})=5`。

特別地，`w_i−w_{i+2}` 不能是原邊：它與其端點的 B 附件構成上述捷徑，但迫兩個不同的 w 相等。也可直接用原 C5 `(v,b_i,w_i,w_{i+2},b_{i+3})`：一側至少含 `b_{i+1},b_{i+2},w_{i+1}`，另一側至少含 `b_{i+4},w_{i+3},w_{i+4}`，違 S5。這個排除依賴 S5，不能從無分隔 C3/C4 推出。

## 完整五面歷史

採 `A,B,C,D=0,1,2,3`、交換色對 `AD,BD,BC,AC,AD` 及全域正規化 `σ^{-1}=(2,3,1,0)`。一輪包含交換前與每次交換後共六個時刻。逐點可留色或受當步 transposition 作用，完整枚舉共有 28 個一輪詞。與兩個固定原框端點在六時刻都異色後，每個 w_i 僅剩以下兩詞：

| 原面第三點 | 一輪歷史 | 正規化後色 |
|---|---|---|
| w0 | CCCBBB / DDDDDA | D / C |
| w1 | CCCBBB / DAAAAA | D / C |
| w2 | BBBBBB / DAAACC | D / B |
| w3 | AAAACC / BBDDDD | B / A |
| w4 | BBDDDA / CCCCCC | C / B |

以上每個詞的逐時顏色及 successor 均在 JSON 逐列保存並獨立檢查；其數字表為：

```text
w0: 222111 -> 3 ; 333330 -> 2
w1: 222111 -> 3 ; 300000 -> 2
w2: 111111 -> 3 ; 300022 -> 1
w3: 000022 -> 1 ; 113333 -> 0
w4: 113330 -> 2 ; 222222 -> 1
```

每個同一 w_i 的正規化初色在兩選項間交替，因此四輪歷史恰由一個二元 phase 決定。這裡沿**同一原頂點**串接四輪，沒有每輪另選著色。`face-certificate.json` 保存全部 `2^5=32` phase assignments、所有五附件的 24 時刻歷史、相容的所有十對原邊以及可能的歷史重合。後者即使存在也不容許合併原點：來源引理 A 已要求它們不同。

每條真正原邊兩端必在全部時刻異色。對五條可能的相鄰 `w_i w_{i+1}` 邊同時施加此必要條件，完整環僅有兩份 phase assignments：

`(0,1,0,0,0)` 以及 `(1,0,1,1,1)`。

各 phase 的 0/1 依上述各行由左至右排列。一輪的五 w 顏色依時刻為：

```text
CDBAB, CABAB, CABAD, BABAD, BABCD, BABCA
DCDBC, DCABC, DCADC, DBADC, DBCDC, ABCDC
```

每行至少有一時刻五 w 共同用了四色。因此不可能存在一個原點 q 同時鄰接五 w 且在整輪中保持 proper。這個結論由上述兩行直接可核，不需 k≤3 cocycle，也不需把任意逐點詞當成實際單分量交換。證書另枚舉全部 2,090 個四輪閉逐點詞，核對兩份完整環都沒有相容的 q 詞，供交叉核驗。

## S5 的具體排除力與負控制

**必要條件命題。** 在本任務的 `G_str` 中，若某份完整 `G−v` 著色完成指定五步且每步框交集為指定單點，則五 w 的相鄰環至少缺一條原邊。等價地，至少一個原鄰點 b_i 度數至少六。

紙證：若五環邊俱在，這是由同一原面附件組成的原簡單 C5。含 v 的開側恰有 `v∪B` 六點：原十個三角面 `b_i b_{i+1} w_i` 與 `b_i w_{i−1} w_i`（後者由引理 B/δ5/S34 保證）填成環帶，加原 v 星填滿此側。另一側若無頂點，五環的三角剖分必有弦，而引理 B 已排除非相鄰 w 原邊。因此另一側非空，S5 迫其恰一點 q。δ≥5 迫 q 接五 w。但完整五面歷史表顯示有一時刻五 w 用全四色，矛盾。若所有 b_i 度五，原輪轉直接給所有 `w_{i−1}w_i` 原面；反向由引理 B 得每條環邊對應的 b_i 度五，故等價。

此命題排除一個具體來源分支，甚至不需四輪閉合；它沒有排除環缺邊時的週期四。真正使用 S5 的位置明確是外部三邊捷徑引理與完整五 w 環另一側的 singleton 強迫。

Errera 的第三點為 `[5,10,9,15,11]`，其原五環邊俱在；兩側分別有六原點，故不符合 S5。它確實有兩份上述 phase 之一的實際四輪回返；此回返的一個完整 Kempe 分量可逃逸。證書保存原圖、原面與 rotation，獨立 BFS 核對全部二十次完整分量交換及全域正規化，並保存每個原外點的完整四輪歷史。這個真填充在新限制下被排除的理由是**原五環兩側 6/6 違 S5**，不是短週期 cocycle，也不是把外側六點縮成一個無法著色的點。

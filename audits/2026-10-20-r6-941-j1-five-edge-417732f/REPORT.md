## 1. 一般五邊路的原幾何

承接一般r6／941來源、原框`(x,y,a,b,c)`、全域最小內點再最大邊數、
原p,h五度、原r六度、全部原附件與C3/C4/C5 pocket定理。
只取`N01232(Q1)=0`的J1分支，固定同一完整核心F著色的type III，
與一條實際12色簡單路

```
P=n–u4–u3–u2–u1–L，字面色1,2,1,2,1,2。
C=(n,h,L,u1,u2,u3,u4)。
```

原h側包含R。C的全部14條可能弦：6條同色禁止，3條會縮出已證不可能的
12色三邊路，nL是原非邊，4條違反h完整五度star。因此**原C必induced**，
不需假設其內部只有R或有界大小，也不先假設四個ui皆為舊框私有點。
此為任意大小同源紙面結論；詳[幾何證明](geometry/PROOF.md)。

若再要求C內部恰只有R，三角化與induced C迫完整W7，R恰七度；
四個ui皆接R，故由舊induced C10自動知其全為原私有點。
原九框`(a,b,q,L,u1,u2,u3,u4,n)`內部恰p,h,R，13個原面完整列出。
27條原外弦中26條由原短圈定理排除，僅a–u4可能，且

```
a–u4存在 ⇔ d_G(n)=5。
```

各ui的完整舊框接觸型依序4／6／6／5個，720個共同組合中112個不交叉。
刪同一組原點`{b,p,h,R,x,y,r}`，得到實際三角化十三圈核心

```
D=G−{b,p,h,R,x,y,r}，
rim(D)=(a,n,u4,u3,u2,u1,L,q,c,s,v,w,t)。
```

仍有11條必要可選框弦；**本輪不假設十三圈induced**。
原n、其所有額外鄰點與任意大小外側私有圖全部保留。

[幾何證書](geometry/certificate.json)另保留真C7二內點控制：R五度、Z六度，
所有局部C3/C4/C5條件及實際12五邊路成立。它是反對「五邊路直接迫W7」的
局部控制，並非完整J1來源，也沒有否定在更強全來源條件下排除二內點型的可能。

## 3. 殘餘語義如何與同源計數接合

一般來源上用X表示完整核心著色集合，a為具名實際完整分量交換，o為共同觀測。
攜帶原始／當前完整見證後，每步精確更新

```
r_next = r P_a D_o，亦即 R_next=T_a(R)∩J^{-1}(o)。
```

選定五邊路及type III是入口條件；若要求後繼仍具此型，必須另加實際篩選，
不能在每步重新選擇一條獨立可行的路或完整染色。觀測相同也不能補滿其fibre。

若當前殘餘為R，候選H某字面外列w的完整接回數仍可精確寫成

```
N_H^R(w)=Σ_{f∈R} |Lift_H(w;f)|。
```

它與全來源`N_H(w)=Σ_i cap_H(w,i) Z_i`有不同量詞。
全來源零值可限制其子集，但全來源正值與完整orbit守恆不能任意套到選路後R；
R通常不是完整交換orbit的聯集，也不保全域色置換。
核心交換與接回R的交換亦未必交換，必須逐份重新核對完整cap。
一般證明及所有負控制見[殘餘報告](residual/REPORT.md)。

一張沿hL接合W7與既有8點disk的真14點disk已從原邊重新枚舉：
11,088份完整著色、48,048份刪R核心著色，59,052個proper字面外列包含53,004個
完整空fibres，所有R-star lifts與整圖枚舉完全相等。
332,640次合法rooted交換逐一核對對合。
固定字面五邊路的兩份共同候選在往返交換中是

```
2 → 1 → 1，接著要求已淘汰分支的觀測則為0。
```

若消去往返動作而丟中途mask便錯回2；補滿觀測、跨monitor選見證、非法動作當loop
也各有具體負控制。另有完整cap重數1→0的原邊反例，說明不能假設接回與交換可交換。
此圖是局部真disk控制，**完整r6／941／J1來源not triggered**，不沿用cell95候選界，
也沒有取得一般壓縮或來源排除。

## 2. 先補 N1 的空支援與原圖預算

### 2.1 N-empty-separating：不用 one-sided 的空支援排除

**新引理。** 在本題原圖中，任一 mixed C 若 `N_B(C)=∅`，就與 Σ-criticality 矛盾。
不使用指定三列的身份。E3 的 one-sided N-empty 是本引理的一個情形。

若 G−C 連通，在同一原圖 G−C 取 z–w 原路 L，允许 L 經 B。
固定 G−C 的合法染色；其在 N(C) 上只有 z、w 的 pins。
同色時把 L 作一個 hub，異色時沿一條原路邊切成兩個連通、互斥、相鄰 hubs。
Hub 的同色要求只在其與 N(C) 的交集，不要求 L 內點同色。
完整 degree 四、拒絕 lists tightness 與 hub 原則排除 C 的局部拒絕。
故任一接點邊的刪邊新染色都能接回完整 C，違反該邊 criticality。

若 G−C 不連通，B 自己連通；原 H−C 的各分量都含 z 或 w。
所以某個 root 側 A 完全不碰 B。`A∪C` 與其餘圖只在另一 root r 接合。
T4 給原 G 至少一份完整四色染色；限制到 `A∪C∪{r}`，再用一次共同 S₄
可配上外部任意指定的 r 色。這份無框 appendage 能接回每份外部染色。
刪其任一非框邊不會新增 Σ，仍違反 criticality。

此證明不虛構避開 C 的內部 z–w 路，沒有把 separating C 收盾弧費用。
真正非相鄰 Σ-edge-minimal 控制仍缺，見 §7。

### 2.2 原 H 不能是 tree：純 Euler 預算

若原 H 是 k 點的 connected tree，完整私有 degree 和為 `4k+2`，
框附件數為 `s=4k+2−2(k−1)=2k+4`。因此

`|E(G)|=5+(k−1)+(2k+4)=3k+8`。

五邊外面的簡單 planar disk 上界為 `3(k+5)−3−5=3k+7`，矛盾。
故本題原 H 必有 cycle；不讀三列、T4 或具體 Σ。
這個限制針對原 G，不能拿 q-core 的 tree 替代原 H。

## 3. N1 主攻：`(2,2)` mixed 加 `(4,4)` core 整類排除

N1 有唯一 separating mixed C。它不可被保留兩 roots 的 core 省略；
原 unary≤2，全部拒絕列至多一個 root 省略例外。
本節不給 C 套 one-sided 盾弧。

**新引理 N1-22-44。** 若 C 的原兩側 incidences 為 `(2,2)`，
而任一拒絕列有兩-root `(4,4)` core，則本題來源不存在。

### 3.1 實際原 core 固定整個 C

[E3 nonadjacent §5](../c5_excess_two_e3/nonadjacent_notes.md#5-每列-q-core-的完整原省略分類)
與全 degree-4 實際分類給：core 是兩個頂點互斥 root triangles，
以一條直接原 bridge 相連，沒有其他 tails。因此整個原 C 精確為

`a—b—c—d`，`N_C(z)={a,b}`，`N_C(w)={c,d}`。

a、d 各有兩個實際框附件，b、c 各一個；這些 degree 包含原全部邊。
原 degree-4 飽和保留整份 C，沒有壓縮任意長 relation 來代替原圖。

每 root 的原 side 容量為三，而 core retained side 只有兩條 spokes。
「無 tails」排除任何 retained unary，所以原每側**只有**兩種：
三 spokes，或兩 spokes加一份 capacity-one unary；後者正是此次省略的 unit。
不能單憑容量三就推出這兩型，實際 core 的無 tails 是必要依賴。

原 unary side S_z、S_w 的 root degree 均三。固定任何字面 β，root list 有 slack，
連通 side 可貪婪接回，所以兩側各自接受全部框列。

### 3.2 三列迫 terminal 框 pair 為真框邊

若 a 或 d 的兩個 actual 框附件在某指定 q 同色，該 terminal 的 degree list 有 slack。

兩 sides 本來全收，拼回即讓 G 接受該 q，矛盾。

| --- | --- |
| 02、14 | q₃ |

因此 a、d 的框附件 pair 都必須是**實際框邊**。
[reductions.json](reductions.json)另保存十個 pair 的全部所選重色列，沒有逐 source key 分類。

### 3.3 兩個具名側各需三框邊

沿原 bridge bc 將 H 分成
`A_z={z,a,b}∪全部原 z-unary`、`A_w={w,c,d}∪全部原 w-unary`。
兩者原連通、互斥，且 `H−A_z=A_w`、`H−A_w=A_z`。
純拓撲盾弧引理 1 只需這些前提，不要求集合本身是原 degree-4 piece；
全 B-touch 又給 actual support 等於盾弧的全部頂點。
所以這次重新驗過前提後，可以收兩個**整側**的互斥盾弧；仍沒有給 separating C 收費。

每側的 support 至少三點。假設某側盾弧≤2，則其 actual support 恰為三個連續框點。

- 有 unit unary：它的原 support 至少三點，又包含在該整側的三點內，故完全相等。
  Unary 盾弧的內點不能被 terminal 接觸，迫 terminal 的兩框附件為三點的外端點。
  外端點非相鄰，與 §3.2 矛盾。
- 無 unary：root 的三條 spokes 恰碰這三点。B 加原三-spoke star 把 disk 分成三面。
  Terminal 的真框邊兩端都是 spoke 端點，同時屬於唯一對應的小三角面。
  原 `H−root` 連通（唯一 C 的剩餘 path 接另一 root 及其全部 unary），並避開 B 和這個 star；
  整塊只能落在該面，全部其他框附件只能碰該框邊兩端。
  加回 root 三 spokes，G 只碰三個框點，違反全 B-touch。

故 `|σ_Az|≥3`、`|σ_Aw|≥3`；兩個具名原 connected sides 的盾弧互斥，
得到 `3+3≤5`，矛盾。本引理使用指定三列，但不讀 q₂／q₄，也不逐 key。

## 4. N2：局部 diagonal 接回與共同盾弧預算

### 4.1 新引理 N-diagonal：只指定 N(C) 的局部 list 版本

對 one-sided degree-4 mixed C，若 actual support 包含於某條框邊 hk，
則對任何 proper β 及任何色 a，完整 C 可接回同色 pins `(a,a)`。

不能直接把它說成舊 B2 的完整外染色定理；此處先重述局部版本：
只給 `λ:N(C)→{0,1,2,3}`，不要求 λ 延拓成 G−C 的完整合法染色。
若局部不可接回，degree 四給 tight lists。外 hub bags 在 N(C) 上各見一色已足夠；
tightness 使每個 C 點在每袋至多一個鄰點，收縮保持原 degree 和 lists。
其餘袋點的輔助顏色不進 C 的 lists。
因此原 hub/Gallai／四條 tethers／K₅ 證明照用，沒有假造外部合法染色。
這正沿用[短支援 §4](../../docs/c5_short_support_singleton.md#4-三-hub-引理排除未見色接點數不設上限)
中不要求保留外部完整染色的輔助 hub 色論證。

具體取 `K=H−C`。它原連通，且每個 B∖{h,k} 框點都有 K 的原附件。
若 a 不等於 β(h)、β(k)，hubs 是 `{h}`、`{k}`、`K∪(B∖{h,k})`。
若 a=β(h)，hubs 是 `{k}`、`K∪(B∖{k})`；a=β(k) 對稱。
各袋連通、互斥、兩兩相鄰，在 N(C) 的交集各見一個不同 pin 色，故局部拒絕矛盾。

令 A_C(β) 是從**完整** R_C 的全部原 contacts 同時避色得到的 root compatibility，
本引理的精確結論是 `{(a,a):a∈[4]}⊆A_C(β)`。
它不是兩個 contact marginals 的乘積。

### 4.2 N2-short-no-unary：整類接受全部三色列

若兩份 original mixed 都短且沒有 unary，任何三色 β 的未用色 D
都避開全部原 root spokes。令兩 roots 都為 D，N-diagonal 分別接回
兩份 mixed 的整份局部 coloring，再在同一 β／D 色框拼回原 G。
故全部三色 β 都被接受，與三列拒絕矛盾；此子類整體排除。

更一般，若全部 mixed 都短，任一拒絕 β 必須滿足
`E_z(β)∩E_w(β)=∅`。這僅是必要條件；off-diagonal 的完整 joint 仍須保留。

## 5. N3：theta 排除全部 m≥3

**新純拓撲引理 N-theta。** 三個不同原 mixed 中，至少一份沒有 actual B-support。

各取內部在原 C_i 內的 simple z–w 路 L_i。三路內部互斥，不碰 B，形成嵌入 theta。
唯一含整段 B 的互補區，其邊界由其中兩路 L_a∪L_b 組成 Jordan cycle J。
第三路 L_c 的內點在 J 有界側。

關鍵是保留**整份原 C_c**：它連通且與 J 不交（roots 不在 C_c，另外兩路位於別的原 pieces），
故整份 C_c 在 J 有界側。B 在外側，任何原 C_c–B 附件都必穿越 J，不可能。
所以 `N_B(C_c)=∅`。不能只把 L_c 當成原分量來計算 support。

m≥3 時，刪任一 mixed 仍有另一份原 mixed 連回 roots，故全部 one-sided。
E3 N-empty 排除此空支援 mixed，與 criticality 矛盾。
因此 **m≤2，N3 的 `(4,5)`、`(5,4)`、原 `(5,5)` 全部排除**。
不使用 q₂／q₄，不需要逐 key，不依赖 N1 的未完成入口。

## 先登記的問題與來源

1. **長鏈與分支樹。** 每條樞紐樹邊配一個私有原三角形，兩端樞紐均接到其三點，
   構成原三角雙中心；各單元只在樞紐處相接。鏈取 4／12／24 單元，
   分支樹取 6／14／30 單元，原圖含端點四葉條件後分別為 21／53／101 與 29／61／125 點。
   三種固定色令兩端候選域相同、交於一色或互斥，檢查共同限制能否跨整條鏈／分支傳播。
   此樞紐接合限定為樹；不能把非共面的雙中心當任意可繞圈的平面二端元件。
2. **較長的跨區迴圈。** 裸原環 C_n 加兩個相反側中心，兩中心固定異色，
   取 n=9／10／25／26／97／98，共 11–100 點。偶環恰有兩份交替延伸；
   奇環無延伸，檢查兩兩交集不能閉合的長距離矛盾何時被消元發現。
3. **非均勻平面三角剖分。** 沿用既有生成器，取 30／60／100 點、seed 0／1；
   每張圖建立一份有實際完整見證的相容固定色，以及同一組非相鄰固定點的另一份色條件，
   共十二份固定色案例。後者先由獨立 DSATUR 搜尋判定；超限保留 UNKNOWN，不預設無解。

前兩族共二十四份具名原圖／固定色條件，第三族十二份，合計三十六份；
每份同圖比較既有約束引擎與交集模式，停用已知衝突捷徑及額外 C₅ 推導。
不修改求解規則，不擴大 C₅ 來源分類或其他研究線的結論。

## 驗證與停止條件

所有原圖逐份驗證平面性、原頂點／原邊／字面固定色及輸入 SHA-256。
結構族另用原構造的獨立精確 oracle：樞紐共同色與各私有三角的六種排列，
或偶環的兩份交替染色。小例與獨立逐原邊枚舉比對，大例以完整 scope 投影核對
每份消元記錄的候選域、輸入列及回填支援，區分全部解保留與只核對一份見證。
隨機族只以獨立搜尋／實際見證交叉核對，不宣稱已窮舉全部合法染色。

主引擎每模式最多 5,000,000 次檢查，沿用 100,000 列儲存界；精確 oracle
單次投影最多 100,000 列，超出須標明未完整核對，不可以空集代替。
主要指標為首次消元前的實際候選域、原圖解保留範圍與矛盾前消元數；
刪列數只作輔助，不把重複推理計為新能力。所有限制結果均為尚未判定。
正常及 seed-17 結果重播，保存來源快照及壓縮完整記錄；不計時、不作一般覆蓋宣稱。

### 長距離傳播與留下的缺口

| 同一原圖的具名條件 | 原圖點數 | 矛盾前消元：原模式 → 交集 |
| --- | ---: | ---: |
| 24 單元長鏈，兩端中心域互斥 | 101 | 98 → 0 |
| 30 單元分支樹，兩端中心域互斥 | 125 | 122 → 0 |
| 97 點原環，兩中心固定異色 | 99 | 95 → 95 |

交集能把兩端的共同限制傳過整條鏈／分支；這些較大圖不是加入互不相干的點來擴大。
125 點相交單色條件的分支樹仍有 `6^30` 份完整解，交集在第一次消元前
把每個樞紐縮為同一個單一候選，各私有三角同時排除此色；刪色數由 4 增為 183。
所有未固定點當時仍未寫色，最後才回填一份相容染色。

長奇環則明確顯示兩兩共同接口不足：每份局部雙色支援都存在，
但整圈無法交替閉合，交集沒有提前這項矛盾。後續值得研究的是保留跨多表的
共同迴圈限制；本輪尚未加入這種新規則，也不能由鏈／樹成功推成一般來源覆蓋。

### 大圖保留資訊的核對範圍

結構族的 [oracle](../scripts/four_color_larger_cases.py) 先對回實際完整原邊、
固定色與構造描述，再以樞紐共同色及私有三角排列，計算每個紀錄 scope 的
**全部全域可延伸色組**；候選域、每張輸入表、每個回填支援都須包含這些色組。
兩模式的所有結構族記錄均完整通過，無投影省略。
這是精確分解及有限投影核對，沒有逐份枚舉展開 `6^30` 等巨量全圖染色。
oracle 的小鏈／小分支及奇偶環另與獨立原邊枚舉、各三點投影核對；
修改原邊／固定色／描述的負控制會拒絕沿用 oracle。
無解結構例的「解保留」檢查為空真；其無解依據另為樞紐共同色與端點域互斥，
或固定雙中心迫出兩色奇環，不能把空投影本身當成新的排除證明。

三角剖分的十份可解案例只核對一份獨立原邊搜尋提供的完整見證，
包括它在所有已記錄候選域、輸入列及回填支援中的保留，與最終輸出的原邊驗證。
二份無解案例由獨立原邊搜尋窮盡判定；沒有用平面性或四色定理作 oracle。
這族沒有「全部解已枚舉保留」的聲明。固定點彼此原本不相鄰，
因此矛盾也不是直接放入一條同色固定邊。

首次消元前的原始刪色合計為 917 → 1,738；但無解案例的停止位置可能不同，
不能將所有計數差都算成新推論。重點仍是具名候選域及矛盾邊界的改變。

### 重播與信任邊界

全部原圖皆由 NetworkX 3.5 獨立核對平面性；完整輸入、字面固定色與 SHA-256 均保存。
凍結隨機參考判定另對回含固定色與未固定原圖的兩份雜湊，防止改圖後誤用舊判定。
原圖、約束表、固定色從頭到尾在同一原頂點次序與字面色框內接合。
有限結果不代表所有平面圖或所有更大圖都能由這些局部推理完成。

完整四色套件 134 項測試通過，其中本輪新增 14 項，涵蓋獨立原邊枚舉、
完整 scope 投影、改圖拒絕沿用、刻意刪除合法列／回填色的負控制，
以及投影預算不足時的明確部分核對狀態。
正常與 `PYTHONHASHSEED=17` 在同一凍結輸入及相同 Python／NetworkX 環境下，
摘要、輸入及七十二份壓縮完整記錄共七十四檔逐位元組一致。
十二份產生／測試來源的雜湊與 [來源快照](../artifacts/four_color_larger_structures/baseline-source/)
逐份核對；初版及前輪七小例的凍結記錄另行保留。

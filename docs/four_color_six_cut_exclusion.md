# 以 hub 輪圈排除非平凡六邊割

2026-10-29。接續[六跨邊的完整色型與同源換色義務](four_color_six_edge_cuts.md)
及[最小無解核心與小邊割](four_color_critical_obstructions.md)。
目前接續入口見[四色導覽](four_color_guide.md)。

**同日後續驗證。** [七邊割紙證與獨立重播](four_color_seven_cut_verification.md)
已排除本頁原七邊停止點，將同一最小性下的非平凡邊割下界提高為八。
本頁保留六邊證明與當時的七邊負控制；七邊論證及修正由後續驗證頁承擔。

**結論。** 假設存在裸平面不可四色染色圖，取全體這類圖中頂點數最少者 `T`。
則對任意頂點分割 `V(T)=X ⊔ Y`，

\[
 |X|,|Y|\ge2\quad\Longrightarrow\quad |\delta_T(X)|\ge7.
\]

本頁補上六邊停止點所缺的平面來源論證：只在**較小的 hub 收縮圖**補輪圈，
再於原側圖的一份完整染色中交換實際 Kempe 分量，取得邊界恰三色的完整染色。
這與既有 SIX-COMPRESSED 的固定二色側矛盾。原圖不必三角化，也不要求邊最小。
本結論是紙面證明；附帶 Python 核對有限色型與操作控制，沒有新增 Lean 證明。
七邊割由上述後續排除；932 可約性及一般平面來源義務仍未解決。

## 前提與沿用結果

`T` 是有限簡單無向平面圖，所有頂點可用色均為 `U={0,1,2,3}`，無固定色。
「最小」是對**所有裸平面不可四色染色圖**的頂點數取最小；因此任何頂點較少的
簡單平面圖均可四色染色，包括另加邊後的較小平面圖，不限於 `T` 的誘導子圖。
不使用四色定理本身作前提。

沿用上述兩篇的紙證：

1. 兩側各至少兩點的邊割至少六；至多三條跨邊總可用整側置換接合。
2. 若恰六條跨邊，兩側均連通。否則一側有至少兩個分量，每個分量至少四條出邊，
   共需至少八條跨邊。
3. SIX-COMPRESSED：交換兩側名稱後，`T[X]` 的所有「邊界至多三色」完整染色
   都恰用二色，另一側的這類完整染色都恰用三色；兩族非空。

跨邊仍按六個有序 incidence 保留。同一原端點可以重複出現。
下面的 hub 度數則計算**不同原端點數**，這兩種數量不可混同。

## 補證：最小反例的度數至少五

刪除度數至多三的點，染好較小圖後必有剩餘色可補回，故不可能有這種點。

若有四度點 `v`，依嵌入輪轉記不同鄰點 `u₁,u₂,u₃,u₄`。
由最小性取 `T−v` 一份完整染色。若鄰點至多三色即可補回 `v`；
否則依序將其色記為 `a,b,c,d`。

在同一份染色中，若有 `{a,c}` 路連接 `u₁,u₃`，便不可能同時有
`{b,d}` 路連接 `u₂,u₄`：兩路的色集互補，故頂點不交；第一條路加上
`u₁v,vu₃` 形成 Jordan 圈，將另外兩條 `v` 輻條分隔於兩側。
第二條路既避開 `v` 又不能碰到第一條路，無法接通兩側。

因此至少一組相對鄰點不在對應的同一雙色分量中。只交換其中一端所在的實際分量，
就使那兩個相對鄰點同色；另外兩種顏色不變，鄰界只剩三色，於是可補回 `v`。
矛盾，故 `δ(T)≥5`。這是本頁對裸平面全體最小反例的補證，
不把一般非平面無解核心原有的 `δ≥4` 宣稱提高到五。

## HUB-RIM：在較小圖補輪圈

固定恰六條跨邊的分割，將連通 `Y` 收縮為一點 `h`，刪 loops 並將平行輻條
只保留一條，得到簡單平面圖 `H`。它保留 `T[X]` 的全部原邊；
`h` 的鄰點恰為不同跨邊端點集合 `S_X`。
設 `m=|S_X|`，若 `m≥3`，依 hub 的輪轉次序列出
`v₁,…,v_m`。

在嵌入星形 `hS_X` 的薄正則鄰域邊界，沿相鄰兩條輻條補弧
`v_i v_{i+1}`（索引模 `m`），形成簡單輪圈 `C`。
具體而言，先取避開所有其他原點、原邊的星形薄鄰域，再將每個葉端的小邊界弧
收至該葉點。於是 `h` 及輻條在圈內，`T[X]` 的全部原邊在圈外或端點上。

**已有同端點原邊時仍另畫一份輪圈弧。** 原邊可能繞在別處，不能直接當作近 hub
的輪圈邊。拓撲上保留新平行弧與全部原邊，染色時取底層簡單圖；平行邊只重複同一個
異色條件。這樣既保有上述輪圈位置，也不丟失任何原側約束。

所得輔助圖的底層簡單圖有 `|X|+1<|T|` 點，故由全體最小性可四色染。
記一份完整染色為 `κ`。輪圈各點都與 `h` 相鄰，故 `κ(S_X)` 至多三色；
而 `C` proper，至少二色。限制到 `T[X]` 得到原側的一份完整 proper 染色。

此步只需一份較小圖染色，沒有假定所有原側染色均能延伸到補邊圖。

## HUB-THREE：由同一份染色取得邊界恰三色

**引理。** 在上述全體最小性、兩側連通、`|Y|≥2` 及 `m≥3` 的前提下，
`T[X]` 存在邊界恰用三色的完整 proper 染色。
引理不另要求恰六條跨邊；六邊的作用在最後與 SIX-COMPRESSED 接合。

取 HUB-RIM 的 `κ`。若輪圈已用三色，限制到原側即得結論。
否則輪圈只有二色 `a,b`，所以 `m` 必為偶數，且 `m≥4`；沿圈必交替為
`a,b,a,b,…`。另外兩色記為 `c,d`。

考察**同一份** `κ|X` 中的兩項連通命題：

\[
 v_1\overset{\{a,c\}}\longleftrightarrow v_3,
 \qquad
 v_2\overset{\{b,d\}}\longleftrightarrow v_4.
\]

兩者不能同時成立。若都成立，取兩條簡單原邊路；色集互補使它們頂點不交，
但它們全在輪圈外側圓盤內（在球面上看其閉包），卻連接交錯的四個圈上原點。
這違反 Jordan 分隔。路可以再經過其他同色圈上點，不影響分隔結論；
它們不能經過另一條路的端點，因那些端點的顏色屬互補色集。
若路另有圈上接觸，可在避開另一條路的小鄰域內將額外接觸稍推入圓盤內，
再套兩對交錯端點的不交路分隔論證；此微擾只用來證明拓撲不可能性。

若第一項不成立，只交換 `v₁` 所在的實際 `{a,c}` 分量。
`v₁` 變為 `c`，`v₃` 仍為 `a`，`b` 色邊界點不變；
邊界原本沒有 `c`，所以現在恰用 `{a,b,c}` 三色。
若第二項不成立，同理交換 `v₂` 的 `{b,d}` 分量，得到恰三色。
交換保留 `T[X]` 的每一條原邊及整側完整染色。證畢。

**見證契約。** 新染色可能不再滿足新增輪圈邊，亦可能與原 hub 顏色衝突；
hub 及新增邊已不屬原側問題，這不影響結論。所需且已保留的是
`T[X]` 全部原點、原邊及同一份染色的一次實際分量交換。
本引理不是任意指定邊界的延伸定理，也沒有拼接不同染色的 Kempe 路。

## SIX-EXCLUDE：全部不同端點數分支

假設有非平凡六邊割，取 SIX-COMPRESSED 的固定二色側 `X`。
令 `m=|S_X|`，其可能值只有一至六。

- `m≥3`：HUB-THREE 取得邊界恰三色的原側完整染色，
  仍屬 `C_X^{≤3}`，直接違反該族全部恰二色。
- `m=1`：任何完整側染色的邊界只有一色，已違反同一結論。
- `m=2`：記兩個不同端點為 `u,v`，分以下兩支。

若 `X={u,v}`，由 `δ(T)≥5`，

\[
 |\delta_T(X)|=\deg_T(u)+\deg_T(v)-2\mathbf1_{uv\in E(T)}\ge8,
\]

與六跨邊矛盾。這也涵蓋原端點多次出現的情形。

若 `|X|≥3`，考慮

\[
 A=T[X]+uv,\qquad B=T[Y\cup\{u,v\}]+uv.
\]

兩圖均為簡單平面圖。對 `A`，由兩端各有跨邊及 `Y` 連通，存在內點全在 `Y`
的 `u−v` 路；刪去其他 `Y` 邊後，將該路收縮到一條邊，即實現新增的 `uv`。
對 `B`，使用連通 `T[X]` 的 `u−v` 路，刪去其餘 `X\{u,v}` 並將路收縮到一邊。
若 `uv` 原已存在，就不必增邊或收縮。兩者都保留其應有的全部原邊。

又 `|A|=|X|<|T|`，`|B|=|Y|+2<|T|`，故都有完整四色染色。
邊 `uv` 迫使兩份染色都在 `u,v` 取不同色，可用一份整圖色置換將 `B` 上的
這兩個**有序**顏色對齊 `A`。沿 `{u,v}` 接合後，所有原點、原邊都被覆蓋：
`X\{u,v}` 沒有任何通往 `Y` 的原邊。於是得到 `T` 完整四色染色，矛盾。

全部分支排除，故非平凡六邊割不存在。合併既有至多五邊排除，得到下界七。
原 SIX-KEMPE 四項鎖定也可直接給出 HUB-THREE 中兩條互補路的矛盾；
這裡採構造三色見證的寫法，將來源／交換／回填對象逐一說清楚。

## 七邊的原停止點（後續已排除）

七條跨邊、兩側邊界均恰三色時，不能再套六邊的固定二／三色方向。
具體完整型為

\[
 a=0001112,\qquad b=0120120,
\]
\[
 F=\{0,1\}\times\{0,1,2\}\ \cup\ \{(2,0)\}.
\]

禁格包含完整 `2×3` 矩形，故沒有合法整側置換，儘管兩邊均用三色。
兩邊 incidence 重數分別為 `3+3+1` 與 `3+2+2`。
HUB-THREE 只給三色存在性，並不排除此型。

更精確地，若七 incidence 的兩個完整色組均恰三色，且不能換色接合，
Hall 禁格至少含 `2×3` 或 `3×2` 矩形；全禁行／列因無四色而不可能。
為了兩側均三色，矩形外至少還需一格。總共只有七 incidence，
因此恰為矩形加一格：該格在第三行（或第三列），且另一座標在原三色集內；
全部七格互異。這是七邊三／三色失敗的完整有限形式；當時尚無全族來源排除，
其後由[雙側一步換色與 Jordan 分隔](four_color_seven_cut_verification.md)完成。

同樣須防止把單對障礙當作最小來源：兩排七點、七條直立跨邊，兩排各連成路，
上排四條同色相鄰邊各細分一次，得到18點23邊真平面圖。
上排用 `0001112`、細分點皆2，下排用 `0120120`，兩份完整側染色不能置換接合。
但保留上排、將下排改成 `1210201`，便得到整圖合法三色解。

當時的下一個窄義務是在同一最小來源、同一有序七跨邊上，約束所有恰三色完整側染色，
排除上述「矩形加一格」的全族阻擋，或給出另一份嚴格較小裸平面無解圖。
單對七格障礙、端點重數、獨立雙色路及有限型表本身都不完成此義務。

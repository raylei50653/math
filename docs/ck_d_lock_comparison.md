## 同一有序環、完整接受集與剩餘義務

令 `R=(r₀,…,rₖ₋₁)` 是指定次序的原邊界環，`Uₖ` 為其 proper 四色指派在
**共同** `S₄` 作用下的全部等色型。只取色名商，不取環的旋轉或反射商。
裸色域的內側構形為 `P`，含全部原邊及私有內點。定義

\[
F_P(c)=\{\kappa:\kappa\text{ 是 }P\text{ 的完整 proper 染色且 }\kappa|_R=c\},
\qquad A(P)=\{c\in U_k:F_P(c)\ne\varnothing\}.
\]

每份列使用一組固定的字面色，完整 fibre 的定義也固定該列；換色只以同一置換作用於整份染色。
計算 `A(P)` 時不省略原附件，不以單點支持代替接口，不將不同 boundary 列的見證拼接。
逐邊原圖枚舉與完整約束消元若都正確，只會給出同一個 `A(P)`；求法的改變本身沒有
加入關於未知外側的新命題。

假想最小反例刪去私有內點後，較小外側由最小性可染，故其實際環關係 `S` 非空。
若原圖仍無解，必有 `S∩A(P)=∅`。接續所需的是排除這樣的**實際外側**，
不能把某一列有內側延伸，或抽象外側選項存在，當成整圖可染。

## 布林 D 的完整分割與固定點

對環色 `c` 及一份互補色對分裂 `θ`，令 `Π(c,θ)` 是全部下列共同分割：

1. 每個 block 只含同一個色對的原環位置，且全部 blocks 覆蓋整個環。
2. 原環邊兩端若屬同一色對，必在同一 block。
3. 兩色組的 blocks **合在一起**不交錯：不能有循環次序 `a,b,c,d`，其中 `a,c` 在一個 block、
   `b,d` 在另一個 block。不是各色對分別檢查後任意拼接。

`O(c,θ,π)` 為任意獨立交換這些 blocks 所得的**全部**共同色型。
對當前阻擋集合 `B`，定義

\[
\mathcal P_B(c,\theta)
=\{\pi\in\Pi(c,\theta):O(c,\theta,\pi)\subseteq B\},
\qquad
D(B)=\{c\in B:\forall\theta,\ \mathcal P_B(c,\theta)\ne\varnothing\}.
\]

從 `B₀=Uₖ\A(P)` 反覆令 `Bᵢ₊₁=D(Bᵢ)`，有限次穩定為 `B∞`。
這是避開 `A(P)` 的最大一致集合：任何一致子集 `S⊆B₀`，若已含於 `Bᵢ`，其每份
支援 orbit 也含於 `Bᵢ`，故 `S⊆D(Bᵢ)`。歸納得 `S⊆B∞`；反向 `B∞` 自己就是一致集。
`B∞=∅` 因而排除每份非空實際外側阻擋。`B∞≠∅` 僅表示 D 尚不能排除，
不證明此集合可由任何平面圖實現。

### 與古典 D 的定義對照

本頁比對的是 [Steinberger §3 的頂點 signed-path-arrangement 定義](https://arxiv.org/pdf/0905.0043#page=11)，
不是只把 repo screen 改名成 D，也沒有宣稱與 RSST 的對偶程式逐條指令相同。

一份上述分割的各 block，在環上可能分成數段連通 runs。以每段首點的相對色給一個
二值符號，就得到 signed arrangement。給定 runs 後，互補色對在 run 的循環次序中交替；
各 block 的符號記錄其中各段的相對首色。所有 fits 恰好是獨立 block 交換加共同 `S₄`
換色所生的集合，取共同色名商後就是 `O(c,θ,π)`。

反向，對一份能 fit `c` 的 signed arrangement，若一個 block 跨兩個互補色對，
可按色對拆細；跨色對首色本已不同，不額外限制 fits，而 block 內其餘符號關係保留。
拆細後各 block 都屬單一色對，且原有 noncrossing 與原環連接限制仍成立。
因此兩個表述的「存在一份完整支援集合包含於 `B`」條件相同，無須分割本身逐一雙射。

實作另用獨立 restricted-growth 分割生成器，及「每個 `Vᵢ` 位於 `R−Vⱼ` 的單一連通分量」
這個原文拓撲條件，逐份比對 C₅–C₈ 的全部具體分割選項；不是只比較最後通過數。

## LOCK-NO-GAIN：由交換仍在 B 推出的鎖定已包含於 D

固定**同一份** `(c,θ,B)`。若 `𝒫_B(c,θ)` 非空，令

\[
E_B(c,\theta)=\bigcap_{\pi\in\mathcal P_B(c,\theta)}\operatorname{Eq}(\pi),
\]

其中 `Eq(π)` 表示同一 block 的原點對。這收集由目前全部容許分割都能保證的同分量關係，
包括同色原點的鎖定，而不是只讀某一份被挑中的支持見證。

**命題。** 加入全部這些鎖定，不會刪去任何 D 容許分割：

\[
\boxed{\{\pi\in\mathcal P_B(c,\theta):
E_B(c,\theta)\subseteq\operatorname{Eq}(\pi)\}
=\mathcal P_B(c,\theta).}
\]

證明直接由交集定義：每份容許分割原已包含每一對共同鎖定。若容許族為空，D 已因該 split
刪除此色型，不需要另處理空族交集。對每輪重新計算鎖定仍成立，故最終固定點也不變。

這正涵蓋「若交換某分量會得到 `B` 以外的列，所以這些原點必須同分量」的推理：
不滿足該要求的分割，其完整交換 orbit 本已不包含於 `B`，已經被 `𝒫_B` 排除。
先禁止一批交換結果、再從中推出連通鎖定，是 D 同一個支援檢查的另一種寫法。

**此命題的界線。** 它沒有將 `∀θ∃πθ` 升為「三份分割可共同來自同一原圖、同一完整染色」。
若額外證明跨 split 的共同原邊、路徑交會或平面拓撲限制，而那些限制不是單 split
`orbit⊆B` 的邏輯後果，本命題沒有說它們無效。本輪沒有建立這種額外定理或增益見證。

**具體鎖定確實出現，但 D 已含。** 相鄰五度點的拒絕列 `010201` 中，
`r₁=r₅=1`。若一份實際阻擋外側染色中，兩點不在同一 `{1,3}` 分量，交換含 `r₁`
的分量便得到字面環色 `030201`。此列可用內點 `u=1,v=3` 補回，逐條原邊皆合法，
故真正阻擋必鎖住 `r₁,r₅`。這正是 D 已排除那些不含此連通的分割；重加此鎖沒有額外刪除。
全16個殘餘色型中，按「色型、split、同色原點對」索引，共有34份這類由阻擋而非
僅由原環邊強迫的鎖定，仍全部包含在 D 的容許族裡。未聲稱存在這樣的實際阻擋外側。

# 保留共同條件的交集與原環閉合

2026-10-25。接續[無衝突的保證與缺口](four_color_guarantee_gap.md)。
本輪先記構造及驗證範圍，再量測；優先消除回填前不相容組合，不以速度淘汰推理。
後續[部分輻條搜尋](four_color_partial_spokes.md)沿用同一精確查詢與接口傳播，
將九點固定色反例提前至零消元；本頁保留原鄰域搜尋批次的結果及來源快照。

## 構造

取實際原頂點 `h` 與不含 `h` 的有序原簡單環 `C`。對每個當前候選 `h=c`，
只在實際原輻條相鄰的環點排除 `c`，用既有原環前向／後向閉合推導。
這是支援查詢，不決定 `h` 的顏色；環的首點色與中心條件色都在整圈保持一致。

設 `L_c` 是該條件下滿足全部環邊、實際輻條及候選域的完整局部關係。
保留 `L_c` 非空的中心色；每個環點的支援對所有可行 `c` **取聯集**。
互斥條件分支不能取交集。另由每個條件的精確單點支援，導出

```text
P_(h,v) = { (c,d) : 存在同一份 L_c 完整延伸，且 v=d }。
```

另保存每條原環邊的二元投影，以及保留中心色的三元投影
`T_(h,u,v) = {(c,a,b) : 某份同一 L_c 延伸中 u=a,v=b}`。
環邊投影由相同中心條件、相同原環首點色的前向／後向狀態接合，閉合邊也保留；
不把不同條件或不同首點色混合。

這些是字面色框下的完整接口投影，二元最多 16 列、三元最多 64 列。把它們作為必要因子，
交回既有完整共同接口交集；交集再縮表及候選域，會重新觸發原環與條件原環，
直到整個流程穩定。原弦、原環外附件及其他原因子均保留。
這些表不物化 `L_c` 的全部完整染色列；逐表非空或兩兩一致不等於已取得
同一份共同見證，也不以局部非空宣布整圖有解。

## 搜尋及正確性邊界

先在每個活動原中心的實際鄰點誘導子圖中找有界基本環，保存原環次序與原輻條。
不依圖族名稱、預存答案或固定頂點號識別輪圖。候選域／活動點變動可重搜；
預設最多 128 份不同中心／原環，每中心搜尋最多 200,000 步，均計入主工作預算。
搜尋截斷只略過可選必要推理，不作完整覆蓋或無解聲明。
本輪自動搜尋的環點皆與中心有原輻條；純查詢 API 也可處理部分輻條，
但未聲稱自動搜尋涵蓋所有部分輻條構型。

任何原圖完整解的限制都屬於其對應 `L_c`，因此在每個導出接口中都有該完整
解的投影列。聯集支援及整列交集都保留所有完整解，加入這些因子不改變原圖可解性。
所有條件計算、精確計數轉錄及新增列的儲存檢查完成後，才提交該次域及因子變更；
中斷回傳 `limit`，不把部分條件結果當完整支援，也不提前填色。

新接口若已由某張現存完整表保證，就共用既有因子：將該表限制於本次準備提交的
候選域，再依同一有序接口投影；只有完整投影確實包含於新接口時才省略新增。
這是可逐列核對的邏輯蘊含，不是只比較單點域。後續精確消元仍保留此蘊含，
因此不用重複保存同一必要限制。既有接口若已受其他交集縮限，仍保留並更新，
不會因新的較寬查詢而擴回。

## 數學保障範圍

本節整理上述操作的一般紙面論證；下方「實際結果」仍是原批次的有限實作核對。
適用有限簡單無向圖、同一字面四色框及同一固定色條件，不要求平面性。
前提是當前候選域由可靠推理取得，所有原邊、固定色及其他原因子仍被保留；
局部查詢不能把外側附件的聯合限制自行改成互相獨立的單點域。

### 全部整圖解保留，空關係可靠否定延伸

先考慮消元前，令 `S` 為目前全部原因子與候選域的共同解集。
任一 `x ∈ S` 限制到原中心 `h` 與原環 `C`，必屬於 `L_(x(h))`。
因此 `x` 的各接口列必出現在相應完整投影中；加入必要接口不會刪去 `x`。
域的支援對可行中心條件取聯集，也保留 `x` 在各原點的色。

兩張表在完整共同接口上交集時，`x` 所選的兩列在該接口完全相同，
故均不會被刪去。反過來，操作只縮域、縮表或增加限制，且保留全部原約束，
也不會創造新共同解。所以每次完整提交的傳播均有

```text
S_before = S_after。
```

此為全部合法整圖解的保留論證，不限於已枚舉的96份控制解。
若候選域或精確關係表被排空，便可靠地證明 `S` 為空；有固定色時，
只否定該固定色延伸。查詢中斷不提交半份條件支援，`limit` 仍是未判定。
消元後則以[完整消元及回填不變式](four_color_guarantee_gap.md#完整消元的數學不變式)
對回同一原圖的全部解，不能直接把較少變數的關係當成原圖染色。

### 任意長度中心環的精確局部查詢

給定任意長度的原簡單環及環外原中心，`L_c` 只包含當前域、全部環邊與
實際輻條的限制。固定 `h=c` 後，沿環保留同一首點色及當前點色；
前綴狀態恰表示一份符合已走過環邊的共同路徑延伸，最後再核對閉合邊。
此歸納不依賴環長；詳見[原環遞推](four_color_local_information.md#任意長度裸環保首點與當前點的-16-種色對)。

因此完整查詢精確判定這份局部關係的空性、計數、單點支援，以及上文指定的
中心／環點二元、原環邊二元及中心／原環邊三元投影。這裡的「完整投影」
不是枚舉所有二／三點子集。四色時至多四個中心條件，各以至多16種首末色對
逐位置推進；精確計數的整數位數仍可隨環長增加。任意環長的正確性不代表
任意長輸入均能在現行預算內完成。

弦與外側附件仍由其他原因子負責；它們若尚有未傳入域的共同限制，
就可能使局部可行列無法延伸到整圖。故此局部查詢的非空不能作全域可解證書。
純查詢可處理部分輻條；自動搜尋仍只有前述有界鄰域基本環範圍。

### 共同三色域奇輪的任意大小家族

令原環長 `n ≥ 3` 為奇數，中心與每個環點都有原輻條；存在同一三色集合 `T`，
使中心與全部環點的當前域均包含於 `T`。對每個中心候選 `c`，環點皆只能用
`T \ {c}` 中至多兩色。沿奇環交替必在閉合邊同色，故不能二染，所有 `L_c` 皆空。

這給出任意奇數環長的紙面排除，不只十二點控制。每個核心點各接一片固定為
同一第四色的私有葉，即可實現這個平面圖家族；`n=5` 是原十二點例。
這證明指定固定色無延伸，不是說解除固定色後的裸輪圖不能四色染色。
若在首次消元前已找到該中心／環並完整完成查詢，且未遇工作或儲存中斷，
便保證零消元發現矛盾。現有搜尋上限不保證每份輸入都會提前找到這項查詢。

### 全域存在性的充分條件與未解界線

傳播穩定、每張表非空及兩兩完整接口一致，仍不保證全域共同解存在。
若完整因子（包含固定色與候選域）可樹形排列、覆蓋全部原約束與活動點，每個變數所在節點連通，
每張完整表皆非空，且相鄰表在完整共同接口的投影一致，就可逐層選取相容列構造共同解；
完整條件及證明沿用[樹形接合](four_color_guarantee_gap.md#可在完整消元以前取得的充分證書)。
現行求解器尚未輸出這項樹證書。全部候選域為單例並滿足所有原因子，
或完整精確消元成功，也各自提供充分條件；最後仍逐原邊及固定色驗證。

九點例只顯示現有有界搜尋與傳播未能在消元前排除跨區不相容，
不證明必須升到四元，也不證明所有二／三元方法皆不完備。
原中心及全部原二元邊仍被保留，原始染色約束本來就能精確表達整個問題；
「表達完整關係」與「現有傳播能判定其共同非空」是不同義務。
消去中心後只用低階接口投影替代原關係的反例，不能直接套成此法的不可能定理。

上述為紙面不變式及條件接合證明，沒有新增 Lean 定理，也不是整份 Python 程式
的形式化驗證。171項測試與四十例支持所測實作，不建立一般傳播完備性、
固定接口大小或一般速度保證。目前跨區義務與接續入口見[導覽停止點](four_color_guide.md#精確停止點)。

## 啟用方式

```bash
python3 scripts/four_color_lab.py solve graph.json --engine constraints --intersections --cycles --cycle-contexts --json result.json --html replay.html
uv run --with-requirements requirements.txt python scripts/four_color_cycle_context_experiment.py
```

Python API 使用 `solve_constraints(graph, use_intersections=True, use_cycles=True,
use_cycle_contexts=True)`；新模式須與交集及原環閉合同時啟用。
`cycle_context_max_contexts` 控制保存的不同中心／環上限，
`cycle_context_max_scan_steps` 控制每中心一次鄰域搜尋步數。
所有查詢與接口新增列另受主工作及儲存上限約束。

### 驗證界線

31 份來源快照與摘要 SHA256 及本輪完成時的程式一致。

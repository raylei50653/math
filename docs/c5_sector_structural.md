## 1. 連通內部與 induced 框圈引理

設有限圖 K 含指定簡單 induced cycle Γ，C=K−V(Γ) 非空連通。
則 K 平面，當且僅當 K 有以 Γ 為外邊界的 disk embedding。

證明：取 K 的平面嵌入，Γ 是 Jordan curve。C 的幾何實現連通且不碰
Γ，因此完全位於 Γ 的同一側。每條 C 到 Γ 的邊去掉框圈端點後，
也是不碰 Γ 的連通弧，且碰 C，所以仍在這一側。剩餘可能的邊只有
框圈上的邊，因 Γ induced，沒有 chord 可以藏在另一側。故另一側
完全無圖，Γ 是該面的邊界。在球面上把這個空面選成外面，得到 disk
embedding。反向由定義立即成立。證畢。

此引理不使用 degree、兩接點、染色或 minimality，也不要求 K 是
2-connected。使用標準 Jordan 分離定理；使用者提供的
[Nguyen–Cook 論文](https://arxiv.org/abs/1002.2954) 摘要陳述該定理，
論文本身研究 grid graphs 中的離散形式化。本處直接採用上述一般平面
論證，不宣稱已由該文或 Lean 形式化了本引理。

## 2. 831 的 proper 語義及 chord 排除

令框圈順序為 `(a,x1,x2,x3,x4)=(z,b1,b2,b3,b4)`，所有列使用至多四色。
在 proper 框圈列的域內：

```
Σ(K)=831  iff  Ext_K(a,x1,x2,x3,x4) ↔ (x1≠x3 or a=x2)
               對每個 proper 列成立。
```

若 x1=x3 且 a≠x2，proper 性使 a、x1、x2 三色互異；x4 不同於 a、x1，
故 x4 等於 x2 或是第四色。這恰是正規化的 01212、01213，即第 6、7 列。
反向立即核對。checker 在全部 240 個有標號列上重驗此等價。

831 也已迫使框圈 induced：下列接受列對每個可能 chord 都有同色端點，
若該 chord 存在便不可能延拓。

| 接受列 | 排除的 chord |
| --- | --- |
| 01012 | z–b2、b1–b3 |
| 01021 | z–b2、b1–b4 |
| 01202 | z–b3、b2–b4 |

因此對含指定 C5 的 831 實現，只要 C 非空連通，第 1 節引理即適用。
既定 degree／二接點類別的目標等價為：

```
Σ(K)=831 and E_B and E_C  =>  K 非平面。  （仍待證）
```

不需要再區分平面與 disk，也不因這個重寫而宣稱已排除其他四個目標。
條件相等公式僅對 proper 列成立，不能直接套到兩個開口列。

## 3. 可從拒絕列安全推出的必要連接

令 K°=K−{zb1,zb4}，只刪這兩條框邊，保留其餘框邊及全部內部接線。
E_B、E_C 正是 K° 在原 q 色框下 z=B、C 的延拓。
每份完整 proper 染色中，交換一個 maximal 雙色連通分量的兩色，仍是
同一張圖的 proper 染色。下面各項都是對**任意一份指定列的延拓**成立，
不需平面性、degree 或 minimality。

固定 A=0、B=1、C=2、D=3。

| 起始列／圖 | 必須存在的雙色連接 |
| --- | --- |
| `(A,B,A,B,C)`，K | A/D 分量連接 z 與 b2 |
| `(B,B,A,B,C)`，K°（E_B） | B/D 分量把 z 接到 b1 或 b3，允許同時接到兩者 |
| `(C,B,A,B,C)`，K°（E_C） | C/D 分量連接 z 與 b4 |
| `(0,1,2,3,2)`，K（proper 第 9 列） | 1/3 分量連接 b1 與 b3 |

前三項證法相同：若指定分量不碰表中的其他端點，交換包含 z 的分量後，
boundary 唯一變動是 z 變成 D。所得列 `(D,B,A,B,C)` proper 且被 831
拒絕。對 K° 的染色可重新加入兩條框邊，因新列在這兩邊也 proper，
遂與拒絕矛盾。這三項只使用同一個拒絕列，不應說成已利用完整八列接受。

第四項：若含 b1 的 1/3 分量不含 b3，交換後 boundary 為 `03232`，
proper 且正規化成被拒絕的 `01212`，矛盾。起始 `01232` 被 831 接受，
故至少有一份這樣的延拓。這條 b1–b3 路徑的內點不會碰其他 boundary
頂點，因那些頂點都染 0 或 2。

## 4. 同一份染色下的平面分離，以及尚缺的步驟

若 K 是 disk，取第 9 列任意一份延拓。上節強迫的 1/3 路徑 b1–b3
是一條 disk crosscut；框圈上 b2 位於它的一側，z、b4 位於另一側。
因此，在**這同一份染色**的 0/2 誘導子圖中：

```
b2 的連通分量同時不含 z 和 b4。
```

否則會有端點交錯、互不相交的兩條 disk 路徑，違反 Jordan 分離。
互不相交來自兩個色對 `{1,3}`、`{0,2}` 不相交，不需另行猜測。

這是一般的必要條件，卻還沒有與雙開口接受形成矛盾。
事實上，已知非平面正控制第 41 號在列 `01232` 恰有一份延拓：
內點 `(u,v,w,x)=(3,0,3,1)`，b2 的 0/2 分量只有 b2 本身。
**這張非平面正控制也通過了這個局部分離條件**，故不能將該條件當成
平面性的充分判準或 3903 的排除證書。

E_B、E_C 各自給出的路徑來自不同染色。proper 第 9 列的染色又是
另一列；不能把它們直接拼成同時存在、內部互斥的 K3,3 路徑。
下一個窄缺口是：能否以完整保留染色與交換歷史的論證，把雙開口接受
轉化成**同一份**第 9 列延拓中的額外連接，或找到另一個有共同 witness
的矛盾？目前沒有這個轉移引理，也未證明這條第 9 列路線必能奏效。
不預設所有 3903 實現都有既有控制的九條路徑，不擴大圖搜尋。

# Canonical shelling 的逐項驗證

2026-10-29。核對提議的第三個突破點；主契約仍由
[4CT導覽](4ct_guide.md#精確消元主線的研究契約)維護。

**裁決：幾何化約成立；共同解存在性仍 OPEN。** 固定平面三角化、外面與有向根邊後，
反向 canonical ordering 可以指定為消元序，使未消去部分一直是具有簡單外環的
二連通近三角化。這提供一種單環完整關係的表示，沒有證明任何固定寬度或非空不變量。

## 外部定理與必須修正的表述

對固定嵌入的簡單平面三角化 `T`，選外面 `v₁v₂vₙ` 與根邊 `v₁v₂`。
古典 canonical ordering 存在；令 `G_k=T[{v₁,…,v_k}]`，則 `k≥3` 時：

1. `G_k` 二連通、內面全為三角形，根邊留在簡單外環上。
2. `v_{k+1}` 位於 `G_k` 外側，其在 `G_k` 的鄰點是外環避開根邊之路上的一段連續區間。

本次查閱的原始研究來源是 Mondal，
[*Layered Polyline Drawings of Planar Graphs*, §2](https://drops.dagstuhl.de/storage/00lipics/lipics-vol357-gd2025/html/LIPIcs.GD.2025.34/LIPIcs.GD.2025.34.html)，
其中明列此定義及相應三棵樹；原始 dFPP 論文的
[出版頁](https://link.springer.com/article/10.1007/BF02122694)只讀到摘要，沒有把付費全文當作已核。
這是外部圖論結果的應用，不是本次新增的 Lean 定理。

逆序消去 `vₙ,…,v₄`，外環確實每次以一條原鄰點路替換一個外環點。
外環始終簡單，因而剩餘圖加其內面的閉包為圓盤；在球面上其外側閉包亦為圓盤。
已消去點均位於外側，跨越已／未消去兩部分的剩餘端點只在外環上。
已消去點的誘導圖也連通：由三角化的嵌入，除了 `vₙ`，每個非根點都有較高編號鄰點，
沿較高編號邊可走到 `vₙ`。這不表示該誘導圖本身就是一個二維圓盤或二連通圖；
「圓盤」應指上述由外環分出的區域。

全體頂點最小反例不因定義而自動為三角化。為證明 4CT，可先在同一點集上補邊取
極大平面擴充：若擴充可染，原圖也可染；若原圖不可染，擴充亦不可染。
這只保留所需的存在性反證，不是原圖完整染色集的等價變換。

## 精確的單環消元契約

令 `X_i={vₙ,…,v_{n-i+1}}`、`U_i=V(T)\X_i`，`B_i` 是 `T[U_i]` 的有序外環。
將所有至少有一端在 `X_i` 的原邊記為 `E_i^out`。定義完整關係

\[
 R_i(b)\iff\exists a:X_i\to C,\quad
 (a\cup b)\text{ 滿足 }E_i^{out}\text{ 的每一條異色條件}.
\]

所有 `E_i^out` 的未消去端點都在 `B_i`，故此式定義良好。
剩餘問題須同時保留 `T[U_i]` 的全部原邊及 `R_i`；不可用 `R_i` 單獨取代兩者。
對每份共同指派 `c:U_i→C`，它能延伸為 `T` 的完整染色，恰當且僅當
`c` proper 於 `T[U_i]` 且 `R_i(c|B_i)`。

下一點為 `x`，`B_i\{x}⊆B_{i+1}`，且 `N_T(x)∩U_{i+1}⊆B_{i+1}`。因此

\[
 R_{i+1}(b')\iff\exists t\in C:\quad
 R_i\big((b'|_{B_i\setminus\{x\}})\cup\{x\mapsto t\}\big)
 \land\bigwedge_{w\in N_T(x)\cap U_{i+1}}t\ne b'(w).
\]

這是原邊加完整舊關係的精確消元。對每列保存所有可用 `t` 作完整 fibre，
亦須保留舊關係的完整歷史；最後找到共同解後才回填。它不把高階因子轉成普通平面邊。
即使改用多個子表表示，幾何性質屬於整個處理區與其共同關係，
不表示任意子因子的 scope 自動形成一個原圖簡單圈。

## 有限重播與負控制

[獨立核對程式](../scripts/four_color_shelling_verification.py)以 NetworkX 3.5 產生候選序，
再直接從原嵌入的誘導輪轉重建每步面，核對二連通、單純外環、三角形內面、
已消去圖連通、全部跨邊端點覆蓋及連續鄰點區間。候選序提供的鄰點區間不作核對 oracle。

[報告](../audits/2026-10-29-four-fronts-verification-4476049/shelling.json)涵蓋
graph atlas 中4–7點的全部9張極大平面圖、正二十面體及5張雙錐圖：
共15例、113個剩餘前綴、98次外環替換，全部通過。
這些是有限幾何核對，不枚舉一般圖，也不核對新增 Python 求解器或新增 Lean。

特別地，取 `r` 圈的雙錐圖，選根邊為圈上一邊，外面第三點為一個錐頂。
逆序第一步刪該錐頂後，外環由3點變成 `r` 點。本次 `r=4,5,8,16,32` 均吻合；
此構造對任意 `r≥4` 成立，故單環性本身沒有常數環長界。

```bash
.venv/bin/python scripts/four_color_shelling_verification.py --out /tmp/shelling.json
```

既有 BFS 掃描的94.23%是特定條件下的訊息量實測；BFS序沒有維持上述面結構的保證，
不能作 canonical shelling 定理的證據。此幾何選序確實縮小了不變量的研究介面，
但仍須證明上述單環精確關係與剩餘原邊具有一份共同解；僅證每步保解會原樣保留無解。

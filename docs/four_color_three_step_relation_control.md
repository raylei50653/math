## 1. 來源、舊狀態與必要條件

一般來源類沿用原報告的 `S`：完整四色域、固定嵌入、雙五度中心、原圈
`C₀=(z,a,b,w,c,d)`、同側原外框 `C`、四條原頂點互斥附件
`a⇝A,b⇝B,c⇝F,d⇝D`。仍須保留消元次序 `(x₁,x₂,z)`、
全部實際 z 附件及原點身份，不預設有完整染色。

有限控制使用原報告的十七點單邊附件來源，z 額外鄰點恰為葉 e。
核心 `Q` 為九點 `(x₁,x₂,z,a,b,c,d,w,e)` 的全部原邊關係；
原 `C₀` 的八個三角面與 `ze` 均保留。兩側只改外框：

\[
C_{alt}=(A,s,F,t,B,u,D,v),\qquad
C_{good}=(A,s,B,t,F,u,D,v).
\]

比較之前先區分三種舊狀態，不把它們混稱完整共同關係。

| 舊狀態 | 完整保存內容 | 能否看到外框差異 |
| --- | --- | --- |
| `O_K`：三步核心狀態 | 每步 `Jᵢ,Rᵢ,Wᵢ`、有序 scope、完整空 fibres、核心尚存原邊；因此也有完整 `Q` 及其六點投影 | 不能；不含外框因子及輪轉 |
| `O_G`：完整剩餘問題 | `O_K` 加四條實際附件、外框與全部其他尚存因子、共享來源證書 | 能；兩個外框的原邊不同 |
| 原圈分量分割 screen | 指定真正原圈的完整接受表、每 split 的聯合非交叉分割與完整交換 orbit | 必須指定在哪一原圈、哪一側使用 |

原因子 ID 與來源 ID 仍各自保留；此處 `O_K` 相同是**有序關係內容**的比較，
不是聲稱兩份來源證書 ID 相同。主契約要求的推導證書仍含原 ID，不會被這個比較覆寫。

舊必要條件沿用私人支援 Group A、單邊容量、兩完整五輪圈、triangle anchor、
原邊 codegree≤2／跨步 scope≥4、接口原邊 proper。
原報告另核具名接口在加入 `ze` 前兩份完整 lifts 上的六對實際分量與三 splits 非交叉。
最後這項僅是兩份 lifts 的檢查，**不是**完整固定點存活證書。
本輪原樣重播該來源控制，不把上述局部檢查升格成完整 D。

## 2. 明定舊閉包，不以有限輪數冒充完整

**關係代數閉包 `C_alg`。** 從 `O_K` 出發，將 `Wᵢ` 視為完整 joined 關係及其空列索引，
允許任意有限次 natural join、任意座標存在投影、同 scope 交集、semijoin，
及兩側共同施用的色名置換。閉包是所有這類有限運算式的結果，沒有輪數截斷。
可額外加入任意一份兩側相同的字面 context；不同的 `C_alt,C_good` 不能偷偷當作相同輸入。
這是本輪相同性命題的精確對照，並非重新命名既有 D。

另實算 `C_proj={π_T R:T⊆(a,b,c,d,w,e)}`，其中 R 是核心完整六點接受關係。
64 張表共 6,833 列，包含空 scope；任兩張表在交集座標上的 semijoin 均不再刪列。
因包含 R 本身，這是該完整關係的全子集投影一致性固定點；
它只是 `C_alg` 的一個有限核對，不宣稱列出全部關係代數運算式。

**既有分量分割固定點。** 另在真正原圈 `C₀` 上，取內側兩中心完整接受關係 A。
只商共同 S₄ 色名，有 31 個 proper 框型、13 個接受型。令

\[
B_0=\operatorname{Pat}(C₀)\setminus A,\qquad
B_{n+1}=\{r∈B_n:∀s\;∃P∈\mathcal N_s(r),\ \operatorname{Orb}_P(r)⊆B_n\}.
\]

`𝒩_s(r)` 枚舉兩個互補色對的**聯合**非交叉分割；同色對原框邊的端點必同 block。
`Orb` 包含任意 block 子集的交換，以同一共同色名商正規化。同步刪除直到固定點。
實作用既有 `ck_kempe_obstruction.py` 的完整定義；它稱 repository component-partition
screen，與古典 D 的定義比對仍沿用該腳本的限定。

此控制具名 `PAIR-C0-D16`：18 個初始阻擋型經一輪刪掉 `010123,012303`，均在 split 1；
剩 16 型，接受 mask `4969575`、殘餘 mask `2075405200`。
這確實是完整固定點，且兩個外框來源共用它；沒有新規則排除這 16 型。
它比較的是**z 尚在原 C₀ 上時的內側雙中心**，不是十七點共同外側族。
消去 z 後 `(a,b,c,d,w,e)` 不是原簡單圈，不能把它硬當 C₆ 再套此 screen。

## 3. 三步完整核相同的紙證

寫 `y=(a,b,c,d,w,e)`，顏色值在公式中以點名簡記。令

\[
U(y)=\{0,1,2,3\}\setminus\{a,b,w\},\quad
V(y)=\{0,1,2,3\}\setminus\{c,d,w\}.
\]

核心完整 fibre 恰為

\[
K(y)=\{(α,β,t):α∈U(y)\setminus\{t\},\ β∈V(y)\setminus\{t\},
\ α≠β,\ t∉\{a,d,e\}\}, \tag{1}
\]

另須 `ab,bw,wc,cd` 全部 proper，否則定義 `K(y)=∅`。
這四條是三步後**尚存核心原邊**，不得漏掉，也不能將最後一張 R₃ 單獨冒充 K。

**完整核相同。** 兩個十七點圖的 x₁ 原邊 bucket 相同。歸納假設此前的派生因子相同；
下一點的全部原邊及派生因子亦相同，因此相同有序 join 的每列、每個可用被消去色都相同，
其存在投影及包括空列的完整 W 亦相同。四條附件與外框邊皆不含 x₁、x₂、z，
故從未進入這三個 buckets。核心尚存四原邊也相同，得到全部 `4⁶` 列的 (1)。
此證明處理全部字面指派，不是只處理原具名空列。

| 階段 | 有序輸出 scope | 非空／空 W 列數 |
| --- | --- | --- |
| 消 x₁ | `(x₂,z,a,b,w)` | 784／240 |
| 消 x₂ | `(z,a,b,c,d,w)` | 2,728／1,368 |
| 消 z | `(a,b,c,d,w,e)` | 3,052／1,044 |
| 加全部核心尚存原邊，完整 K | 同上，fibres 為 `(x₁,x₂,z)` | 732／3,364；共 936 份 lifts |

**閉包相同與保留。** 對 `C_alg` 的運算式結構歸納：相同輸入的 join、projection、
intersection、semijoin 與共同色名置換均相同；完整量化 fibres 逐指派相同。
故任意深度結果相同，並非觀察幾輪後猜測。任何只由這些狀態決定的同步刪列更新亦逐輪相同；
有限固定域上的刪除序列停止時，兩邊固定點相同。
這證明了指定合併／投影的**相同性保留**，沒有藉此提出新的平面不變量。

更一般地，固定所有會進入三步 buckets 的實際原邊與推導，改動不進 bucket 的外側圖，
上述論證仍成立。一般 S 若增加 z 的實際鄰邊，必須一起進 bucket，不能沿用固定 K 的式子。

## 4. 整個共同外側 context 的精確控制

令 `p=(A,s,F,t,B,u,D,v)`，`O_g(y,p)` 表示四條單邊附件與來源 g 的全部外框邊 proper。
十四點接口的**完整**三內點 fibre 為

\[
H_g(y,p)=\begin{cases}K(y)&O_g(y,p),\\∅&\text{其他情形}.\end{cases} \tag{2}
\]

證明只需把原邊分成核心邊與不含三個內點的外側邊；在同一指派上同時檢查。
所以在整個共同 context `O_alt∧O_good` 上，兩族所有 fibres 相同，空 fibres 也相同。
這允許完整共同 context 的 join／projection，不需從端點 marginals 拼接見證。

**反控制：完整剩餘問題可區分。** (2) 中兩個 O 不同，不能消去該差異。
精確 factorized 核對全部 `4¹⁴` 列的計數如下；未逐列展開 268,435,456 列，
重播使用所有 `4⁶` 核心列、所有 `4⁸` 外框列及四條附件的相容數，按 (2) 完整求和。

| 全部十四點接口 | ALT | 平面 twin |
| --- | --- | --- |
| 完整原圖解 | 1,924,992 | 1,913,472 |
| 非空 fibres | 1,499,520 | 1,488,000 |
| 空 fibres | 266,935,936 | 266,947,456 |

產物另存 ALT-only 與 twin-only 的十七點完整染色：各自在另一圖失敗於原邊 `Fu`、`Bu`。
這能攔截「兩份完整剩餘 CSP 相同」的錯誤宣稱。

## 5. 更外層投影控制，以及它丟掉的資訊

將九點核心全部量化，只留 C 的八個點，兩圖的 Boolean 接受關係都恰為全部 proper C₈ 色列。
此處兩表各自按其原 C 的循環位置比較；固定同一字面原點順序時，proper 外框表仍不同，
不是 `O_G` 的相等。圈位置的接受表相同也不代表完整 fibres 相同。

**紙證。** 固定任意四色 ports `(A,B,F,D)`。可選互異 p,q,r，使
`p∉{A,F},q≠B,r≠D`：三個候選集大小至少 2、3、3；任兩集聯集至少 3、三集合聯集至少 3，
故三個集合可選不同代表。也可直接先選 p；q、r 刪 p 後各至少二選，故可互異。
令 h 為第四色，取

\[
a=c=p,\ b=q,\ d=r,\ z=w=h,\ x₁=r,\ x₂=q,\ e=p.
\]

逐邊檢查，核心與四附件全部 proper。故任意 proper 外框色列均有延伸，與兩種 port order 無關。
兩邊各有 6,564 份字面 proper C₈ 色列、274 個共同 S₄ 型。
此處接受全體，故上述 obstruction screen 的初始補集已空；沒有可供新規則再刪的舊阻擋。

重播保存全部 256 份四 port 指派的**完整九點 fibres**，用索引指回同一份 936 色列清單，
每 fibre 大小 216–366。外框位置字 `01012012` 的 twin fibre 為 276 份、ALT 為 291 份。
因此不能由各自圈位置的 Boolean 表相等，推論完整來源 tensor 或歷史相等。
這個額外投影只作資訊流失控制；主任務的三步與延遲回寫規則沒有改變。

## 6. 對新附件限制的裁決與缺口

保留原 C、兩條原互斥路及同側證書的 P，對一般 S 及同來源 join／projection 的來源保留性，
仍由[原報告 §§2–3](four_color_three_step_source_invariant.md#2-可檢查性質-p-與來源證明)證明。
把這些證書附在完整關係族上會拒絕 ALT 的接線，但不能刪除它共用的 K：
平面 twin 已完整實現 K，且滿足 P。任何對所有指定平面來源有效的規則，
若只看 `O_K` 或 `C_alg(O_K)`，就必須保留此整份具名 `KERNEL-936/732`。
這是對本候選的不可區分裁決，不是所有含附件資訊的新規則均不可能。

缺口分兩層。若狀態只留生成表，缺的是尚存外框因子、原有序附件及共同來源身份；
若再投影成 Boolean 外框表，又丟掉完整 fibre／分量資訊。完整來源原邊與完整 fibres 本已足以
計算各份實際分量，所以**不是原始資料絕對不足**。目前缺的是從這些資料抽出並證明：
對每一共同 row／lift，同一原圖上的六對分量、原附件路徑及交換後的 lift 必須共同滿足哪個
跨列限制；以及一份通過相同來源範圍之完整舊閉包、但違反新限制的具名候選。
只保留一個輪轉標籤或各 split 分別有一份支援，仍未補足這個義務。

本輪沒有提出可通過正向驗收的新刪列定理。`PAIR-C0-D16` 仍存，`KERNEL-936/732`
不能排除，ALT 的來源排除不重計；停止擴大同核枚舉。
一般附件族的共同限制、來源覆蓋、共同解存在性與 4CT 仍 OPEN，無新增 Lean。

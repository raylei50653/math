# 四色傳播無衝突的保證與缺口

2026-10-25。接續[交集與原環閉合共同傳播](four_color_combined_cycles.md)。
本輪核對「未發現衝突」是否足以保證同一原圖、同一固定色條件有完整延伸；
主求解器不加入新推理規則，前輪凍結輸入、記錄及來源快照均保留。
此處保留發現缺口時的基準；後續[保留共同條件的交集與原環閉合](four_color_cycle_contexts.md)
另加入可選接口推理並比較同一原圖，不覆寫這裡的基準證據。
再後續的[部分輻條搜尋](four_color_partial_spokes.md)補上九點例的消元前判否，
仍不把傳播穩定當成全域共同解的存在保證。

## 保證的判定位置

令每張原因子／派生表為 `R_i`，當前候選域為 `D_v`。
真正要證明的是整個共同關係非空：

```text
S = { x ∈ ∏ D_v : 對所有 i，x 在 scope(R_i) 上的限制屬於 R_i } ≠ ∅。
```

每個候選域非空、每張表非空、每對表的完整共同接口一致，以及每個裸原環
各自有延伸，都是必要條件；一般不會自動推出 `S ≠ ∅`。
必須分清以下情況：

| 狀態／條件 | 可保證的內容 |
| --- | --- |
| 傳播穩定且未報衝突 | 目前推理未排空，尚不保證存在共同延伸 |
| 所有點候選域均為單例，且所有原因子在這些域下非空 | 單一候選向量已同時滿足全部原因子；可直接逐原邊及固定色驗證 |
| 完整精確消元全部成功，未遇工作／儲存限制 | 存在共同延伸，保存的完整回填表可構造一份 |
| `colored` 並通過全部原邊及固定色的直接核對 | 已有具體合法完整染色 |
| `limit` | 尚未判定，不能當成無解或成功證書 |

### 完整消元的數學不變式

設所有含 `x` 的因子為 `B_1,…,B_k`，其餘因子為 `Q`，有序接口為 `Y`。
以完整關係

```text
R(Y) = { y : 存在 x ∈ D_x，同時滿足 B_1(x,y),…,B_k(x,y) }
```

替換這個 bucket，便有
`∃x (Q ∧ B_1 ∧ … ∧ B_k) ⇔ Q ∧ R`。
這要求合併所有含 `x` 的因子，保存完整接口列，並為每列保留全部可用 `x` 色；
不把列拆成互相獨立的單點候選。逐步消到沒有變數而沒有空關係，便證明存在。
倒序回填時，後面已選的完整接口列仍在表內，故其非空 fibre 提供可相容的 `x`，
可逐步接回同一份完整染色。此論證不要求解唯一。

現行[求解器](../scripts/four_color_constraints.py)採用這個不變式，最後再逐原邊、
逐固定色核對；目前不是整份 Python 程式的形式化驗證，也未新增 Lean 定理。
2026-10-25後續：[完整消元完備性證明](four_color_completeness.md)補齊任意有限輸入的
終止、雙向判定、可靠傳播與倒序回填論證；本頁的局部穩定反例及凍結基準保留。

## 明確的平面反例：奇輪圖與固定葉

原頂點為 `0,…,11`。中心 `0` 接五環 `1–2–3–4–5–1` 的每一點；
另有六條私有葉邊 `(v,v+6)`，`v=0,…,5`。葉 `6,…,11` 全固定為字面色 `3`。
共 12 點、16 邊，平面性可直接由輪圖嵌入加懸掛邊看出。
本段使用程式字面色 `0,1,2,3`，播放器顯示為 `1,2,3,4`。

### 為甚麼局部檢查全部通過

固定葉使六個核心點的域同為 `{0,1,2}`。五張原三角形各保留三色的全部六個排列；
相鄰三角形共享邊的投影都恰好是六個異色對，因此完整接口交集無法刪除任何列。
其餘原葉邊只與三角形共用一點，單點傳播也已穩定。

葉的度數為 1，所以任意原簡單環都只位於六點核心。環只用共同三色域時必可染，
而三色置換對稱保證每個位置的每一色均有支援。
因此即使查遍**全部原簡單環**並反覆回饋其精確單點支援，也沒有新候選可刪。
此反例不依賴目前基本環搜尋的上限。

### 為甚麼整體確定無解

中心必使用 `{0,1,2}` 中某色 `c`。五個環點全部與同一中心相鄰，因此環上每點
都只能用另外兩色。但長度 5 的奇環不能二染，矛盾。
所以這份固定色條件無延伸；不是聲稱解除固定色後的裸平面圖不能四色染色。

缺的資訊是五張三角形必須共用**同一個中心色**。各表對另一張表都有支援，
並不保證能為整圈同時選出互相相容的支援列。

## 可在完整消元以前取得的充分證書

若全部因子可排列成一棵樹，且滿足：

1. 所有原因子與派生因子都在樹內；固定色及候選域也作為一元表納入，
   每一活動點都被覆蓋。
2. 每個變數出現的樹節點構成連通子樹（running intersection）。
3. 每張完整表非空，樹上相鄰兩表對完整共同接口的投影相同。

就能保證共同解存在。證明是任選根表的一列，再沿樹為子表選一列，
令它在父子共同接口上與父列相同。第三條保證能選；第二條保證子表與先前所有
已選表的重疊變數都已在父接口上核對，故不會在別處出現相矛盾的顏色。
逐點接完便是一份完整共同解，同樣不要求唯一。
若在消元途中使用這項證書，先取得活動點的共同解，再用原有完整回填表
接回已消去點；仍必須保留全部原始限制的來源。

這是約束網路的標準 join-tree 條件，參見
[Zhang 與 Mackworth 的原始論文 §2.3–2.4](https://www.cs.ubc.ca/labs/lci/papers/docs1993/mac-LaPPAI.pdf)。
「原圖看起來像樹」或「找得到基本環」都不是這三條的替代；現行求解器尚未輸出
此種樹證書。必要時可把多張表精確合併成較大的表，再尋找符合條件的排列；
合併可能增加接口與表格大小。

## 這個缺口可如何補強

對原中心 `h` 與其相鄰原環，暫時保留條件色 `h=c`，只在支援查詢中令環鄰點
排除 `c`，再檢查整圈是否閉合。中心僅保留有完整環延伸的 `c`；環點支援則對
所有可行 `c` **取聯集**，不能對互斥條件分支取交集。
這些是支援計算，不把試查的 `c` 寫成原圖的確定色。

在上述五輪例，每個中心候選都令整圈只剩同一兩色，所以三個條件分支全部為空，
能在消元前排空中心。這說明下一個具體可補的關係；本輪只作診斷與核對，
未把這項新傳播加入主求解器，也不聲稱它能補齊任意多表網路的缺口。

## 有限核對的預先範圍

主反例另配偶六環及解除中心私有葉固定色的控制；分別應有 0、6、90 份完整原邊解。
同圖比較交集／原環／已知衝突全開，及再啟用結構 C₅ 的兩模式。
另核對一份 9 點 21 邊的實際平面圖：來自原 10 點 seed-6 三角剖分刪點 3，
保留實際原 ID；固定 `0=0,6=3`。其全體四色解都強制 `c(0)=c(6)`，
故固定不同色無法延伸。不能把舊生成器的 `n=10` 元資料當成實際點數。

每份圖以原邊及字面固定色獨立全枚舉；可解控制逐份核對全部解在候選域、
輸入表與回填表中的保留。對穩定狀態枚舉全部原簡單環，另以直接列枚舉核對
精確計數及各點支援，不只重用動態環查詢。正常／seed-17 重播須逐位元組一致。
所有結果只作用於凍結原圖及固定色條件；新證據不改變其他 C₅／W7 研究線的停止點。

# 兩步消元候選的獨立核對

2026-10-29；來源基線 `4476049`。本頁核對原邊初始化、全部四色、先消相鄰兩點的候選；
沒有修改求解器或新增 Lean 定理。依據既有[有限域分解契約](four_color_bounded_projection.md)
及 [ColoringBoundedProjection.lean](../Math/ColoringBoundedProjection.lean)。

## 單邊瓶頸：成立，但原 anchor 表示沒有語義缺漏

消去 x，另一點為 y；假定唯一同時含 x、y 的原因子是異色邊 x≠y。
在同一份其餘變數指派 z 上，令 A(z) 為滿足所有其他含 x 因子的完整可用色集合。
保留 Group A 的意思是精確保留條件 A(z)≠∅，而非只記每張表各自存在某個 z。

對 y 的完整轉移為

\[
K(A)=\{b\in\{0,1,2,3\}:\exists a\in A,\ a\ne b\}.
\]

若 |A|≥2，K(A) 是全部四色；若 A={c}，K(A) 恰為四色去掉 c。
每張 Group B 子投影只交較少的 x 因子，支援 S 包含 A，故 K(A)⊆K(S)。
所以在滿足 Group A 的同一指派上，每張 B 表都只能排除同一色 c，或完全不排色。
若整個 y 桶空交，來自此 B 群的排色證書至多需要一張表；它不能提供兩個不同排色。
這是逐指派的排除證書定理，並非允許各表挑不同指派後合併見證。
若 A=∅，容量結論不適用：x 的另外四個鄰點分別取 0、1、2、3，四份三鄰點 B 表
會各排 y 的一個不同色。因此採用「每群至多一張 B」的新排程時，不能省去顯式 A。

既有 anchored 方案直接列出「anchor 加至多三個其他因子」，已由
`exists_anchor_iff_bounded_subfamilies` 證明精確；其全部 B 表合取也蘊含 A(z)≠∅。
故「省略顯式 Group A」不構成正確性錯誤。新點是另行顯式保存 A，利用群內相依性減少
第二步的冗餘候選；目前原型尚未實作這種排程。

在 K₂,₁₂ 先消 hub x 再消 anchor 葉 y，y 另有且只有一條原邊；此邊排至多一色，
上述 B 群排至多一色，故第二步在 A 下無新限制：候選 735,130 可由此證明省去。
代價須另計：若用未指定 anchor 的四因子方案顯式保存 A，第一步另有 C(11,4)=330 張
候選；也可對 A 再用 anchor 壓縮。這不是既有原型的實測加速結論。

## 三角形 anchor：成立，五度點為三張表

假定原圖含三角形 xb₀b₁，將三條原邊共同視為 Δ 因子。固定 b₀、b₁ 後，
若兩色相同，Δ 支援為空；若不同，x 有兩色支援，故統一上界為 t=2。
其餘 d−2 條 x 原邊任選兩條，與 Δ 一起投影，即有 C(d−2,2) 張四元候選表（d≥4）。
這由既有 anchor 定理直接推出，不要求平面性；輪圈嵌入提供實際三角形來源。
原有 b₀b₁ 因子可保留，合併進 Δ 後也不會增加原解。

五度點確為三張四元表，合取精確表示中心可回填；拒絕的是鄰點用齊四色的星形阻擋。
這裡不能把「用齊四色」混稱為 C₅ 關係 T₄=932，更不構成 932 排除。
獨立重播逐列核對 d=3,…,8，共 87,360 份原邊界指派。

## 維度下界：原邊來源定理成立；拒列數應為 24

現在額外限定：兩步開始於全部原邊因子，無固定色，各點域為完整四色。
令 S=N(x)\{y}、T=N(y)\{x}。分別令

\[
A=C\setminus c(S),\qquad B=C\setminus c(T).
\]

完整兩步投影等價於 A、B 均非空，且它們不等於同一個單色集合。
前兩條由兩側各自的 Group A／星投影保留；跨兩側的新阻擋正是：
存在三點 S₀⊆S、三點 T₀⊆T，兩者均用齊同樣的三色。
每個這種極小原邊來源的 scope 是 S₀∪T₀，故

\[
|S_0\cup T_0|=6-|S_0\cap T_0|\ge6-|N(x)\cap N(y)|.
\]

無分離三角形的平面三角化中，邊 xy 的共鄰點只有兩個面鄰點，因此這類跨步來源至少四點。
這是保留來源的投影表示定理，不能提升成「任意後續因子或條件化／semijoin 後不可能有低元限制」。
例如以下四元表固定 a=0、b=1、p=2 後即對 q 給出一元限制 q≠2。
任意非原邊因素、縮小色域及更多步消元也超出此定理前提。

等號時 S₀={a,b,p}、T₀={a,b,q}，唯一局部拒絕條件為

\[
a\ne b\quad\land\quad p=q\notin\{a,b\}.
\]

在完整 4⁴=256 份字面列中，a、b 有 4·3=12 種有序異色，p=q 有另外兩種色，
所以恰拒 **24** 列、接受 232 列；原提議的「12 列」有二倍計數差異。
這些數字是在該原邊來源上計算，尚未條件化其他剩餘原邊。

## 1. 精確來源與新增結論

沿用全部目錄外 disk-C5 圖中先最小化內點、再最大化邊數的完整來源 G，
原有序框為 B，完整 Σ 共同搬到 933／941。令 h=Σ_B(deg_G−4)。
在 h=3 的分支，原框邊 b_i b_(i+1) 的面第三點為 a_i；五個 a_i 與三個
只接一個框點的 y 組成具名 C₈，H 為此 C₈ 及其原內侧圖。
既有結論保證 C₈ 無內弦、H 內面三角化、deg_H(a_i)≥3、deg_H(y)≥4，
嚴格內點 degree≥5。

本輪對上游八項必要殘留全部證明

\[
\boxed{\deg_H(a_i)\ge4,\qquad\deg_G(a_i)\ge6\quad(i=0,\ldots,4).}
\]

因此 H 嚴格內側至少有六個五度點，且

\[
\boxed{h=3\Longrightarrow k(G)\ge14.}
\]

八項仍是必要條件殘留，沒有整項再排除；共同 h≥3、n₅≥9 不提高。
這是 **h=3 分支**的大小界，不是一般 k≥14，更不是 K≤13=K≤5。
沒有加入 N2、ε、edge-critical、Gallai 或計數錐猜想。

## 2. 三度邊界點的共同計數不等式

反設某個 a 在 H 中度三，兩個 C₈ 鄰點為 l,r，唯一內鄰點為 t。
由兩個原三角面 alt、art，t 同時鄰接 l,r。
固定其餘七個具名 C₈ 點的 literal 顏色，並令 l,r 同色 c。
對 H−a，依 t 使用三個其餘色中的哪一個，將完整 lifts 分成 z₁,z₂,z₃。
在 a 使用第 i 色時，延伸數恰為

\[
x_i=z_j+z_k\quad(\{i,j,k\}=\{1,2,3\}),
\qquad x_i\le x_j+x_k.
\]

這是同一原 H、同一固定外部指派下的完整計數式，適用任意內側大小。
將三個 literal 指派查回 normalized 列時，若索引重複必保留重數；
不把三份來源或不同色框的獨立計數接合。

## 3. 四十項完整條件排除

八份原來源契約各有五個具名 apex，共四十個 `deg_H(a)=3` 假設。
先從上游已證的完整必要支援開始，交替使用：

1. 三色計數不等式：若三項中只剩一個可能非零的出現項（重數為一），
   該項也必為零。
2. 同一 H 的可逆 Kempe 軌道計數：含已迫零座標的軌道權重必零，
   無可用軌道支撐的座標也必零。

其中 **38 項**已使原接受外列沒有完整內列前像，矛盾。
剩下 c04-941／a1 與 c07-941／a4，分別有獨立保存的精確有理分離證書：
在全部 91 個非零 noncrossing equality 向量上，`−y_01232` 恰等於
非負軌道項與上述非負不等式的總和，另加原必要零列項。
故 y_01232≤0，與原完整 941 必接受 `01232` 矛盾。
驗收使用 Python Fraction 精確核對，浮點 LP 僅用於發現候選。

這些證書作用於所有符合原來源上界的 H，不只否定八份已保存的選定向量。
原必要向量仍保留；本輪新增的是無三度 apex 的圖層限制。

## 4. 曲率推論、驗證及停止點

令 I=V(H)\V(C₈)。原三角化的精確曲率式給

\[
n_5(I)=6+\sum_{w\in C_8}(d_H(w)-4)
       +\sum_{w\in I,\ d_H(w)\ge7}(d_H(w)-6)\ge6.
\]

所以 |I|≥6，原 G 的內點包括八個 C₈ 點，k=8+|I|≥14。
由既有原面第三點公式，八個位置均有 t_(i−1)≠t_i；這不表示八個第三點全異。
五個 apex 全部原 degree≥6 不意味提高全圖 n₅ 下界；原三個 y 的度數
變動仍須按同一曲率式計帳。

```bash
python3 -B audits/2026-10-13-c8-apex-degree-45bc1c3/check.py --check
PYTHONHASHSEED=17 python3 -B audits/2026-10-13-c8-apex-degree-45bc1c3/check.py --check
```

獨立重算、負控制與固定小圖校準入口見隔離報告。證據層是新紙面局部引理、
沿用上游完備 Kempe／共同計數介面及新增精確有限證書；沒有新增 Lean theorem。

分量，h≥4 的一般來源與 K∞=K≤5 仍 **OPEN**。

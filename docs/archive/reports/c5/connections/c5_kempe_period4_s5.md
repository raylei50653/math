## 1. 精確命題與判定範圍

\(G\in\mathcal G_{\mathrm{str}}\) 表示有限簡單球面三角剖分，最小度至少五，
無分隔三／四環（S34），每個分隔五環至少一個開側恰有一點（S5）。
固定五度點 \(v\)，其原輪轉為 \(B=(b_0,\ldots,b_4)\)，\(O=G-v\)。
\(K\) 是完整字面 proper 四著色 Kempe 圖的一個連通分量；
「全封鎖」表示其中沒有任何著色在 B 上只用三色。

固定 \(X_0=\{c\in K:c|_B=(A,B,A,C,D)\}\)。五次交換的色對／根點依序為
\((AD,b_2),(BD,b_4),(BC,b_1),(AC,b_3),(AD,b_0)\)，
每次都交換**當下完整 O 的一個實際雙色分量**。
末態對整份著色作用 \(\sigma^{-1}\)，其中 \(\sigma=(A\ D\ B\ C)\)，得 H。
全封鎖假設確保每步分量與 B 的交集為指定單點，並使 H 成為 \(X_0\) 的置換。
待判定的是

\[
P_4:\quad G\in\mathcal G_{\mathrm{str}},\ d_G(v)=5,\ K\text{ 全封鎖}
\Longrightarrow \forall c\in X_0,\ H^4(c)\ne c.
\]

既有同源三角面證明及有限 F2 證書排除週期一、二、三及所有奇週期，
故此處 \(H^4c=c\) 在其前提下恰為最短週期四。本輪未重新生成既有 cocycle。

為檢驗較強說法，也在未假設封鎖的完整著色空間中使用**部分映射** h：
只在五步均有指定單點框交集時定義，末態同樣全域正規化。
合法圖中的 h 四週期僅反駁「S5 排除所有這類局部回返」；
還需另核該完整 Kempe 分量全封鎖，才反駁 \(P_4\)。

## 2. 五個共同原面與真正使用 S5 的限制

令 \(w_i\) 是原邊 \(b_ib_{i+1}\) 在 O 側原三角面的第三點，下標模五。
每個 \(w_i\) 固定為同一原點，四輪內不替換附件。

**附件引理（S34）。** 每個 \(x\in V(O)\setminus B\) 在 B 的附件至多為一點或一對相鄰點，亦可為空。
否則 \(v,b_i,x,b_j\) 是分隔四環，B 的兩條開弧各含原點。
因此五個 \(w_i\) 皆在 B 外、兩兩不同，各自只接 B 的指定二端。
這個結論沒有使用 S5；保留附件是否相同是推導它的前提。

**三邊捷徑引理（S5）。** 若存在原路 \(b_i-x-y-b_{i+2}\)，
其中 \(x,y\in V(O)\setminus B\) 是不同的原點，則

\[
x=w_i,\quad y=w_{i+1},\quad d_G(b_{i+1})=5.
\]

紙證：原簡單五環 \((v,b_i,x,y,b_{i+2})\) 的兩開側分別含
\(b_{i+1}\) 與 \(b_{i+3},b_{i+4}\)，由原 v 輪轉確定側別。
S5 迫前側恰為 \(b_{i+1}\)。該點不能越環接邊，最小度五迫它接全部五個環點，
故得到上述原面身份與度數。特別地，非相鄰 \(w_i,w_{i+2}\) 不得有原邊。
這是原圖短路限制，不是不同著色路徑的拼接。

**五面歷史。** 一輪六時刻的逐點「留色／受當步交換」有 28 個詞。
同時避開每條原邊二端的完整色史後，每個原 \(w_i\) 只剩兩詞：

| 點 | 一輪詞 → 全域正規化後色 |
| --- | --- |
| \(w_0\) | CCCBBB → D；DDDDDA → C |
| \(w_1\) | CCCBBB → D；DAAAAA → C |
| \(w_2\) | BBBBBB → D；DAAACC → B |
| \(w_3\) | AAAACC → B；BBDDDD → A |
| \(w_4\) | BBDDDA → C；CCCCCC → B |

同一 \(w_i\) 的正規化初色在兩選項間交替。因此 \(H^2\) 固定 B 與全部五個
\(w_i\) 的顏色；這**不**表示第一緩衝區或完整 O 在 \(H^2\) 下固定。
完整四輪色史由五個二元 phase 聯合決定，共 32 份。
[面證書](../../../../../audits/2026-10-30-c5-period4-s5/face-certificate.json)保存全部 24 時刻、
所有十對附件的逐時相容性與歷史重合檢查，以及全部 2,090 個四輪閉逐點詞的數目與雜湊。
逐點詞僅為實際分量交換的必要鬆弛，不聲稱每份可實現。

**可證的來源排除命題。** 在 \(G\in\mathcal G_{\mathrm{str}}\) 中，
只要完成一輪指定五步且每步框交集為指定單點，就必有

\[
\exists i:\quad w_{i-1}w_i\notin E(G),\qquad
\text{等價於}\quad \exists i:\ d_G(b_i)\ge6.
\]

紙證：若五條相鄰 w 邊全在，三邊捷徑引理迫每個 \(b_i\) 度五，
原面環帶加 v 星填滿 w 五環的一側，恰有 \(B\cup\{v\}\) 六點。
另一側不能空：三角化空五邊形必有弦，而非相鄰 w 原邊已被上引理禁止。
S5 故迫另一側恰為單點 q，最小度五迫 q 接五個 w。
五條 w 環邊在完整色史中相容只容許兩份 phase，五點各時刻顏色為

```text
CDBAB, CABAB, CABAD, BABAD, BABCD, BABCA
DCDBC, DCABC, DCADC, DBADC, DBCDC, ABCDC
```

兩行各有時刻用全四色，q 當時無色可給，矛盾。
反向若每個 \(b_i\) 度五，其原輪轉迫全部 w 環邊，故等價成立。
這個排除甚至不需四輪閉合；沒有排除 w 環缺邊的來源。
詳證與逐項來源控制見[五面論證](../../../../../audits/2026-10-30-c5-period4-s5/face-proof.md)。

## 3. 保留完整 O 的緩衝區與固定五環剛性

沿既有距離層 \(L_j=\{x:d_O(x,B)=j\}\)，取
\(A_r=O[B\cup L_1\cup\cdots\cup L_r]\)、
\(E_r=O[L_r\cup L_{r+1}\cup\cdots]\)，r=1、2。
接口為按原標號排序的同一 \(L_r\)，不預設它是簡單環。
所有歷史保留完整 O；沒有把緩衝區併入私有核心。

**實際分量接合引理。** 固定一份當下完整 O 著色及一個色對，
將 \(O-A_r\) 的每個實際雙色分量縮成輔助星，連至它在 \(A_r\) 的**全部原附件**，
再與 \(A_r\) 的原雙色邊合成，所得在 \(A_r\) 的連通分割恰為完整 O 分量的交集。
正向由全 O 路徑切成近／遠段；反向將每段輔助星路在同一遠端分量內展開。
每次交換後重新計算，不能沿用交換前的重接，也不能混用另一完整著色的路徑。
本輪對 Errera 的四輪六時刻、六個色對及兩種 buffer 共 288 份記錄逐份核此等式。

**固定五環剛性（S5）。** 設 C 是 O 中的原簡單五環，v 所在開側至少有兩點。
若兩份完整 proper 四著色 c、d 在 C 上逐點相同，則它們在不含 v 的開側也全相同。

紙證：若該側非空，S5 迫其恰有一點 q。q 不能向環外接邊，最小度五迫它鄰接
C 的全部五點。奇五環至少用三色，q 的存在又使其至多用三色，故恰為三色，
q 只有唯一的第四色可用。c、d 在 C 相同，q 必相同。空側則結論平凡。

應用至 \(c,H^2c\)：真正週期四的差異集
\(D_2=\{x:c(x)\ne H^2c(x)\}\) 非空，且避開 \(B\cup\{w_i\}\)。
若欲將其中的差異藏在上述五環後，該環必也含 \(D_2\) 的點。
**尚未證明一定能從 \(D_2\) 找到這種固定的原五環**；差異可以經較寬接口延續。
這是本輪從緩衝資料走向 S5 矛盾仍缺的步驟。

[兩輪差異的原附件接續](c5_d2_attachment_separation.md)已證：每個非空差異分量的
全部附件含一個至少六點的固定原簡單分隔環，因而排除至多五附件的差異核心。
合法 S5 的真兩輪前綴保存固定六環控制；它未封鎖、未四輪閉合，
故一般迫五環與週期四命題仍 OPEN。
後續[無弦六附件跨輪研究](c5_six_attachment_cross_round.md)補六附件等號與整個開側結論，
保存兩組差異、二十次交換及重新接合，並證首次指定步失敗時的條件逃逸；尚未迫出該失敗。

## 4. Errera 負控制與有限搜尋

Errera 的五個原第三點為 \((5,10,9,15,11)\)，恰形成原五環；
兩開側各六點。它的最短 H 週期四與全部二十次真交換由
[獨立重播證書](../../../../../audits/2026-10-30-c5-period4-s5/replay-certificate.json)保存並重算。
這個五環在 \(c,H^2c\) 下逐點相同，但不含 v 側仍有差異，
明確展示上節剛性若刪掉 S5 便失敗。其完整 Kempe 分量為 100 份共同 S4 商態，
即 2,400 份字面著色，含三色框，故**不是全封鎖分量**。

第一／二緩衝區各有 48 份實際遠端重接記錄（以本輪四輪六時刻、色對、完整分量計數）。
每一輪 H 雖恢復 B，兩種 buffer 都改色；\(H^2\) 在第一 buffer 已恢復，
第二 buffer 仍改色，而完整著色最短週期是四。
這些只是在 δ5／S34 圖上的負控制，不能作合法 S5 反例。
Errera 的真面鏈填充也繼續反對將 k≤3 cocycle 直接外推到四。

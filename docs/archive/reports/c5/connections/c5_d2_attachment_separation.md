# 兩輪差異的原附件與六點分隔下界

2026-10-30。沿用 [S5／週期四報告](c5_kempe_period4_s5.md) 的完整來源、
字面色框、全域正規化與實際分量交換。本輪得到**附件分隔引理**：
每個非空兩輪差異分量的附件包含至少六點的固定原簡單分隔環。
因此排除全部至多五附件的差異核心；沒有迫出固定五環，週期四仍 **OPEN**。
後續[六附件跨輪研究](c5_six_attachment_cross_round.md)補證等號時附件恰為原無弦六環，
且 Q 佔滿其一個開側；六附件分支的全封鎖四週期排除仍 OPEN。
[同源證書與重播](../../../../../audits/2026-10-30-c5-d2-separation/VERIFICATION.md)保存實際覆蓋範圍。

## 1. 前提與新增排除力

令 \(G\) 為有限簡單球面三角剖分，\(\delta(G)\ge5\)，滿足 S34、S5：
無分隔三／四環，每個分隔五環至少一個開側恰有一點。
固定五度點 \(v\) 的原輪轉 \(B=(b_0,\ldots,b_4)\)，\(O=G-v\)，
\(w_i\) 為原邊 \(b_ib_{i+1}\) 在 O 側原三角面的第三點。
這五點的原身份、互異性及 B 附件沿用上游附件引理。

先證一項比週期假設更一般的結論。取兩份**同一完整 O** 的 proper 四著色 \(c,d\)，
假定它們在 \(B\cup\{w_0,\ldots,w_4\}\) 上逐點相同；令

\[
D=\{x:c(x)\ne d(x)\},\qquad
Q\in\pi_0(O[D]),\quad Q\ne\varnothing,\qquad
A=N_G(Q)=\left(\bigcup_{x\in Q}N_G(x)\right)\setminus Q.
\]

**附件分隔引理。** \(A\) 全部逐點固定，且 \(G[A]\) 含一個固定的原簡單環 C，
將**全部 Q** 與 v 分隔，C 不等於 B，並且

\[
|C|\ge6,\qquad |A|\ge6.
\]

更精確地，C 的原邊可從「只刪 Q 後，含 v 分量面向 Q 的面邊界閉走」抽出。
A 本身、該閉走及 C 是三個不同物件。引理不假設它們相同、簡單，或大小有上界。
若 Q 是單點，立即得到其原度至少六。

應用時取 \(d=H^2c\)。全封鎖及真正四週期
\(H^4c=c,\ H^2c\ne c\) 保證 D₂ 非空；既有共同原面色史保證它避開 B 與五個 w。
故上述結論對 **O[D₂] 的每個分量** 成立，沒有只選一個小核心。
新增排除力為全部 \(|N_G(Q)|\le5\) 分支，包括附件重合、非簡單閉走的情形；
它不需要另外假定附件已形成五環。

## 2. 紙面證明與原 B 例外

若 \(a\in A\cap D\)，原邊會把 a 接入 Q，與 Q 是 D 分量矛盾。
故 A 全固定。又 Q 避 B，沒有 Q 點鄰接 v，所以 \(N_G(Q)=N_O(Q)\)。

只刪 Q，令 R 是 \(G-Q\) 中含 v 的連通分量，保留其誘導原嵌入。
**R 可含其他差異分量**；這裡沒有把 R 當固定區。
原路 \(v-b_i-w_i\) 都未被刪除，故 \(v,B,w_i\) 全在 R。
Q 連通且避 R，因而全部落在 R 的同一個面 f 內。
v 的完整原星及其三角面都保留在 R，故 v 不在 f 的面邊界上。

令 W 為 f 的完整面邊界閉走，沿原輪轉逐有向邊追蹤，允許重點與重邊。
每條 W 邊在 f 側的原三角面第三點必屬 Q：若該點不屬 Q，它鄰接 R，
便也在 R；該原三角面仍是 R 的面，不能是包含 Q 的 f。
因此 W 的每個頂點都原鄰接 Q，即 \(V(W)\subseteq A\)。
原邊 \(b_ib_{i+1}\) 的兩個原第三點恰為 v、wᵢ，都在 R，
故其兩側原面都保留；**W 不含任何 B 邊**。

將 W 按重點分解為原簡單環，取消立即回折的邊對。
從 f 內的 Q 點到 v 原星內鄰域取泛位置弧，避開 W 的頂點；
其與 W 的模二交數為一。故至少一個分解環 C 分隔兩端。
C 的邊都是 W 的原邊，沒有補弦；Q 連通且避 C，故全部 Q 位於不含 v 側。
這個抽環步驟使用平面面側，不以閉走長度或附件數冒充環長。

若 C 為三／四環，兩開側分別含 Q 點與 v，違反 S34。
若 C 為五環且含 v 側只有 v，v 的五個鄰點全須在 C 上，
其原輪轉迫 C 就是 B，與 W 不含 B 邊矛盾。
因此五環情形的含 v 側至少兩點；C 全固定，卻將 Q 差異隔在另一側，
直接違反上游[固定五環剛性](c5_kempe_period4_s5.md#3-保留完整-o-的緩衝區與固定五環剛性)。
所以 C 至少六點。證畢。

含 v 側至少兩點只在上述五環分支獲證；對一般較長 C 不附加此結論。
較長環的單點側可以有原弦，不能由 d(v)=5 推出 v 鄰接全部環點。

**六附件等號推論（2026-10-30 獨立補核）。** 若 \(|N_G(Q)|=6\)，上述 C 的六個點
已佔滿全部附件，且 \(G[N_G(Q)]=C\) 是原無弦分隔六環。
若有原弦，其所在側被切成長度至多五的兩個原子環；由 Q 連通或選含 v 子盤，
可取一個固定子環分隔全 Q 與 v。三／四環違 S34，五環違固定五環剛性，
唯一的含 v 單點側例外只能是 B，卻與子環含 C 的非 B 原邊矛盾。
此外無弦環每個非空開側的誘導圖連通，故 Q 就是不含 v 的完整開側，沒有自身側固定內島。
完整證明與另一組兩輪差異的適用範圍見[等號及整側引理](c5_six_attachment_cross_round.md#1-量詞兩組差異與六附件等號)。
這裡固定仍只指本次比較的兩份著色，沒有宣稱四時刻固定。

這裡沒有對 B 套剛性。B 的含 v 開側確實只有 v，且與 \(d(v)=5\) 相容；
排除該例外靠的是 R 保存全部五個原面第三點，使 W 完全不使用 B 的邊。

## 4. 真 S5 的六接口控制及缺口不能直接閉成五環

合法控制取上游保存的 `n17.ascii` 第 0 份原 rotation，中心 \(v=2\)，

\[
B=(0,1,7,8,3),\qquad (w_0,\ldots,w_4)=(5,6,14,9,4).
\]

它滿足最小度五、S34、S5。完整 O 的統一色向量次序為
`(0,1,7,8,3,4,5,6,9,10,11,12,13,14,15,16)`，兩端為

```text
c    = A B A C D B C D A C D A C B D B
h²c  = A B A C D B C D A C D B C B D A
```

這是同一來源上十次真實分量交換與兩次全域正規化，五原第三點全固定；
\(D=Q=\{12,16\}\) 是一條原邊。全部固定附件恰為原無弦六環

\[
C=(5,6,13,15,10,11),\qquad
\operatorname{side}_{\neg v}(C)=\{12,16\},\quad
\operatorname{side}_v(C)=\{0,1,2,3,4,7,8,9,14\}.
\]

沒有另一個固定原五環滿足剛性位置且包住差異：全部 33 個固定原五環中，
只有 B 的不含 v 側含差異，而 B 的含 v 側恰一點。
A 中唯一原簡單環就是上述六環，沒有可供縮成五環的原弦。

附件環缺口恰在原點 7、3 的 link：`6–13–14` 及 `9–10–4`；
其餘 link 為 `4–5`、`5–6`、`14–9`。
原 collar 是固定七環 `(4,5,6,13,14,9,10)`，不是五環。
S5 三邊捷徑仍只約束跨 B 兩格的原長三路；它沒有供給 `6–14`、`9–4`
或六環內的不存在原弦。這份來源與真實跨界分量表明：
**原缺口／捷徑限制加兩輪可行性，尚不足以迫出所需固定五環。**

控制有完整 ABACD fibre 8 份、完整 Kempe 商態 54 份／字面 1,296 份。
它不是全封鎖：初態交換 `(BD,{1,6})` 已可到三色框。
第三輪第 3 步的 `(BC,root=1)` 實際分量碰框 `{1,3,8}`，局部 h³ 未定義。
所以這是新引理六點下界的合法幾何／兩輪控制，
**不是原命題在全封鎖且四輪閉合前提下的反例**。

Errera 另保存四輪二十次真交換、12 份 ABACD fibre、100 份商態／2,400 字面態。
其兩種差異核心的附件也各六點，但更外層原 w 五環固定、兩側各六點，
並包住差異；剛性位置成立而 S5 失敗。完整枚舉在四次比較各找出一份這種五環。
它明確校準 S5 的使用位置，仍為 `S5=false`、非全封鎖的負控制。

## 1. 來源圖類與固定三步

來源類 `S` 是帶固定平面嵌入的有限簡單圖，包含下列具名資料；所有點域均為完整四色，
圖類定義不指定顏色，也不假定存在完整染色。

- 原簡單圈 `C₀=(z,a,b,w,c,d)` 包圍一個三角化圓盤，其內部恰有相鄰的 `x₁,x₂`。
  兩中心在全圖的鄰點恰為
  `N(x₁)={x₂,z,w,a,b}`、`N(x₂)={x₁,z,w,c,d}`。
- 另一原簡單圈 `C` 包圍整個 `C₀` 及兩中心。四個不同原 ports `A,B,F,D` 位於 `C`。
  有四條具名原附件路徑 `a⇝A,b⇝B,c⇝F,d⇝D`，位於兩圈間的閉 annulus，
  除預定端點外不碰兩圈，且彼此原頂點互斥。
- 其餘原點／邊及外側附件可以存在，但必須尊重同一嵌入與上述中心完整鄰域。
  `C` 的 port 順序不先寫入假設，正是待抽取的必要限制。

三步固定為 `(x₁,x₂,z)`。`z` 是內框 `C₀` 上的共同鄰點，並不要求位於外框 `C`；
消去 `z` 時須一起合併其全部實際外側附件，不能只處理兩中心送來的表。
最小有限對照取四條附件均為單邊，`C` 有八點，另有原葉邊 `ze`，共十七點。
更長框、細分附件及任意合法外側圖仍屬一般來源契約，不由有限例替代紙證。

內框的八個三角面可直接列為
`zx₁a, ax₁b, bx₁w, wx₁x₂, zx₂x₁, wc x₂, cd x₂, dzx₂`。
它們給出完整原輪轉／輪圈，而非兩張各自聲稱可實現的抽象中心表。

## 2. 可檢查性質 P 與來源證明

保留兩條具名原路徑

\[
 H_1=A\leadsto a-x_1-b\leadsto B,\qquad
 H_2=F\leadsto c-x_2-d\leadsto D.
\]

兩路原頂點互斥、除兩端外均位於 `C` 的開圓盤中。中心間的邊 `x₁x₂` 不屬於任一路，
共同鄰點 `z,w` 亦不屬於任一路；不能因整個來源連通便抹去這兩條具名路徑的身份。

**P（原附件非交錯）。** 沿同一有向原圈 `C`，兩路端點不得交替：
不存在循環順序 `A,F,B,D` 或其反向／換起點形式。

直接 checker 只需核原圈與原邊、路徑簡單性／互斥性／內外側證書，再比四個 ports 的循環位置。
它不求染色，不以「最後投影非空」定義 P；僅有不交替端點也不是來源可平面實現的充分證書。

**來源滿足 P（紙證）。** `H₁` 是圓盤內的一條 crosscut，與 `C` 的任一 `A`–`B` 弧
圍出 Jordan 分隔。若端點交替，`F,D` 位於此 crosscut 的兩側；
除端點外不碰 `C` 的 `H₂` 必與 `H₁` 相交，違反原頂點互斥及平面嵌入。
故來源類 `S` 的每份來源均滿足 P。證明不使用四色定理或任何染色存在性。

## 3. 合併與投影保留什麼

每個原因子附同一來源 ID、原點身份、有序 scope 與原邊 ID；共享的來源證書保存
原輪轉、`C₀,C`、兩條具名路徑及外側附件。派生因子另外保存子因子 ID、合併與量化次序、
完整 fibres。三步指定操作為

\[
 J_i=\Join\{R:x_i\in\operatorname{scope}(R)\},\quad
 R_i=\exists x_i\,J_i,\quad
 W_i(y)=\{t:(t,y)\in J_i\}.
\]

沒有包含 `xᵢ` 的原邊／派生因子繼續留在剩餘問題中。空的 `Wᵢ(y)` 亦須保存。

**限定保留命題。** 若開始於同一 `S` 來源，合併只組合同一來源的因子、投影不識別原點，
而原路徑／原框證書持續保留，則每個派生因子的共同來源仍滿足 P。

證明對推導歸納。原邊因子指回固定來源；合併聯集其原因子，但仍指回同一嵌入，
不會製造新的附件交點或改變原框循環序。量化只刪除關係座標；
`x₁,x₂,z` 在原路徑／輪圈證書中仍是原點，故不會把兩條原互斥路變成交錯路。
完整 `Wᵢ` 另外保證反向回寫使用同一份剩餘指派；這是語義義務，不能代替上節的拓撲證明。

本命題是**共同來源證書的保留**，不是任意兩個各自可平面實現的因子 join-closed；
不同來源、換框、識別 ports 或刪掉歷史附件後，都不能沿用此證明。
第三步後 `C₀−z` 不再是圈，當前因子 scope 也不必為圓盤邊界；仍檢查原 `C`，不畫假平面因子圖。

## 4. 具名阻擋 ALT-OUTER-17 與舊條件對照

保留上述完整內框、兩個五度中心與原葉邊 `ze`，取單邊附件 `aA,bB,cF,dD`。
改用外框

\[
 C_{\rm alt}=(A,s,F,t,B,u,D,v).
\]

十七點、二十八原邊。固定有序接口
`(a,b,c,d,w,e,A,s,F,t,B,u,D,v)` 為
`(0,1,1,0,0,1,2,3,2,3,2,3,2,3)`。
這是指定接口的試驗，不把固定色加入來源圖類。

令兩中心在尚未加入 z 的鄰邊前可用色為

\[
 U=\{0,1,2,3\}\setminus\{c(a),c(b),c(w)\},\quad
 V=\{0,1,2,3\}\setminus\{c(c),c(d),c(w)\}.
\]

同一 `z=t` 下的完整前驅 fibre 恰為
`L(t)={(α,β)∈(U\{t})×(V\{t}):α≠β}`。
本列 `U=V={2,3}`，所以 `L(0)=L(1)={(2,3),(3,2)}`，`L(2)=L(3)=∅`。
兩中心共同禁掉 2、3，原邊 `za,zd` 禁 0，`ze` 禁 1，完整三步 fibre 為空。

| 既有必要檢查 | 此阻擋為何通過 |
| --- | --- |
| 私人支援的 Group A、單邊容量 | 尚未加入 `z` 與中心間邊時的私人支援 `U,V` 非空；各中心單獨加入 `z=t` 後的 `U\{t},V\{t}` 亦非空。單邊傳輸仍至多禁一色；共同兩色排除來自兩中心的相鄰異色條件。 |
| triangle anchor `t=2` | `x₁x₂z`、`x₁x₂w` 及兩個完整原輪圈的全部邊均存在。前驅兩中心可合法取 `(2,3)` 或 `(3,2)`。 |
| 原邊來源的維度下界 | 中心邊共鄰點恰為 `z,w`，故既有跨步最小 scope≥4；全圖每條邊共鄰點均≤2。沒有偷加第三共鄰點。 |
| 已留在接口的原邊 | 全部不含 `x₁,x₂,z` 的原邊在本列都 proper，包括外框及四條實際附件。 |
| 給定完整前驅上的全部 split 非交叉 | 刪去尚待合併的單一原邊 `ze`，完整原圖恰有兩份內部 lifts `(2,3,1),(3,2,1)`；下表逐份檢查實際分量。 |

最後一列刻意在第三步最後加入 `ze` 前檢查；完整空 fibre 沒有完整染色可供分量檢查，不能作真空通過。
這不宣稱完整兩步關係接受 `z=2,3`；它恰應拒絕這兩色，完整三步也恰應拒絕具名接口列。
對兩份 lifts，六種雙色分量在同一外框上的非空 trace 均為：

| 色對 | 分量與原外框的交集 |
| --- | --- |
| 01 | 無 |
| 02、12 | `{A},{F},{B},{D}`，四個 singleton blocks |
| 03、13 | `{s},{t},{u},{v}`，四個 singleton blocks |
| 23 | 整個外框一個 block |

六對各自非交叉，三個 complementary splits 合併兩對 blocks 後也都非交叉。
故在**這個指定外框與兩份完整前驅**上，P 的拒絕不能替換成某一 split 的交叉拒絕。
這不是完整 Kempe／D 固定點存活證書；未計算完整 D 閉包，不聲稱超越既有 D 的停止裁決。

P 拒絕的是 `A-a-x₁-b-B` 與 `F-c-x₂-d-D` 的端點交替，與它們沿途用了幾種顏色無關。
這個共同原附件證書不能由各 split 各自通過或兩份局部輪圈證書拼出。
`ALT-OUTER-17` 因而沒有指定同側的平面來源；不是說它的裸圖無四色染色，亦不是說其禁色表只能來自非平面圖。

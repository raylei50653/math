## 2. 真正共同原圖公理與有限註記域

**完整公理 `A_src(R,a)`。** 註記 a 保存一份上述指定嵌入 H、全部原點／原邊身份、
完整 `Col₄(H)`（包括每列的全部／空 fibres）、每份完整染色 f 的六對**原頂點**分量
`Πₚᴴ(f)`（含孤立點及不觸框分量），以及每份分量子集交換的精確目標 f′。
要求 `R={f|C₀:f∈Col₄(H)}`，所有分量與交換均由**同一 H、同一 f**產生；
交換後另外四對從同一 f′ 重算。不得借其他 lift 的目標或分量。
H 的大小未有上界，故這是無限註記域。

**來源 soundness。** 每份指定平面來源刪去內側兩中心便得到一份 H，
取其完整染色、實際誘導分量及逐原點交換，必滿足 `A_src(R,a)`。
分量外原邊的另一端若在同色對，本就應在該分量內，故交換保持每條原邊 proper。
這不預設 H 或全圖有染色；空關係／空 fibres 也照存。
此來源定理不把 R 強行指定成待排除的 S。

現在明定有限放鬆。對一份字面 proper 框列 r，狀態

\[
x=(r,P_0,P_1,P_2),\qquad P_i\in\mathcal N_i(r)
\]

同時保存六對在**相同原 C₀ 點**的分量 traces：每個 Pᵢ 包含該 split 兩個色對的分割。
blocks 不空、互斥、涵蓋對應色對的全部框點；同色對原框邊迫同 block，
互補兩份分割聯合非交叉。分割域是所有這類集合分割，沒有圖大小界或任選代表。
有限域不是全部原分量的有限編碼，也不聲稱每個三分割 tuple 都可由共同 H 實現。

**公理 `A_∂(R,a)`。** a 是此有限域中的狀態族 X 及完整交換立方族，要求：

1. `π_C₀ X=R`，同一列可有多份狀態，不能預選每列唯一分量資料。
2. 對每份 `x∈X` 及每個 split i，存在一份由 Pᵢ 全部 block 子集 T 索引的完整立方
   `T↦x_T∈X`。空子集頂點為 x；頂點色列是 r 在恰好 T 中所有原框點的精確交換。
3. 整份立方都保留 Pᵢ 的兩份分割；另四對的兩份分割必在**同一目標狀態** x_T，
   但此放鬆不再指定它們由哪份隱藏原圖染色重新計算。

立方同時含所有子集，故具有同 split 的反向交換與可交換操作見證。
不同立方可共享頂點，也可有多份合法目標；投影後不主張存在單值全域交換作用。
只造一條箭頭或只在每個 split 分別留一列不滿足本定義。

## 3. 有限域覆蓋全部指定平面來源

對任意大小的 H 及每份完整 f，將 `Πₚᴴ(f)` 每個原分量與 C₀ 相交，
捨去空交集，便得到六份 traces 與一份狀態 x。
原框雙色邊給強制連接；互補色對原分量在同一側互不相交，Jordan 分隔給聯合非交叉。
因此實際 traces 必屬上述**完整有限域**。

固定 f 與 split i，每個觸框 trace 恰來自一個原分量。
同時交換任意子集的這些原分量，保留其餘（包括所有不觸框分量），
得到完整立方 `f_T`。這一 split 的原誘導圖與兩份分量不變；
其他四對在各份同一 `f_T` 重算，再投影便是 `A_∂` 要求的共同目標。
取全部完整 f 的 states／cubes，故

\[
A_{src}(R,a)\ \Longrightarrow\ \exists b\ A_\partial(R,b).
\]

這是任意來源大小的紙面覆蓋證明，非以十七點實驗推廣。
不觸框分量仍留在 `A_src`／完整 fibres；有限放鬆只忘掉它們。
多份 f 可能投成同一 x，故有限 arrows 是帶 witnesses 的關係，不能無條件把路徑見證相接。
覆蓋只是一方向，沒有宣稱有限 tuples 或立方可同時還原成同一 H。

## 4. 存在量化恰等於完整舊閉包

**命題（適用任意長度原圈、共同 S₄ 封閉的 B）。** 令 `D*(B)` 是 §1 screen 的最大固定子集。
在所有色列限於 B、滿足完整立方公理的狀態族中，最大族精確為

\[
X_D=\{(r,P_0,P_1,P_2):r\in D^*(B),\
        P_i\in\mathcal N_i(r),\
        \operatorname{Orb}_{i,P_i}(r)\subseteq D^*(B)\quad(\forall i)\}.
\tag{1}
\]

特別地 `π_C₀ X_D=D*(B)`，且 `∃a A_∂(B,a)` 當且僅當 `D(B)=B`。
空 B 以空狀態族滿足；本輪候選 S 非空。

**所有註記的上界。** 任取合法族 X，令 `R=π_C₀ X⊆B`。
對每份 r 選其中任一狀態；三份完整立方給每個 split 一份全部 orbit 留在 R 的分割，
故 `D(R)=R`。同步舊閉包每輪都保留任意固定子集，於是 `R⊆D*(B)`。
每份 x 的每個 Pᵢ 亦因它的完整立方而有 `Orb⊆R`，所以 `X⊆X_D`。
此步量化涵蓋全部合法狀態族／立方選擇，沒有只拒任選註記。

**完整有限共同註記的構造。** 任取 `x∈X_D` 與 split i，保留 Pᵢ。
對每個 T，交換色列 r 得 r_T。各 block 交換不改點所屬的互補色對，
Pᵢ 仍合法；完整 orbit 在此交換下不變，故仍含於 `D*(B)`。
因 r_T 在舊固定點，每個其他 split 都有至少一份完整 orbit 留在固定點的分割。
在同一 x_T 同時選這兩份分割，得到 `x_T∈X_D`；T 空時取原 x。
這給完整立方，而非僅每步個別可走。每個 r 在 D* 亦各有三份分割，故投影恰為 D*。

因此，**此有限公理下**共同保存六對分割、同／互補分量保持與完整交換立方，
並不增加關係排除力。缺的資訊是同一 H 的跨 split 實現與原點間的連接，
不能用「共同」一詞或任選目標函數代替它。

## 5. 指定合併／投影與完整 fibres 保留

指定操作仍為原邊 exact natural join、消去 `(x₁,x₂,z)` 的存在投影與延遲回寫。
原圖、原框、H、原點身份與原因子 ID 始終隨來源保存，沒有識別接口點。
對任一有序 scope T，附註記的投影定義為

\[
\widehat R_T(t)=\{(f,a_f):f\in\operatorname{Col}_4(G),\ f|_T=t\}.
\]

從這種完整 witness relation 投影，纖維恰為對同一 f 的存在量化；
join 必須在共同完整 f 上相容，不能把兩側任意存在的 lifts 拼接。
投影掉 a 與投影原座標可交換；同一原圖所有原因子 join 的相容 fibres 亦如此。
這由 natural join 的相容指派定義及存在量詞交換直接證明，含全部空 fibres。
全圖 G 真分量交換 `f↦f′` 保每條原邊，因此兩端完整 witnesses 及其共同交換證書
可沿每個指定 join／projection 保留，最後逆向回寫得到同一份原指派。

**範圍限制。** H 的分量交換可能破壞內側邊，故不能拿 H 的立方宣稱任意內側因子 join 後仍封閉。
`A_∂`／D 固定關係不對任意 intersection、外加限制或 Boolean 投影封閉。
此處保留的是來源與既有相容交換的完整 witnesses，不是每張中間表都另有原圈或獨立 D 穩定性。
同樣，不能在忘掉 witnesses 後從兩端各自存在推回一份共同合法交換。

對本輪最大有限族，(1) 給精確相等後再作任意指定座標投影，故
`π_T π_C₀ X_D=π_T D*(B)`，其完整註記 fibres 逐列照存。
證書保存 S 的全部64個座標子集投影與全部空／非空 state fibres；
未把少點投影冒充另一個原簡單圈的 screen。

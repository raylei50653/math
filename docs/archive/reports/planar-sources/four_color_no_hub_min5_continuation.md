## 1. 先排除保留雙錐的填區候選

若保留原雙錐 `T_ℓ` 的全部原點、原邊及球面嵌入，只在原面內添點／邊，
則不存在滿足 S34 且最小度五的擴充三角化。
因 `T_ℓ` 已為球面三角化，任何新點都在一個原三角面中；該三角框另一側有原雙錐點，
所以此三環兩側都有環外原點，違反 S34。沒有新點時，極大平面性不允許再加簡單邊，
原環點仍度四。這是該填區候選的不存在證明，以下停止使用它，改用不同原圖。

## 2. 原圖、短環前提與可核選序

令 `n≥6` 為偶數。原圖 `A_n` 的原頂點是

\[
 \{a,b\}\sqcup\{x_i:i\in\mathbb Z/n\}\sqcup\{y_i:i\in\mathbb Z/n\},
\]

原邊**恰為**

\[
 x_ix_{i+1},\quad y_iy_{i+1},\quad ax_i,\quad by_i,
 \quad x_iy_i,\quad x_{i+1}y_i. \tag{G}
\]

兩個輪帽與交錯接帶給出球面嵌入；原面為
`ax_ix_{i+1}`、`by_iy_{i+1}`、`x_ix_{i+1}y_i`、`x_{i+1}y_iy_{i+1}`。
各有 `n` 個面，共 `2n+2` 點、`6n` 邊、`4n` 面。各環點度五、兩帽度 `n`。
原帽、接帶與下文使用的弧均在同一原圖，沒有虛擬 hub。

**S34／S5 的一般紙證。** 沿用[短環前提](four_color_bond_perimeter_small_cuts.md#1-完整假設與周長契約)：
三／四環不能兩側都有環外原點；五環不能兩側各有至少兩點。
固定長至多五的簡單原環 `Q`。

若 Q 避開兩帽而分開兩帽，`n` 條內點互斥的原路 `a–x_i–y_i–b`
各須碰 Q，且交點互異，迫 `|Q|≥n≥6`，矛盾。
若兩帽在同側，另一側不能含任何 x 或 y：內側 x 到 a、內側 y 到 b 的原邊都會穿過 Q。
所以另一側無原點。Q 也不能含兩帽，因兩帽原距離為三，兩條環弧各至少三邊。

只含 a 時，寫 `Q=a–x_i–P–x_j–a`；P 在環帶中長至多三。以 X／Y 表示點所屬原環，
依原接帶逐項取靠 a 的短扇區：

| P 的點類型 | 該扇區內、Q 外的原點 |
| --- | --- |
| `XX`、`XXX`、`XXXX` | 無；P 是連續原 X 弧 |
| `XYX` | 無；共同 y 的兩個 X 鄰點相鄰 |
| `XXYX`、`XYXX` | 無；三個 X 點連續，扇區由原三角面拼成 |
| `XYYX` | 至多一個 X 點 |

最後一型可反向使中間點為 `y_t,y_{t+1}`；兩端分別在 `{x_t,x_{t+1}}`、
`{x_{t+1},x_{t+2}}`，且互異。只有兩端為 `x_t,x_{t+2}` 時扇區含唯一點 `x_{t+1}`；
另外兩型皆空。表已列盡長一至三的 P，`n≥6` 保證這些局部索引不混同。
含 b 的情形由交換兩環及反向索引得到。因此三／四環必有空側，五環必有至多一點側。∎

**明確 canonical 選序。** 固定根面 `(x₁,x₀,y₀)`，取

\[
 (x_1,x_0,a,x_2,\ldots,x_{n-1},
      y_{n-1},y_{n-2},\ldots,y_1,b,y_0). \tag{O}
\]

前三點成原面；接下來的較早鄰點路依次為：

| 新點 | 較早鄰點路；`m` |
| --- | --- |
| `x₂,…,x_{n−2}` | `x_{i−1}–a`；2 |
| `x_{n−1}` | `x_{n−2}–a–x₀`；3 |
| `y_{n−1}` | `x_{n−1}–x₀`；2 |
| `y_{n−2},…,y₁` | `x_i–x_{i+1}–y_{i+1}`；3 |
| `b` | `y_{n−1}–…–y₁`；`n−1` |
| `y₀` | `x₀–y_{n−1}–b–y₁–x₁`；5 |

每次在當前外環的這段連續路外貼原三角扇；根邊保留、前綴誘導、二連通且內面皆三角形。
對尚未加入的點，與前綴的鄰接仍只在新外環上。因此 (O) 確實為 canonical ordering。
反向曝出 a 前，a 始終為嚴格內點；反向處理 `x_{n−1}` 的 `m=3` 步首次令它上框，
得到 `U={a,x₀,…,x_{n−2}}` 的首次飽和來源。此時已處理全部 Y、b 及 `x_{n−1}`。

最小具名例為 `A₆`：以 `x_i=i,y_i=6+i,a=12,b=13` 標號，選序是
`(1,0,12,2,3,4,5,11,10,9,8,7,13,6)`，首次飽和 `k=6`。
第 4 節直接給出此階段的實際原邊見證，故來源確實非空；並非任意造出的 disk 關係。

## 3. 由原幾何定義的來源子類與完整 fibres

在同一 `A_n` 中，選連續原弧 `J=[l,r]`，含二至 `n−1` 個 X 點；取

\[
 U_J=\{a,x_l,\ldots,x_r\},\quad
 B_J=(x_l,\ldots,x_r,a),\quad X_J=V(A_n)\setminus U_J.
\]

循環起點與方向可重新選取。只取實際 canonical 飽和來源，
`D_J=(V(A_n),E^{out}_J\cup E(B_J))`，沿用[外側契約](four_color_reverse_shelling_continuation.md#對象邊集合與完整關係)。
(O) 達到最大弧，其後剝兩端；任意指定弧均能藉旋轉／反向的 (O) 到達。
固定某根時合法耳可能較少，以下證兩端所有收口，故也涵蓋該根允許的全部收口。

`A_n[U_J]` 恰為 fan，所有剩餘點都在 B 上，故已飽和。D 的原邊是 (G) 中
**除去** `ax_i (l<i<r)` 的全部邊；沒有其他刪邊。
任何共同原 hub 必須鄰接 a，故只能是已處理 X 點；但無弦 X 環中沒有第三點同時鄰接
可見相鄰點 `x_l,x_{l+1}`。所以每階段，包括末三角，都沒有共同原 hub。

取字面色框 `C={0,1,2,3}`。固定**整份有序**邊界列
`z=(z_l,…,z_r,s)`，其中 `s` 是 a 色。對每個 `q∈C` 定義

\[
 L_i(z)=\begin{cases}\{z_i\},&i\in J,\\C\setminus\{s\},&i\notin J,\end{cases}
 \qquad
 S_i(q,z)=\{(u,v):u\in L_i(z),\ v\ne q,\ u\ne v\}.
\]

這裡 `u,v∈C`。相鄰原欄的轉移為

\[
 K((u,v),(u',v'))\quad\Longleftrightarrow\quad
 u\ne u',\ v\ne v',\ v\ne u'.
\]

`W_J(q,z)` 是**全部帶原欄標號的閉合色串**
`(σ₀,…,σ_{n−1})`，滿足 `σ_i∈S_i(q,z)` 及每個循環相鄰對的 K，包括最後回到首欄。
若 z 在 B 不 proper，直接令以下整個 fibre 為空；否則有精確雙射

\[
 \boxed{\operatorname{Fib}_{D_J}(z)
 \simeq\coprod_{q\in C}\{q\}\times W_J(q,z).} \tag{F}
\]

讀出 `b=q,x_i=u_i,y_i=v_i`，並固定 `a=s`，即得到同一 D 的完整染色。
狀態中的不等式恰查 `by_i,x_iy_i`；K 恰查兩條環邊與 `y_ix_{i+1}`；
隱藏 X 的色域恰查其 a 輻邊，可見兩端的 a 輻邊由 proper z 核過。
剩餘可見內部 a 輻邊尚未加入，不可提前查它們。
因此全部 D 原邊逐項且恰好覆蓋。反向從完整染色讀出 q 及每欄色對，恢復唯一串，證雙射。

完整關係是 `tilde R_J={z:Fib_DJ(z)≠∅}`；所有 `4^{|B_J|}` 個索引均保留，
不 proper、色串不存在的列明列空 fibre。不將 q 的邊際或不同閉合串拼接；
傳輸矩陣的 trace 可以計數，仍不能代替這些具名原見證。

## 4. 交替弧支援與所有合法收口的一般定理

直接在整份邊界列上定義支援子族

\[
 \mathcal E_J=\{z:\exists u\ne v,\ s\notin\{u,v\},\quad
 z_{l+h}=\begin{cases}u,&h\text{ 偶},\\v,&h\text{ 奇}.\end{cases}\}. \tag{E}
\]

它僅查可見弧的原次序與奇偶，不定義為「可完成收口的列」。每階段恰有24份列。
對任一列，令 `P={u,v}`、`Q=C\P`；把 X 沿同一奇偶用 P 交替延長到整個原環，
把 Y 用 Q 交替（兩相位），取 `b∈P`（兩選擇），保留 `a=s∈Q`。
因 n 偶，兩個原環均閉合；跨邊兩端在互補色盤、帽輻邊也異色。
這提供 (F) 中四份**不同且同框**的實際原見證，所以
`∅≠E_J⊆tilde R_J`。例如 A₆ 可取 X 交替 `0,1`、Y 交替 `2,3`、`a=2,b=0`。
支援沒有替代完整關係，亦不要求某固定三色盤的全部 proper 外環列受支援。

不變量 I 是第 3 節的原圖／連弧幾何、完整雙射 (F) 及支援包含 (E)。
它不含「最後可染」或未來所有步驟成功這種條件。

**定理。** 從這類實際、已非空的完整外側來源出發，I 經全部合法 canonical `m=2`
收口保留。每一步有待閉合端點異色的同一見證舊整列，整段後綴非空。

**幾何與分支完備性。** 可見 X 弧至少三點時，剩餘 fan 中只有兩端是度二耳；
其餘 X 點剩餘度三，a 剩餘度至少三。因此合法 `m=2` 步只能去掉 `x_l` 或 `x_r`。
去右端加原邊 `ax_{r−1}`，去左端加 `ax_{l+1}`；新弧仍連續。二點弧為終止三角形。
這查盡任意固定根允許的步驟。

**全部 fibres 的保留。** 以去右端為例，`J'=[l,r−1]`、`x=x_r`。
對任一新列 `z'=(z_l,…,z_{r−1},s)`，以 `z'⊕t` 表示插回 x 色的舊整列。
若新列 proper，則

\[
 \boxed{\operatorname{Fib}_{D_{J'}}(z')
 \simeq\coprod_{t\in C\setminus\{s,z_{r-1}\}}
       \{t\}\times\operatorname{Fib}_{D_J}(z'\oplus t).} \tag{T}
\]

若新列不 proper，轉移 fibre 定義為空。因 `D_{J'}=D_J+ax_{r−1}`，
z' 已核新增邊，剩下只把舊 x 的色移入 fibre。全部原點與其顏色保持同一份。
在 (F) 中，此事恰是把 `u_r=t` 的舊單點條件換為新隱藏域 `C\{s}`；
新端點 `u_{r−1}≠s` 則由 proper z' 核過，K 與其他條件不變。
因此 (F) 在新幾何仍精確，連所有空列及全部實際見證一起保留。

**支援與同一舊見證。** 每份新 E 列有唯一的交替舊色 t；它避開 s 及相鄰 X 色，
給出舊 E 整列。前述四份原見證逐份在新舊 fibre 中對應。
反過來，任何舊 E 列本就令 a 異於全部可見 X，故它的**全部舊外側見證**都通過新增邊，
投影後仍在新 E。左端對稱。歸納得到定理。∎

完整轉移 mask 對每份新列保存

\[
 M_J(z')=\begin{cases}
 \{t\in C\setminus\{s,z_{r-1}\}:\operatorname{Fib}_{D_J}(z'\oplus t)\ne\varnothing\},
       &z'\text{ proper},\\
 \varnothing,&\text{其他}.
 \end{cases}
\]

每個 t 仍附帶其全部原見證；保留零 mask，最後沿相容的全部 fibres 回寫。
這是完整列的存在／轉移證明，不是從兩端各自非空的色域推共同見證。

## 5. 古典化約涵蓋核對與確切邊界

本類不是雙錐度四化約的改名：全部原點度至少五，S34／S5 已由原幾何證明。
但它仍有直接 C 型還原，不能出現在裸平面頂點最小不可四色反例。

**保留對側見證的辨識還原。** 刪去 a 及全部 X，騰出的閉圓盤邊界是原 Y 環。
在此空圓盤內畫一個星，連到全部偶數下標 Y 點，再收縮此星將它們辨識為 h。
偶數 Y 彼此不鄰接，故不產生自環；平行邊取底層簡單圖，得

\[
 H=K_{2,n/2}+bh,
\]

其中二點側是 `{b,h}`，另一側是全部原奇數 Y。構造在原嵌入內不交叉，
H 簡單平面、`|V(H)|=n/2+2<2n+2`，不要求縮圖保持最小度或 S34／S5。

給任意 `κ∈Col₄(H)`，記 `B=κ(b),H₀=κ(h)`，它們因原縮圖邊 bh 而異色；
將其餘兩色集合記為 R。每個奇數 Y 皆鄰接 b,h，故原 κ 在其上的色屬 R。
先把同一份 κ 拆回原 Y：偶數 Y 皆取 H₀，奇數 Y 及 b 原色保留。再填

\[
 a=H_0,\quad x_{2j}=B,\quad
 x_{2j+1}=\text{R 中異於 }\kappa(y_{2j+1})\text{ 的唯一色}. \tag{C}
\]

X 環在 B 與 R 之間交替；a 的色不在其中。每個奇數 X 避開其同下標奇數 Y 及前一個偶數 Y；
每個偶數 X 的 B 避開所有 Y。因此 (G) 全部原邊 proper，原對側 `{b}∪Y` 的同一份拆回見證
原封保留。這對 H 的每份染色有效，不用重新選取 κ、Kempe 交換或4CT。
辨識條件限制了被保留的 Y 染色族；本命題沒有要求任意原 Y 輪染色都能延伸。

**整圖的更小還原核對。** 另可只保留原面三角形 `H_△=A_n[{a,x₀,x₁}]`。
它簡單平面且只有三點，嚴格較小。給定 H_△ 的**任意** proper 染色 κ，取
`P={κ(x₀),κ(x₁)}`、`Q=C\P`。令 X 交替延伸 κ 的兩色、Y 用 Q 交替，
保留 `a=κ(a)`，b 任取 P 色；每份 κ 有四份指定延伸，逐邊驗證與第 4 節完全相同。
原三角形的同一份 κ 原封保留，不用再挑縮圖染色、Kempe 交換或4CT。

這是對整份具名原圖類的明確 C 型還原；**不宣稱**已逐項匹配某個古典局部構形目錄。
另在 `n=6` 時，任一帽與其六環恰是十二割的 W₆ 側，已被
[既有 W6-BELT-TRIANGLE 還原](four_color_twelve_cut_c6_sources.md#4-w6-belt-triangle具名來源型的-c-還原)涵蓋。
`n≥8` 的該輪帽割大小為 `2n`，不能援用「十二割 W₆」的特定前提；上述整圖還原另行有效。

因此這裡「來源非空」指滿足題目明列結構條件的實際來源非空，並不主張存在不可四色最小反例。
若另強加原圖是裸平面頂點最小不可四色者，本候選類由上述還原不存在，並在該契約下停止。
沒有新的不可避免構形、抽象 D 必零列、一般無 hub 不鎖定或 4CT 結論。

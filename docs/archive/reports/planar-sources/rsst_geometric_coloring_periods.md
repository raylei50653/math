# RSST 構形的幾何接合與染色週期

2026-10-31。此輪為週期平面三角化的獨立實驗，不改變四色主攻或既有 Kempe 回返裁決。

## 對象與週期定義

輸入是 Steinberger 附檔所保存的 RSST 633 構形之 **free completion**，
保留有序環、所有原點／原邊及每點旋轉次序。
來源：[unavoidable.conf](https://arxiv.org/src/1401.6481v1/anc/unavoidable.conf)，
SHA256 `1c92fc280a9b384f736b94077fc59aac75e3d830d441ffd2d18683ee4b524e84`。
這是拿已知有限圓盤建造新無限圖；「RSST 構形本身有無限週期」不是本輪命題。

選定幾何晶格 `L=Z T₁+Z T₂`。新圖的頂點寫成 `(v,x,y)`；每條邊保存
`[u,v,dx,dy]`，即 `(u,x,y)` 與 `(v,x+dx,y+dy)` 相鄰。
完整染色的原色平移群為 `P(c)={t∈L:c(z+t)=c(z) 對每個原點成立}`。
比較量是有限指數 `[L:P(c)]`。指定子晶格 `H≤P(c)` 的可行見證可以有額外對稱，
所以指定域的面積不必是該見證的最小域；另以完整平移掃描求出實際指數。
本輪的最小性一律相對選定 `L`，未證明所選幾何單元是最小原胞，亦未分類額外幾何對稱。

## 如何形成真的平面週期圖

四邊方案：偶數環長 `r=2(a+b)`，依原環順序分成 `(a,b,a,b)` 條邊，
四角放在單位正方形，對邊以平移識別。邊界點保留同一 motif ID 及不同整數位移；
內點不識別。得到每格 `N=n-r/2-1`、`E=3N`、`F=2N`。
本輪掃描固定原起點0，採 `a=floor(r/4), b=r/2-a`；沒有窮盡其他切角或接法。

六角方案只用 #1：在晶格分數座標取
`[(1,1),(-1,2),(-2,1),(-1,-1),(1,-2),(2,-1)]/3`，
物理基底 `T₁=(1,0), T₂=(1/2,√3/2)`，對邊相差整數晶格平移。
分數座標面積為1，物理面積為 `√3/2`，六角蜂巢恰覆蓋平面。

七個精選標本的內點以等權調和方程求解，使用 `Fraction` 做精確有理數消元。
不是把原始展示座標直接拉成週期圖。
逐份檢查全部面正向、面積總和、全部原邊段兩兩不交叉且無非端點落在邊上，
再檢查每個週期邊軌道恰有兩張反向原面，以及每個 lifted 頂點的 link 為單一環。
這些證書配合明定的正方形／蜂巢鋪排，給出選定七個無限平面三角化。
原構形內點度數完全保留；接縫點重新計度，且每格 `Σ(6-deg)=0`。
未精選的342個偶環樣本僅作組合接縫與染色商圖掃描，未逐份作上述精確幾何驗證。

### Birkhoff diamond 的兩格必要性與明示見證

來源環點按原始檔使用1至6，內點7至10。
一個幾何單元即重複的染色會迫使環點1、3、5同色 A，2、4、6同色 B，且 A≠B。
原內點7、8、9構成三角形，每個都鄰接 A、B 兩色的環點，因此只剩兩色可用，矛盾。
這個障礙不用 SAT 或四色定理。

本輪 motif 0至5 的兩列見證為

```text
y 偶數: [3,2,1,0,2,0]
y 奇數: [3,1,2,0,1,0]
```

完整原環映射依次為
`[(0,0,0),(1,-1,0),(0,-1,0),(1,-1,-1),(0,0,-1),(1,0,-1)]`；
內點7至10依次對 motif 2至5、位移0。全部來源邊及接縫已核對異色。
所以 `P(c)=⟨(1,0),(0,2)⟩`，指數恰為2；第一方向平移保持原色，第二方向平移交換色1、2，
平移兩次才恢復原色。幾何重複、整體換色重複及原色重複在同一原圖中明確分開。

## 斜週期補足原12晶體圖鑑

原圖鑑只測六個矩形。本輪使用每個有限指數子群唯一的 HNF 基底
`H=⟨(a,0),(b,d)⟩`，其中 `a,d>0,0≤b<a`、指數 `ad`。
取 `0≤x<a,0≤y<d` 為代表；`y=qd+r` 時把 `(x,y)` 化為 `((x-qb) mod a,r)`。
這窮盡指數1至4的15個子晶格，沒有遺漏斜域。

原12例共180個商圖：168 SAT、12 UNSAT。相對各自所選幾何晶格，最小指數為
`P01=3, P05=2, P09=2`，其餘九例為1。
特別是 P05 的 `2×1`、`1×2` 皆不可行，
但 `H=⟨(2,0),(1,1)⟩` 可行；該見證兩軸週期皆為2，斜移 `(1,1)` 亦保持原色，
所以最小域只有2格，不能按 `2×2` 矩形面積算成4。
原 README 的「六矩形中最小面積3」仍是當時正確的限定敘述，本輪補出了真正較小的斜域。

## 幾何單步能否由一個全域色號置換表示

固定 `α,β∈S₄` 且 `αβ=βα`，考慮
`c(v,x,y)=α^x β^y(c(v,0,0))`。
每條原邊要求 `c(u,0,0)≠α^dx β^dy(c(v,0,0))`。
枚舉全部120個有序 commuting pairs，各自保留固定字面色框，**不固定第一張面色號**；
因為任意改名會共軛 α、β，對一對已固定置換直接 pin 色可能誤刪解。
每個 SAT 見證另在置換階數形成的完整矩形 lift 逐邊、逐面核對。

`ρ:Z²→S₄` 的像為交換子群，故其階數只可能為1、2、3、4。
若包含三循環，其中心化子只有該 C₃；若包含四循環，中心化子為該 C₄；
其餘非單位元素皆為對換／雙對換，互相交換時至多生成 C₂或 Klein 四元群。
圖中有三角形，至少用到三色；固定所有已用色的 S₄ 置換只能是恆等。
因此原色平移群恰為 `ker ρ`，指數恰為像的階數，至多4。
此上界只對每個幾何單步皆可整體換色的染色成立，不限制一般週期染色。

原12例的1,440對判定為1,337 SAT、103 UNSAT；每例至少一對可行。
P01／P05／P09 的可行對數為58／83／116，其餘九例均120。
精選 RSST 七例另有840對判定，每例也都有可行對；完整結果依原圖保存在各自 JSON。
一份任選週期見證平移後不能全域換色，不表示該圖不存在另一份能全域換色的見證。

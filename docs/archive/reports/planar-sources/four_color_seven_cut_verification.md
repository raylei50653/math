# 七邊割突破點的獨立驗證

2026-10-29，以 `4476049` 為核對基線。接續[六邊割排除](four_color_six_cut_exclusion.md)，
此頁承擔新七邊結論的獨立審計；既有六邊原證明與 frozen 證據保留。

**同日 e1a90fe 後續。** [八割來源與三步續進](four_color_eight_cut_three_step_continuation.md)
在額外的球面三角化及短環契約下，將兩側各至少三點的割提高至九；二點八割仍保留。
本頁對一般裸平面最小反例的七邊排除與下界八不變。

**判定：結論可證，但原提案的一項分量斷言需要減弱。**
若 `T` 是全體有限簡單裸平面不可四色染色圖中頂點數最少者，則

\[
 V(T)=X\sqcup Y,\quad |X|,|Y|\ge2
 \quad\Longrightarrow\quad |\delta_T(X)|\ge8.
\]

以下紙證只用既有六邊割下界、HUB-THREE、Hall 配對與 Jordan 分隔，
不使用四色定理或平面圖目錄。有限腳本另核全部 2,520 份三／三色失敗對；
它提供核對，沒有形式化任意來源的平面拓撲。沒有新增 Lean 證明。

## 來源縮約與共同圓周

假設存在七邊割。兩側必連通：否則一側至少有兩個分量；單點分量由
`δ(T)≥5` 至少有五條出邊，多點分量由既有非平凡邊割下界至少有七條，
故總跨邊至少十條。此處沿用的是同一全體頂點最小性，不增加三角化假設。

兩側連通使此割為 plane bond，可取一條 Jordan 圈 `γ`，避開所有原頂點，
且恰與每條跨邊相交一次。具體可取 `T[X]` 的薄正則鄰域：因 `T[Y]` 連通，
它全部位於同一補面；面向該補面的那一條鄰域邊界穿過每條跨邊一次，其他邊界可填平。
因此雙側具有同一循環 incidence 次序，方向反轉不影響不交叉性。
把截斷跨邊的半邊一併放入雙側閉圓盤後，實際互補雙色分量給出不交叉分割。
同一端點的重複 incidence 只會強制同 block；忽略這項強制得到更寬鬆的必要篩選，
不會把原來源錯誤排除。

兩側不同跨邊端點數都至少三。端點數一造成割點；頂點最小反例不能有割點，
因各塊的較小圖染色可在共同一點經整側置換接合。端點數二時，若該側只有兩點，
`δ(T)≥5` 迫割大小至少八；若至少三點，沿用 SIX-EXCLUDE 的兩個嚴格較小平面圖
`T[X]+uv` 與 `T[Y∪{u,v}]+uv` 接合矛盾。

於是兩側皆可套 HUB-THREE，取得同一來源兩側各一份完整染色，邊界均恰三色。
若它們不能直接置換接合，既有七 incidence 的 Hall 分類允許交換側名及顏色後，寫成

\[
 a(p_j)=0,\quad a(q_j)=1\ (j=0,1,2),\quad a(i)=2,
\]
\[
 b(p_j)=b(q_j)=j,\qquad b(i)=0.
\]

色 3 在兩側邊界都未使用，但可在內部使用。

## Y 側：三組相鄰配對

假設所有原側完整染色都不能接合；對上述同一份 `κ_Y` 的每個實際分量交換，
所得完整染色仍必與固定 `a` 無法接合。

對任意 `{j,k}⊂{0,1,2}`，`p_j,p_k` 必在同一 `{j,k}` 分量，
`q_j,q_k` 也必如此。否則只交換含其中一端的分量，一行失去三色全覆蓋，
又未引入第四色，唯一 Hall 矩形被破壞，即可接合。

同樣，`p_j,q_j` 必在同一 `{j,3}` 分量。否則交換含 `p_j` 的分量即可接合；
當 `j=0` 時是否連帶交換 `i` 都不影響這個結論。
例如 `j=1` 可用置換 `π=(3,0,2,1)`，`j=2` 可用 `(3,2,0,1)`，
`j=0` 可用 `(0,2,3,1)`；此處 `π` 將 Y 色映到 X 色框。

記 `P_j={p_j,q_j}`。互補雙色路不相交，故 `P_j` 的連通路不能把另外兩個
`p` 點分置兩弧，也不能把另外兩個 `q` 點分置兩弧。
刪去 `i` 後，這迫每個 `P_j` 都是六個位置中的相鄰對：若某個 `P_j` 不相鄰，
其一弧必恰含另兩個 `p`，另一弧恰含另兩個 `q`；沿前一弧，三個 `p` 中居中的
`p_k` 到 `q_k` 的路便分隔另兩個 `p`，違反剛才的互補路限制。
因此六個位置排成三個互不重疊的相鄰對 `P₀,P₁,P₂`。

## X 側：只需兩項弱連通結論

固定 `b`，在同一份 `κ_X` 中，`I₀={p₀,p₁,p₂}` 必在同一 `{0,3}` 分量，
`I₁={q₀,q₁,q₂}` 必在同一 `{1,3}` 分量。
若其中一組被分開，交換其一部分就把該行拆成兩種顏色；直接四色情形的 Hall 配對
可接合。這一步保留其餘原點、原邊與整側完整染色。

此外 `p₁,p₂` 必在同一 `{0,2}` 分量；若不連，交換含 `p₁` 的分量，
使 `a(p₁)=2,a(p₂)=0`，置換 `π=(3,0,2,1)` 即可接合，無論是否連帶 `p₀,i`。
對稱地，`q₁,q₂` 必在同一 `{1,2}` 分量。

**修正原提案。** `{0,2}` 不必迫 `p₀` 與 `i` 同分量。只看這四個端點，
每個 block 單換都保持無配對的分割恰有三種：

\[
 \{p₀,p₁,p₂\}\mid\{i\},\qquad
 \{p₁,p₂\}\mid\{p₀,i\},\qquad
 \{p₀,p₁,p₂,i\}.
\]

第一種是原「唯一拆分」說法的代數反控制：換任一 block 使四點全為色 0 或全為色 2，
仍有二／三色 Hall 矩形。但三種全都保留證明所需的 `p₁↔p₂`，所以不傷最後結論。
這是分量分割層的反控制，不聲稱它能與其他 splits 一起實現於任意來源。

## 四種朝向全部矛盾

刪去 `i`，經循環移位、必要時反轉，三對可依 `P₀,P₁,P₂` 排列。
`P₀` 的內部朝向不影響下表；X 側實際互補色樹不能交錯。

| `P₁,P₂` 的四點次序 | 被迫交錯的兩條 X 側連通路 |
| --- | --- |
| `p₁,q₁,p₂,q₂` | `{0,2}` 的 `p₁—p₂` 與 `{1,3}` 的 `q₀—q₁` |
| `q₁,p₁,q₂,p₂` | `{0,2}` 的 `p₁—p₂` 與 `{1,3}` 的 `q₁—q₂` |
| `p₁,q₁,q₂,p₂` | `{0,2}` 的 `p₁—p₂` 與 `{1,3}` 的 `q₀—q₁` |
| `q₁,p₁,p₂,q₂` | `{1,2}` 的 `q₁—q₂` 與 `{0,3}` 的 `p₀—p₁` |

每行兩條路來自 X 側同一份染色，色集互補，所以頂點不交；其端點卻在同一圓盤邊界交錯，
與 Jordan 分隔矛盾。七邊割排除，合併既有結果得下界八。

## 有限重播及口徑

[獨立腳本](../../../../scripts/four_color_seven_cut_verification.py)不匯入既有求解器，
列舉每個 split 的全部兩類雙色 block 分割，將兩類合在一起檢查 noncrossing，
並只測每個單 block 的交換。各 split 可以獨立選分割；未偷加跨 split 同源條件。
腳本允許四種邊界色的交換結果，不把新邊界仍恰三色當作篩選前提。
[報告](../../../../audits/2026-10-29-four-fronts-verification-4476049/seven-cut.json)結果如下。

| 完整有限範圍 | 結果 |
| --- | --- |
| 恰三色的七位置 canonical rows | 301；有序對 90,601，其中無置換接合 2,520 |
| 單側一步必要條件 | X 存活 560，Y 存活 560 |
| 雙側合看 | 兩側皆失敗 1,400；只 X 存活 560；只 Y 存活 560；兩側皆存活 0 |
| 移除 noncrossing 條件 | 2,520 全部雙側存活 |
| 固定 a 重數 `3+3+1`，Y 單側存活 | 168；反方向 a 重數 `3+2+2` 為 392；合計 560 |
| 六個具名端點的三對相鄰循環序，模 rotation | 16；插入具名 `i` 後 96 |
| 分割生成器控制 | 七點全部 877 分割與獨立 restricted-growth 生成一致；其中 429 noncrossing |

16／96 是具名循環序，560 是全表兩方向獨立色歸一化後的有序型對，不可直接混算。
對 `a=3+3+1` 方向，96 乘七個線性起點、再除兩個行名與兩個非特別列名交換，得到168。
原六邊腳本另有 365 個「至多三色」rows／133,225 對；本腳本先限定兩側恰三色，故母數不同。

## 八的停止範圍

兩相鄰五度點的二點側確有 `5+5−2=8` 條跨邊，所以「只用最小度五排除二端點側」
在八處停止，HUB-THREE 也不能套到兩端點側。
這不證明該配置能出現在最小反例，也不證明所有其他邊割方法都無法提高下界。
本頁不將「八是純邊割論證的緊極限」當作已證的普遍不可能性定理。
932 排除、一般平面消元不變量、不可避免構形與四色定理新證明仍 OPEN。

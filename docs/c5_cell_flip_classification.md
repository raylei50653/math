# C5 cell 的翻邊距離與有限分類

2026-10-13。沿用[四格翻邊引理與工具](c5_cell_flip.md)，從既有目錄的 **132 份具名代表圖**
逐一作三步 BFS。每一步保留實圖與同一有序外框，不以目標 mask 換入另一份代表。
結果得到 **29 組三步特徵相同的代表**，以及完整的
[132×132 距離表](../artifacts/c5_cell_flip_distances/distances.csv)。
這是指定代表與指定嵌入選擇規則下的有限分類；不是所有同 Σ 圖的分類定理。
後續[Σ 的幾何編碼與操作界線](c5_cell_flip.md#6-σ-的數字能否直接表示操作)
給出五格加五格座標及邊界弦清位公式，並以具名反例證明 Σ 甚至逐列延伸數仍不足以決定一般 flip。

## 1. 距離的對象

固定目錄代表 $G_s$，令

\[
d_3(s,t)=\min\{\ell\le3:G_s=H_0\to H_1\to\cdots\to H_\ell,
\ \Sigma(H_\ell)=t\}.
\]

每一箭頭是 `c5_cell_transform.py` 所列的嚴格 facial flip：在當前實圖重新計算的
disk rotation 中，移除兩個三角面的共邊並加入另一對角線。以完整具名邊集作 BFS key，
不以 Σ 去重，不允許加點、刪點、單獨加刪邊、邊界旋轉或代表替換。
所有 132 個目標均保留原十列 bit 次序；D₅ 只用於事後比較。

因此有三個不同問題：

| 對象 | 本次能說明的步數 |
| --- | --- |
| 指定原圖 → 指定原圖 | flip 保留頂點集合及邊數；不同結構分層無法到達 |
| 指定目錄代表 → 目標 Σ | 本次距離表的定義；終點可與目標代表有不同內點數／邊數 |
| 只在 Σ 上接轉移箭頭 | 不能據此讀取實圖步數；中間兩箭頭可能需要不同代表 |

非空的表值是在上述 **NetworkX 3.5 重新選嵌入規則** 下的精確最短步數。
允許任選其他嵌入時，保存路徑仍給出上界，但其最短性尚未核對。
此距離有方向，也不主張三角不等式：從 $G_s$ 到達的 $H$ 未必就是下一列起點 $G_t$。
`null`／CSV 的 `>3` 表示三步內未到達，涵蓋較遠和不可達兩種情況。
JSON 中 `exhausted=true` 另表示已證該來源在此規則下的完整可達分量窮盡；
`false` 只表示未取得這份窮盡證明。

搜尋將每列全部 $4^k$ 內點賦色保存在精確 bitset 中，逐邊交集後計算完整延伸數，
沒有用端點 marginals 或 mask 相交來判定翻邊。每個實圖保存十列計數（含零）；
代表性路徑另輸出[逐步完整四格證書](../artifacts/c5_cell_flip_distances/witnesses/paths.json)，
保存空 fibres 及全部完整 lifts。

## 2. 第一層：flip 保留的圖結構

令 $k$ 為實圖內點數、$m$ 為包含五條框邊的總邊數，定義

\[
\delta=3k+7-m.
\]

這是相對 C5 disk 三角化的缺邊數；對本次圖也等於內部面之 $|f|-3$ 的總和。
純 flip 保留 $k,m$，因此保留 $(k,\delta)$。既有 132 份代表分成 13 個結構分層：

| $k$ | $\delta=0$ | $\delta=1$ | $\delta=2$ |
| ---: | ---: | ---: | ---: |
| 0 | 5 | 5 | 1 |
| 1 | 6 | 5 | 0 |
| 2 | 15 | 15 | 0 |
| 3 | 20 | 15 | 0 |
| 4 | 20 | 5 | 0 |
| 5 | 10 | 10 | 0 |

76 份完全三角化，55 份有一個內部四邊形，另有裸 C5。
這些分層限制**實圖到實圖**，不能套用到終點 Σ 的另一份小代表。
固定嵌入時，非三角面的具名邊界還是不變量；本次沒有將這項更細資料用作分類 key。

## 3. 單步與三步結果

全部來源共有 **1,179** 個候選操作，投影成 **649** 個不同的有向 Σ 轉移：

| 單步對 Σ 的效果 | 操作數 |
| --- | ---: |
| 完全保持 Σ | 0 |
| 只新增可延拓列 | 96 |
| 只失去可延拓列 | 20 |
| 同時新增與失去列 | 1,063 |

六份原代表無可翻邊：`431,757,830,967,1016,1023`。
前五份是 C5 加一條 chord，另一份是裸 C5；在所選嵌入中沒有兩個相鄰三角面。
其餘 126 份雖可移動，每個第一步都改變 Σ。因此，在本次操作規則下，
**全部 132 份原代表都沒有非空的全程保 Σ 翻邊路徑**。
這個局部結論不涉及其他同 Σ 代表、其他嵌入或加入其他操作後的可縮減性。

三步 BFS 共保存 **20,531 張不同實圖**，展開其中 **5,441 張**的全部候選；
深度三的未展開前緣仍保存實圖及完整逐列計數。132² 個有序來源／目標關係對如下：

| 最短步數 | 有序對數 |
| --- | ---: |
| 0 | 132 |
| 1 | 649 |
| 2 | 1,862 |
| 3 | 2,101 |
| 三步內未到達 | 12,680 |

所有走訪圖的 Σ 均在原 132 類內。這是本次搜尋的核對結果，並非任意大小的閉包證明。

## 5. 步數提供的簡單分類與實際路徑

若先只看 $\eta$，有一個很清楚的有限三分法：

| 類別 | 原代表數 | 意義 |
| --- | ---: | --- |
| 無內點底層 | 11 | 沒有更小 $k$ 目標；其中 5 份三角化仍可互翻 |
| 一步到較小代表的關係 | 120 | 全部 $k>0$ 代表，除了 91 |
| 兩步到較小代表的關係 | 1 | 91，即五輪 W5 |

具體例子：

- `91 → 721 → 165`：兩步，過程仍保留同一個內點。第一步的五個目標關係都沒有
  $k=0$ 的目錄代表，第二步到達的 `165` 有，故 $\eta(91)=2$。
- `165 → 564 → 774`：兩步，三張圖皆為無內點五邊形三角化；該五圖分量完整窮盡。
- `891 → 987`：一步，仍是五內點原圖的翻邊結果；目錄 `987` 的一內點代表只在
  密封外框用途下給關係等價，不能在 BFS 中替換進來。

第三例的終圖與原目錄 `987` 的頂點數、邊數不同；若要求到達目錄的**那一張** `987`，
純 flip 根本無法達成。反向查詢也必須從實際終圖開始，不能直接改用目錄 `987`。

因此後續較有用的方向是：先固定 $(k,\delta)$ 及必要的非三角面資料，在**同一批實圖**
中研究可達分量與距離；若允許密封代表替換，須另定義該操作及成本後重算。
本輪停止於三步分類，沒有把 `>3` 推成全域不可達，也沒有得到保 Σ 的一般縮減定理。

## 6. 證據與重播

搜尋程式為 [c5_cell_flip_distances.py](../scripts/c5_cell_flip_distances.py)，
完整壓縮資料為 [atlas.json.gz](../artifacts/c5_cell_flip_distances/atlas.json.gz)，
來源快照及 SHA-256 見 [BASE.json](../artifacts/c5_cell_flip_distances/BASE.json)。
快照保存當時的 catalogue、既有翻邊工具與新搜尋程式的實際位元組；
包含開始時已有的未追蹤工具，不把 HEAD 當成這些輸入的替代。

```bash
# 重算整批資料；輸出路徑必須不存在
uv run --with networkx==3.5 python scripts/c5_cell_flip_distances.py \
  --depth 3 --output /tmp/c5-distance-atlas.json.gz --csv /tmp/c5-distance-matrix.csv

# 從凍結輸入完整重播
uv run --with networkx==3.5 python \
  artifacts/c5_cell_flip_distances/inputs/scripts/c5_cell_flip_distances.py \
  --check artifacts/c5_cell_flip_distances/atlas.json.gz

# 查閱步數、逐步實圖及邊操作
uv run --with networkx==3.5 python scripts/c5_cell_flip_distances.py \
  --query artifacts/c5_cell_flip_distances/atlas.json.gz --source 91 --target 165

# 獨立核對保存的面、候選、染色、BFS 及路徑
uv run --with networkx==3.5 python scripts/check_c5_cell_flip_distances.py \
  artifacts/c5_cell_flip_distances/atlas.json.gz

uv run --with networkx==3.5 python -m unittest discover \
  -s tools/tests -p test_c5_cell_flip_distances.py

# 八份逐步證書的完整賦色與 132² 個 CSV 表值
python3 artifacts/c5_cell_flip_distances/verify_witnesses.py
```

獨立 checker 與測試不以重呼叫搜尋程式作為距離正確性的唯一證據；具體覆蓋與
實際通過的命令見 [驗證紀錄](../artifacts/c5_cell_flip_distances/verification.json)。
本輪是有限 Python 證據，沒有新增 Lean 定理；一般嵌入選擇、無界距離、其他同 Σ
代表與保 Σ 縮減均仍未處理。

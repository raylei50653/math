# 輪環與偶長雙扇之外：十三點非對稱四接點 disk

2026-09-30。接續[偶長雙扇定理](c5_two_vertex_repair_fans.md)，給出固定
十三點 disk D₁₃ 的完整四接點等式，以及反覆替換得到的任意大小
R127／R167 來源族。兩側均擴張時，密封 clique 補片、整來源奇偶路徑、
輪環與偶長雙扇縮減皆無起點；新 D₁₃ 規則可逐層帶回原核心。

任意上下文等價及任意層數結論由下述紙面證明負責；
[checker](../scripts/c5_two_vertex_repair_caps.py)及
[artifact](../artifacts/c5_two_vertex_overlap/repair_caps.json)保存有限原邊重播。
沒有外部染色定理、新 Lean theorem 或 `native_decide`。
目前停止點由[兩點重疊導覽](c5_two_vertex_overlap_guide.md)維護。

## 1. 完整接線與局部關係

接點依序為 `0,1,2,3`，密封內點為 `4,…,12`。D₁₃ 保留四環框邊，
其餘完整接線如下；每條非框邊恰列一次，沒有其他邊。

| 點 | 所列鄰點 |
| --- | --- |
| 0 | 4,9,11 |
| 1 | 11 |
| 2 | 5,11,12 |
| 3 | 5,8,9 |
| 4 | 6,9,11 |
| 5 | 6,7,8,12 |
| 6 | 7,9,10,11,12 |
| 7 | 8,10 |
| 8 | 9,10 |
| 9 | 10 |
| 11 | 12 |

十三點三十二邊的二十個有向內面為

```text
(0,9,3)   (2,12,11) (0,4,9)   (11,1,2) (6,11,12)
(7,5,8)   (5,6,12)  (7,10,6)  (7,6,5)  (9,4,6)
(9,6,10)  (11,6,4)  (0,1,11)  (0,11,4) (8,10,7)
(9,10,8)  (9,8,3)   (5,12,2)  (3,8,5)  (3,5,2)
```

加外面 `(3,2,1,0)` 後，每邊恰出現兩個反向 dart、每點的 link 是
一個 cycle，且 `13−32+21=2`。這給具名 disk 嵌入；逐條接線亦確認
每個三角形都在上述內面中，框無對角線。

**四接點定理。** 在共同色框 D={0,1,2,3} 上，D₁₃ 與四輪星 W 的
完整關係相等，恰接受 proper 且至多三色的四框賦色。

**必要方向。** 若框四色互異，只作全域色置換後為 `0123`。
點11鄰接框0、1、2，故色為3。點5與12各只能取0或1，又有邊5–12，
故它們恰用這兩色。點6鄰接5、12、11，色被迫為2；點9鄰接框0、3
及6，色被迫為1。於是點4的鄰點0、11、6、9用滿四色，矛盾。

**充分方向。** Proper 四框至多三色，按同一全域色置換恰有下列三型。
表列按點4,…,12排序的完整延拓，逐邊皆正常：

| 框0,1,2,3 | 內點4,…,12 |
| --- | --- |
| 0101 | 120102321 |
| 0102 | 310201323 |
| 0121 | 102123031 |

所以完整關係為三個 S₄ 軌道／60份具名賦色。固定任意外部圖每點
顏色後，上式逐份等價延拓，故可在**任意上下文**替換四輪星；四接點
的外部附件全部保留，九個內點全部密封。若原四輪星的四個三角面
構成 disk，上述面表直接給保框平面替換。

**密封及完整接線不能省。** 沿用點4作原中心，五點順序為
`(0,1,2,3,4)`。W 接受 `01213` 而 D₁₃ 拒絕；D₁₃ 接受 `01011`
而 W 拒絕。刪去邊4–6則可延拓四色框 `0123`；artifact 保存完整
五點關係及缺邊後的實際染色。

另保存一個未採用的固定候選：兩個五環加上下帽的十二點球面圖刪去
一條帽邊。它接受全部四種 proper 框型，共84份賦色，較 W 多出
`0123` 的24份，故不作同 class 替換。本輪不聲稱最小性或枚舉完備性。

## 2. 兩來源的任意層數族

沿用[具名核心](c5_two_vertex_repair_sources.md#1-具名核心與可檢查來源條件)，
`U=(x,l,y,m,n,p,q,r)`；正向 `(s,t)=(x,y)`，反向 `(s,t)=(y,x)`。

| 來源 | 原中心（對應局部點4） | 首層有序接點0,1,2,3 |
| --- | --- | --- |
| A | h5 | h7,y,h9,x |
| B | v | r,q,w,p |

每側選 d_A、d_B≥0 次替換；零次保留原星。每次保留點4作下一中心，
新一層有序 rim 選上一層的 `(0,11,6,9)`。這四點恰是點4的全部
鄰點，沿面序成無弦四環，故可反覆施工。新點保持該側 ownership，
兩來源仍只共享 x、y。每次增加八點二十四邊，因此

```text
|V|=15+8(d_A+d_B)，|E|=35+24(d_A+d_B)。
```

完整四接點等價逐次保留來源 R127／R167，進而保留共同色框中的 J。
從 `core_lift` 開始，每一步以 §1 三行表延拓，僅重染本次密封內點；
U 及該次外部各點顏色皆保留。任意有限層數由歸納證成。

## 3. 輪環與偶長雙扇均不能開始

以下對所有 d_A,d_B≥1 成立。單側控制只聲稱擴張側超出整來源路徑。

**私有度數不變量。** D₁₃ 的局部度數依點0,…,12為

```text
5,3,5,5,4,6,7,4,5,6,4,6,4。
```

替換 W 時四接點總度數增量依序為 `(2,0,2,2)`，不減少舊度數。
新局部四度內點是 `{4,7,10,12}`，其誘導邊只有7–10；唯一五度
內點是8，且四度點中只有7、10鄰接它。

首次兩側都替換後，A 剩餘的舊四度私有點 h6、h8只形成一條邊，
h7、h9升為7、6，B 的 w升為6。後續 rim `(0,11,6,9)` 的私有點
度數都至少六；A 的局部0繼承 h7，B 的局部0繼承原框 r。因此後續
替換除中心外不接到舊四度／五度私有點，也不產生舊點降度。歸納得到：

1. 所有私有點總度數至少四。
2. 全部私有四度點的誘導圖只含孤點及互斥單邊。
3. 每個私有四度點至多鄰接一個私有五度點。

**阻斷偶長雙扇。** 非平凡偶長 L≥4 的密封雙扇需要 L−1≥3 個
連續路徑內點；每個內點的完整鄰域恰為兩 hub 與兩路徑鄰點，故總度數
四。中間點在私有四度誘導圖至少有兩個鄰點，與第2項矛盾。L=2只是
原星，沒有縮小圖。此論證包含重新標號、改選 hub 及跨來源的候選。

**阻斷輪環。** 既有輪環逆化約需要一個私有四度中心及四個私有
五度環點，且中心鄰接全部四個環點，與第3項矛盾。degree≤3 消去
亦由第1項排除。這是必要模式的否定，不把 degree screen 反向當成
充分偵測器；checker 另用真正輪環及 F₄ 驗正控制。

**無密封 clique 補片。** 舊來源每個三角形皆為面；D₁₃也有此性質，
且只透過無弦四框接回。替換後的三角形只能是保留的舊面或新局部面，
所以任意層數仍全部為面。[輪環報告的 disk 引理](c5_two_vertex_repair_rings.md#3-舊密封補片及整來源奇偶化約無法開始)
遂排除附件為至多三點 clique 的密封私有分量，包括保留 U 的跨來源補片。

**無整來源路徑或舊核心副本。** 每次新增全私有三角形7–8–10，且
後續替換不接觸它，故兩側私有圖均含環。首層局部接點1、3沒有
共同內鄰點，於是 A 的私有 x、y共鄰只剩 h7、h9，B 的私有 p、q
共鄰只剩 w；後續不新增接到這兩對框點的內點。因此兩側都不含
保持框點與 ownership 的舊核心子圖單射。

所以已有四類只縮減規則在此族皆無第一步，新 D₁₃ 逆化約則可逐層
回到原核心。不排除容許先擴張再縮減的序列，也未證 D₁₃ 最小、
新規則獨立於任意混合改寫、正常形唯一或全部代表可化約。

## 4. 全部外框與 repairs 保留

U 誘導圖未變，仍恰有五個候選五框。兩個既有可用框
`C₁=(x,n,m,y,q)`、`C₂=(s,l,t,r,p)` 的 rotations，以 §1 面表逐層
替換原星，限制到來源仍是各自原 C₅ disk。

另外三框的否定證書使用如下局部 spoke subdivision：

```text
4–0；4–11–1；4–6–12–2；4–9–3。
```

四路除中心4外互不相交，且內點均不在 rim。原交錯 crosscuts 因而
逐層延伸、仍保持不相交，保存三個不可用框。可用框恰為 `{C₁,C₂}`；
這一拓撲結論有獨立證書，不只由 J 相等推定。

完整 J 與全部可用框相同，故 P 相同。兩方向仍有
`J/P/Δ=60/114/54` 軌道，`r=0,…,4` 的殘留為 `54,54,16,16,0`。
完整四點投影、三種 exact rejectors 及兩類覆蓋等式不變；原十一份
稀疏 U 補全逐層延拓，保留各自改動的 U 集合。由
[共同 repair lemma](c5_two_vertex_common_repair.md)，全部極小修復仍為

```text
A={x,l,y,m}，T={s,t,p,q}，B={s,p,q,r}
𝓔={S⊆U : |S|=4, {q,r}⊆S}∖{B}
{A,B}；{A,T,E}，E∈𝓔。
```

共十五組，r*=4。正反向的完整具名資料仍分別核對，未視為同型。

## 5. 有限證書、重播與停止點

每方向核對 `(d_A,d_B)=(1,0),(0,1),(1,1),(2,2)`，共八個23／31／47點圖。

ownership、來源 disk、全部候選框、clique 完整分量與舊核心單射。
另從最終圖計算全體私有度數及誘導邊，獨立否定兩種局部逆化約起點。

局部掃 `4^4`、來源掃 `4^5`、整圖掃 `4^8`，都由原邊回溯核對；

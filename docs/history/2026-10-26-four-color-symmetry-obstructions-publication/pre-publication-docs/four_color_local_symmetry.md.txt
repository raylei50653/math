## 適用範圍與精確關係

輸入仍是任意有限簡單無向圖、原邊異色限制與各原點的字面候選域；固定色先與域相交。
沿用經原邊覆蓋及 running intersection 驗證的袋樹，填補邊只決定分解。
令 `V_t` 是袋 `t` 及全部後代袋的原點聯集，包含父接口 `S_t`；`D_v` 是有效域。
定義

```text
H_t = { π ∈ S4 : 對每個 v ∈ V_t，π(D_v) = D_v }。
```

這裡每份置換共同作用在完整子樹及其接口，沒有對接口各點獨立換色。
原邊的異色關係在任何共同色置換下都成立，所以對精確子樹存在性查詢有

```text
Q_t(πσ) = Q_t(σ)    （π ∈ H_t）。
```

證明是將整份延伸逐原點換色，逆置換提供反方向；域、原邊及完整接口均保留。
因此可以依 `(袋身份, canonical_t(σ))` 索引已完成答案，未詢問列仍由原限制與
精確查詢程序隱式保存。快取沒有宣稱是全部字面支持列或完整 fibres。
若日後加入其他因子，還須證明那些因子在所用置換下不變；僅核域不足以涵蓋任意因子。

## 群的建構與見證還原

兩色可以互換，恰好是它們在 `V_t` 的每份有效域中具有相同成員關係。
這將四色分成等價類；`H_t` 是各類內全部置換的直積。實作以六個色對的 bit mask，
將本袋（包含接口）的域限制與孩子的 mask 取交，不逐袋重掃全部後代。
每次查詢按完整接口順序，將同類首次出現的色依序映到該類由小到大的色，
再補齊未出現色的對應，得到可逆置換。單次正規化處理接口及四色，無須逐次枚舉24置換。

肯定答案必須同時保留色框：首份成功的字面查詢 `σ` 若用 `π` 正規化，
其 owner 見證色 `c` 存為 `π(c)`。回填字面接口 `σ′` 時，若其正規化置換為 `τ`，
則 owner 色取 `τ⁻¹(π(c))`，不能直接把快取色寫回原點。

孩子的成功見證為何仍可取得，是這次新增的相容性義務。由
`V_child ⊆ V_parent` 得 `H_parent ⊆ H_child`。父袋換色後，所問孩子的完整字面接口
與原成功見證的孩子接口只差 `τ⁻¹π ∈ H_parent ⊆ H_child`，故命中同一孩子 canonical key。
孩子再以自己的逆置換還原，仍與同一份父袋字面列一致。沿樹歸納可接出共同原圖見證。
所有根成功後才開始寫色，最後逐原邊、固定色及候選域核對。

最小肯定控制是三點原路徑 `0–2–1`、固定 `1=0`。根先嘗試色0時，自由孩子成功、
固定孩子失敗；改試色1時，自由孩子可共用先前肯定快取，但其 owner 必須逆換色。
另以兩色偶環核對填補邊不增加異色限制；以私有固定色、非對稱候選域及完整三角接口
核對不能任意按等色型合併。

## 工作、訊息與資源契約

歷史字面快取仍是預設。`color_symmetry=False` 與凍結基準比較判定、色、原有統計及完整
訊息；本版另外新增模式欄位與兩個統計欄位，不宣稱輸出 schema 逐位元組不變。
模式開啟後，群建構、接口正規化及回填還原的邏輯工作計入 `checks`；這仍不是 CPU 指令數。

| 統計 | 意義 |
| --- | --- |
| `queries`／`negative_replies` | 實際詢問／否定答覆次數，包含根與重複詢問。 |
| `unique_queries` | 不同的字面 `(袋, 完整接口列)` 數；包含根。 |
| `cache_entries` | 已完成的快取項數；開啟時依 canonical key 計數。 |
| `symmetry_cache_hits` | 命中與該項首存字面列不同的同軌道列之次數；同一列重複命中仍累加。 |
| `symmetry_bags` | 子樹保域群非恆等的袋數；不表示其實際查詢必能節省。 |

每個完成的 canonical 項保存布林、一份私有 owner 色及首存字面接口，後者用於命中統計；
不能以項數直接聲稱相同比例的 byte／RSS 節省。`max_checks`、`max_messages`、
`max_cache_entries` 仍分別約束工作、發送事件及快取項，未約束所有 Python 配置的位元組數。
任何階段超限均回 `limit`、`colors=None`；未完成查詢不回否定。`transcript_limit` 只截斷紀錄。

## 保留邊界

這項群不變性與相容回填是紙面演算法論證，實作另有有限測試，沒有新 Lean 或整份 Python
形式化驗證。每個軌道至多24列，不能消除接口隨原圖增長的指數可能性；最壞仍可問遍全部軌道。
無資源限制時仍精確決定任意有限輸入，在有限預算下仍可超限。
完整接口沒有被低階投影取代，原始求解器的全 fibres 輸出亦未被本單一見證 API 取代。
一般自動啟用、主引擎整合、固定寬度、分散安全隔離與密碼學隱私仍未提供；
所有平面輸入必可四色染色的額外證明義務及 C5／932 等來源問題不因本次快取改進而改變。

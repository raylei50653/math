# 去掉奇偶：五端點偶補匹配的探索任務

2026-10-23。本頁是由[三支共同目標的等價表述](../c5_equivalent_formulations.md)
衍生的探索任務規格，依 [Kempe 導覽 §3](../c5_kempe_guide.md#3-停止點與保留缺口) 的提議排程。
目的不是再加一個分支界，而是確認：把偶補條件拿掉後 (E) 為何成立，
以及奇偶究竟在哪一步、以什麼結構擋住證明。

**本頁只登記任務與起點資料；四份任務均未開始。** 去奇偶版本成立不推出 (E)，
任何任務結束都不得宣告 `K∞=K≤5`、排除 932／933／941，或觸及 4CT 等價部分。

## 共用 BASE、記號與交付規則

**以接手時的 commit 為 BASE**，記錄實際 SHA 與 Git 狀態，凍結引用檔雜湊。
只在各任務專屬的 `audits/<日期>-parity-<任務代號>-<唯一後綴>/` 工作，
不改共用文件、舊證書或其他任務目錄；commit、push、PR 須另獲授權。

G 是外框為具名有序 `B=(b0,…,b4)`、內面皆三角形的 C₅ disk。網路 Q 由 G 的平面對偶
把外面頂點拆成五個葉端點 `t0,…,t4` 得到；端邊 `e_i` 對應框邊 `b_i b_{i+1}`，
內點（G 的內面）皆三度，內點數 `2k+3` 為奇數。對端點對 {i,j}：

| 記號 | 意義 |
| --- | --- |
| `PM_ij(Q)` | `Q−t_i−t_j` 的完美匹配，**不要求**補圖奇偶 |
| `𝓜_ij(Q)` | `PM_ij` 中補圖每個閉環皆偶者；`N_β=Σ_{M∈𝓜_ij}2^{c(M)}` |
| `Γ(G)` | `𝓜_ij≠∅` 的端點對集合，恰為 Σ(G) 的另一種寫法 |
| `Γ_PM(G)` | `PM_ij≠∅` 的端點對集合，`Γ⊆Γ_PM` |
| `odd(M)` | `Q−M` 的奇閉環數 |

端點對與邊界列的對應：C₅ 相鄰對 `{s−1,s}` ↔ 三色列 `y_s`；不相鄰對 ↔ 四色列，
例如 `{1,4}` ↔ `x24`（01232）。三支即「Γ 含整個五角星，且 Γ 在 C₅ 上的邊是一組匹配」，
(E) 是「`{1,4}∈Γ ⇒ {2,3},{0,1},{0,4}` 至少一對在 Γ」。

保存原則沿用既有任務：同一 Q、同一具名端點與環序；比較兩個匹配時保存
完整差集的路與環；不得以各自正規化的色名或不同圖的成功列拼接結論。
交付至少含 `REPORT.md`、凍結清單、紙面論證或明示未解義務；有計算時附可重播
checker 與證書，逐項標示 `triggered and holds`、`not triggered` 或 `counterexample`，
分開紙面普遍證明、有限校準與 Lean。

## 任務 P1：去奇偶層的完整紙面化與 Γ_PM 結構

**要解的問題。** 把 F2 寫成完整引理，並確定去奇偶後還剩哪些約束，
以界定「奇偶以外」的資訊上限。

1. 證明 F2：葉端點在同一外面上的平面圖中，兩條頂點不交路不能以交叉方式配對
   四個端點；處理差集路經過葉點、平行邊及框弦對偶的情形。
2. 寫出 PM 計數的 Pfaffian／Kuo 型關係在本網路的確切形式（含端點奇偶修正），
   並推出 Γ_PM 的全部必要閉包條件。
3. 對 K132 的實際 witnesses 計算 Γ_PM，比較 Γ 與 Γ_PM；回答內點度≥5 的
   近三角化是否總有 Γ_PM 為全部十對（小域有限校準即可）。

**驗收與停止點。** 交付 F2 完整證明、Γ_PM 閉包條件與 K132 對照表。若 Γ_PM
在相關類別恆為全集，明記「去奇偶層對 (E) 不含額外資訊」後停止。
不得把任何 Γ_PM 結論寫成 Γ 結論。

## 任務 P2：交錯交換下的補圖奇偶變化

**要解的問題。** 對完美匹配 M 與交錯路／環 P，`M⊕P` 的補圖由原補圖的分量
切開再接上。給出 `odd(M⊕P)−odd(M)` 的精確局部公式，找出可用的不變量。

1. 以 P 經過的補圖分量及其上被切點的環序，寫出重接後各分量長度的奇偶公式；
   開路（連兩個暴露端點）與閉環分開處理。
2. 判定是否存在平面特有的模 2 不變量，例如由兩個獨立 F₂ 線性泛函給出的
   面二染色，能預測一次交換後奇環數的奇偶或下界。
3. 對 F4 的失敗案例逐一套用公式，說明每個候選交換為何產生奇環；
   以此分類失敗型態（例如同一補圈被切成兩奇段）。

**驗收與停止點。** 交付公式、證明及對 F4 全部失敗案例的逐案解釋 checker。
若不存在比逐案計算更強的不變量，給出最小反例後停止；不擴大到多步搜尋。

## 任務 P3：把 C1 區域修復改寫到五葉網路，並研究多參考共同阻斷

**要解的問題。** [C1 定理](../../audits/2026-10-18-abstraction-bottleneck-9f1fe84/C/PROOF.md)
對封閉三正則圖成立：整塊交換 `D−(M∩R)` 的完整區域，奇環減 `q_W`、標記變 `s_W`；
在族內奇環最少時，正收益區域的標記向量線性獨立。這裡要把它改寫到 Q。

1. 以端邊是否在 M 為標記，寫出五葉版本的 C1 與秩界；說明參考 R 可暴露
   不同端點對時標記如何改變，以及開路分量如何處理。不得用中心點封閉網路，
   那會丟掉四色列。
2. 推出反例約束：取目標族中 `odd(M)` 最小的 M，對每個偶補參考 R
   （反例中至少五個五角星對，933／941 另有 C₅ 邊），M 的奇環都集中在
   至多「標記秩」個阻斷區域，且**對所有參考同時成立**。
3. 在隨機小圖上校準第 2 點的集中現象；再研究不同參考的阻斷區域
   能否在同一平面 disk 共存，嘗試導出矛盾，或給出具名的共存控制。

**驗收與停止點。** 交付五葉 C1 證明、反例約束的精確陳述與校準 checker。
C1 原文已說明區域數上界不等於改善存在；若多參考共存無法排除，
交付最小共存控制與未解拓撲義務後停止，不改寫成 (E) 的證明。

## 任務 P4：凍結並延伸負面資料

**要解的問題。** 把 F4 從探索性結果變成可引用的控制，並量出最小可行機制。

1. 凍結 F4 的生成器、種子與全部失敗案例的完整匹配集合。
2. 依序放寬機制：兩次交換、從任意 `PM_ij`（不要求偶補）出發的交換、
   以及 P3 的整區交換；記錄在小圖上首次全部成功的層級。
3. 若可行，加入內點度≥5、框點度≥4 的近三角化樣本，並與
   [大 k 隨機搜尋](../../audits/2026-10-23-c5-large-k-random-78375cc/REPORT.md)的生成器共用輸入。

**驗收與停止點。** 交付凍結控制與機制層級表。小圖全部成功只稱有限校準，
不升格為普遍引理；不做大型來源枚舉。

## 順序與依賴

P1、P2 互相獨立，是 P3 的前置理解；P4 可與 P1 並行，但第 2 步的整區交換依賴 P3。
建議先做 P1 第 1 步及 P2，因為 F3 已指出反例的全部難度在補圖奇偶。

## 共用 BASE、來源契約與交付規則

**以本研究包的 commit 為 BASE。** 接手時解析並記錄實際 SHA，核對 Git 狀態，
凍結引用檔及其雜湊。只在各任務專屬的 `audits/<日期>-<任務名>-<唯一後綴>/`
工作，不修改共用文件、舊證書、舊研究包或其他任務的目錄。本任務沒有
commit、push、開 PR 或外部發布授權；這些動作須另獲授權。

圖類是有限簡單平面 disk 圖，外邊界固定為具名、有序的

\[
B=(b_0,b_1,b_2,b_3,b_4).
\]

\(\Sigma\) 是四色著色的完整十列關係，五個位置固定，只商掉整體色名置換。
目錄 \(K\) 有 132 個關係、各有至多五內點的實際 disk witness，且對聯集封閉。
沿用的必要 screen、四色定理依賴及外部 Dvořák–Lidický 定理，必須按原報告
分開標示；本批不重證這些外部或上游前提。

條件來源 \(G\) 的身份是：在**所有 \(\Sigma(G)\notin K\) 的來源中全域最小化
內點數，再於該內點數最大化邊數**。它可選成二連通、chordless-C5、內面全為
三角形，且

\[
k(G)\ge13,\qquad \deg_G(v)\ge5\ (v\text{ 內點}),\qquad
\deg_G(b_i)\ge4,\qquad n_5\ge6.
\]

這個身份沒有給出 edge-critical／edge-minimal 前提。舊研究線的 deficiency、
Gallai 或 minimal q-core 引理，只有逐項證明其前提時才能引用。目標候選
933／941 的整圖 D5 像仍沒有實際來源；抽象 mask、必要模板或零觸發控制不能
當作它們的實現或排除。

每份任務必須保存同一原圖的外圈 \(B\)、原 degree-5 點 \(v\)、循環鄰點
\(L=(\ell_0,\ldots,\ell_4)\)，以及原邊、rotation、實際 attachments／supports、
分量與 bridge 的 ownership。若有額外 contacts，逐一具名，保留重合身份及
循環位置。所有組件先共同對齊同一色框，再做完整 join；保存十列中每一列的
完整介面關係、空 fibres、full lifts，以及原圖和變換圖的整張著色見證。
不得用 pair marginals、各自正規化的色名或不同原圖的成功列拼接結論。

尚無實際來源的條件性紙面論證，須保留上述具名來源、全部十列的關係公式及
full-lift 兩向構造，不能要求或捏造未知原圖的數值 fibres。有限控制則須保存
實際完整 fibres 與全圖 witnesses；可採可無損展開的分塊完整 join 編碼，並由
checker 核對其完整語義，不能改存單點／成對 marginals。

交付至少含 `REPORT.md`、凍結清單、紙面論證或明示未解義務；有有限計算時，
另附可重播 checker 與所需證書。逐項標示 `triggered and holds`、`not triggered` 或
`counterexample`，分開紙面普遍證明、有限校準與 Lean；未執行的驗證不寫成
通過。各任務只處理下面的明確子域，不以本批結束宣告
\(K_\infty=K_{\le5}\)。

## 任務 A：degree-5 link 的平面位置分類與替換契約

**要解的問題。** 在上述條件來源中，取一個 degree-5 內點 \(v\)。完整分類
其五個循環鄰點與原 \(B\) 的接觸位置，並給出每種位置可以安全套用的
「帶具名 pins 的 disk patch 替換」定理。這是一份紙面來源契約任務，不要求
本輪找到必然可縮減的點。

1. 從既有最小性逐步證明 link 的簡單性、是否 induced，以及分離三角形的
   排除如何適用；不能把圖上的五鄰點自動當成完全內部的分離五環。
2. 對 \(m=|V(L)\cap V(B)|=0,1,\ldots,5\)，列出保留 \(B\) 與 \(L\) 循環
   次序的所有合法接觸類型。區分共享點、共享邊、外框短／長弧，逐類證明
   不可能的類型或記錄 Jordan 分離得到的實際區域。D5 化簡須同時搬運兩個
   具名循環及所有附件，不得各自重新標號。
3. 對合法類型，明列各 cap／annulus 的邊界、可能的 chords、共享 pins、
   原支援歸屬及禁止跨區域的邊。若不是具簡單邊界的 disk，明寫實際拓撲
   及邊界 walk，例如 annulus 的雙邊界、共享 pin 造成的重複頂點；不套用
   僅對 C5 disk 成立的五內點代表。
4. 證明一個一般替換引理：固定所有實際介面 pins，若舊 patch 與新 patch
   的**完整具名介面關係**相同，且新 patch 能沿原 rotation 合法嵌入，則
   對任意同一外部圖的完整 join 保持原 \(\Sigma\)。寫出 full-lift 的兩向
   構造，並明示若只保留外圈十 bit 投影、漏掉額外 pins，哪一步會失效。
5. 給出每個可替換類型的內點計數式，例如
   \(k(H)=t+\sum_i k(P_i')\)，其中 \(t\) 必須逐一指出是哪些原介面點及
   中心點。指出哪些已由 C4 的三內點界、C5 的五內點界推出
   \(k(H)\le12\)，哪些仍需要更強的 pinned relation 界。

**驗收與停止點。** 交付完整位置表、具名平面分解圖或 rotation 資料、替換
引理及每類的計數／殘餘。若某類無法證明分解，給出該類最小的合法平面控制
或精確未解拓撲義務後停止。沒有完成的位置分類不能稱為一般縮減定理。
不依賴任務 B 的控制結果或任務 C 的 cap 聯集結論。

## 任務 B：同源 degree-5 star 的十列完整重接控制

**要解的問題。** 在固定的實際 disk witnesses 上，完整比較刪邊、合法 flip
與刪除中心後的合法 equality quotient，找出哪些局部條件足以保持全部
\(\Sigma\)，或給出明確反控制。目的在驗證重接條件的 soundness，有限成功
不升格為條件來源的普遍可縮減性。

**固定控制域。** 從 BASE 的凍結 132 個 literal witnesses 取所有 degree-5
內點標記，保留原嵌入與外框。另加入一個明示 literal edges 的五輪圖
\(W_5\)（C5 外圈加一個鄰接五外點的中心），保證 star 分支有正觸發。
\(W_5\) 的外點 degree 三，故只是控制，不能聲稱符合全域最小目錄外身份。
開始前凍結來源清單、標記規則及預期列數；不得用任意 candidate mask 代替
實際圖。目錄的 literal 輸入由
[cofacial v2 證書](../../audits/2026-10-12-cofacial-uniform-separation-eb6b2303/controls/certificate.v2.json)
及其原 checker 讀取，禁止覆寫。
在這些一般目錄控制中，\(L\) 首先只是按原 rotation 排列的五個鄰點；
只有逐邊核對相鄰鄰點確實相連後，才能稱它為 C5 link 或套用五輪分解。

1. 對每個 \((G,v,L)\) 保存十列的原圖 full lifts、\(G-v\) 的完整
   \((B,L)\) 關係及中心可用色。由實際同一份著色核對「中心可延拓」等價於
   五鄰點至多使用三色；不要只記是否存在一份 lift。
2. 枚舉每條原 spoke 的刪除；當兩側內面形成合法四邊形時，枚舉刪 spoke
   再加相對角線的 flip。保存刪邊圖上、同一份著色的兩個異色條件，包含
   十列所有空格，重建原圖及 flip 圖的關係。
3. 刪去 \(v\) 後，枚舉可穿過原空出的 disk 識別的非相鄰鄰點對。至少一端
   是原內點，且不得識別兩個不同外框 label；多重識別另外核對非交叉性、
   自環／平行邊簡化及原外框的保留。只把通過這些條件者列為合法變換。
4. 對每項變換比較完整 \(\Sigma\)：相等、嚴格縮小、嚴格擴大或互不包含。
   保存差異列及 literal 全圖著色見證，並分開「某指定列全部舊 lifts
   保留」與「全部十列關係保留」。若檢驗一個候選充分條件，必須先寫出它
   在同一 \((B,L)\) 關係上的精確公式，再凍結檢驗。
5. 用獨立回溯或直接枚舉核對全圖與介面關係，驗證平面性／disk 外框。
   加入破損證書測試，使 checker 拒絕漏列、錯 label、錯 lift 及非法 quotient。

**驗收與停止點。** 交付固定控制域的完整操作表、所有 relations／空 fibres／
full lifts、合法性證書與可重播 checker；至少明示哪些自然重接條件被反控制
否定。若全部固定圖都通過某條件，只稱固定域校準。933／941 的實際條件來源
若零觸發，明列 `not triggered`。不搜尋任意大小來源，不引用 edge-critical
假設，不依賴任務 A 或 C 的未完成結論。

## 任務 C：兩個外框接點的 C5＋C5 cap 分支

**要解的精確子域。** 獨立處理以下具名原圖位置，不要求分類其他位置：

\[
B=(a,b,c,d,e),\qquad L=(a,x,c,y,z),\qquad
N_G(v)=\{a,x,c,y,z\},
\]

其中 \(x,y,z,v\) 是互異原內點，只有 \(a,c\) 屬於原外框。原 rotation
使星形區域外的兩個 cap 恰為

\[
P:\ (a,b,c,y,z),\qquad Q:\ (a,x,c,d,e).
\]

也就是外框短弧 \(a-b-c\) 配上 link 的三邊路徑
\(c-y-z-a\)，外框長弧 \(c-d-e-a\) 配上 link 的兩邊路徑
\(a-x-c\)。先由原圖證明這是兩個 disk、沒有跨 cap 邊；不能僅憑示意圖
假定。另一個 C4＋C6 朝向、只碰一個外點及全內部 link 都不在本任務範圍。

**待驗證的有限閉合命題。** 對任意 \(R_P,R_Q\in K\)，把其實際 C5
representatives 按上述固定次序接上同一個中心五輪，所得完整外圈關係仍在
\(K\)。這是具名 cap 黏合的有限命題，不假設任意候選 \(\Sigma\) 可實現。

對固定原外圈指派 \((A,B,C,D,E)\)，共同枚舉 \(X,Y,Z,V\)，精確接合條件為

\[
(A,B,C,Y,Z)\in R_P,\qquad (A,X,C,D,E)\in R_Q,\qquad
V\notin\{A,X,C,Y,Z\}.
\]

兩份 \(R\) 先展開成 proper 色名指派，再按本式接合，不在各 cap 內另行更名。

1. 由全域內點最小性證明原 \(P,Q\) 的關係在 \(K\)：兩 cap 各自都比
   原 \(G\) 少內點，邊界 label 與次序依上式固定。由完整關係替換的兩向
   full lifts，證明只需檢驗目錄 cap pairs；本步自行證明，不等待任務 A。
2. 凍結全部 \(132^2\) 組有序 pair。把每個 cap 的十列展開到同一色框，對
   每個原 \(B\) 列枚舉 \(x,y,z,v\) 的共同指派。中心必須異於五個原鄰點，
   \(P,Q\) 的同名 \(a,c\) 必須使用同一色。保存包含 empties 的整份
   joint，以及每個接受列的 literal cap／整圖 full lift。
3. 使用原 literal cap witnesses 建立實際 disk 圖，逐項核對外圈、
   rotation、簡單化及平面性；若兩 cap 帶有同端點的平行邊，明記保留哪條
   嵌入邊及簡化不改著色的理由。不得只用 mask 算出的抽象成功值。
   標記原 \(x,y,z,v\) 的 ownership，重建圖內點數至多
   \(5+5+4=14\)，不能以 \(K_{\le12}=K\) 宣告其關係在 \(K\)。
4. 獨立實作關係 join 與 literal 圖著色，核對全部十列。將每個產出關係
   對回凍結 \(K\)，並列出各最少內點代表的索引。若全數在 \(K\)，交付
   此分支不可能出現在最小目錄外來源的紙面推論及有限證書。
5. 若有產出不在 \(K\)，先核對它是否為實際簡單 disk 圖、外圈標號是否
   正確、是否通過既有 screen；交付 literal 圖、完整十列／fibres、平面
   嵌入、內點數與可重播見證。若只是假資料、錯黏合或不合法嵌入，記為
   checker finding，不能稱數學反例。

第 1 步及原 cap 分解是對任意大小原圖的紙面適用性論證；第 2–5 步是固定
\(132^2\) 有序關係 pair 的完整有限核對。兩層都成立，才有原圖子域排除。

**驗收與停止點。** 結果只能是這個 C5＋C5 子域的完整閉合證書／條件排除，
或具體可實現的有限反控制／精確未解義務。十三內點以上的一般來源、至少六個
degree-5 點能否迫使出現本位置、C4＋C6 子域與一般壓縮命題繼續 OPEN。
這份任務只依 BASE 的已採納前提，不依任務 A、B 的新結果。

抽象 action 只保留被交換色對與互補色對的分割，因此要求目標：

row = 01020；01 分割 = {0,1,2}|{4}；23 分割 = {3}。

從全部 670 個既有 profiles 逐筆匹配，得到 IDs **329–342** 共十四個。
既有刪除輪已排除 329、334、336、341，留下十個，並非只有 330。

## 2. 單條禁令後，603 集合仍是固定域的最大閉合集合

前輪禁令限於同一圖的 sector 結構、degree、disk、兩拒絕列與指定
maximal 分量交換。把這個必要條件加入原抽象系統時，本輪只禁止
**(source=397, action=2, target=330)**，不將來源或目標狀態整體刪除。

重播既有 67 個刪除理由，確認它們各在保存的同步輪中確實無所需後繼，
或缺少必要全域置換後繼；得到原 603 集合。再核對其全部
**11,362 項存在後繼要求與 3,618 項全域色置換要求**。

加入禁令後只修改一項 witness：

```
397 / action 2：330 → 331。
```

331 同屬原存活集合，完整 row 與兩個保留分割都符合要求。
其他保存的 witnesses 不變；逐項核對全部要求後，仍有完整閉合證書。
這不是只看 397 的出度，也沒有把 331 當成圖層實現。

最大性亦不需重新迭代：加禁令只會減少容許後繼，故新最大閉合集合
包含於原 603 集合；上面的完整 witness 又證明這 603 個全可保留。
因此在**固定 670 catalogue、原規則加這一條禁令**的精確系統中，
最大閉合集合仍恰為原 603。這不表示更多有證明的禁令也都無效。
原 artifacts 沒有改寫，也沒有重啟圖搜尋、染色搜尋或固定點迴圈。

## 3. 相同抽象要求不等於相同實際交換

action 1 交換框交集 {4} 的 01 分量；它與 action 2 恰有相同的抽象
後繼要求，原 witness 也選 330。然而選中的實際 maximal 分量不同。
圖中可能還有不碰框的 01 分量；單獨交換 {4} 所在分量，不一定等於
交換 {0,1,2} 所在分量再作全圖色置換。
所以本輪不把 action 2 的證明直接貼到 action 1，更不把選取位元或
六個混合色分割相同視為同一份實際見證。需另證不碰框分量的影響。

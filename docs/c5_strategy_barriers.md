survivor-811 閉包，不新增圖或染色搜尋範圍。

**結果層級**：以下具體數字與規則為完整固定圖的 Python 證書證據；

## 1. state 126 為什麼必須升高？

在 boundary-root 轉移圖中，只保留 `χ≤3` 的 states。包含 state 126 的
連通分量 B₃ 有 **384 個 states，全都 χ=3，沒有 Goal**。
這裡可以用無向連通分量，是因為 checker 核對了每條 rooted component swap 的反向邊。

B₃ 的所有出口：

| 出口目標 χ | component-labeled 有向邊數 |
|---|---:|
| 4 | 192 |
| 5 | 360 |
| 6 | 48 |

這完整解釋了「升高不可避免」：在門檻 3 內可以走遍 B₃，但沒有成功位置；
任何成功歷程的第一次離開都要升高。不是只檢查選定三步詞。

更有用的是：**192 條升到 4 的出口，全部能接上峰值≤4、且不再返回 B₃ 的成功路徑。**
168 個 states 直接有這種出口；其餘 states 最多走兩步 χ 不變操作即可到達其中之一。
因此可為整個 B₃ 給出以下完整狀態宏操作：

```text
至多兩步留在 χ=3 → 一步升到 4 → 不返回 B₃ 的成功續接
```

所保存的每個成功歷程總長至多 6 步。每個 B₃ state 的最小必要峰值均為 4。
這是特定起始區域的成功實現正規化；還不是任意局部片段保相同離開狀態的替換。

## 2. state 247 的低谷也不能刪掉

既有成功歷程：

```text
state: 247 → 84 → 531 → 2026 → 4147 (Goal)
χ:       4 →  2 →   2 →    3 →    2
```

只說「先降到 2 會陷入需要回升的區域」仍不足以解釋必要性；也許另有路線可避開下降。
本輪因此完整檢查高度帶 `3≤χ≤4` 中包含 247 的連通分量 U：

- U 有 **600 個 states**：480 個 χ=3，120 個 χ=4；沒有 Goal。
- 在門檻 4 內，U 的 **240 條出口**只到達 **120 個 χ=2 states**。
- 這 120 個出口目標全部不能在 χ≤2 內成功，最小成功峰值均為 3。

故得到固定圖上的更強結論：

> 從 247 出發的每一條峰值≤4 成功歷程，都必須先到達 χ=2，之後再回到 χ≥3。

證明：成功歷程必須離開無目標的 U，第一次離開只能降到 2；
該出口目標沒有峰值≤2 的成功續接，因此之後必須再升高。
這是路徑子序列的必要性，不要求每條路都逐步呈現 `4,2,2,3,2`。

也測試了相同完整離開狀態的片段替換：從 247 到 2026，或到 4147，
若中間 states 都限制在 `[3,4]`（允許終點 4147 自己低於 3），均不可達。
證書保存這兩次搜尋的完整可達集合。故不能用「跳過低谷、保留相同出口」修補這條路。

### 低谷內可以怎麼離開？

在 χ≤2 下，包含 84 和 531 的分量 B₂ 有 **72 states，全都 χ=2，沒有 Goal**。
其 336 條出口中，48 條到 χ=3，288 條到 χ=4。
全部 48 條低出口都能接上峰值≤3、且不返回 B₂ 的成功路徑。
48 個 states 直接有低出口，其餘最多一步等高操作就能到達。

```text
至多一步留在 χ=2 → 一步升到 3 → 不返回 B₂ 的成功續接
```

保存的每條完整路徑總長至多 3 步；每個 B₂ state 的最小必要峰值均為 3。
兩個 B 的 456 條成功歷程共 1,645 步，全部按各自完整染色重算 maximal components 回放。

## 3. 升高究竟是哪個 cut 重接造成的？

### state 126 → 14：一組系統由一個 cycle 變成兩個

操作 `BD@3`，component 是 `{3,4,9,16,21}`，cut 有 15 條原圖邊。
三組 dual systems 的 cycle 向量為

```text
(1,1,1) → (2,1,1)
```

第一組（XOR edge types `{1,2}`）刪除 cut 後沒有殘存 cycle。
將 retained components 收縮為 R₀,R₁,…（索引由證書固定）後：

| 加回哪一組 cut 邊 | 形成 cycle 的收縮圖結構 | cycle 數 |
|---|---|---:|
| source 邊 | R₄ 與 R₇ 間兩條平行邊，原邊 IDs 32、43 | 1 |
| target 邊 | R₄ 上的 loop 42；R₁ 與 R₃ 間平行邊 7、23 | 2 |

其餘收縮邊不增加 cycle rank。目標兩個真實 dual cycles 的原邊集合為
`{36,42,52,56}` 與 `{5,7,23,24,33,49}`。
後兩組 cycle 數各維持 1；它們的 boundary paths 仍可能改變，不能說全部結構不動。

### state 531 → 2026：新邊封閉 retained path

操作 `AC@0`，component 是 `{0,1,3,4,14,15,18,21}`，cut 長 30。

```text
(1,1,0) → (1,1,1)
```

第三組（types `{2,3}`）在刪 cut 後無 cycle；加回 source 邊的收縮圖也無 cycle。
加回 target 邊時，原邊 44 成為 retained block R₉ 上的 loop，恰增加一個 cycle。
實際新 cycle 是 `{32,36,43,44,52,56}`。
第一組同時把舊 loop 重接成平行邊所成的 cycle，數量仍為 1；第二組保持原 cycle。

### 第一條三步路徑的增減帳

| 轉移 | cycle 向量變化 | cut 重接的作用 |
|---|---|---|
| 126→14 | `(1,1,1)→(2,1,1)` | 第一組恢復舊 1 cycle／閉合新 2 cycles |
| 14→122 | `(2,1,1)→(2,2,0)` | 第二組 +1，第三組 −1，總數不變 |
| 122→630 | `(2,2,0)→(1,2,0)` | 第一組 −1，第二組雖重接但數量不變，達到 Goal |

同一個 count 並不表示同一個 cycle 或同一份 boundary pairing；這個帳只分析數量。

## 4. 一般 cut-cycle 計數引理（紙面證明）

對一組固定 dual system，把 source 與 target 的共同非 cut 子圖記為 H。
令 A₀、A₁ 分別為 source／target 要加回的 cut 邊。
固定頂點集包含所有內部 faces 及五個 boundary terminals，未使用的 terminals 仍作孤點。

把 H 的每個連通分量收縮成一點，分別由 A₀、A₁ 建立 multigraph Q₀、Q₁。
**保留自環、平行邊及孤點。** 對有限 multigraph 定義

\[
\beta(F)=|E(F)|-|V(F)|+\operatorname{cc}(F).
\]

則

\[
\beta(H\cup A_j)=\beta(H)+\beta(Q_j),\qquad
\boxed{\Delta\mathrm{cycles}=\beta(Q_1)-\beta(Q_0).}
\]

**證明。** H 與 Aⱼ 邊集不交；Qⱼ 的頂點數為 cc(H)，邊數為 |Aⱼ|。
沿 H 分量收縮保留連通分量對應，所以 cc(H∪Aⱼ)=cc(Qⱼ)。代入：

\[
|E(H)|+|A_j|-|V(H)|+\operatorname{cc}(Q_j)
=\beta(H)+|A_j|-\operatorname{cc}(H)+\operatorname{cc}(Q_j).
\]

這就是第一式。合法 dual system 的內部頂點度數為 2、terminals 度數為 0 或 1，
所以每個分量為 path、cycle 或孤點，β 恰為 cycle 數；兩式相減得結論。
相加三組便得到 χ 的變化。此計數引理本身不依賴額外平面分離論證，
但把圖解釋為這些 dual systems 仍依賴既有模型假設。

本輪核對 **240 條低出口＋7 條指定 witness transitions** 的三組計數。
其中 216 條低出口的向量增量是 `(1,0,0)` 的排列，另 24 條是 `(2,-1,0)` 的排列。
因此連「總數只加一」也不能解讀成「只一組新生一個 cycle」。

負控制：把 126→14 第一組 target quotient 改成 simple graph、合併平行邊，
β 會從 2 錯成 1。只保存無重邊的鄰接關係不足以計數。
本引理補的是既有 retained-component connectivity 接口的計數層；未宣稱它足以
列出下一步合法 actions、更新任意長歷程或讓介面大小有界。

## 5. 可用的規範歷程引理（紙面證明）

在具可逆操作的完整狀態系統中，χ 取整數值。假設 B 是 `{χ≤k}` 轉移圖的一個
連通分量，B 不含 Goal，而且 B 的每點 χ=k。設 E⊆B 是一組出口來源，滿足：

1. 每個 s∈B 都能經至多 L 步 B 內操作到達 E。
2. 每個 e∈E 有一步到 t∉B，χ(t)=k+1。
3. 這些指定 t 都有不返回 B、且峰值≤k+1 的有限成功續接。

則每個 s∈B 有「至多 L 步等高、一步升高、外部成功續接」的歷程，且 κ(s)=k+1。

**證明。** 串接三段給出上界。若存在峰值≤k 的成功歷程，它從 B 出發且無法離開
該 sublevel 連通分量，便會在不含 Goal 的 B 中成功，矛盾。因此下界為 k+1。

這能替換從 B 出發的成功歷程，保留 **escape 成功這個目標觀察**，並排除大於 k+1
的峰值。若原歷程走了更高峰值，整條歷程的該類壞狀態數便嚴格下降至零。
它不保證相同終點染色、相同後續 action word 或相同靜態 Σ；若要嵌回尚有後綴的
歷程，仍須另證離開狀態相等或足夠的續接等價。

本輪 B₃ 與 B₂ 用有限證書滿足這些假設；跨圖難點仍是如何由結構推出出口存在
和成功續接，而不是把已計算出的 winning rank 當成局部結構理由。

## 6. 下一入口與重現

受控出口，而且出口不把成功續接再送回同一個障礙區域？**
先比較本證書的 240 條低出口，尤其 `(2,-1,0)` 的 24 條補償型增量。

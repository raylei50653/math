## 1. 查詢域與五個目標

固定 K 邊界 `(z,b1,b2,b3,b4)`；開口時去掉框邊 `zb1,zb4`，保留路徑
`b1b2b3b4` 及所有碰內部 C 的邊。允許至多四色，色置換正規化後共 19 列。
前十列採 `c5_cell_enumerator.REPS` 順序；額外兩列如下。
位元編號從 0 開始，整數 mask 的第 i 位對應第 i 列，1 表示接受。

| i | 正規化列 | 備註 |
| --- | --- | --- |
| 0 | 01012 | proper C5 |
| 1 | 01021 | proper C5 |
| 2 | 01023 | proper C5 |
| 3 | 01201 | proper C5 |
| 4 | 01202 | proper C5 |
| 5 | 01203 | proper C5 |
| 6 | 01212 | proper C5 |
| 7 | 01213 | fixed-q 的 z=D |
| 8 | 01231 | proper C5 |
| 9 | 01232 | proper C5 |
| 10 | 00102 | fixed-q 的 z=B |
| 11 | 01210 | fixed-q 的 z=C |

fixed-q 的 z=A 是第 0 列。接合公式與四列檢查用到的聯集恰是這十二列；
其他七列自由，因此不必逐一跑 524,288 張表：完整窮舉 4,096 個投影後，
每個投影恰有 128 個 lifts。兩種實作（索引位元／直接集合查詢）一致。

| 條件 | 19-bit 表數 |
| --- | ---: |
| T4 全接受、拒絕 q、F_C(q)={D} | 3,072 |
| 再限制恰缺 q 與一相鄰 p | 640 |

五個 12-bit masks 為 **3647、3703、3895、3901、3903**。
3703 的外側 Σ mask 是 1020，其餘四個是 958。每個目標另逐一核對
全部 240 個有標號原 boundary rows。這些數字重現使用者初測；只是目前
fixed-q 查詢的充分投影，並非一般接合、刪邊或跨圖充分 state。

## 2. 已保存接線的對照

讀取既有 `artifacts/c5_cells/cells.json` 的 132 份代表，施以全部十個
boundary 二面體重標記，篩選 chordless C5、C 非空連通、所有內點完整
degree=4、z 恰有兩個內鄰居，再按實際有標號邊集去重：留下 **14 份**。
全部重新核對 apex-disk planarity，保存 rotation、來源索引與 boundary map。
每個 12-bit 結果同時由回溯染色與內部四色 assignment 窮舉驗證。
全部五目標的逐位差異保存在 artifact，沒有命中。

最接近的三組對照如下；同一簽章可能來自不同實際接線。

| 實際簽章 | 目標 | 唯一差異 | F_C(q) |
| --- | --- | --- | --- |
| 1855 | 3903 | 第 11 列：實際拒絕 z=C，目標接受 | {C,D} |
| 3831 | 3703 | 第 7 列：實際接受 z=D，目標拒絕 | 空集 |
| 4031 | 3903 | 第 7 列：實際接受 z=D，目標拒絕 | 空集 |

第一行就是既有二內點非 minimal 控制的介面現象：其他八列已接受，卻連帶
拒絕 C。後兩行展示另一種一位之差：開口測試通過，但 q 本身也可延拓。
這是不同固定圖的對照，沒有建立能在兩者間改一條邊的操作或因果關係。

此 catalogue 每個完整 Σ 只保存代表，不能據此排除同 Σ 的其他圖實現，
也沒有使用 Σ 代表替代其他圖的開口測試。未重跑原 catalogue 或 R24–R31。

## 3. 固定第一目標的有限反向搜尋

選 3647，窮舉 `1≤|C|≤3` 的全部有標號 simple 內部圖與 boundary 接線。
內部圖要求連通，逐點選恰使完整 degree=4 的 boundary 鄰集，要求 z
恰有兩個不同內鄰居；框邊固定為 C5，沒有 boundary chords。
沒有預先施加 Gallai-tree 或 minimality 篩選，因此涵蓋此大小下完整的
指定圖類。|C|=1 因無法提供兩個不同接點而沒有候選。

| 內點數 | degree／接點合格 | disk 合格 | 3647 命中（檢查 disk 前） |
| ---: | ---: | ---: | ---: |
| 1 | 0 | 0 | 0 |
| 2 | 36 | 10 | 0 |
| 3 | 1,512 | 120 | 0 |

這些是有標號圖數，沒有除以內點置換。所有候選都保存於確定性重播範圍，
130 份 disk 圖另保存實際邊及 rotation；其餘非 disk 圖只記計數，不存拓撲
排除證書。拓撲判定信任 NetworkX 3.5 與 boundary-apex disk 等價。

130 份 disk 圖中，恰相鄰雙缺失者只有兩份有標號接線，簽章都是 1855，
F_C(q)={C,D}；兩者只是已知二內點控制的內點換名。
既有原圖的全部 240 列及逐非 boundary 邊刪除已重驗，唯一冗餘邊仍是
`zb4`。沒有發現新的共同機制。第一目標在 planarity 檢查前就零命中，
所以這批失敗不能當作 disk 拓撲作用的證據。

已完成抽象篩選重建、既有 sector 代表對照與第一目標的 |C|≤3 反向搜尋。

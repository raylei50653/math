## 圈法與精確契約

所有方法只產生原頂點的一份完整消元排列，再交給既有 `solve_local_messages`。
它依該排列建立袋樹，重新核對每條原邊的覆蓋及同一原點所在袋的連通性。
規劃填補邊只代表依賴，不增加異色條件；原頂點、原邊、固定色及候選域不變。
每次孩子答覆仍針對同一份父袋列投影出的**完整有序接口色組**；未問列由原限制
及精確查詢程序隱式保存。沒有刪除接口列、以低階投影代替共同關係或提前填色。

| 策略 | 實際圈區方式 |
| --- | --- |
| `min_fill` | 原型預設，每步依新增填補邊數、接口大小及輸入次序選點。 |
| `min_degree` | 依當前填補圖的最小度選點，作較便宜的次序對照。 |
| `geometric_sweep` | 沿兩座標軸各試正反方向，依原圖 frontier 評分選一份窄條掃描次序。 |
| `geometric_nested` | 以座標軸線跨邊的一側端點作分隔；遞迴先處理內部，再處理分隔點。 |
| `bfs_sweep` | 以圖距離的整層依序展開／收縮，從四份候選次序中依原圖 frontier 評分選一份。 |
| `bfs_nested` | 用完整 BFS 層作平衡分隔，遞迴先處理內部，再處理分隔點。 |

`bfs_sweep` 不需要座標。各連通分量取輸入第一點及其一個最遠點作兩個根，
各根有距離層升序／降序兩種次序，層內依輸入次序；跨分量串接對應版本得到
四份全圖候選。依「已處理前綴在未處理部分的原鄰點集合」之最大大小、累計大小、
固定候選次序選一份。只讀圖結構，不用固定色、求解結果或事後最快模式選贏家。
frontier 評分是啟發式，並非實際查詢量或耗時上界。

兩種遞迴方法在每次切區時使用**當前填補圖**，子區評分含祖先留下的外部接口。
最大子區須不超過當區2/3；小葉或無可用分隔時用局部min-fill，預設葉門檻8。
這避免漏算當時已存在的跨區依賴，仍不保證後續最大接口：祖先分隔點最後接合時
可能變大。幾何方法須有明確座標，不拿播放器自造位置當原圖幾何。

此處的「圈」是圖的分隔／處理前沿，BFS層及軸線分隔不保證每區是單純多邊形。
無資源限制的精確性沿用既有樹形查詢契約；有限預算下仍可 `limit`。
本輪沒有新增Lean，也未形式化驗證Python規劃器或證明一般固定接口寬度。

## 樣本、成本與比較方式

固定33份圖與域／固定色條件，含普通格圖、規則三角格、單格翻對角線、
每格隨機選對角線、兩色奇偶環與K5。它們不是33份互相獨立的原圖抽樣。
18份發展條件、10份另設確認條件、2份探索後挑出的展示例及3份小控制分開保存。
確認條件使用不同大小／seed，沒有拿它們調整策略；仍不是統計隨機代表樣本。
網格幾何例由不交叉的格邊與每格至多一條對角線直接構造；K5另作非平面控制。

每策略每例總預算2,000,000 checks，**規劃工作先扣除，再將餘額交給求解器**；
規劃、重播填補圖、分解驗證、局部查詢及回填均計入。排序、配置與所有Python指令
並非逐一計數，因此 checks 是所定義的邏輯工作，另存含規劃的實際時間。
換色快取固定關閉，避免把色群壓縮混入圈法收益。無座標的三份控制不跑兩種幾何策略，
共192份執行。訊息、快取與完整紀錄各保留足夠容量，沒有截斷transcript。

主要指標是所有**非根詢問＋答覆中傳送的顏色值總數**，包含重複訊息及否定答覆。
這是完整接口tuple的負載，不是JSON大小、網路傳輸位元組或RSS；頂點ID、封包標頭
等未計入。另存每色2-bit加每答覆1-bit的邏輯編碼量、實際查詢數、最大接口及
候選域乘積；後兩者不冒充實際訊息量。

## 結果

下表每列只比較該方法與基準**皆已完成**的同一組條件；超限另列，不把部分成本
當成完整成本。幾何模式只適用30份有座標條件，各列集合不同，不直接互除總量。

| 方法 | 完成／超限 | 訊息減少／相同／增加例數 | 共同完成條件的色值量變化 |
| --- | ---: | ---: | ---: |
| `min_degree` | 32／1 | 9／6／17 | −3.91% |
| `geometric_sweep` | 30／0 | 16／1／13 | −79.32% |
| `geometric_nested` | 28／2 | 2／0／26 | +71.17% |
| `bfs_sweep` | 33／0 | 20／3／10 | **−94.23%** |
| `bfs_nested` | 31／2 | 4／3／24 | +105.48% |

`min_fill` 與 `bfs_sweep` 均為24份可染、9份精確無解／指定條件無延伸。

| BFS掃描對照範圍 | 原型色值量 → 掃描色值量 | 減少 | 含規劃checks → 掃描checks |
| --- | ---: | ---: | ---: |
| 全33份 | 1,177,408 → 67,934 | 94.23% | 4,018,894 → 407,630 |
| 排除2份探索後選出的展示例 | 401,660 → 63,144 | 84.28% | 2,298,264 → 354,432 |
| 10份確認條件 | 219,784 → 24,448 | 88.88% | 1,091,823 → 144,858 |

全33份逐例訊息減少比例的中位數30.42%，確認集78.31%；整批總量受困難案例影響。
最終重播的求解總時間（包含規劃）約1.424→0.118秒，確認集0.300→0.041秒。
這是本機單次、固定順序量測，不提供一般加速倍數或穩定統計估計。

具名案例同時保留收益與退步：

| 原圖條件 | 最大接口：原型→BFS | 色值量：原型→BFS | 判讀 |
| --- | ---: | ---: | --- |
| 12×16規則三角格，四色、無固定色 | 18→12 | 73,862→3,572 | 少95.16%；探索示例，沒有三色域限制。 |
| 8×9規則三角格，四色、相容固定點seed4627 | 11→8 | 701,886→1,218 | 少99.83%；探索示例。 |
| 10×13規則三角格，四色、相容固定點seed2027 | 15→10 | 47,786→2,234 | 少95.32%；另設確認條件。 |
| 9×10普通格圖，四色 | 12→9 | 892→1,194 | 增33.86%，接口較窄仍可能傳得更多。 |
| 7×9隨機對角線，四色、相容固定點seed211 | 9→11 | 9,808→12,562 | 增28.08%；確認集退步保留。 |

收益與查詢次序有關：完整關係可按需查，找到相容路徑較早就不必問遍其他列。
接口大小只限制每份訊息的長度及可能狀態數，不能決定實際重複詢問次數。
確認集10份中有6份接口峰值增加，但7份實際負載減少。因此這次證據支持
**某些掃描次序能減少實際接口查詢負擔**，不支持所有圈法都能縮小接面。

## 驗證與證據層

每份條件都由獨立原邊MRV窮舉求得參考判定，有解只需一份見證；未使用四色定理oracle。
187份完成執行皆與參考一致，5份 `limit` 保持未判定；所有回傳染色逐原邊、固定色及域核對。
其中70份分解以完整自底向上關係逐答覆核對，包含空關係；另外117份完成執行只核
最終原圖判定與見證，沒有聲稱所有大接口答覆均經獨立全表枚舉。

新增13項測試涵蓋604份小圖／域／次序條件，逐答覆核原子樹存在性，另核排列驗證、
巨大／負標號、填補邊負控制、規劃與查詢預算中斷及回填途中超限不公開顏色。
全套399項四色測試通過後，另加的回填超限回歸與全部13項新測試再通過。
預設 `elimination_order=None` 對33份條件的判定、完整統計、見證及transcript
與進入本輪前的來源快照逐份完全相等。

保存探索比較 `comparison/`、修正重播入口後的 `final/`，以及預算稽核文字修正後的
`verified/`。最終以 `PYTHONHASHSEED=17` 重播192份，所有判定、計數與前輪一致；
5份超限的稽核文字改為未判定。各輪來源快照與hash分開，未覆寫前輪證據。
獨立 `verify.py` 重算全部壓縮證據hash、實際訊息量與成功見證；完整表核對來自
比較程式的獨立reference，不把這個後續重算當成再次全表枚舉。

## 使用與重播

```python
from four_color_region_order import build_region_order
from four_color_local_messages import solve_local_messages

budget = 2_000_000
plan = build_region_order(graph, "bfs_sweep", max_checks=budget)
if plan["status"] == "planned":
    result = solve_local_messages(
        graph, elimination_order=plan["order"],
        max_checks=budget - plan["stats"]["checks"],
    )
    # result["status"] 是 colored / unsatisfiable / limit。
else:
    result = {"status": "limit", "colors": None}
```

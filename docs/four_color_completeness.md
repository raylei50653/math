# 完整精確消元的四色判定與共同見證回寫

本頁證明：對任意有限簡單無向圖及合法的部分固定色，若不受工作、儲存等資源限制，

構造同一份共同相容的完整染色。此結論不要求圖平面，也不要求解唯一。

## 輸入、因子與完整解

設 `G=(V,E)` 為有限簡單無向圖，色集合固定為 `C={0,1,2,3}`。
部分固定色是函數 `f:F→C`，其中 `F⊆V`。每點的初始域為

```text
D_v = {f(v)}，若 v∈F；否則 D_v = C。
```

所有表共用同一份原頂點身份與字面色號，不對各表獨立換色。
為每個有限頂點集合選定欄位次序；`C^S` 表示 `S` 上的完整指派，表列只是這種
指派依該次序寫成的 tuple。特別約定

```text
C^∅ = {ε}，其中 ε 是唯一的空指派。
```

一個因子是 `(S,R)`，其中 scope 為 `S`，關係為 `R⊆C^S`。
指派 `s` 滿足此因子，恰指 `s|S∈R`。關係可以為空，scope 也可以為空。

初始問題記為 `I`，包含：

1. 每一個 `v∈V` 的一元域因子 `({v},D_v)`，包括孤立點。
2. 每一條原邊 `uv∈E` 的異色因子，完整列為所有 `s∈C^{ {u,v} }`
   且 `s(u)≠s(v)` 的指派。

所以 `Sol(I)` 恰好是同時滿足全部原邊及固定色的完整四色染色集合。
一元因子可以實作為獨立候選域；證明中將它明列，避免把孤立點或域限制漏出問題。

一般的當前問題記為 `P=(U,𝓕)`，其中 `U` 是活動頂點集合，`𝓕` 是有限因子族，
每個 scope 都包含於 `U`，且每個活動點的當前域都由一元因子或等價的域表示保存。
定義

```text
Sol(P) = { s∈C^U : 對每個 (S,R)∈𝓕，皆有 s|S∈R }。
```

下文的「完整」均指一份指定問題的完整聯合關係，不是各欄的獨立候選集合。
完整表可以為空；未列出的邊界在記錄當下的域乘積內表示空 fibre，不能自行填補。

## 傳播契約：保留全部當前解，且有限終止

一輪傳播 `Prop` 必須滿足以下條件：

- 活動集合 `U` 不變；傳播結果仍只含活動變數。若某操作也移除變數，該操作必須另有
  精確投影與重建紀錄，不能僅歸入這裡的傳播。
- 保留完整解集合：`Sol(Prop(P))=Sol(P)`。僅保留「有解／無解」的真假值不足以
  保證後續任取的解仍能使用既有回寫紀錄。
- 每輪傳播有限終止；也可只執行任意有限次符合上述等式的步驟，不必求至固定點。

例如，刪除沒有支援的域值或關係列，必須證明沒有一份當前完整解會使用它；
加入派生因子，必須證明每份當前完整解都滿足它。每一步滿足此要求，有限次合成
便仍保留全部解。這不表示傳播能發現所有無解情況。

有限域本身不會阻止程式反覆執行無作用規則。若要由有限性推出固定點程序終止，
可採用有限的候選因子族，讓域與既有表只縮小、每個候選至多插入一次，並在沒有
變更時停止；如此只有有限次刪值、刪列及插入。不得靠刪除後反覆重加同一因子，
或把重複查詢本身算成進度。以下定理直接以有限終止的可靠傳播為前提。

為免混淆初始傳播與第一步消元，令

```text
P_0 = Prop(I)。
```

因此 `P_0` 的活動集合仍為 `V`，且 `Sol(P_0)=Sol(I)`。
`Prop` 可以是恆等操作；完整消元的完備性不依賴局部傳播額外刪掉任何選項。

## 單步精確消元

設消元前問題為 `P_i`，活動集合為 `U_i`，任選 `x_i∈U_i`。
將**所有**含 `x_i` 的當前因子放入 bucket `𝓑_i`，其餘因子記為 `𝓠_i`。
令有序接口為

```text
Y_i = (所有 𝓑_i 因子的 scope 聯集) \ {x_i}。
```

記當前各點域為 `D_v^i`。對每個 `y∈∏_{v∈Y_i}D_v^i`，定義完整支援集合

```text
W_i(y) = { a∈D_{x_i}^i :
           y∪{x_i↦a} 同時滿足 𝓑_i 的每一個因子 }，
R_i = { y∈∏_{v∈Y_i}D_v^i : W_i(y)≠∅ }。
```

這裡是一份 `y` 同時滿足所有 bucket 因子，不是替不同因子各找一份可能不同的
邊界或內部顏色。所有當前域也始終受到一元因子約束；上述定義只略去域外本已禁止
的指派，沒有略去域內可能合法的列。

消元結果記為 `E_i`：活動集合改為 `U_i\{x_i}`，用新因子 `(Y_i,R_i)`
取代整個 bucket，保留 `𝓠_i`。同時保存 `x_i`、有序 `Y_i`、當時的域及全部
`W_i(y)`。不屬於 `R_i` 的域內邊界，明確具有空支援集合。
回寫紀錄保存後不再改寫；後續活動因子即使被篩選或消去，也不覆寫這份歷史 fibre。

### 引理：完整解的逐份投影等價

令 `π_i` 表示將活動指派限制到 `U_i\{x_i}`。則

```text
Sol(E_i) = π_i(Sol(P_i))。
```

這是完整解集合的等式。具體而言，對每一份剩餘指派 `t`，
`t∈Sol(E_i)` 當且僅當存在顏色 `a`，使 `t∪{x_i↦a}∈Sol(P_i)`。

**正向。** 若 `s∈Sol(P_i)`，令 `t=π_i(s)`、`y=t|Y_i`、`a=s(x_i)`。
因為 `s` 滿足全部當前域及 bucket 因子，所以 `a∈W_i(y)`，進而 `y∈R_i`。
`𝓠_i` 不含 `x_i`，故 `t` 仍滿足其中每個因子。於是 `t∈Sol(E_i)`。

**反向。** 若 `t∈Sol(E_i)`，令 `y=t|Y_i`。新因子保證 `y∈R_i`，所以
`W_i(y)≠∅`。任取 `a∈W_i(y)`，令 `s=t∪{x_i↦a}`。
按支援集合定義，`s` 同時滿足全部 bucket 因子；`𝓠_i` 不含 `x_i`，故它們
仍由原來的同一份 `t` 滿足。兩部分涵蓋 `P_i` 的所有因子，因此 `s∈Sol(P_i)`。

兩向也證明 `P_i` 與 `E_i` 等可滿足。這一步需要合併所有含 `x_i` 的因子，
並保留完整 `Y_i` 列；任意漏因子、拆成各欄支援或只保留低階投影，都不能直接
沿用此引理。

## 全程不變式與有解／無解判定

每次消元後再令

```text
P_{i+1} = Prop(E_i)，U_{i+1}=U_i\{x_i}。
```

因傳播保留全部當前解，單步引理給出

```text
Sol(P_{i+1}) = Sol(E_i) = π_i(Sol(P_i))。
```

由 `Sol(P_0)=Sol(I)` 歸納，對每個已完成的階段 k 都有

```text
Sol(P_k) = { s|U_k : s∈Sol(I) }。
```

也就是當前完整解，恰好是原問題完整解在剩餘活動點上的投影；不是僅保留了某些
各自可延伸的局部選項。

若傳播已發現空域或空因子，或者某步 `R_i=∅`，當前問題沒有解；依此不變式，
原問題也沒有解。因此可以立即回傳 `unsatisfiable`。有固定色時，這只表示該份
固定色無延伸，不是否定解除固定色後的原圖四色染色。

反之，設全部點都已消元。此時活動集合為空，剩餘因子只能是零元因子。
必須檢查它們：若有空關係便判無解；若每個關係都包含 `ε`，則唯一的空指派
滿足全部因子，故 `Sol(P_n)={ε}`。不變式隨即推出 `Sol(I)≠∅`。
零元真因子可以省略，零元假因子不能靜默丟棄。

## 倒序回寫始終延伸同一份見證

全部消元成功後，從 `s_n=ε∈Sol(P_n)` 開始。假設已取得一份
`s_{i+1}∈Sol(P_{i+1})`，要回寫 `x_i`。

由傳播等式，這份**同一指派**也屬於 `Sol(E_i)`。因此它在完整接口上的限制
`y=s_{i+1}|Y_i` 必屬於 `R_i`，保存的 `W_i(y)` 必非空。
任取 `a∈W_i(y)`，設定

```text
s_i = s_{i+1}∪{x_i↦a}。
```

單步引理的反向證明立即給出 `s_i∈Sol(P_i)`。所有已確定的活動點色保持原樣，
只替這個 `x_i` 增加一色。倒序時 `Y_i` 中的點已全部回寫，所以查詢是一份確定的
完整接口列，不需要猜測尚未確定的邊界。

如此歸納至 `s_0∈Sol(P_0)=Sol(I)`，便得到符合全部原邊與固定色的完整染色。
後續傳播即使收緊活動域，也不需改寫舊的 `W_i`：回寫時先有一份滿足 `E_i`
的完整剩餘指派，再使用它指定的那一列；該列內任一保存色都同時滿足當時全部
bucket 因子。任意拼接不同列的各欄顏色則沒有這項保證。

因此有解時不會在回寫途中突然找不到支援。保留多份支援沒有問題；回寫只需逐步
選出一份共同見證，不要求先證明解唯一。最後可再直接逐原邊、逐固定色核對輸出。

## 有限終止與邊界情況

設 `n=|V|`。每輪傳播依契約有限終止；每次成功消元恰移除一個活動點，
所以至多進行 n 次消元。每個域最多四色，每個 bucket 都只有有限個因子；
對接口 `Y_i`，完整列舉至多檢查 `4^{|Y_i|+1}` 份邊界及內部色組合。
每份組合只需核對有限個有限關係，所以單次消元及其完整紀錄都有限。
最後至多 n 次回寫，每次查有限表並取一個支援色，也有限終止。

因而，在不因資源限制中斷的前提下，演算法一定走到以下兩種結果之一：

- 無解時回傳 `unsatisfiable`；若直到活動集合為空才顯現矛盾，最後的零元因子檢查
  仍會發現它，不會錯誤進入成功回寫。
- 有解時完成全部消元與倒序回寫，取得一份合法完整染色，回傳 `colored`。

這也涵蓋以下情況：

- **空接口。** `∏_{v∈∅}D_v={ε}`。若 `W_i(ε)≠∅`，投影為零元真因子
  `R_i={ε}`；若 `W_i(ε)=∅`，投影為零元假因子 `R_i=∅`，必須判否。
- **孤立點。** 若其 bucket 只有一元域因子，則接口為空，`W_i(ε)=D_{x_i}^i`；
  非空域可在回寫時任取一色，空域判否。孤立點不需要原邊才能被處理。
- **空圖。** `V=∅` 時合法固定色也只能為空。初始無邊、無一元因子，唯一空指派
  已是一份合法完整染色；零次消元、零次回寫即可成功。
- **不連通圖或非平面圖。** 同一證明直接適用，不需額外幾何前提。
  某圖不可四色染色時，正確結果是無解，並非演算法無法處理該有限輸入。

有限終止不是一般效率保證。接口大小可以隨圖增長，完整表最壞會指數成長；
對每個固定有限輸入存在足夠大的有限資源，不表示存在實用的統一時間或記憶體界。

## 與現行精確枚舉、模板及快取的關係

初始逐邊因子可用精確三角形或 K₄ 因子分組表示，只要涵蓋全部原邊且其完整關係
恰好等於相應邊限制的合取，初始解集合便不變。一元域仍須保留。
額外結構因子若由同一原圖及當前約束可靠推出，也只是加入邏輯後果。
有界找型漏掉這類可選因子，會減少傳播機會，不會漏掉初始原邊或取代完整消元。

現行消元可選 bucket 中一張完整因子作為起點，枚舉它的每一列，再枚舉該列尚未
指定的接口座標，最後核對其餘所有 bucket 因子。任何真正滿足整個 bucket 的指派
必定限制成起點表中的一列，所以這種枚舉不會遺漏合法指派；通過全部核對的指派
也確實合法。只要保留所有完整列及全部支援色，它計算的仍是上述同一份 `W_i`、
`R_i`。沒有起點因子時可直接列舉域乘積；概念上的一元域因子已涵蓋孤立點情況。

可選索引與快取亦須遵守同一契約：查詢結果與完整列舉一致，域或因子改變時正確
失效，容量不足時退回精確計算或只移除可重建的索引。這些做法可減少重算，
不改變投影等式。若改為近似表、漏列、過期查詢或只留邊際支援，則不在本證明內。

## 結論適用範圍與仍開放的問題

本定理保證的是「可靠傳播＋完整精確消元＋共同見證回寫」這個完整演算法。
只做局部傳播，或在每張表非空、兩兩接口一致時停止，不能套用本定理的成功結論；
相關反例及充分條件見[保證與局部缺口](four_color_guarantee_gap.md)。
現有可選局部規則對所有輸入都能在消元前完成判定，仍無一般保證（OPEN）；
一般高效率、固定大小接口及普遍免消元完成也沒有由此得到保證。

現行程式保留有限工作與儲存預算，可能回傳 `limit`，其意義始終是尚未判定。
本頁沒有聲稱已有無限預算的 CLI 開關，也沒有把有限測試擴大成整份實作的形式化驗證。
紙證說明正確實作上述契約時的完備性；程式來源、有限回歸及最後原邊核對是不同層次的證據。
這項有限圖求解定理亦不改變 C₅／W7／J1／J2 的原來源排除、覆蓋或其他研究 OPEN 義務。

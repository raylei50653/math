本報告保留研究輪當時的紀錄；後續整合提交與重播範圍見
[STATUS §59](STATUS.md#59-3903-六輪成果整理與提交核對)。

2026-09-19，接續尚未提交的 [框點切斷分支](c5_sector_frame_cut.md)。
本輪用四色重數分類排除五內點情形。結合前輪，得到：
**在原 sector 的圖結構條件下，disk 的 397→330 必有至少六內點。**
沒有證明六內點可達或一般排除；沒有擴大候選圖搜尋，也未刪除 profiles。

## 1. 精確前提與四個必有內點

沿用 Γ=(0,1,2,3,4) induced、C 非空連通、G=K−{01,04}，
內點 degree≤4。另使用原 sector 的兩接點條件 **deg_G(0)=2**；
本輪證明實際只需 deg_G(0)≥2。這個框點條件不可省略。
舊 proper 框列 01021，S 為單一 maximal 0/1 分量且
S∩Γ={0,1,2}，c′ 由同一 c 在 S 上交換得出。

本輪只處理 S−{1} 切斷 0、2 的分支。使用的 profile 条件為：

- 來源 397：舊 13 有 L₃:1→4；舊 02 分離 0 與 3（也與 2 分離）。
- 候選 330：新原始 02 有 L₂:1→3；新原始 13 分離 0、4。

其餘新 12／13 分離不需用於本次下界，仍是一般問題的必要條件。
以上路徑均選簡單 Γ-path。由前輪，S 有 0–1 Γ-path，給內部舊色
0、1 的頂點 a、b；L₂ 第一內點 p 舊色 2，L₃ 第一內點 q 舊色 3。
它們互異。反設 |C|=5，唯一多出的頂點記 r。

此時至多一種色有兩個內點，故 S 內的簡單 0–1 路徑不能多於兩個
內點：若有四個內點便需各兩個舊色 0、1。因此可具名為
**0–b–a–1**；a,b∈S。r 若是色 0 或 1，分別考慮在 S 內或外，
不能只憑顏色斷定分量歸屬。

## 2. 四種重複色的排除

### r 是色 0

q 是唯一內部色 3，故 L₃ 必為 1–q–4。
p 是唯一內部色 2。新色 0 的可能內點只有 b，以及 r（僅當 r∉S）。
因此 L₂ 只能是 1–p–b–3，或 r∉S 時的 1–p–r–3。
第一型立刻給互斥 Γ-paths 0–b–3、1–q–4，端點交錯，非 disk。

第二型中，0 的內鄰點只可能為 b,p,q；a,r 與 0 同舊色。
若有 0–p，舊 02 路徑 0–p–r–3 違反來源分離；若有 0–q，
新 13 路徑 0–q–4 違反候選分離。故 0 只可能鄰接 b，
與 deg_G(0)≥2 矛盾。框上的所有可能鄰點都已由 induced 與刪邊排除。

### r 是色 1

仍有 L₃=1–q–4。L₂ 只能為 1–p–b–3，或 r∈S 時的 1–p–r–3。
第一型同上排除。第二型中，0 的可能內鄰點為 b,p,q,r。
若有 0–p 或 0–r，分別得到 Γ-path 0–p–r–3 或 0–r–3，
均與 1–q–4 互斥交錯；若有 0–q，新 13 的 0/4 分離失敗。
所以仍只剩鄰點 b，與 deg_G(0)≥2 矛盾。

這比用內點 b 的 degree=4 作矛盾更強：無須內點度數等號，
但明確依賴框點 0 的接點下界及新 13 分離。

### r 是色 2

新色 0 的內點只有 b，所以簡單 L₂ 必為 1–p–b–3；
雖然多了一個色 2 的 r，簡單路徑沒有第二個新色 0 內點可供繼續交替。
仍有 L₃=1–q–4，故由 0–b–3 與 1–q–4 排除。

### r 是色 3

仍有 L₂=1–p–b–3。舊 13 的內部色 1 只有 b，故 L₃ 只能是
1–q–4 或 1–q–b–r–4（q 已具名為第一內點）。
第一型給同樣的交錯互斥路徑。第二型使 b 鄰接六個不同頂點
**0,a,p,3,q,r**，違反內點 degree≤4。

四色已盡。因此本分支不可能恰有五內點。前輪已排除至多四內點；
另一個「S−{1} 尚連通」分支已有六內點下界，故總結論為 **|C|≥6**。
這是由上述前提推出的必要下界，不是 3903 可實現性或一般閉包定理。

## 3. 可重播的路徑分類證書

[checker](../scripts/c5_sector_five_inner.py) 以 a=5,b=6,p=7,q=8,r=9
核對上述有限引理。四種 r 顏色連同色 0／1 的 S 內外，共六種型別。
先建立只限制 proper、框圈無 chord 與 S maximal 的容許邊超圖，
再列出以 q、p 開始的全部簡單 L₃、L₂ Γ-paths。
0–b–a–1 固定；多內點路徑不可能的完備性由 §1 證明承擔。

共有 **9 種必要路徑配置**：

| 拒絕證據 | 數量 |
| --- | ---: |
| 實際邊上的交錯互斥 Γ-paths | 6 |
| 框點 0 的全部可能鄰點僅剩 b | 2 |
| b 已被強迫有六個鄰點 | 1 |

鄰點排除逐一保存實際路徑：分離違反或 disk 交錯障礙均隨加邊保持，
因此不能由添加別的邊修復。checker 不需要枚舉任何接線補全。
六種型別容許多餘的非實現配置；全部必要路徑仍在其中，逐項排除有效。
保存的是帶色身份的**路徑證書**，不是九張 degree-4 候選圖，
也不是九份 K₃,₃ subdivision；disk 排除使用 Γ 交錯性。

[JSON 證書](../artifacts/c5_sector_five_inner/observations.json) 保存每項型別、
同一原頂點身份的 c/S、必要邊、拒絕路徑與依賴 hashes。
本輪不新增／重枚舉候選圖、不計算新染色集、不調用 planarity oracle。
先前弱前提 disk 控制沿用，沒有宣稱新增完整 397→330 disk 控制。

## 4. 停止點與驗證

六內點以上可能有更多同色頂點，§2 的短路徑不再被迫。
下一問優先抽取**框點 0 的鄰點排除準則**：對每個真實鄰點，
能否用同一 c,S 下的舊 02／新 13 分離或交錯路徑排除，
從而在不限制內點數的情況迫使 deg_G(0)≤1？
一般情形舊 13 不必為 1–q–4，不能直接照搬五內點證明。
舊 13 最後 S 接入口與各候選 0–3 路徑的共同身份仍須保留。
另一分支保留 T₂、T₃ 的共同分離與 degree 飽和限制。
下界不是可達性結論或擴大搜尋指令。

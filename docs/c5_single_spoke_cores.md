## 1. 來源與完整接點關係

G 是有限簡單 induced-C5 disk 圖，外框依序 B=(b0,…,b4)。有效內點誘導圖
H 連通，G 是 q=01012 的 edge-minimal obstruction（每條非框邊刪除後接受 q）。
唯一完整 degree-5 內點 z 的 boundary 鄰居恰為 b_s；其餘有效內點完整 degree=4。
下列覆蓋與接點引理不需 T4；支援表另要求 G 接受全部四色 boundary patterns T4。
U={0,1,2,3}，A=U\{q_s}。指定相鄰 singleton 缺失列為 p₁=01021、p₂=01212。

對 H−z 的每個連通分量 C，保留原來有序的 P_C=N(z)∩C、每點的實際
boundary 鄰居及所有中間 bridges。任意 proper row b 的精確介面是

```
L_b(v)=U\{b_i : vb_i∈E},
R_C(b)={(f(v))_(v∈P_C) : f 是 C 的 proper L_b-coloring},
F_C(b)={a : 每個 t∈R_C(b) 都至少有一座標等於 a},
Z_G(b)=(U\{b_s})\⋃_C F_C(b).
```

b 延拓 iff Z_G(b) 非空。R_C(b) 非空：各點 |L_b(v)|≥deg_C(v)，每個
接點另有至少一色 slack；以該點為根用 R10 貪婪引理。故
`F_C(b)=⋂_(t∈R_C(b)) set(t)`，特別有 |F_C(b)|≤|P_C|。
上述交集是完整 tuples 的共同限制；一維 marginals 不能替代 R_C。
所有分量對同一 b、同一 z 色查詢，不能各自重新對齊 boundary 色框。

## 2. 四種不可刪減覆蓋：任意大小結論

R10 的解除引理給出 `⋃F_C(q)=A`，且每個 F_C 都有未被其他分量覆蓋的
private color。A 恰有三色，接點總數四，故只有下列四型。
以 a,b,c 表示互異且組成 A 的三色；同接點數的分量仍有各自身份。

| 接點分拆 | 禁色覆蓋的全部可能 | 固定 s、有標號分量的數目 |
| --- | --- | ---: |
| (4) | F₄=A | 1 |
| (3,1) | (F₃,F₁)=(A\{c},{c}) | 3 |
| (2,2) | ({a},{b,c})；({a,b},{c})；({a,c},{b,c}) | 3+3+6=12 |
| (2,1,1) | ({a},{b},{c}) | 6 |

證明：(3,1) 的單接點禁色必為 singleton，且必有 private color，故另一
分量恰禁其補集。(2,2) 各禁一或二色，覆蓋三色且各有 private color，
只可能大小 (1,2)、(2,1)、(2,2)，最後一種恰交於一色。
(2,1,1) 的三個 private colors 已耗尽 A，任何額外交疊都會破壞其中一個
private color，故三者恰為不同 singleton。這些條件不斷言 disk 可實現。

**接點逐邊解除的關係限制。** 對 a∈F_C(q) 及任意具名接點 v_j，刪除
zv_j 後用 R10 在固定 z=a 下著色。該 coloring 在 C 內仍合法，其 tuple
在其餘接點都避開 a；原查詢被拒絕，故第 j 座標必為 a。於是 R_C(q)
必含一個「恰在第 j 座標出現 a」的 tuple。不同 j 可用不同完整 coloring。
同一論證對任意 b、a∈F_C(b) 都成立，因 R10 解除引理不只適用 q。

特別地，二接點且 F={a,b} 時，**R_C(q) 恰為 {(a,b),(b,a)}**。
在 (2,1,1) 中，若二接點分量禁 a，則每個 tuple 含 a，且有
(a,x)、(y,a)，x,y≠a，所有 tuple 色集的交集恰為 {a}。單接點分量的
完整 root 關係各恰為 {(b)}、{(c)}。二接點這些必要代數條件恰容許 95 個
完整關係：七個含 a 的 pairs 任取子集，兩側非對角 witnesses 都須存在，
並排除額外共同色。算式為 `2(2³−1)²−3=95`。
它們只是固定 q 的關係候選，不能逐列自由選 95 個候選來拼成一張來源圖。

## 3. 任意大小的支援與嵌入限制

記 S_C={i : 某個 v∈C 實際鄰接 b_i}，不是允許接線的超集。
每個 S_C 非空：若空，任意全域色置換保持 C 的 boundary lists，故 F_C(q)
只能是 ∅ 或 U；不可刪減覆蓋要求它非空且包含於三元素 A，矛盾。

**K4-free 與外部至少兩色。** 每個 C 有被拒絕的 z 色，B∪{z} 經唯一
spoke 連通，故可直接用已證連通外框 K4 引理；每個 C 都不含 K4 block。
R10 的 degree-list 定理又給 C 是 Gallai tree，planarity 排除更大的 clique，
所以只剩 bridges 與 odd-cycle blocks。此处不套用全 degree-4 整圖的分類。

若固定 a∈F_C(q) 時 `|q(S_C)∪{a}|=1`，tightness 使每點最多一個外鄰居，
因而 deg_C(v)≥3。有限 K4-free Gallai tree 卻必有 degree≤2 的頂點：
singleton 明顯；否則取 leaf block 的非 cut 頂點，bridge 給 degree=1，
odd cycle 給 degree=2。矛盾。所以外部至少兩色。

**切開 spoke 的次序引理。** 沿實際邊 zb_s 切開 disk，z 成為切口上的
boundary 點，b_s 有兩個副本。對面的 boundary 線依次為

```
位置 0,1,2,3,4,5 對應 b_s,b_(s+1),…,b_(s+4),b_s  （下標 mod 5）。
```

在 z 周圍以 spoke 為起點線性讀取四個接點；取與上述 boundary 線相容的
方向。每個分量的接點必連成一個區塊，各分量的實際支援可提升為非空位置集
T_C⊆{0,…,5}，使區塊次序 C₁,…,Cᵣ 滿足

```
max T_C₁ ≤ min T_C₂，…，max T_C_(r−1) ≤ min T_Cᵣ。      (1)
```

若 s∉S_C，提升唯一；若 s∈S_C，可使用 0、5 或兩者，取決於實際邊在
切口哪一側。兩個副本仍是同一原框點，絕不給它們不同顏色。等號允許不同
分量共用 boundary 頂點，不能改成嚴格不等式。

證明：把各 z-contact 在 z 附近截短成小圓上的相異端點，各 C 加上截短邊
是互不相交的連通集合，並至少接到對面的 boundary 線。若一個 C 的兩個
接點夾住另一分量 D 的接點，C 內連接這兩點的簡單路徑與 z 形成 Jordan
曲線；不含 spoke 的側不含 B，卻困住 D，與 D 必碰 B 矛盾。故接點成區塊。
兩個不同區塊若在對面線出現反向的相異支援端點，分別在兩分量內取
contact-to-boundary 路徑，便是 disk 中端點交錯的兩條不交叉 crosscuts，
不可能。這給 (1)。共用框端點可在小鄰域中分開各入射邊，保留其原旋轉。
證明不縮短分量、不移動接點，也不限制 cycle 數或 bridge 長度。

因此 (2,1,1) 的二接點必相鄰於這個線性接點序列，不能被 singleton 接點
或 spoke 分隔；三個區塊的身份與二接點內部先後仍保留。checker 的支援
表記區塊順序；二接點的兩個具名座標可任一先後，並未被合併。

## 4. 反射與有限支援化約

沿用 [既有反射](c5_two_spoke_reflection.md) 的
ρ=(3,2,1,0,4)、π=(0 1)、(Tb)_i=π(b_ρ(i))。同一來源保留全部內點、
分量、ordered contacts 與 bridges，只把每條 vb_i 移到 vb_ρ(i)，反轉
embedding rotations，對整份 coloring 同時作用 π。於是

```
R*_C(Tb)=π R_C(b)， F*_C(Tb)=π F_C(b)， Z_G*(Tb)=π Z_G(b)。
```

[TwoSpokeReflection.lean](../Math/TwoSpokeReflection.lean) 的
`contactRelation_transport`、`forbidden_transport` 對任意 contact type P
成立，故直接涵蓋此處的一、二、三、四接點，沒有新增特殊反射定理。
同一圖同構搬運全部刪邊 colorings。spoke orbits 為 {0,3}、{1,2}、{4}；
切口位置 k 變成 5−k，區塊先後反轉，但 tuple 的原具名座標不重排。
T 固定 q，交換 p₁、p₂ 的色置換等價類；checker 保留有標號 row。

只分析 s=0、1、4。對 (2,1,1)，以被禁色 a 命名分量 C_a，其支援
S_a 必滿足：固定 q 在 S_a 上的任意色置換都固定 a；外部至少兩色；
以及 (1)。第一項等價於「a 已出現在 q(S_a)，或其餘三色都出現」。
特別是 S₃ 必碰 b4、至少一個 b0/b2、至少一個 b1/b3。

若某列 b 在 S_a 上恰為 π_a∘q，則全分量換色給
`R_Ca(b)=π_a R_Ca(q)`、`F_Ca(b)={π_a(a)}`。
這裡各 π_a 是對同一具名 b 的相容雙射，不是各自商掉共同色框。
若不存在相容置換，該列關係保持未知。已知禁色若覆蓋 U\{b_s}，便證
該列拒絕；在 T4 上出現這種情形即可排除支援型。若三個分量全已知、
且禁色沒有覆蓋可用色時，即可標記 p 可延拓。

未知列仍有**接點數限制的換色上界**：令 V_C={b_i:i∈S_C}，
F_C(b) 在固定 V_C 的色置換群下不變，而且 |F_C(b)|≤|P_C|。
所以若 |U\V_C|>|P_C|，這些未見色全都不在 F_C(b)；否則上界保留 U。
對單接點分量，支援列只見兩色時，其餘兩色都不能被禁；對二接點分量，
兩個未見色則仍可能同時被禁。把已知禁色與未知禁色的這些上界聯集，
任何未被覆蓋的可用 z 色都能延拓。此界來自完整 tuple 關係的對稱性及
共同色集交集，不是 endpoint marginals。證書保存保證可延拓的 z 色。

這在證明任意大小的必要條件後，才枚舉五個框點的非空支援子集及區塊順序。
不枚舉來源圖、不假定小型 graph normal form。分量實際內部關係仍是未知
R_C，支援表不是 R_C 的替代 state。

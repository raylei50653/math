## 1. 量詞、兩組差異與六附件等號

固定有限簡單球面三角剖分 G、最小度至少五、S34、S5，以及原五度點 v、
原輪轉 B、完整 O=G−v。S34、S5、五個原面第三點 wᵢ、H 的五次實際分量交換及
每輪末全域正規化，均與[上游規格](c5_kempe_period4_s5.md#1-精確命題與判定範圍)相同。
條件式假設 K 全封鎖、cₜ=Hᵗc、c₄=c₀、c₂≠c₀，定義

\[
D^{(0)}=\{x:c_0(x)\ne c_2(x)\},\qquad
D^{(1)}=\{x:c_1(x)\ne c_3(x)\}.
\]

H 是 X₀ 的置換，故兩組均非空；共同原面色史使它們均避開 B 與全部 wᵢ。
**對每個** Q∈π₀(O[D⁽ᵉ⁾])，取全部原附件 A=N_G(Q)。不假定其他分量也有六附件。
附件分隔引理給原簡單環 C⊂G[A]，全 Q 與 v 分居兩開側，|C|≥6，
而且 C 的原邊來自只刪 Q 的含 v 分量之面邊界 W，完全不使用 B 邊。

**六附件等號引理。** 在上述前提下，若 |A|=6，則 G[A] 恰為這個原無弦分隔六環。
其原點、原邊及側別由 G 決定；「固定」只指相應比較 cₑ、cₑ₊₂ 在 C 上逐點相同。

證明：|C|≥6 與 C⊂G[A] 迫 V(C)=A、|C|=6。若有原弦 xy，
它位於 C 的某開側，把該側切為兩個由弦和 C 原弧組成、長度至多五的原子環。
若弦在 Q 側，Q 連通且避開弦，故全 Q 位於其中一個子環的開側；
若弦在 v 側，選開側含 v 的子環。兩種情形均得到固定子環 J，分隔 Q 與 v。
長三／四違反 S34。長五時，若 v 側至少兩點，固定五環剛性禁止另一側的 Q 差異；
若 v 側只有 v，五度及原輪轉迫 J=B。然而 J 包含 C 的原邊，C 完全不含 B 邊，矛盾。
因此無弦。此證明沒有補邊，也沒有把任意較長環的含 v 側宣稱為至少兩點。

**完整開側引理。** 三角剖分中，原無弦簡單環長至少四時，每個非空開側的誘導圖連通。
因此六附件等號下

\[
Q=\operatorname{side}_{\neg v}(C),\qquad N_G(Q)=V(C).
\]

證明：C 每條邊在某側的原面第三點必在該開側，否則出現原弦。
沿每個環點的該側原 link，兩條環邊第三點之間的所有內鄰點形成原路；
無弦性保證該路內點都不在 C。這些路把該側全部鄰 C 的點連為一體。
側內任一連通分量必鄰 C，否則與 G 的連通性矛盾，故該側連通。
Q 的全部外鄰點已在 C，於是 Q 是整個開側。

這處理了固定內島與其他差異分量：在這個 Q 的六環內側，它們不存在；
同一次比較的其他差異分量及任何固定點都在 C 或含 v 側。
該側仍須完整保留，不能刪成只有 B 的外殼。
七附件以上沒有這項等號結論，仍可能有多輪廓、固定內島及非簡單投影閉走。

## 2. 四輪比兩輪前綴多出的必要條件

對 D⁽⁰⁾、D⁽¹⁾ 分別建立全部 Q、A、原面、分隔環與原雙面側。
同一原點可以在兩組間從核心變成接口，兩個核心也可以相交而不相等。
H 是**著色的映射**，不是原點的置換；不能假定它把一個 Q 逐點搬成另一個 Q。

同步比較第 r、r+2 輪的同一步：當下完整著色為 a、b，當步色對為 P，
從同一原框根點求得的實際完整分量為 U、V，令
\(J=\{x:a(x)\in P\text{ 且 }b(x)\in P\}\)。交換後有精確差異傳播式

\[
\operatorname{diff}(a',b')=
\operatorname{diff}(a,b)\mathbin{\triangle}\bigl((U\mathbin{\triangle}V)\cap J\bigr).
\]

兩邊同換或同不換保留相等性；只有一邊換時，兩色都在 P 中才切換相等性。
共同全域正規化不改差異集。因此五步把 D⁽⁰⁾ 傳成 D⁽¹⁾，再五步傳回 D⁽⁰⁾；
U△V 卻可包含原本固定的遠端點，使差異分量分裂、合併或穿越原接口。
這是完整差異集的傳播等式，沒有給任何單個 Q 的逐點搬運。

令 τ=(A C B D)=σ⁻¹ 表示程式的 `ALIGN=(2,3,1,0)`。
第 r 輪（r=0,1,2,3）步 j 的色對為 Pⱼ、實際交換分量為 Sᵣⱼ。
將該輪整份色態以 τ⁻ʳ 換回同一全域色框，交換色對變成 τ⁻ʳ(Pⱼ)，分量點集不變。
四輪於是是一條**連續二十次真交換**的閉路，因為 τ⁴=id；
每輪六時刻的原資料仍另外保存，沒有把正規化算成 Kempe 交換。

對每個原點 x，記 εₓ,ᵣⱼ=1[x∈Sᵣⱼ]，並按時序合成所受共軛 transposition，得 Tₓ。
四輪閉合只迫

\[
T_x(c_0(x))=c_0(x),
\]

**不迫 Tₓ=id**；在 x 未使用的其他色上仍可有非平凡作用。
真正四週期還要求 c₂≠c₀。對 C⁽ᵉ⁾，兩輪固定條件只要求
cₑ|C⁽ᵉ⁾=cₑ₊₂|C⁽ᵉ⁾；另外兩時刻必須實算。

每個六環以其**完整 Q 開側、原六接口、完整含 v 開側減去 v**三分。
在每份當下完整著色及每個色對中，保留兩開側的全部雙色分量、全部原附件、
所有接口跨邊與同色對附件，包括零接口的分量；接口本身的原雙色邊也保留。
將每個側內分量縮星再接回接口，展開後的完整分量恰等於全 O 直接重算的分量。
證明是同一份色態內把路切成接口／側內段，再逐段展開；不借用其他時刻的路。

額外必要條件因而包括：兩套差異與全部原面相容、第三及第四輪仍有指定單點框交集、
二十個實際分量的逐點色詞閉合，以及每次交換後兩側重新接合仍給正確的下一分量。
兩輪前綴沒有這些後半部義務。
但是這些**必要條件及其記錄方法尚未導出一般矛盾**；逐點詞和接口分割都不能單獨當作原圖實現。

## 3. 可證的局部交換與逃逸引理

**小六附件核心。** 若 |Q|=1，該點原度為六，C 是其完整 link。
它在兩端改色、C 固定，迫 C 只用另外兩色；proper 六環故兩色交替。
Q 是兩缺色的完整單點 Kempe 分量，交換一次即可切到另一端。

若 |Q|=2，寫 Q={u,z}；兩點有原邊。S34 使每個原三角形皆為原面，
故 uz 恰有兩個共同鄰點 p,q。每點至少有四個 C 附件，合集六、交集二，
迫各原度五。兩側原 link 給

\[
C=(p,a,b,q,c,d),\quad N(u)\cap C=\{p,a,b,q\},\quad
N(z)\cap C=\{q,c,d,p\}.
\]

每點在兩端均改色，其四附件至多用兩色；各自長三原路迫兩色交替，且 p、q 異色。
故整個 C 用同一對色交替；u,z 用另外兩色且兩端恰互換。
Q 正是完整 O 的該雙色分量，一次合法交換連接這兩份填色。
兩案都只改核心，B 的色數不變；它們本身不是逃逸證明。

**獨立切換的必要條件。** 同一 D⁽ᵉ⁾ 的任意 k 個上述小核心可獨立切換，
得到同一 K 的 2ᵏ 份完整混合色態：不同差異分量間沒有原邊，各自附件保持不動，
每次所換仍為當下完整雙色分量。其他大核心及全部外側維持原完整色態。
因此全封鎖不僅要求四份 cₜ 沒有出口，也要求這些混合態全部沒有出口。
不能把任意大核心的另一份 proper 盤填色也當作一次 Kempe 切換。

**singleton 失接逃逸。** 當下 proper C₅ 四色框恰有一個重色與三個 singleton 色。
若任兩 singleton 色 p、q 的框點在完整 O 的 pq 圖中不連通，
交換其中一點所在的完整分量，就從 B 消去它的色，得到三色框。
所有路與失接都在同一份當下完整著色判斷。
若失接出現在上述混合態，從原態至多 k+1 次合法交換即可逃逸。
故全封鎖還迫所有這些混合態的三對 singleton 框點均雙色連通。

**首次指定失敗逃逸。** 在指定五步的任一步之前，設所選色對是重色 r 與 singleton 色 s，
root 是其中一個 r 框點。另一個 r 框點與 s 框點有原 B 邊。
若 root 的完整 rs 分量不只碰 root，它必碰這三個框點。
在該分量取 root 到其他框點的路，截至**首次碰到另一個 B 點**，並刪去迴路，
得到內部完全避開 B 的同一當下 rs 原簡單路。其末端可為另一個 r 或 s；
兩種情形的兩端都與另兩個 singleton 色 p、q 的框點在 B 上交替。
O 的原盤面中，任何 pq 路因 Jordan 分離必碰這條 rs 路；
同一份當下著色的互補色對路點集互斥，故 pq 框點不連通。
因此在該步改換一個完整 pq 分量即得三色框。
這給「合法指定前綴首次失敗」的有限建構出口；它**沒有證明**合法 S5 四週期一定失敗。

## 4. n17 與 Errera 的完整來源校準

   四輪閉合迫出其中一次失接、指定步失敗，或一個可用固定五環。

所以六附件候選目標仍 OPEN；七附件以上、一般 P₄、週期六以上、全封鎖分量存在性、
support 932、原 Q5 與一般 4CT 均保留 OPEN，即使將來排除六附件分支亦同。

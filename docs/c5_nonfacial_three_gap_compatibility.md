# 非面五環恰三缺邊：完整命中分類與雙端葉子型排除

2026-10-30，BASE `e1a90fea41702d7c98747716a5960198aecbecb3`。
接續[非面二缺邊排除](c5_nonfacial_two_gap_exclusion.md)。
**本輪完成三缺側字／內弦分類，並排除「至少兩個環點直接連端葉」子型。**
分類使用極小性；排除使用完整 Γ 的整族非空，不挑五份代表。
保留含內弦的真 plane 三缺控制：它缺完整 Γ，故與新排除相容。
**一般三缺相容性、面環、非面四／五缺、一般 E932 與 4CT 仍 OPEN。**

## 1. 完整來源與子類假設

沿用[完整來源契約](c5_five_reference_source_exclusion.md#1-同一來源與完整量詞)：
Q 是有限、連通、無 loop 的 plane 五葉 disk 網路，內點三度，五葉依指定環序在外面；
平行原邊保留。二葉偶補支援恰為 `Γ={02,03,13,14,24}`，五族全部非空、相鄰偶補族全空。
固定非空相鄰普通族 `PM_I` 中使 `odd(Q−M)` 最小的 M，以及 `Q−M` 的同一實際奇環 O。
本輪另假設

```text
O 非面，O=C₅，|E(O)∖E₁(O)|=3。
```

五環與三缺仍是子類假設，沒有由完整 Γ 的一般來源迫出。
`E₁` 取所有 `J∈Γ`、所有 `R∈𝓜_J` 的 singleton 命中存在投影；
每份完整 `H_R=R∩E(O)`、全部內外回返、未接 O 的閉環與完整 C1 區域均保留。
十種族對保留每份完整笛卡兒產品，不把族縮成一份參考。
非面包含只有內弦、沒有嚴格內點的情形。

記 O 的原點依序為 `v0,…,v4`，原環邊 `ei=vi v(i+1 mod 5)`；
`b(v)=1` 指非 O 半邊朝有界內側，0 指外側。
S 是全部嚴格內點，`n=|S|`、`k=Σb(v)`；內弦兩端各計一次 incidence。

## 2. 側字、兩條 E₁ 邊與內弦的完整分類

前篇已證

```text
n≡k (mod 2)，
H_R={uv} ⇒ b(u)=b(v)=n mod 2，
極小 M ⇒ 不存在內向 singleton。
```

最後一式來自含 O 的**完整** C1 區域 W：若唯一命中兩端內向，W 無端葉，
`s_W=0,q_W≥1`，整區交換在同一 `PM_I` 降低奇環數。
本輪沿用此論證，不從不同 R 拼區域。

**分類命題 TG-SIDE。** 旋轉編號後，唯一可能為

```text
b=11000，n 偶，E₁={e2,e3}，缺邊={e0,e1,e4}。            (1)
```

**證明。** E₁ 有兩條邊，故非空。極小性使任何 singleton 端點都外向，
內側奇偶再迫 n、k 偶。非面性及連通性給 `0<k<5`，所以 k 是 2 或 4。
k=4 僅一個外向點，不能容納 E₁ 邊。k=2 剩三個外向點；
要容納兩條不同 E₁ 邊，三點必形成同一連續兩邊路。
兩個內向點因此相鄰，且這兩條外向路邊就是完整 E₁，得到 (1)。證畢。

兩條 E₁ 不相鄰的全部情形已排除；內外意義沒有互換。

**內部二分支。** 所有內弦都只能連 `v0,v1`，所以至多一條，並與 e0 平行。
若有內弦 c，它用盡兩個內向 incidence；連通性迫 S 空，內部恰為這條 c。
若無內弦，內側有且僅有兩條 `S–O` 原邊，兩者都在 M，S 非空且 n 偶。
後一分支中 S 也必連通：否則每個內部分量各接一條切邊，M 的匹配奇偶使其點數奇；
任一既有 e2 或 e3 singleton 的補圖卻把該分量分成完整偶環，迫點數偶，矛盾。
這只是內部來源限制，不是聲稱任意二端 cap 都可實現。

## 3. 全部單／雙命中與完整回返義務

T1 使 H_R 非空，五環匹配至多兩邊。逐個保留五個 singleton 與五個雙命中候選，
同時施加 SIDE、singleton 內側奇偶與極小性，恰剩以下**必要**輪廓。
此表不要求五型都實現，也沒有指定某族只能取某一型。

| 完整 H_R | 內向活端口 | 外向活端口 | O 上全部保留段及完整內回返合成的結果 |
| --- | --- | --- | --- |
| `{e2}` | 無 | v2,v3 | 完整保留弧長 4 |
| `{e3}` | 無 | v3,v4 | 完整保留弧長 4 |
| `{e0,e2}` | v0,v1 | v2,v3 | 兩條保留弧與內回返 P 合成長 `|P|+3` 的路 |
| `{e0,e3}` | v0,v1 | v3,v4 | 兩條保留弧與 P 合成長 `|P|+3` 的路 |
| `{e1,e4}` | v0,v1 | v2,v4 | `P+e0` 為閉環；外向保留路為 e2,e3，長 2 |

其餘 singleton 或端點在禁止側，或是內向 singleton；其餘雙命中是
`{e1,e3}`、`{e2,e4}`，各只有一個內向活端口，被 SIDE 拒絕。

前兩型的內側補圖沒有活端口，S 全部被完整偶閉環分割。
後三型在內側恰有一條完整 `v0–v1` 回返 P，其餘仍為完整偶閉環；
`n=(|P|−1)+偶數` 迫 P 奇長。直接內弦 `P=c` 長一完全合法。
因此表中的外向合成路全部偶長，最後一型的內閉環也偶長。
**這五型在此層沒有段奇偶矛盾。** 特別不能刪掉 `{e1,e4}`，
或把控制未出現該型誤當成一般來源禁止。

每份 R 還須保留其外側的全部實際路與閉環：外側路端點是該列兩個外向活端口
及 J 的兩個端葉。若兩個活端口互返，該完整外返須偶長，另有端葉路；
若各接端葉，形成完整開路，不能另施閉環偶長條件。
所有未接 O 的內外閉環都須偶長。上述條件須在同一原圖、同一 R 重新接合，
不能把不同 R 的內返、外返或族對產品混在一起。
每份 `Q−(M∩R)` 的 C1 區域及全部批次仍另有極小性約束；
本表通過不保證這些條件或完整來源可實現。

## 4. F5-THREE-GAP-TWO-LEAVES：雙直接端葉子型排除

**命題。** 在 §1 的完整來源及三缺假設下，O 至多一個環點直接連端葉。
亦即「至少兩個環點直接連不同端葉」子型被排除，無論有無內弦。

**證明。** 端葉全在 O 外，直接端葉只能接 v2,v3,v4。
設其中兩點 x,y 分別直接連 `ti,tj`；葉度一，i、j 必不同。
取任何與 `{i,j}` 不交的 `J∈Γ`。對**每份** `R∈𝓜_J`，兩葉未暴露，
故兩條實際端葉邊都必在 R，H_R 不能碰 x 或 y。
但 §3 的每一允許命中都恰碰三個外向環點中的兩個，必碰 `{x,y}`，矛盾。
因此整族 `𝓜_J=∅`，包含該族的一切單／雙命中可能性。

必存在這種 J：Γ 是葉指標上的五環 `0–2–4–1–3–0`，
任意三個葉指標都含一條 Γ 邊，故 `{0,…,4}∖{i,j}` 至少含一族。
這與完整 Γ 五族非空矛盾。證畢。

全部葉對對應的強制缺族如下；x,y 的兩種指派都適用。

| 直接端葉對 ij | 與 ij 不交、整族必空的 Γ 族 |
| --- | --- |
| 01 | 24 |
| 02 | 13、14 |
| 03 | 14、24 |
| 04 | 13 |
| 12 | 03 |
| 13 | 02、24 |
| 14 | 02、03 |
| 23 | 14 |
| 24 | 03、13 |
| 34 | 02 |

這是完整族的缺失，並非選定五份代表後的抽象不相容。
十種族對仍是完整乘積；在較弱控制中涉及缺族的產品確為空，不能宣稱已觸發五族阻擋。
本證明只用來源迫出的命中分類，沒有以缺族或禁止 profile 作子類假設。

## 5. 內弦消去另證普通 PM 與 odd 的轉移

§4 的排除不需要二端消去。為釐清內弦分支仍另外證下列轉移，
避免僅憑 Tait 的 n/y 計數倍率推論極小 M。

若有內弦 c，刪 v0,v1 及 `e0,c,e1,e4`，加入一條具名新邊 `d=v2v4`，得 Q′。
允許 d 與外側原邊平行；其兩端不同，無 loop。嵌入沿原長三路收縮，五葉及環序不變。
對任意暴露葉集合 I（包含零、二、四葉）與每份 `N∈PM_I(Q′)`：

- 若 `d∉N`，其全部 lifts 恰有兩份：相同外部邊分別加 e0 或 c。
  補圖的 d 被另一條內邊與 e1,e4 組成的長三路替換；同一補圖分量長增加二。
- 若 `d∈N`，唯一 lift 是刪 d、加 e1,e4。補圖另添 `e0+c` 的偶二環；其餘分量不變。

反向由 v0,v1 的飽和性：e1,e4 必同時選或同時不選，後者必恰選 e0,c 之一。
故列完全部普通 PM，無漏 fibre，空族也保留；逐份有

```text
odd(Q−lift(N))=odd(Q′−N)。                              (2)
```

所以每族最小奇環數相同，極小者恰為縮圖全部極小者的全部 lifts，
二葉偶補支援也相同。題設 M 選 c，投影不選 d，O 投影為面三角環；
這本身沒有矛盾，不能從面三角環擅自反推一般三缺來源已排除。
縮圖參考仍應由上述**完整 fibres**回拉，原 C1 資料亦留在原圖；
本輪未宣稱 C1 區域在縮圖中逐區雙射。

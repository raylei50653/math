## 問題與契約

固定同一實際原圖、有序接口與字面色號 0–3。局部資訊分成單點候選、
低階投影，以及完整接口關係。要區分：能安全刪去不可能候選，與能保證
任意外側的共同延伸，兩者並不相同。

子圖內部只經接口 S 與其餘部分接合；不准遺忘內點到外側的原邊。
若候選域取自已發生的外部傳播，該上下文亦屬來源契約，不能跨圖任意沿用。
本輪以完整原邊枚舉作有限 oracle，不以目錄或四色定理作 oracle。

## 先登記的驗證計畫

1. 四葉星：求同一原圖在四葉上的完整關係，與全部一／二／三點投影重接比較；
   保留所有多收列及每列中心的完整可回填色，不只比較列數。
2. 五輪圖：五環加一共同中心，以同一原五環為接口；檢查三點投影是否丟掉
   「原中心仍須有剩餘色」這份結構限制。
3. 任意長度裸環：保留首點／當前點的完整色對訊息，檢查閉合後的判定、
   每點支援及一份完整回填，逐原邊核對；涵蓋奇／偶環及已固定的候選域。
4. 分隔接口：以兩份有私有內點的實際子圖，在同一字面接口共同接合；
   核對保留完整接口關係與直接合圖的一致性。
5. 負控制：共同接口不完整、只保單點／低階投影，以及把有弦子圖當裸環，
   明確標為資訊不足，不能給整圖可延伸證書。

預計有限來源：上述具名星／輪圖、環長 3–10 的指定候選域樣本及少量具名接口接合。
零失敗或必要篩選存活都不推成一般小接口定理。

## 紙面可證的正向範圍

這裡應用既有[新增點／邊影響 §4.3](extension_effects.md#43-真正可用的界線是共享介面)
及[局部封環](local_closure.md)的完整 separator 接合語義；
`LocalClosure.summary_glue`／`replacement` 已有普通 Lean 證明，來源為
[LocalClosure.lean](../Math/LocalClosure.lean)。本頁沒有新增接合定理或 Lean 證明，
而是展開本輪會用到的續接契約、三點投影比較及一般環的 16 狀態實作方向。

### 完整接口關係可接任意外側

若 A、B 的交集恰為有序接口 S，且沒有私有內點之間的跨邊，定義
`F_A(σ) = {A 的完整合法染色：在 S 上恰為字面色組 σ}`，
`R_A(S) = {σ：F_A(σ) 非空}`。固定色及內部候選域若屬 A 的前提，也納入定義。
則

```text
A ∪ B 可延伸  ⇔  存在同一 σ ∈ R_A(S) ∩ R_B(S)。
```

正向限制完整染色到 S；反向選同一 σ 的兩份內部見證即可接回，因為所有跨接
都已包含在 S。接口關係可以用精確結構公式表示，不必列成表。
保留全部 fibres 或能生成它們的精確轉移網路，可保全部延伸；只要一份解時，
每列保存一份可追溯見證即可。非空列數與完整染色數不同，僅保支援也不保計數。

在允許固定接口字面顏色的任意外側下，這也給出一個必要且充分的語義標準：
兩份區域 P、Q 在同一有序 S 上對所有外側有相同可延伸答案，恰好等價於
`R_P(S) = R_Q(S)`。充分性由上式；必要性則取兩關係差集中的一列 σ，
用外側把接口逐點固定為 σ，即可分辨 P、Q。因此完整共同關係在語義上不能丟，
但可用公式、因子或轉移系統保存；這沒有給出最少儲存位元或最小約束元數。

### 樹形接合：一致的完整接口可逐層外推

以下是同一存在量化接合法在樹形袋上的紙面展開。
設覆蓋所有原頂點的局部袋 `X_t` 由一棵樹連接，滿足兩項結構條件：每份原約束完整落在某個袋中；
對任一原頂點 v，所有含 v 的袋在樹上連通，亦即 running-intersection。
各袋保存同一字面色框中的完整共同合法列，將每條樹邊兩側投影到交集
`S_tu = X_t ∩ X_u`，雙向刪除無匹配整列的袋列。

若傳播後每袋非空，且相鄰袋在整個交集上的投影集合相等，任選一份根袋列，
就能逐層選到與父袋完整接口列相符的子袋列。已選部分與新子樹之間的共同原點
全位於父子接口，否則該點所在袋不會連通；所以沒有被漏掉的遠端同點衝突。
每份原約束又都在袋內成立，故選出的列合成完整合法染色。

這裡要求整個接口列匹配，僅各欄投影相同不夠；局部袋形成迴圈時，
也不能直接沿用這份樹形證明。兩色奇環便是逐邊都有支援、全環卻無解的反例。
外推成本由過程中必須同時保留的接口決定；袋大小至多 b 時，每袋可用至多
`4^b` 個字面列表示，沒有因此宣稱所有平面圖都有固定 b。

### 任意長度裸環：保首點與當前點的 16 種色對

對 `C_n = v₀…vₙ₋₁v₀`，給定單點域 `D_i`，定義前綴共同關係

```text
P₀ = {(a,a)：a ∈ D₀}
Pᵢ = {(a,b)：b ∈ Dᵢ，存在 d，使 (a,d) ∈ Pᵢ₋₁ 且 d ≠ b}
最後只接受 Pₙ₋₁ 中 b ≠ a 的列。
```

歸納可知 `(a,b) ∈ P_i` 恰表示前綴路徑存在一份從 `v₀=a` 到 `v_i=b`
的共同染色；再核對末邊即得到全環存在性。每步至多 16 個布林色對，與環長無關，
沿 n 個位置推進；計數版雖同為 16 個欄位，整數的位數仍可隨 n 增加。
要回填可保存沿途合法轉移或前驅，固定四色時共 O(n) 空間；要全部延伸則須保全部
合法轉移，而非每列任選一份。單點精確支援可再用與 C₅ 相同的錨點雙向傳遞取得。

等價地，裸環可切成三點袋 `{v₀,vᵢ,vᵢ₊₁}`，`i=1,…,n−2`，
相鄰袋以二點接口 `{v₀,vᵢ₊₁}` 接合，符合上述樹形條件。
16 狀態的續接契約是：已忘掉的頂點後續只能經仍保留的首點／當前點發生作用。
弦或外部附件若接到被遺忘點，必須擴大接口或繼續保留相應原變數與因子。
如果全環每點都接外側，外部接口就是這 n 點；不能把它改成任意外側都只看兩點。

## 紙面結構例：什麼能壓縮，什麼會丟掉

### 四葉星：三點投影仍漏掉共同四色堵塞

此公式是既有[新增私有點判準](extension_effects.md#22-加一個點)的直接應用，
該處已對應 `LocalClosure.hub_iff`；本輪另檢查其全部三點投影。
取中心 x 及四個互不相鄰的原葉點 `u₁,…,u₄`，只有四條星邊，所有域為四色。
消去 x 後，其完整接口關係與 fibre 有直接公式：

```text
F_x(c₁,c₂,c₃,c₄) = {0,1,2,3} \ {c₁,c₂,c₃,c₄}
R_star = {c：|{c₁,c₂,c₃,c₄}| ≤ 3}。
```

所以四葉接口共有 `4^4 − 4! = 232` 列；完整五點染色數則是
`4 × 3^4 = 324`。任意三葉的任意指定色至多用了三色，可以先替中心選一個
未用色，再替第四葉選異於中心的色。因此每個三點投影都是全部 `4^3 = 64` 列，
把所有三點投影接回仍得 256 列，錯收四葉恰好互異的 24 列。
這是真實平面原子圖的負例，但只否定這種三點投影摘要，不否定符號壓縮。

對任意度數的裸星形，令 `U = OR_i (1 << c_i)`，則中心可用色遮罩為
`D_x & (15 ^ U)`；只需 4-bit 已用色遮罩就能沿鄰點計算這項結構條件。
保留下來的符號因子仍必須是原接口變數的共同謂詞
`Φ(c₁,…,c_d) ⇔ D_x & (15 ^ OR_i (1 << c_i)) ≠ 0`，
並保留中心的回填色。4-bit 是計算一份共同賦色時的累積狀態；任取一個遮罩並丟掉
它與各原葉點的關係，不能代表接任意外側的完整接口。外側可逐點固定葉色，會區分
同一已用色遮罩下不同的葉點賦色。

### 五輪圖：三點投影無法保留中心的剩餘色

這是既有[高階影響例 `star_31`](extension_effects.md#31-高階影響看不見於任何單一配對)
的同一結構，原報告已記錄 240→120 且全部兩點投影相同；本輪將比較推至三點投影。
取原五環加一個連到全環的中心 h，以有序五環為接口，不加其他邊或固定色。
完整結構公式是五條環邊異色，且環上至多用三色；中心 fibre 為未被環使用的色。
奇環至少用三色，因此合法接口恰用三色，中心色唯一。
裸環的 q 色合法列數為 `(q−1)^5 − (q−1)`，可沿環的色轉移直接計數；
此輪的接口列數為 `4 × (2^5−2) = 120`，裸四色五環則有 `3^5−3 = 240` 列。

五輪與裸五環在任意三點上的投影相同。理由是三點只有兩種循環間隔型：
連續三點的間隔為 `(1,1,3)`，或一邊加第三點的間隔為 `(1,2,2)`。
只要指定三點不違反其中的原環邊，選一份包含其指定色的三色盤：前型剩一條
有兩個內點的路徑，任意端點色都能補；後型兩個未定點各僅須避開至多兩個
已定鄰色，也都能補。因此全部三點投影重接只留下五條環邊條件，仍接受裸環的
240 列，漏掉輪圖的「中心必須有剩餘色」。

保留 `∃c_h，對所有 i 有 c_h ≠ c_i` 這份共同符號因子，就能精確保留該限制；
或保留全部原星邊與同一個隱藏中心變數 h。原始二元邊約束加隱藏變數本來就完整，
問題出在消去隱藏變數後又只留下低階投影，沒有保存存在量化產生的共同關係。
這與既有[C₅ 關係階數 §2](c5_relation_arity.md#2-接合的紙面上界與代表無關性)
的界線一致；其[具體反例 §4](c5_relation_arity.md#4-有限初驗與具體反例)
已有 20 份具名 C₅ 來源需要五階投影，連全部四點投影都不夠。
本頁星／輪的三點例是便於直接看出結構原因的示例，不是已知所需階數的最高下界。

### 逐步操作還須另證摘要可更新

靜態接口的延伸等價，不自動保證 Kempe 操作後能由摘要算出下一份摘要。
既有[狀態指南的停止點](c5_state_guide.md#3-停止點與保留缺口)及
[同染色聯合 Kempe 反例](../audits/2026-10-20-joint-kempe-state-1148ce0/REPORT.md)

下一摘要，第二步框色也可不同。這是既有的動態摘要邊界，與本頁星／輪的靜態投影
反例分開；本輪沒有新增 Kempe 實驗或一般未來行為分類。

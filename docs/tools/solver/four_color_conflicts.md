[C₅ 結構推導與查表](four_color_c5.md)。把目前已知的局部衝突登記成有條件的子型，

## 使用

```bash
python3 scripts/four_color_lab.py conflict-demo
python3 scripts/four_color_lab.py solve graph.json --engine constraints --json result.json --html replay.html
# 相同輸入關閉這層辨識，保留原有精確約束求解作對照：
python3 scripts/four_color_lab.py solve graph.json --engine constraints --no-conflicts --json baseline.json
```

約束引擎預設啟用已知衝突辨識；`--no-conflicts` 只關閉這層提早辨識。
沒有命中時，仍以原邊約束、聯合傳播、完整消元及倒序回填繼續求解。
命中表示一份已核對的充分矛盾，沒有命中不表示圖可染色，也不表示已找齊衝突子圖。
JSON／Python 色號為 0–3，畫面色號為 1–4。

## 目前登記的五種子型

| 子型 ID | 原子圖與當前條件 | 可以判定什麼 |
| --- | --- | --- |
| `fixed_edge` | 一條原邊的兩端都只剩同一個顏色 | 該候選域條件沒有延伸 |
| `four_color_star` | 同一中心的四個不同原鄰點各只剩一色，合起來覆蓋四色 | 中心沒有可用色，該候選域條件沒有延伸 |
| `triangle_two_colors` | 原三角形三點的候選域聯集至多兩色 | 三點無法共同兩兩異色 |
| `c5_two_colors` | 原五環五點的候選域聯集至多兩色 | 奇環無法只用這兩色延伸 |
| `k5` | 五個不同原頂點之間的十條邊全部存在 | 這份原子圖本身沒有四色染色 |

`fixed_edge` 是穩定的子型名稱；觸發條件也接受由可靠傳播得到的同色 singleton，
不能只從名稱推斷兩端都是輸入的固定點。候選域的實際來源另隨命中記錄保存。
星形不要求葉子之間沒有邊；四條原中心邊已足以推出這個條件矛盾。
辨識時使用原圖的實際連接，不從播放器座標推斷邊或平面性。

三角形和 C₅ 的兩色規則只是完整關係為空的一類充分條件。
其中 C₅ 兩色衝突可以直接由奇環交替推出，不需要在執行時查 240 列；
唯一逃逸點與雙中心等色的推導見[結構自約束](four_color_c5_structure.md)。
結構模式還將雙中心等色以 `c5_hub_equality` 二元因子導入；這是有合法列的關係，
後續與目前候選域及其餘原圖約束共同傳播，可能再推出無延伸。
其他候選域配置也可能無延伸；仍由原有精確傳播與消元判定。
K₅ 是一般圖的負控制；求解器不假定輸入平面，這份控制也不是平面反例。

## 為什麼能把星形放進表庫

裸四葉星形可二染，不能因為曾經堵住中心，就把整個裸星形標成不可四色染色。
可重用的是它的完整有序關係，以及導致空 fibre 的條件。

固定葉子次序 `(l₀,l₁,l₂,l₃)`，中心記作 `x`。表庫保存：

```text
R(c₀,c₁,c₂,c₃) = { x ∈ {0,1,2,3} : 對每個 i，x ≠ cᵢ }
```

全部 `4⁴ = 256` 個葉子色組都被計算：**232 列有中心支援，24 列為空**。
空列恰為葉子使用四色的 24 個排列；非空列保存全部可用中心色，不只任選一個見證。
因此「四葉各固定成四色」可立即查到空列；解除固定後，同一原星形仍保留大量合法列。
當中心本身也受限時，還必須把中心支援色與目前中心候選域相交。

三角形與五環同理：依裸子圖的完整合法關係及目前候選域推導；
五環可直接沿原邊算出精確支援，也保留完整色組表供核對。
不能把某次固定色過濾後的空表，跨圖當成裸子圖永遠不可染色的定理。
這些條件表沿用同一字面色框，沒有讓各子圖分別換色後再拼接。

## 每次命中要保留什麼

命中記錄要能回到同一份輸入，而不只給一個「形狀名稱」：

- 子型 ID、實際原頂點與觸發矛盾的原邊，以及有序角色映射。
- 觸發當時的候選域與相關固定色；候選縮限另保留其來源邊與來源頂點。
- 判定範圍：輸入固定色、目前候選域，或試色求解器的當前分支。

約束引擎沒有提前猜色；其中的候選域是原固定色及精確傳播的結果，
排空時否定的是這份輸入固定色的延伸。
逐點試色引擎中的四色阻擋星形則可能只否定當前分支，回退後還能成功；
不能把分支失敗擴大為整圖無解。

若候選域由外部約束縮限，單獨列出命中子圖的原邊仍不足以重建那些縮限。
因此子型記錄同時保存當時條件，不宣稱找到了最小矛盾核心、全部成因，
或可任意移植的上下文快取。新增一種子型，也不等於完成任意子圖同構辨識。

**結論。** 每份裸四色無解圖都包含一個刪點、刪邊皆不可再縮的無解核心；
在此核心中，每條原邊至少屬於三個不同奇圈。更強的是：刪去該邊後，
任一份完整染色都必須同時給出三條具名雙色路，將那兩端鎖在同色。
另由完整換色配對可證：假設有裸平面最小反例，將兩側各至少兩點隔開需要至少六條邊；
五條跨邊只能孤立一個五度點。這項小邊割推論不要求每條邊皆不可刪。
這是必要條件與原圖證書，不是新的充分無解判準或四色定理證明。

## 核心及量詞

固定同一有限簡單無向原圖與各原點的有效字面候選域，固定色先與域相交。
若原問題無解，先在其子圖中選頂點數最少的無解者，再在同頂點集選邊數最少者，記為 `H`。
所有域仍取自原問題，沒有另加固定色或填補邊。
有限性與刪點／刪邊的單調性給出：

```text
H 無解；對每個 v，H−v 有解；對每條 e，H−e 有解。
```

若有空域，核心可以只剩單點；下列裸四色的圈與度數結論只用在各域皆為 `U={0,1,2,3}`。
核心不必是原圖的誘導子圖，因為第二步可能刪去冗餘原邊。
原圖附加的孤點、樹枝或其他分量不必滿足核心的度數條件。

只取頂點最少還不足以假定每條邊不可少。本輪九點控制是 Mycielski(K4) 再加 clone 邊 `4–5`：
刪任一點都可染，但仍有四條冗餘邊；不能對那些邊宣稱刪邊後有染色見證。

## 從單點封色到兩點共同封色

最小核心刪去 `v` 後的完整鄰界關係 `R_v` 非空，而且

\[
\forall\sigma\in R_v,\qquad
D_v\subseteq\{\sigma(u):u\in N_H(v)\}.
\]

否則漏掉的一個可用色可以補回 `v`。因此 `deg_H(v)≥|D_v|`；
裸四色核心最小度至少四、至少五點且至少 `2|V(H)|` 條邊。
這是核心上的必要下界，非充分條件。

再取原邊 `e=xy`。對**同一份** `H−{x,y}` 外側完整染色 `σ`，定義

\[
A_\sigma=D_x\setminus\sigma(N_H(x)\setminus\{y\}),\qquad
B_\sigma=D_y\setminus\sigma(N_H(y)\setminus\{x\}).
\]

兩點連同原邊不能補回，恰好是

\[
A_\sigma=\varnothing\quad\lor\quad B_\sigma=\varnothing
\quad\lor\quad A_\sigma=B_\sigma=\{c\}.
\]

因為若兩集合非空且不能選出不同的兩色，它們就必須是同一個 singleton。
局部延伸數精確為 `|Aσ||Bσ|−|Aσ∩Bσ|`；不能把不同外側染色的兩個剩餘域相乘。

**刪邊見證更強。** 任取 `H−e` 的一份完整染色 `κ`，其兩端必有
`κ(x)=κ(y)=c`，否則原邊可直接加回。刪去兩端點後得到的同一外側 `σ` 必滿足

\[
\boxed{A_\sigma=B_\sigma=\{c\}.}
\]

兩集合都含 `c`，所以空域兩支已排除；若另有可用色，也能改染一端補回原邊。
這裡是對每份 `H−e` 解成立；每條不同的邊可以使用不同見證，但同一邊的兩端必共用一份外側。

## 裸四色的三路必要條件

現在要求所有域皆為四色全集。固定上述**同一份** `κ`，對任意 `d≠c`，
兩端 `x,y` 必在 `H−e` 的同一個 `{c,d}` 雙色連通分量中。

證明：若不連通，只交換含 `x` 的整個 `{c,d}` 分量。這保留 `H−e` 的所有原邊，
卻使 `x=d,y=c`，於是可以加回 `e` 得 `H` 的四色解，矛盾。
因此每個 `d≠c` 都有一條原邊雙色路 `P_d:x→y`。
兩端同為 `c`，proper 雙色路長為偶數且至少二；加回 `e` 得奇圈。
三個不同 `d` 的路在 `x` 旁使用不同顏色，故得到三個不同奇圈。

\[
\boxed{\text{每條核心原邊至少在三個不同奇圈上。}}
\]

三路不共原邊，因為它們的每條邊分屬不同顏色對；三個所得奇圈的邊交恰為 `e`。
加上原邊本身，兩端間有四條邊不交路，故此核心沒有少於四條邊的非平凡邊割。
三路可共享內部 `c` 色點；沒有推出內點互不相交、Jordan 交叉或 K5 minor。
如果原圖無三角形，各路至少四邊、各圈至少五邊。

有固定色或非對稱域時，分量交換必須另核每個點仍落在有效域。
兩相鄰點都固定色0已是無解核心，刪邊後卻沒有任何雙色連接路；
不能將裸四色三路定理套到這種無延伸問題。

| 23點 Mycielski²(C5) | 原圖無解；23份刪點、71份刪邊皆可染；213份具名雙色路皆長四，形成五圈見證。 |
| 九點 Mycielski(K4) 加 clone 邊 | 刪任一點皆可染，但四條邊冗餘；頂點最小不能替代邊最小。 |

| 兩相鄰點皆固定0 | 無延伸、刪邊可解，但三路不存在；固定色條件不可省。 |

213是按「被刪原邊、見證染色、另一個色」索引的路／圈證書份數，
不表示原圖有213個不同五圈。每邊只保存一份刪邊見證；
對每份染色皆成立的量詞由上述紙面證明提供，未宣稱已列舉所有刪邊圖染色。
刪邊見證證明邊不可再刪，原圖無解仍須另外精確判定，不能倒用見證冒充無解證書。

**11點平面負控制。** 取邊 `xy`，另加三條內點互不相交的長四路
`x–a_d–b_d–c_d–y`（`d=1,2,3`）。它可畫成三條並行路加原邊，沒有三角形。
刪 `xy` 後令 `x=y=b_d=0`、`a_d=c_d=d`，兩端都只剩色0，且同時有三條雙色路。
但原圖可取 `x=0,y=1`，各路內點依序取 `1,0,2`，得到合法三色染色。
因此「存在一份被鎖住的染色」不足以取代「每份染色皆被鎖住」。

另一個純結構負控制是 `K_{2,2,2,2}`：各 part 用一色即可四色染，
每條邊卻都有另外兩個 part 的四個共鄰點，因而至少在四個三角形上。
所以即使每條邊都在至少三個奇圈上，仍不足以判無解。

## 至多五條跨邊的完整換色判準

以下只要求裸四色的頂點最小無解圖 `H`，不要求每條邊皆不可刪。
將頂點分成非空的 `X,Y`，跨邊依序為 `x_i y_i`（`x_i∈X,y_i∈Y`），數量為 `t`。
兩側都是較小的誘導子圖，故各有完整染色。對任取的一對染色，記跨邊端點色組為
`a=(κ_X(x_i))`、`b=(κ_Y(y_i))`，重複的原端點仍在每條 incidence 上保留。
若有一份 `π∈S4` 使每個 `a_i≠π(b_i)`，就將 `Y` 的**整份染色**一起換色再接合，得到 `H` 的解。
因此無解迫使每一對完整側染色都沒有這種置換，不能只查兩側單點支持。

**有限引理（紙面及完整枚舉）。**

| 跨邊數 | 沒有合法共同換色的充要條件 |
| --- | --- |
| `t≤3` | 不可能；必可換色接合。 |
| `t=4` | 一側四個 incidence 全同色，另一側四個 incidence 用齊四色。 |
| `t=5` | 可選出其中四條跨邊，使一側四個 incidence 全同色、另一側用齊四色。 |

把每條跨邊看成禁止一個對應 `π(b_i)=a_i` 的格子。若四行四列的允許矩陣沒有完美配對，
從最大配對的未配行沿交替路，可得某 `r` 行只鄰到至多 `r−1` 列；
至少有 `r(5−r)` 個禁格。`r=2,3` 均需至少六個不同禁格，五條跨邊不足；
只餘一整行或一整列四格全禁，恰為上表的四條跨邊判準。反向顯然不能配對。
同一格可以被多條邊重複禁止，不能把 incidence 數誤當不同禁格數。

[獨立換色表](../../../audits/2026-10-26-four-color-critical-obstructions-b783475/cut_patterns.py)
對 `t=0,…,5` 的全部端點等色型及24份完整置換逐一核對，
[結果](../../../audits/2026-10-26-four-color-critical-obstructions-b783475/cut_report.json)
在四邊得到2個、五邊得到60個有序不相容型對。這裡獨立歸一化兩側只是列舉型態，
真正接合仍必須提供一份作用於整側的共同置換。

**方向不能逐列改。** 四邊時，兩類是「全同色」與「全四色」；五邊時，兩類分別是
`L={五個全同色，或四同一異}`、`R={恰用齊四色，型態2+1+1+1}`。
兩類互斥，且不相容型對只在 `L×R` 或 `R×L` 中。
若任取一對完整側染色有 `X` 屬 `L`、`Y` 屬 `R`，固定這份 `Y` 染色遍查 `X` 的全部染色，
便迫使 `X` 全部屬 `L`；再固定最初那份 `X` 染色，迫使 `Y` 全部屬 `R`。
所以同一側的每份完整染色都在跨邊端點用齊四色，而不是不同見證各湊一部分。
五邊的 `L/R` 類型本身尚非不相容的充分條件，四條 incidence 的位置仍須對齊。

## 平面最小反例的非平凡邊割至少六

現在假設存在裸平面無解圖，取全體平面反例中頂點數最少者 `T`。
前節直接適用於 `T`，不需先刪邊或補邊。

1. 度數≤3可直接補色；度數4可由循序四鄰點的兩對互補 Kempe 路分隔修復，故 `δ(T)≥5`。
2. 前節排除至多三條跨邊。若一個四／五邊割的一側有兩個連通分量，
   每分量各須至少四條離開它的邊，總數至少八，矛盾。因此兩側各連通。
3. 前節又迫使某一側 `Y` 的每份完整染色，都在跨邊端點用齊四色。
   將另一個連通側 `X` 收縮為一個 hub，移除收縮產生的 loops 並合併重邊，得到簡單平面圖 `T'`。
   `Y` 的原邊不變，hub 鄰接的正是那些跨邊端點；每份 `Y` 染色都令 hub 無色，所以 `T'` 無解。
4. 若 `|X|≥2`，則 `T'` 比 `T` 少點，違反全體最小性。故 `X` 只能是單點。
   四邊割會令此點度四，已排除；五邊割則恰孤立一個五度點。

因此有條件式結論

\[
\boxed{|X|,|Y|\ge2\quad\Longrightarrow\quad |\delta_T(X)|\ge6.}
\]

結合 Euler 平均度及 `δ(T)≥5`，`T` 存在五度點，故最小邊割大小恰為五，
且每個大小五的邊割都孤立一個五度點。這是邊割結論，不能直接升格成頂點連通度、
排除所有分離六圈或排除932。收縮這一步只用更小平面圖的最小性，不假定四色定理。

**六條跨邊是本論證的停止點。** 取端點色組

```text
a = 000111，b = 012012。
```

六個禁格形成 `2×3` 矩形，沒有合法四色置換；兩側卻各只用二色與三色，
不存在前節用來接 hub 的全四色側。這個具名控制另存於換色表收據，沒有枚舉全部六邊型對。
K5 分成 K2 與 K3 時正好給這六條跨邊，但它不是平面實現。
尚須研究的是這類共同障礙的真實平面來源限制，不能從換色表本身宣稱已排除。

## 與平面最小反例及既有成果的關係

不使用四色定理，假設存在裸平面反例，先取全體平面反例中頂點最少者，再刪冗餘邊。
仍可保留最小頂點數、平面性、每點最小度至少五，以及

\[
n_5\ge12+\sum_{d\ge7}(d-6)n_d.
\]

度數≤3可補色，度數4由嵌入循序的兩對互補 Kempe 路分隔修復；
其餘由 `m≤3n−6` 推得。但刪冗餘邊可能破壞三角化、面及原有 C5 接口，
不能同時沿用另一份補邊三角化來源的全部契約。

本輪沒有把雙 root 對角強迫當作新定理。它的特定來源版本已在
[完整有序色對接口](../../archive/reports/c5/adjacent-degree5/c5_adjacent_degree5_interfaces.md#3-root-edge-對角強迫)，
兩側同 singleton 的無 mixed 版本見[既有報告](../../archive/reports/c5/adjacent-degree5/c5_adjacent_degree5_no_mixed.md)。
相鄰五度點的完整六點接受表亦已有[13列基線](../../../audits/2026-10-18-smaller-source-9f1fe84/B/PROOF.md)。
本次增量是將必要條件寫成一般核心上的共同見證命題，並保存逐原邊、逐原路徑可核的控制及反例。

## 構型與有序接口

型號：`nine_point_joint_equality_v1`。取同一原圖的九個**互異**原頂點：

| 角色 | 具名九點例的原 ID | 意義 |
| --- | ---: | --- |
| `u,v` | `0,6` | 原本缺少等色限制的兩點 |
| `a,b` | `1,5` | 彼此相鄰、同時鄰接 `u,v` 的共同點 |
| `r0,r1,r2,r3` | `2,4,7,8` | 保留次序的原四環 |
| `h` | `9` | 同時鄰接四個環點的原中心 |

以下 21 條原邊全部是套用前提，不能只靠度數、單點候選域或幾張表看起來相似：

```text
共同點：u-a, u-b, v-a, v-b, a-b
附件：  u-r0, a-r0, v-r1, a-r1, v-r2, b-r2, u-r3, b-r3
原環：  r0-r1, r1-r2, r2-r3, r3-r0
中心：  h-r0, h-r1, h-r2, h-r3
```

本次先輸出有序接口 **`(u,v,h)`** 的共同必要限制：

```text
R(u,v,h) = {(0,0,0), (1,1,1), (2,2,2), (3,3,3)}。
```

這保留三點的共同顏色，沒有決定其字面色。二元接口 `(u,v)`、`(u,h)`、`(v,h)`
皆可由此表投影成四色等色表；原問題要求的 `0=6` 是其中一個投影。
若對同一原圖再套入固定 `0=0,6=3`，這張三元表沒有相容列。

## 為甚麼可以導出三點等色

先假設 `u≠v`，將四色命名為 `u=A,v=D`。共同原邊使 `a,b` 必須用另兩色，
令 `a=B,b=C`。四環的候選域依次包含於

```text
r0:{C,D}, r1:{A,C}, r2:{A,B}, r3:{B,D}。
```

原環邊分離相鄰點；兩組對角的候選域互斥，也必異色。因此四環用盡四色，
共同原鄰點 `h` 沒有可用色，矛盾。故 `u=v=A`。

此時 `a=B,b=C` 是另外三色中的兩個不同色，將最後一色記為 `D`。
`r0,r1` 都只能用 `{C,D}`，其原邊迫兩色各出現一次；`r2,r3` 都只能用 `{B,D}`，
也各出現一次。四環因此用到 `B,C,D`，中心只能用 `A`，得到 **`u=v=h`**。

每一個對角色組的全部延伸還可直接構造：任選有序的 `B,C`，有 `3×2` 種；
四環只有以下兩份共同配置：

```text
(r0,r1,r2,r3) = (C,D,B,D) 或 (D,C,D,B)。
```

所以 21 邊裸構型的每一個 `(A,A,A)` 恰有 12 份完整延伸，共 48 份。
這是裸構型的完整接口關係；放進較大原圖後，外側附件仍須共同滿足。

## 套用契約與來源

角色映射必須是單射，且所有必要邊都是同一目標圖中的實際原邊。這是原子圖條件，
不要求誘導子圖或平面性。額外邊、外側附件、固定色與候選域可以繼續限制合法解，
不會破壞上述必要等色結論。

因此可以輸出三元必要因子，但不能宣稱它的四個對角列均能延伸到完整目標圖。
例如再加原邊 `u-v`，目標圖反而無解；等色表仍是必要限制，須與該原邊一起處理。
也不把裸構型的 12 份局部 fibre 當成已滿足外側附件的完整目標圖見證。

輸出應同時保留型號、九個原 ID 的角色映射、21 條必要原邊、有序接口、
字面色列及來源契約。結構表由必要原邊推出，固定色另外套用；
不得把某次額外固定條件下才成立的限制擴張成無條件規則。

## 預先核對範圍

以原九點來源解除兩個固定色後，直接枚舉 `4^9` 份指派，只核對原邊。
保存 `(u,v,h)` 的全部 64 個接口列，包含 60 個空 fibre，以及四個非空列的全部延伸；
另保存 `(u,v)` 的全部 16 列與完整 fibres。

再逐一刪掉 21 條必要邊，作為前提檢查的反控制；核對所有原邊均存在時才可套用。
另外核對非連續 ID 的角色映射、額外原邊／外接葉、固定色與結構表分開，
以及全部 48 份原邊解均被新表保留。正常／seed-17 在新目錄重播，不改寫前輪資料。

直接原邊枚舉核對了 `4^9 = 262,144` 份指派，得到 48 份完整解，
與上面的構造公式逐份相同。三元接口保留全部 64 個fibres：四個全等列各有12份延伸，
其他60列為空；二元 `(u,v)` 接口的16個fibres也全部保存，四個對角列各12份，其他12列為空。
所有完整列都保留原頂點次序、字面色框及全部內點色，不混接不同配置的單點支援。

逐一刪掉必要邊的21個控制，皆出現 `u≠v` 的合法完整見證，且前提檢查全部拒絕輸出因子。
這是指定裸構型的刪邊核對，不是所有等色構型的最小性定理。
非連續ID及頂點次序反轉後仍有48解，全被新因子保留；外接一片葉的144解也全保留。
另加原邊 `u-v` 的控制無解，而必要等色表仍有四列，具體展示「必要表非空」不保證目標圖有解。

固定色重播保留同一張結構表的四列，再獨立套用 `0=0,6=3`，相容列為空；
原邊獨立枚舉也沒有完整解。原型沒有將任一共同色寫入原圖。

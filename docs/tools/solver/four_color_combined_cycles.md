## 方法與先登記的範圍

原「交集模式」已包含原邊／子構造傳播、完整消元及最後回填。
本輪加入[一般原環推導](four_color_local_information.md#任意長度裸環保首點與當前點的-16-種色對)：
先令原候選域與共同接口交集穩定，再沿原環保留相同首點色，
做前向／後向傳遞並檢查閉合邊。環推出新候選限制後，重新交回原因子及交集，
直到整個組合無新限制，或得到矛盾，最後才進入完整消元及倒序回填。

只使用同一原圖的實際簡單環，循環次序與字面色號完整保留；
原弦、環外附件及其餘因子繼續參與求解。這是裸原環及候選域的必要傳播，
不把其各點支援當成任意多表網路的完整共同關係，也不以非空局部環宣布整圖可解。

環搜尋採有界基本環：先掃各二色／三色域所誘導的原子圖，再掃完整活動原圖，
以生成森林的非樹邊找原環。候選域／活動點變動後可重搜，最多保存 128 個不同環；
每次搜尋最多 200,000 步。搜尋截斷只省略冗餘傳播器，不能判無環、無解或全部環已查。
搜尋與環推導均計入主工作預算；主預算耗盡仍回傳尚未判定，不能提前寫色。
搜尋中斷明記未完成；若精確局部計數超出 Python 的十進位記錄上限，也以
`limit` 停止，並在提交該次候選域變更之前返回。

同一份[前輪凍結輸入](../../../artifacts/four_color_larger_structures/inputs.json)，
三十六案例各比較原模式、原模式＋交集、原模式＋交集＋原環閉合三種模式。
停用已知衝突捷徑與額外 C₅ 推導，以隔離本輪組合；主預算仍為 5,000,000 次，
表格仍為 100,000 列。完整結構投影與隨機族指定見證的核對範圍沿用前輪，
另補長奇環零消元、偶環完整延伸、兩方法反覆觸發及發現／推導預算的負控制。
正常／seed-17 重播同一來源，保存完整記錄與來源快照；不修改前輪凍結證據。

### 兩種方法確實互相觸發

新增一個由實際原邊及固定色構成的控制，事件依序為：

```text
共同接口交集縮限 → 原環推出新候選 → 另一原環繼續縮限
→ 回到原因子與共同接口交集 → 矛盾，消元數仍為 0
```

不是把兩種方法的獨立結論拼接；所有事件在同一原圖、同一分支候選域及同一字面
色框內發生，實際來源邊與候選域原因隨記錄保留。未固定點始終沒有提前寫色。

### 核對範圍與限制

沿用前輪的二十四結構例：十五可解例以精確全域 scope 投影核對所有完整記錄，
九無解例由原構造的端點域互斥或兩色奇環獨立判定；後者的解保留檢查為空真。
十二三角剖分例中，十可解例逐記錄保留一份獨立原邊搜尋的完整見證，
二無解例沿用凍結、綁定相同原圖與固定色的窮盡搜尋判定；不聲稱這族已枚舉全部解。
所有最終輸出均核對全部原邊與固定色。

一般環的動態推導只傳回各點精確局部支援；原弦、外側附件、全表因子及其接合責任
都保留。基本環搜尋即使完成預設掃描，也不是找到全部簡單環；截斷不能當無環或無解。
因此本輪加入的是有界原環閉合傳播，不是任意多表共同關係的完整閉包。

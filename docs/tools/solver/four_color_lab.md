## 直接使用

在專案根目錄執行；求解器和內建案例只依賴 Python 標準函式庫：

```bash
python3 scripts/four_color_lab.py demo
```

用瀏覽器打開 `artifacts/four_color_lab/index.html`。可選 8 張圖、每圖 4 種設定，
逐步播放、拖曳時間軸、跳到衝突、選取頂點看候選色和阻擋它的鄰點。
這份頁面離線可用，播放的是 Python 實際執行記錄。

自己的圖使用這種 JSON：

```json
{"vertices": [0, 1, 2], "edges": [[0, 1], [1, 2], [2, 0]], "fixed": [[0, 0]]}
```

```bash
python3 scripts/four_color_lab.py solve graph.json --json result.json --html replay.html
python3 scripts/four_color_lab.py solve graph.json --strategy natural --no-propagation --no-backtracking
```

JSON 色號為 **0–3**；畫面使用 **1–4**。頂點必須是不同整數；自然順序依
`vertices` 的列出順序。`fixed` 可省略；這些顏色永不回退。
可提供與頂點對齊的 `positions: [[x,y], ...]`，建議座標在 0–1；未提供時採圓周排版，
圓周上的線段相交不代表圖非平面。自訂圖的平面性不會被這個求解命令認證。

## 規則有幾條

目前把程式分成四條操作規則：

| 規則 | 動作 | 計數方式 |
| --- | --- | --- |
| R1 刪除鄰色 | 候選色排除已染鄰點的顏色 | 每次刪去一個頂點的一個候選色算一次 |
| R2 唯一色強迫 | 只剩一色就填入 | 每個強迫填色算一次 |
| R3 選點試色 | 選點，依色號順序試仍可用的色 | 每個試色算一次，含回退後重試 |
| R4 衝突回退 | 空候選集合時，撤銷失敗分支，換下一個選擇 | 每撤銷一次試色及其後果算一次 |

四條是這份實作的分組方式，並非最少規則數，也不是四色定理的構形數。
R2 可以關閉，R1／R3／R4 仍能完整搜尋，但可能多走非常多分支。
**規則少，並不表示計算量小**：R3／R4 的搜尋樹最壞可指數增長。

選點有兩種：自然順序，以及 DSATUR（優先選已染鄰點出現不同色最多的點，
相同時選原圖度數較大者，再以頂點列出順序打破平手）。沒有加入 Kempe 交換、
平面化約或預先準備的不可避免構形表。

## 衝突長什麼樣，怎麼產生

這個求解器不會先放入一條同色邊再補救。除了輸入本來就有同色固定邊的情況外，
每一步的部分染色都合法。遇到的直接衝突是：某個尚未染色的點，四個色號各被
至少一個已染鄰點佔用。程式選每種色的一個實際鄰點，留下**四色阻擋星形**。

這個星形不代表整圖需要五色。例如 `binomial_tree_t5` 是 16 點的樹，本來可二染；
在自然順序、不強迫、不回退時，點 0、2、6、14 先後得到畫面的色 1、2、3、4，
而它們都是最後一點 15 的鄰點，於是堵住 15。開啟回退後，撤銷兩次試色便成功；
開啟唯一色強迫則完全避開這次衝突。

播放器用紅邊標示直接阻擋，用金色虛線往前追溯「這些已染點的候選色，當時
又被誰限制」。每個來源都是**同一張圖、同一分支狀態的原邊**，回退時完整還原。
猜測與強迫分開標記：限制候選集合，不等於所選的顏色必然被迫。
這是一份可核對的來源追蹤，沒有宣稱最小矛盾核心、全部成因或完整衝突形狀分類。

`star_free` 與 `star_fixed_four_colours` 使用同一張四葉星形圖。
前者容易染色；後者把四片葉子固定成四種不同色，中心就無法延伸。
解除固定色仍然可二染。`k5_nonplanar_control` 則是確實無四色染色的非平面負控制。

## 實際比較

12 點、seed 8 的同一張平面三角剖分圖：

| 選點／強迫 | 填色次數 | 衝突次數 | 回退次數 | 結果 |
| --- | ---: | ---: | ---: | --- |
| 自然順序、無強迫 | 81 | 26 | 69 | 成功 |
| 自然順序、有強迫 | 52 | 12 | 18 | 成功 |
| DSATUR、有強迫 | 17 | 2 | 3 | 成功 |

這張圖表明：較好的選點方法仍會遇到死路，必須保留修復手段。

另取 **100 張各 30 點**、seed 0–99 的平面三角剖分圖，同一批圖分別跑四種設定。
每圖每設定限制 10,000 次填色，回退開啟；超限只記 `limit`：

| 設定 | 成功／超限 | 曾遇衝突的圖 | 總衝突 | 總回退 |
| --- | ---: | ---: | ---: | ---: |
| 自然順序、無強迫 | 80／20 | 100 | 133,897 | 338,027 |
| 自然順序、有強迫 | 100／0 | 88 | 5,403 | 8,924 |
| DSATUR、無強迫 | 100／0 | 53 | 164 | 857 |
| DSATUR、有強迫 | 100／0 | 53 | 164 | 257 |

計數包含失敗分支和超限前的工作。兩種 DSATUR 恰有相同衝突數是這批資料的觀察，
不推廣為一般性質。產生器是面內插點、幾何合法翻邊，再隨機重編號；**非均勻抽樣**，
沒有代表任意平面圖或任意輸入大小。每張樣本另以鎖定的 `networkx==3.5` 檢查平面性；
每份成功輸出都直接核對全部原邊與固定色。

重播比較需要專案既有的 NetworkX 依賴：

```bash
uv run --with-requirements requirements.txt python scripts/four_color_lab.py experiment --count 100 --vertices 30 --seed 0 --max-steps 10000
python3 -m unittest discover -s tools/tests -p test_four_color_lab.py -v
```

13 項測試通過，包括全部 1,024 張五點標號簡單圖、各四種設定，合計 4,096 次
與獨立暴力枚舉比較；另核對固定色、非 K5 無解例、每一步候選集合、衝突原邊、
回退、確定性、非法輸入，以及搜尋／記錄兩種上限。

## 結果與限制的精確語義

| 狀態 | 意義 |
| --- | --- |
| `colored` | 已找到且逐原邊驗證一份完整染色，符合所有固定色 |
| `unsatisfiable` | 所有允許分支都已窮盡；有固定色時，只表示該固定色無延伸 |
| `stuck` | 回退關閉，目前分支失敗，其他分支未判定 |
| `limit` | 填色次數超限，未判定；不是不可染色 |

有限圖上，不設搜尋上限而保留回退時，搜尋會窮盡所有合法延伸或找到一份染色。
理由是每次試色減少未染點，分支依序涵蓋全部仍合法的色；唯一色強迫不刪除合法解。
這份完備性說明適用一般圖，不給平面圖一定成功的額外保證。

`--max-steps` 限制試色與強迫填色的總次數；`--trace-limit` 只限制保存的事件數，
不會停止搜尋。追蹤截短時頁面明示，不能把最後保存的一步當成搜尋的終點。
JSON 保留有序頂點、原邊、固定色的 SHA-256；版面座標不參與此雜湊。

目前能回答的是這四條規則在具體輸入上的效果及衝突來源。
「增加哪些局部修復規則能保證免搜尋完成所有平面圖」仍未處理；本實驗也沒有
給出一般衝突分類、最少規則數或研究主命題的排除結果。

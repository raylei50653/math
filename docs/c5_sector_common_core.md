## 1. 共同核心與精確雙側擴張

設 c 是一般圖 G 的 proper 四色染色，S 是單一 maximal a/b 分量，
c′ 是交換 S 後尚未重標的染色。對 (x,y)=(a,b) 或 (b,a)，及第三色 d，
令 X、Y、D 為舊色類，定義

```
C(x,d) = G[(X∩S) ∪ D]。
舊 x/d 圖 = C(x,d) 加上 X\S。
新 y/d 圖 = C(x,d) 加上 Y\S。
```

兩式是誘導圖的精確等式。兩批外點各自獨立；X\S 不鄰接 X∩S
是 properness，Y\S 不鄰接 X∩S 是 S maximal。因此兩種擴張都只新增
外點到 D 的邊。把 C 的每個分量縮成一點，分別接上兩批外點及其
D-neighbor incidences，即精確給出交換前後的框分割。

**證明。** 舊 x/d 的頂點為 X∪D，新 y/d 的頂點為
(X∩S)∪(Y\S)∪D。刪掉各自的外點後都恰為 C，新增邊只有上述種類。
縮分量把路徑投影成 walk；反向則用分量內路徑提升每一步，故保持
框連通。無框核心分量及外點都不能任意刪去。

這把先前單側刪點／加 stars 的表達，改為**同一核心的兩側擴張**。
核心紀錄保留全部 X∩S 的原 star IDs 及 D 頂點 IDs；同色 d 的两個
核心共享同一 D 集，另兩份核心共享同一批交換 stars。這些身份來自
同一 c、S；任意拼裝的四份 quotient 不因此獲得共同可實現性。

## 2. 可證的必要條件與 397→330

設 T 是 C 中的框點，P_C 為其框分割。令 P_old、P_new 分別是舊 x/d、
新 y/d 的分割，則

```
P_C ≼ (P_old|T) ∧ (P_new|T)。
```

≼ 表示細化，∧ 是分割交集。理由是核心每條路徑同時存在於兩個
擴張圖。若擴張把兩個原本不同的核心框塊接起來，該連通必須使用
至少一個相應的外點；不能把擴張後的連通倒推為核心本身已連通。
這個引理不限圖大小，也不使用平面性或固定控制的完備性。

代入舊框列 01021、S∩框={0,1,2}；新原始框列 10121，將 0/1
互換標籤後是 330 的 01020。四組界如下：

| 舊色對 | 新原始色對 | 核心框 T | 來源界 | 候選界 |
| --- | --- | --- | --- | --- |
| 02 | 12 | 0,2,3 | {0}\|{2,3} | {0}\|{2,3} |
| 03 | 13 | 0,2 | {0}\|{2} | {0}\|{2} |
| 12 | 02 | 1,3 | {1,3} | {1,3} |
| 13 | 03 | 1 | {1} | {1} |

**四份交集都沒有縮緊來源界。** 因此只用這項框投影必要條件不能
拒絕 397→330；也沒有證明它可實現。尤其 {1,3} 是上界，不能擅自
要求兩點在共同核心內相連。核心內的已知框邊仍必須保留，例如 2–3。

這是對特定投影規則的限制，不是對全部共同 incidence 條件的不可能
定理。跨核心的共同 D 身份、外點 incidences 及平面性仍未用盡。
